ScheduleControl Properties
ScheduleControl Class See Also Send Feedback

The ScheduleControl type exposes the following members.

Properties

  NameDescription
AlertWindow
Gets the AlertForm that displays the alerts.
AllowAdjustAppointmentsWithMouse
Gets/sets whether the user can change an appointment time or date with the mouse.

Default value is true.

Appearance
A property that gets or sets a ScheduleAppearance object that controls the visual properties of the ScheduleControl.
Calendar
A read-only property that gets the NavigationCalendar associated with is SceduleControl.
CaptionPanel
A read-only property that gets the Panel, holding the caption above the Calendar. This panel may hold two navigation buttons and HeaderLabel.
Culture
A property that gets / sets the culture used for the date formatting.
DataSource
A property of type IScheduleDataProvider that gets or sets data source for this ScheduleControl.
DisplayTimeSpansInEndTimeDropDown
Gets/sets whether the EndTime dropdown in the AppointmentsForm tries to parenthetically display the time span in minutes.

Default value is true.

EnableAlerts
A property that gets or sets whether the alerts should be raised as appointment time approaches.
HeaderLabel
Gets or sets the Label Control that serves as the caption at the top of the ScheduleControl.
ISO8601CalenderFormat
Gets or Sets a value indicating whether ISO 8601 calender format is applied or not.
ItemSelected
Gets whether an ISchedule item has input focus (i.e., has been clicked)
NavigationPanel
A property that gets or sets the panel where you can place additional controls and have them appear adjacent to the ScheduleControl.
NavigationPanelFillWithCalendar
Gets or sets whether the Calendar occupies the entire NavigationPanel and sizes dynamically as the ScheduleControl is sized.
NavigationPanelPosition
Indicates the location of the NavigationPanel.
ScheduleType
A property that gets or sets whether a daily, weekly or monthly schedule is displayed.
ShowAllSpansInAllDayPanel
Gets/sets whether non-AllDay multiday appointments are displayed in the AllDay area of the Day, WorkWeek and CustomDay views.

Default value is false.

ShowMultiDayAppointmentsAsSpans
Gets/sets whether the multiday appointments are displayed across days in Month, Day, WorkWeek and CustomDay views.

Default value is true.

ShowRoundedCorners
Gets/sets whether the appointments are displayed with rounded corners.

Default value is false.

SwitchViewStyle
Gets/Sets whether the view style should be changed in the Control

Default value is true.

UseMirroredFormsWithRTL
Gets/sets whether the forms used with editing appointments are mirrored when ScheduleControl.RightToLeft is set to Yes.

Default value is true.
