PivotEngine Properties
PivotEngine Class See Also Send Feedback

The PivotEngine type exposes the following members.

Properties

  NameDescription
AllowedFields
Gets a collection of FieldInfo objects that hold field names that you want to be visible in the engine. The names can be either public property names of the underlying data objects, or they can be expression field.
ColumnCount
Gets the number of columns in this pivot table;
CoveredRanges
Gets a list of CoveredCellRange objects that specify the cells that need to be covered.
DataSource
Gets or sets source of data for this pivot table. This object should be either an IEnumerable list, or a DataTable.
DataSourceList
Used internally. Gets or sets an IEnumerable list that is used as the data for the pivot table. The default behavior is to initialize this list from DataSource.
EmptyPivot
Gets whether a pivot results contains any items.

Remarks

For example, if you apply a filter which filters out all items in the underlying data source, then this EmptyPivot property will be set true. The RowCount and ColumnCount will be set to one, and the Engine[0, 0] will hold the value EmptyPivotString.
EmptyPivotString
Gets or sets the string that appears when no items are present in a pivot result.
EnableOnDemandCalculations
Gets of sets whether the calculations are postponed until the value is requested through the Indexer on PivotEngine. The default value is false.
Filters
Gets a List holding FilterExpression values that specify any filters that need to be applied to this pivot table.
GetValue
Gets or sets a GetValueDelegate delegate that returns a property value for a given object.
GrandString
Gets or sets the prefix string for the collection-wide totals that appear below and to the right of the pivot table.
IndexEngine
Gets or sets the Indexed engine.
IsDataDynamic
Gets or sets whether the DataSource is a collection of dynamic objects supported in the .Net 4.0 framework.
Item
Gets the PivotCellInfo object associated with a particular cell in the pivot table. The PivotCellInfo contains Value and FormattedText properties that hold this cell's contents.
ItemCollection
Gets or Sets the Collection of Items
ItemProperties
Gets or sets a collection of property descriptors for the items in the DataSource. This property is usually initialized directly from the DataSource.
ItemType
Gets of sets the type of the objects in the DataSource. This property is usually initialized directly from the DataSource.
PivotCalculations
Gets or sets a collection of pivot calculations.
PivotColumns
Gets or sets a collection of column pivot properties.
PivotRows
Gets or set a collection of row pivot properties.
PivotValues
RowCount
Gets the number of rows in this pivot table.
ShowCalculationsAsColumns
Gets or sets whether the calculations should appear as rows or columns. THe default behavior is for the calculations to appear as columns.
ShowEmptyCells
Gets or sets a value indicating whether show empty value cell if summary value has null value. By default true.
ShowGrandTotals
Gets or sets whether grand total calculations should be completed by the engine.
ShowNullAsBlank
Gets or sets whether the PivotGrid cell should display Null value as blank instead of 0(which is the default behavior)
SortDirection
Gets or sets the sorting direction
SummaryLibrary
Gets a dictionary of SummaryBase computations available in this PivotEngine.
UseDescriptionInCalculationHeader
Gets or sets whether the [!:PivotComputation.FieldName] or the [!:PivotComputation.Description] is displayed in the header cell when more than one calculation is being used. The default behavior is to use the FieldName.
UseIndexedEngine
Gets or sets whether an optimized algorithm that relies on indexing the raw data should be used to compute the pivot information.
