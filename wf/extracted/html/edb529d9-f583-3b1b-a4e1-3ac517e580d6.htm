Groups
ShortCut for ((GroupsDetails) Details).Groups. A group can either be a final node with records or it can be a node with nested groups. If a group has records, its Groups collection will be empty and the Records collection will contain all records. If a group has nested groups, its Groups collection will have the nested groups and the Records collection will be empty.

SourceList
Returns the list that is associated with this ChildTable. The value will only be initialized when you have a UniformChildList relation and Engine.UseOldUniformChildListRelation is false. The list is a reference to the strong-typed nested collection in this child table. The ChildTable listens to ListChanged events on that list if IBindingList interface is implemented. For all other relation kinds this value will always be null.
