Gets or sets value indicating whether parser parses lexem internals or it doesn't. In complex constructions data between begin and end blocks can have own formats.

IsEndRegex
Gets or sets value indicating whether EndBlock property contains Regular expression or it doesn't.

Gets or sets sign indicating whether the end-block is just the way to exit higher by stack, or it is real ending of lexem.
Language
Language lexem belongs to.
NextID
Gets or sets ID of the lexem configuration, that follows right after current one is parsed. Such lexem must be complex and "OnlyLocalSublexems", without beginblock and with endblock.
NextLexem
gets resolved next-lexem.
OnlyLocalSublexems
Gets or sets value indicating whether parser should look for lexem's config just in local array or also look in parents.
ParentConfig
Gets or sets parent of the config.
Priority
If many lexems have the same begin string then parser must control the order in which to interpret input as lexem.
References
Gets or sets list of references. If config was not found in sub lexems, then search is done in this list.
SubLexems
Gets or sets sublexems that must be skipped if they are found after BeginBlock string before EndBock string.
Type
Gets or sets format which must be used for coloring. If format is Custom then used FormatName property for format identification.
TypeCollapsed
Gets or sets name of the format to be used in collapsed state.
TypeXML

UseCustomControl
Gets or sets value indicating if custom control should be used instead of the simple lexem rendering.
VirtualConfig
