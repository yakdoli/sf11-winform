Properties

Gets / sets whether the GetValue(Record) method should trim whitespace at end of text if field is a string. This is useful if databases return string with fixed character length and fill up the rest of field with blanks. (Default is True.)
Collection

A default value that should be used for empty fields in the AddNewRecord.
FieldPropertyType

FieldPropertyTypeString
Serialize helper for Xml Serialization of FieldPropertyType
ForceImmediateSaveValue
Gets / sets whether changes to the field in a record should immeditaly trigger a SaveValue event without first calling BeginEdit on the current record. This property is usefull if you do want to have unbound fields that should not trigger ListChanged events when only the unbound property is modified on the current record.
Hide
Gets / sets Hide state of the field.
IsSorting
Internal only.
MappingName
The mapping for this field. You should specify which field of a DataTable or strong-typed collection you want to display in the grid at this field. The MappingName can also point to a property inside a complex object with nested properties of a collection when a '.' is specified.
Name
The name of the field.
PreventUnboundFieldTypeCheck
Internal only.
ReadOnly
Gets / set Read-only state of the field.
ReferencedFields
Gets / sets ReferencedFields state of the field. Use a semicolon as delimiter when specifying multiple fields. The Engine will use these fields in the ListChanged event to determine which cells to update when a change was made in an underlying field.
TableDescriptor
The TableDescriptor that this descriptor belongs to.
