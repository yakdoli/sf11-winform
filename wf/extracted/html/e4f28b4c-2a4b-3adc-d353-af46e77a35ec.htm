Properties

  NameDescription
AllowAppearanceDeserialization
To enable/disable appearance deserialization.
AllowBlink
Specifies whether the cell allows being highlighted when its value is changed. In such case the cell is being highlighted with colors specified in the BaseStyles collection and the time period specified in BlinkTime of the GridGroupingControl. Default value is false.
AllowDropDownCell
Specified whether the grid can show a drop-down list for cells in this column if column represents a foreign key field from a related table.
AllowFilter
Gets / sets if column supports FilterBar.
AllowGroupByColumn
Specifies whether the grid can be grouped by this column when the user drags the column over the GropDropArea.
AllowSort
Enable/disable sort by this column.
Appearance
The default GridTableCellAppearance with default GridTableCellStyleInfo information for all cell elements that display data of this column. This property lets you control almost any aspect of the appearance of the grouping grid like cell backcolor, font, or the cell type.
Collection
The collection this descriptor belongs to.
EditFormColumnIndex
Specifies column index in form edit mode.
Engine
Gets the GridEngine that this column descriptor belongs to.
FieldDescriptor
Gets the field descriptor this descriptor holds. If this column descriptor is not a bound column, the method will return NULL.
GroupByAppearance
The default GridTableCellAppearance with default GridTableCellStyleInfo information for all cell elements in the table that belong to groups that were grouped by this column. This property only has an effect on the appearance of the table if this column has been added to the GroupedColumns collection of a TableDescriptor.
GroupByOptions
The GridGroupOptionsStyleInfo which lets you control the look and behavior of the child groups. You can control the caption text, where and if AddNewRow will be displayed, or whether captions, footers, previews and summaries are displayed.

This property only has an effect on the appearance of the table if this column has been added to the GroupedColumns collection of a TableDescriptor.

HeaderImage
Gets or sets the image to draw in header cell
HeaderImageAlignment
Get or set the alignment of image at header
HeaderText
The header text to be displayed in the column header. If no header text has been specified, the header text will be the same as the Name.
Info
Used internally.
MappingName
The mapping for this column. You should specify which column of a DataTable you want to display in the grid at this column.
MaxLength
Specifies the maximum length of the formatted text for this column. This value will be used for calculating the optimal width of a column. If the value is -1 the engine will determine the optimal width of a column either by looping through the first n records or using a SummaryDescriptor that keeps track of the entry with most characters (see GridTableOptionsStyleInfo.ColumnsMaxLengthStrategy and GridTableOptionsStyleInfo.ColumnsMaxLengthFirstNRecords).
Name
The name of the column.
ReadOnly
Gets / sets Read-only state of the column.
SerializedImageArray
string which used for serialization and deserialization of header images
SortByDisplayMember
Enable/disable sort this column by display member.
TableDescriptor
The TableDescriptor that this descriptor belongs to.
TrackWidthOfParentColumn
Specifies a column in a parent record that the column in the child record should track. Use this if you have frozen columns and want to make sure that columns in nested records are properly aligned.
Width
Gets / sets the width of the column.
