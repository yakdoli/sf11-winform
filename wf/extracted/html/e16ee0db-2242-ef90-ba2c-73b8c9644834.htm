Member nameValueDescription
None0 Disable selecting cells.
Row1 Rows can be selected.
Column2 Columns can be selected.
Table4 Whole table can be selected.
Cell8 Individual cells can be selected.
Multiple16 Multiple ranges of cells can be selected. The user has to press Control Key to select multiple ranges.
Shift32 Allow extend existing selection when user holds Shift Key and clicks on a cell.
Keyboard64 Allow extend existing selection when user holds Shift Key and arrow keys.
AlphaBlend128 Use alpha blending to highlight selected cells.
MixRangeType256 Allow both rows and columns to be selected at same time when Multiple is specified. By default, the grid does not allow having rows and column ranges be selected at the same time.
Any255 Default behavior for selecting cells: Rows, Columns, Table, Cell, Multiple, Extends Shift Key support, and alphablending.
