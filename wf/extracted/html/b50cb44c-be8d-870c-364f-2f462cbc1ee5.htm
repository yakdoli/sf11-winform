The AutoComplete type exposes the following members.

Properties

  NameDescription
AccessibleDescription
Gets or sets the description of the control used by accessibility client applications.
AccessibleName
Gets or sets the name of the control used by accessibility client applications.
AccessibleRole
Gets or sets the accessible role of the control used by accessibility client applications.
ActiveFocusControl
Gets or sets the target control with the current focus.
AdjustHeightToItemCount
Indicates whether the height of the drop down should be adjusted based on the number of items.
AllowListDelete
Indicates whether to allow deletion of items in the list when user pressed Delete Key.
AutoAddItem
Indicates whether the current item in the target control is to be automatically added to the history list during validation and when the Enter key is pressed.
AutoCompletePopup
Returns the PopUp of AutoComplete
AutoPersistentDropDownSize
Gets or Sets whether DropDown size is automatically persistent.
AutoSerialize
Indicates whether the AutoComplete control persists its data.
AutoSortList
Indicates whether default sorting is to be performed.
BorderType
Specifies the kind of border the AutoComplete control should use for the popup control displayed when in AutoSuggest Mode.
CaseSensitive
Indicates whether the replacement of the matching entry is to be case sensitive. If the user enters 'A' and there is a matching entry 'abcd', the AutoComplete will set the target edit control's Text to 'abcd' if this property is set to false and 'Abcd' if this property is set to true.
CategoryName
Gets or sets the user defined category name under which the internal data is serialized.
ChangeDataManagerPosition
Indicates whether the DataManager position is to be changed when entries in the ListControl are selected (when the DataSource property is set to a data source).
Columns
Returns the columns that will be displayed in the popup control when the AutoCompleteMode is set to AutoSuggest. The Columns property is a collection of AutoCompleteDataColumnInfo objects that specifies the attributes of a column.
DataSource
Gets or sets the external data source that will be used as the history item list.
IgnoreCase
Indicates whether the case sensitivity should be used for string comparison.
ImageColumnIndex
Returns the column index that will serve as the image index.
ImageList
Gets or sets the ImageList that will specify the images to be used by the popup control when in AutoSuggest Mode.
Initializing
Implementation of the ISupportInitialize interface.
MatchColumnName
Gets or sets the column that is to be used for matching during AutoCompletion.
MatchMode
Gets or sets the matching mode for the matching routine.
MaxNumberofSuggestion
Indicates How many number of items to be displayed in the AutoComplete.
MetroColor
Indicates the metro color.
MinColumnWidth
Returns the minimum column width. The AutoComplete class supports multiple columns in the drop down window of the possible matches. This static member is set to the minimum width of such columns when displayed in the drop down.
OverrideCombo
Indicates whether the AutoComplete control should suppress or override the ComboBox control's own dropdown.
ParentForm
Gets or sets the ParentForm for databinding purposes.
PreferredHeight
Gets or sets the preferred height for the drop down list displayed by the AutoComplete control.
PreferredWidth
Gets or sets the preferred width for the drop down list displayed by the AutoComplete control.
SelectedIndex
Sets or retrieves the index of the selected option.
SelectedItem
Returns the selected item. This is a changing property and valid only at runtime. The last browsed item in an AutoComplete control drop down will be set as the selected item.
SelectedValue
Gets or sets the value of the selected item in the AutoComplete control.
ShowCloseButton
Gets or sets a value indicating whether to show the close button at the bottom right of the DropDownContainer.
ShowColumnHeader
Indicates whether the popup control displayed during AutoSuggest mode has headers. This property will apply to all the columns.
ShowGripper
The size gripper at the bottom right of the DropDownContainer will be shown as long as the ShowGripper property is set to true.
SingleClick
Indicates whether the dropdown for an AutoComplete enabled control appears in a single click.
Style
Indicates the visual style.
TableData
This is a read only property that provides the internal DataTable object that is used to manipulate the list of history items.
