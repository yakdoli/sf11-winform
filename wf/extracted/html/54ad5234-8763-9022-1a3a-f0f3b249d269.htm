The GridSummaryColumnDescriptor type exposes the following members.

Properties

  NameDescription
Appearance
The default GridTableCellAppearance with default GridTableCellStyleInfo information for all cell elements that display data of this summary column.
ColInRecord
Returns the grid column index of the target cell where the summary is displayed.
Collection
The collection this descriptor belongs to.
DataMember
The mapping for this column. You should specify here a field name of a FieldDescriptor ( or GridColumnDescriptor.MappingName)
DisplayColumn
The target column at which to display the summary.
Engine
Gets the GridEngine that this summary column descriptor belongs to.
Format
The format string used to format the text to display in the summary column. A format string consists of the PropertyName of the summaryType and a format specifier known from String.Format, e.g. {Average:###.00}.
IgnoreRecordFilterCriteria
Specifies whether RecordFilter criteria should be ignored and the summary should be calculated for all records.
MaxLength
Specifies the maximum length of the formatted text for this summary column. This value will be used for calculating the optimal width of a column. The default is the length of the Format text plus 5.
Name
The name of this descriptor. This name is used to look up the summary in the GridSummaryColumnDescriptorCollection.
ParentRow
The GridSummaryRowDescriptor this summary column belongs to.
RowInRecord
Returns the row index relative to the first row in the summary section of a group.
Style
Gets / sets whether a summary should fill the entire row, only a column, or if it should be hidden.
SummaryDescriptor
Gets the SummaryDescriptor that is used for calculating the summaries. The GridEngine internally creates SummaryDescriptors for each GridColumnDescriptor based on the SummaryType and DataMember defined in the GridColumnDescriptor. If SummaryType.Custom was specified, the TableDescriptor.QueryCustomSummary event needs to instantiate the SummaryDescriptor.
SummaryType
The type of summary.
TableDescriptor
The TableDescriptor that this descriptor belongs to.
