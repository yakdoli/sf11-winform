Remarks

The push button cell is XP Themes enabled. It will be drawn themed if ThemesEnabled is true.

A renderer is created for each GridCellModelBase and GridControlBase. There can be several renderers associated with one GridPushButtonCellModel if several views display the same GridModel.

The following table lists some characteristics about the PushButton cell type.

The cell's behavior and appearance can be customized with the following properties of the GridStyleInfo class.

PropertyNameDescription
BaseStyle (String)The base style for this style instance with default values for properties that are not initialized for this style object. (Default: String.Empty)
Borders (GridBordersInfo)Top, left, bottom, and right border settings. (Default: GridBordersInfo.Default)
CellAppearance (GridCellAppearance)Specifies if cell edges shall be drawn raised, sunken, or flat (default). (Default: GridCellAppearance.Flat)
CellTipText (String)ToolTip text to be displayed when user hovers mouse over cell. (Default: String.Empty)
CellType (String)PushButton. (Default: TextBox)
Clickable (Boolean)Specifies if the button can be clicked with the mouse. See Enabled how to disable activating the cell as current cell. (Default: true)
Description (String)Gets or sets the text that is shown in the button. (Default: String.Empty)
Enabled (Boolean)Specifies if the cell can be activated as current cell or if cell should be skipped when moving the current cell. When disabled, the button will be drawn grayed out. (Default: true)
Font (GridFontInfo)The font for drawing text. (Default: GridFontInfo.Default)
HotkeyPrefix (HotkeyPrefix)Specifies how hot-key prefixes should be displayed. Hot-keys are indicated in text with an '&' (ampersand). When you enable hot-key prefix, the specific characters can be displayed underlined or regular. The '&' will not be displayed. (Default: HotkeyPrefix.Show)
Interior (BrushInfo)The PushButton usually fills the whole cell area. Therefore the background is only visible if you programmatically force the button to be smaller. (Default: SystemColors.Window)
Themed (Boolean)Specifies if cell should be drawn using Windows XP themes when ThemesEnabled has been set. (Default: true)
Trimming (StringTrimming)Indicates how text is trimmed when it exceeds the edges of the cell text rectangle. (Default: StringTrimming.Character)
WrapText (Boolean)Specifies if text should be wrapped when it does not fit into a single line. (Default: true)
