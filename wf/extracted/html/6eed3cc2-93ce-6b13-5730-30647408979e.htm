GridTableDescriptor Properties
GridTableDescriptor Class See Also Send Feedback

The GridTableDescriptor type exposes the following members.

Properties

  NameDescription
AllowCalculateMaxColumnWidth
Gets / sets whether the maximum number of characters found in record field cells should be calculated for columns. See also TableOptions.ColumnsMaxLengthStrategy.
Appearance
The default GridTableCellAppearance with default GridTableCellStyleInfo information for all cell elements in the table. This property lets you control almost every aspect of the appearance of the grouping grid like cell backcolor, font, or the cell type.
ChildGroupOptions
Lets you control the look of inner groups like whether the Caption Row is visible or what CaptionText is.
Columns
A collection of GridColumnDescriptor columns with mapping information to columns of the underlying datasource.
ColumnSets
A collection from GridColumnSetDescriptor with GridColumnSpanDescriptor information about columns that can spread multiple grid rows or columns.

ConditionalFormats
A collection from GridConditionalFormatDescriptor which provides filter criteria for displaying a subset of records from the underlying datasource with conditional cell formatting.

Engine
Gets the GridEngine that this table descriptor belongs to.
ForceEmptyColumns
Gets or sets whether the Columns collection should not be autopopulated. When you set this property true Columns.[!:Columns.Clear] will be called. When you set this property false, ResetColumns()()()() will be called.
ForceEmptyVisibleColumns
Gets or sets whether the VisibleColumns collection should not be autopopulated. When you set this property true VisibleColumns.[!:VisibleColumns.Clear] will be called. When you set this property false, ResetVisibleColumns()()()() will be called.
FrozenColumn
Freeze columns. The name of a GridColumnDescriptor which defines the columns to prevent scrolling.
HasCustomSummaryFilterBarChoices
Returns true if there are columns with .AllowFilter = true and GridFilterBarChoicesEventArgs.ShouldCreateSummaryDescriptor set to false.
HasSummaryFilterBarChoices
Returns true if any summaries were implicitly created for FilterBar
InheritAppearanceFomParent
Gets / sets whether the Appearance of the table descriptor should inherit properties of a ParentTableDescriptor if this object is the child table descriptor in a relation.
IsExcelFilterWired
Indicates the grouping grid is wired with excel style filter. This is specifically used to apply the filter in excel sheet while exporting.
ParentRelation
Gets the GridRelationDescriptor that this table descriptor belongs to if it is a child table of a relation; returns NULL if it is the main table descriptor.
ParentTableDescriptor
Gets the GridTableDescriptor that the ParentRelation belongs to if this table descriptor is a child table of a relation; returns NULL if it is the main table descriptor.
PreviewRowsPerRecord
Gets the number of preview rows that should be added to each record.
(Overrides TableDescriptorPreviewRowsPerRecord.)
RecordRowColumns
An internal array used for multiple rows per Record and Column to Field Mapping.
RecordRowCoveredRanges
An internal array used for multiple rows per Record and Column to Field Mapping.
Relations
Gets the collection of GridRelationDescriptor objects defining relations to other tables.
RowsPerRecord
Gets the number of rows that should be added to each record.
(Overrides TableDescriptorRowsPerRecord.)
StackedHeaderRows
A collection of GridStackedHeaderRowDescriptor objects that declares StackedHeader rows each with one or multiple GridStackedHeaderDescriptor elements. An instance of this collection is returned by the StackedHeaderRows property of a GridTableDescriptor. StackedHeaders allow you to display headers that spread multiple columns before the regular column headers.
Summaries
Gets the collection of SummaryDescriptor objects defining summaries of the table. This collection is maintained automatically by the GridTableDescriptor and is filled with summaries from the SummaryRows collection. You should not directly modify this collection. Instead, you should modify SummaryRows.
SummaryRows
A collection from GridSummaryRowDescriptor that declares summary rows each with one or multiple GridSummaryColumnDescriptor elements.
SupportColumnAppearanceDeserialization
To enable/disable column appearance deserialization.
TableOptions
Lets you set table-wide properties like the width of the indent column or whether header rows should be visible.
TopLevelGroupOptions
Lets you control the look of the top most group like whether the Caption Row is visible or what CaptionText is.
VisibleColumns
A collection of GridVisibleColumnDescriptor columns each referencing a GridColumnDescriptor or GridColumnSetDescriptor. The order of GridVisibleColumnDescriptors in the VisibleColumns collection defines the left to right order of columns shown in the grid.
