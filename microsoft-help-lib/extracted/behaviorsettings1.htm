Behavior Settings

 

TextBox Settings

 

To display the text / value selected from the dropdown datagrid, set the DataTextFormatField property. This property must be set to the column name as given in the data source. Multiple column text can be displayed by specifying the various column names inside '{}' in the required format delimited by ','. This automatically displays the selected text inside the textbox.

 

Property

Description

DataTextFormatField

Specifies the format string to use when formatting on client side via the value retrieved from selected grid item text. For example: "Text1 {ID}, Text2 {Name}".

 

The setting of the text format as should be displayed in the textbox.

 

[aspx]

 

<cc1:MultiColumnDropDownCombo ID="MultiColumnDropDownCombo1" runat="server" DataTextFormatField="{BookName} - ({AuthorName})"><cc1:MultiColumnDropDownCombo>

 

[C#]

 

this.MultiColumnDropDownCombo1.DataTextFormatField = "{BookName} -({AuthorName})";

 

[VB]

 

Private Me.MultiColumnDropDownCombo1.DataTextFormatField = "{BookName} -({AuthorName})"

 

The text displayed in the textbox can be edited by setting the AllowTextEditing property to True. Otherwise the text can be prevented from being edited.

 

Property

Description

AllowTextEditing

Specifies whether to allow to edit text. Default value is False.

 

DropDown Settings

 

The header and footer can be made visible / hidden by using the ShowHeader and ShowFooter properties. The display of the grid lines can be altered the drop down using one of the option as required, by setting the GridLines property.

 

Property

Description

GridLines

Specifies how the grid lines should be rendered. The default value is Both. The options included are as follows:

·      None

·      Horizontal

·      Vertical

·      Both

ShowHeader

Specifies if the header should be displayed for the dropdown. Default value is True.

ShowFooter

Specifies if the footer should be displayed for the dropdown. Default value is False.

 

Programmatically the properties can be set as follows.

 

[C#]

 

this.MultiColumnDropDownCombo1.AllowTextEditing = true;

this.MultiColumnDropDownCombo1.GridLines = GridLines.Both;

this.MultiColumnDropDownCombo1.ShowFooter = true;

this.MultiColumnDropDownCombo1.ShowHeader = false;

 

[VB]

 

Private Me.MultiColumnDropDownCombo1.AllowTextEditing = True

Private Me.MultiColumnDropDownCombo1.GridLines = GridLines.Both

Private Me.MultiColumnDropDownCombo1.ShowFooter = True

Private Me.MultiColumnDropDownCombo1.ShowHeader = False

 

Property

Description

AutoGenerateColumns

Specifies whether to automatically generate columns with respect to the associated data source.
