Creating a WPF Application

The following steps will guide you to create a simple WPF application:

 

1.   Open Microsoft Visual Studio 2008.

 

Figure 32: Microsoft Visual Studio 2008 Window

 

2.   On the File menu of Visual Studio, click New Project. The following dialog is displayed.

 

Figure 33: New Project Dialog

 

3.   Select WPF application and give appropriate name for your Application. Then click OK. It creates a new Application window.

 

Figure 34: New Application Window

 

4.   Add the following additional namespace to the xaml code page.

 

[XAML]

 

xmlns:sfchart="http://schemas.syncfusion.com/wpf"

 

Figure 35: Syncfusion WPF Namespace added to the Application

 

A new WPF application is created.

 

Deploying Essential Chart into the WPF Application

 

The following steps will guide to deploy the Essential into the above WPF application:

 

1.   Right-click the Reference and select Add Reference, which opens a new Add Reference window. In the window, select the following additional dlls and click OK.

 

·      Syncfusion.Chart.WPF

·      Syncfusion.Core

·      Syncfusion.Shared.WPF

·      Syncfusion.VectorImage.WPF

 

2.   Drag the Chart control from the Syncfusion tab in the toolbox or add the below code to the Xaml Page. The following code adds a chart with primary and secondary axes.

 

[XAML]

 

<syncfusion:Chart Name="Chart1" Grid.Row="1" Margin="20,20,15,20">          

           <syncfusion:ChartArea IsContextMenuEnabled="True" Name="area" Background="Transparent">

             

      <syncfusion:ChartArea.PrimaryAxis>

                     <syncfusion:ChartAxis Header="Days"  ValueType="String"  RangePadding="Additional" LabelsSource="{Binding Source={StaticResource myXmlData}, XPath=Travel/TravelDetails}" PositionPath="DayCount" ContentPath="Day">

                       </syncfusion:ChartAxis>

                 </syncfusion:ChartArea.PrimaryAxis>      

                 <syncfusion:ChartArea.SecondaryAxis>

                      <syncfusion:ChartAxis Header="Distance Travelled" >

                      </syncfusion:ChartAxis>

                  </syncfusion:ChartArea.SecondaryAxis>

              </syncfusion:ChartArea>

</syncfusion:Chart>

 

 The above code adds a single chart area to the chart. It is also possible to add multiple Chart Areas to the Chart.

 

 

Figure 36: Adding Chart Control

 

3.   The following output is displayed when you run the application.

 

 

Figure 37: Output of the Chart

 

4.   Add a Chart Series to the Chart Area as follows.

 

[XAML]

 

<sfchart:Chart Name="Chart1">

<sfchart:ChartArea.>

    <syncfusion:ChartSeries  IsIndexed="False"  Name="series1"  Label="Series1" Type="FastStackingColumn"  />

</sfchart:ChartArea>

</sfchart:Chart>

 

[C#]

 

Chart Chart1 = new Chart();

Chart1.Areas.Add(new ChartArea());;

Chart1.Areas[0].Series.Add(new ChartSeries());

 

 It is also possible to add multiple Chart Series to a Chart Area. To learn more about populating series, see Populating ChartSeries.

 

5.   Then bind the series data to the chart by adding the following code inside Chart Series in xaml page.

 

[XAML]

 

<syncfusion:ChartSeries DataSource="{Binding Source={StaticResource myXmlData}, XPath=Travel/TravelDetails}" BindingPathX="DayCount" BindingPathsY="Kms" IsIndexed="False"  Name="series1"  Label="Series1" Type="FastStackingColumn" Interior="{StaticResource SeriesAInterior}" />

 

6.   Add the xml data for the StaticResource as follows.

 

[XAML]

 

<XmlDataProvider x:Key="myXmlData">

            <x:XData>

                <Travel xmlns="">

                    <TravelDetails DayCount="1"  Kms="30" Day="Mon"/>

                    <TravelDetails DayCount="2" Kms="45" Day="Tue"/>

                    <TravelDetails DayCount="3" Kms="50" Day="Wed"/>

                    <TravelDetails DayCount="4" Kms="60" Day="Thu"/>

                    <TravelDetails DayCount="5" Kms="55" Day="Fri"/>

                    <TravelDetails DayCount="6" Kms="75" Day="Sat"/>

                    <TravelDetails DayCount="7" Kms="55" Day="Sun"/>

                    <TravelDetails DayCount="8" Kms="40" Day="Mon"/>

                    <TravelDetails DayCount="9" Kms="30" Day="Tue"/>

                   

                </Travel>

            </x:XData>

</XmlDataProvider>
