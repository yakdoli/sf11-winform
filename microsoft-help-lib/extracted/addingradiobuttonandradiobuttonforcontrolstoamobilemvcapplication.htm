Adding RadioButton and RadioButtonFor Controls to a Mobile MVC Application

In the Getting Started section, we discussed how to create a Mobile MVC application and add the Tools package to the application. This section guides you to add the RadioButton and RadioButtonFor controls to an application.

 

1.   In the view, invoke the Radio Button and RadioButtonFor helpers with the group name of the radio button control as the first argument.

 

RadioButton Control

[ASPX]

        <% Html.MobSyncfusion().RadioButton("group1", "Male").AutoFormat(MobSkins.BlueLight).Render(); %>

< br />

        @{ Html.MobSyncfusion().RadioButton("group1", "Male").AutoFormat(MobSkins.BlueLight).Render(); }

RadioButtonFor Control

 

[ASPX]

<% foreach (var data in Model)

           { %>

        <% Html.MobSyncfusion().RadioButtonFor(model => data.id, data.value, new { name = data.name, @checked = data.ischecked, id = data.id }).OnTouchStart("onStart").OnTouchStop("onStop").Render();%>

RadioButtonFor         

        <br/>

        <% } %>

 

[Razor]

@{ foreach (var data in Model)

                @{

                     Html.MobSyncfusion().RadioButtonFor(model => data.id, data.value, new { name = data.name, @checked = data.ischecked, id = data.id }).OnTouchStart("onStart").OnTouchStop("onStop").Render();

                 }

RadioButtonFor

            }

 

Controller

        public ActionResult Index()

        {

            List<RadioButtonData> data = this.getData();

            return View(data);

        }     

        publicList<RadioButtonData> getData()

        {

            List<RadioButtonData> data = newList<RadioButtonData>();

            data.Add(new RadioButtonData() { ischecked = true, name = "groupe", value = "milk" , id="radio1", state=true});

            data.Add(new RadioButtonData() { ischecked = false, name = "groupe", value = "cheese", id = "radio2", state=false });

            data.Add(new RadioButtonData() { ischecked = false, name = "groupe", value = "butter", id = "radio3", state=true });

            return data;

        }

    publicclassRadioButtonData

    {

        publicbool state { get; set; }

        publicbool ischecked { get; set; }

        publicstring name { get; set; }

        publicstring value { get; set; }

        publicstring id { get; set; }

    }
