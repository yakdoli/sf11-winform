Chart Axis Gridlines

 

The Essential chart for Silverlight allows you to show / hide the grid lines in the chart area using ShowGridLines property.  If the ShowGridLines property is set to true, then Grid line will be visible in the chart area; Otherwise lines are invisible.

 

The following lines of code can be used to hide the grid lines of an axis.

 

[XAML]

 

</syncfusion:Chart>

<syncfusion:Chart Background="{StaticResource ChartBackground}">

                <syncfusion:ChartArea>

                    <syncfusion:ChartArea.PrimaryAxis>

                        <syncfusion:ChartAxis Header="X-Axis" ShowGridLines="True" GridLineStyle="5,2"/>

                    </syncfusion:ChartArea.PrimaryAxis>

 

                    <syncfusion:ChartArea.SecondaryAxis>

                        <syncfusion:ChartAxis Header="Y-Axis" ShowGridLines="True" GridLineStyle="5,2"/>

                    </syncfusion:ChartArea.SecondaryAxis>

 

                    <syncfusion:ChartSeries Data="1,9,2,18,3,13" Interior="{StaticResource Series1}"/>

 

                </syncfusion:ChartArea>

</syncfusion:Chart>

 

[C#]

 

chart.Areas[0].PrimaryAxis.ShowGridLines = true;

chart.Areas[0].PrimaryAxis.GridLineStyle = new DoubleCollection() { 5, 2 };

Grid Line Color

 

The Chart Grid line color and thickness can be customized using the following code.

 

[XAML]

 

<syncfusion:Chart Background="{StaticResource ChartBackground}">

  <syncfusion:Area FontWeight="Bold">

    <syncfusion:Area.PrimaryAxis>

      <syncfusion:Axis GridLineStroke="Green" GridLineStrokeThickness="2" />

    </syncfusion:Area.PrimaryAxis>

    <syncfusion:Area.SecondaryAxis>

      <syncfusion:Axis Header="Y-Axis" GridLineStroke="Green" GridLineStrokeThickness="2" />

    </syncfusion:Area.SecondaryAxis>

    <syncfusion:Series Data="1,9,2,18,3,13" Foreground="{StaticResource Series1}"/>

  </syncfusion:Area>

</syncfusion:Chart>

 

[C#]

 

ChartArea area = new ChartArea();

 

//Create instance for primary Axis

ChartAxis axis1 = new ChartAxis();

axis1.Orientation = Orientation.Horizontal;

axis1.Header = "X-Axis";

axis1.GridLineStroke = new SolidColorBrush(Colors.Green);

axis1.GridLineStrokeThickness = 2;

 

//Create instance for Secondary Axis

ChartAxis axis2 = new ChartAxis();

axis2.Orientation = Orientation.Vertical;

axis2.Header = "Y-Axis";

axis2.GridLineStroke = new SolidColorBrush(Colors.Green);

axis2.GridLineStrokeThickness = 2;

 

area.PrimaryAxis = axis1;

area.SecondaryAxis = axis2;
