To raise and process the server-side methods:

 

1.   Add a new Web Page in your project.

2.   Drag the Ribbon Control and add the required items in the .aspx page.

 

[ASPX]

 

<syncfusion:RibbonTabContext Name="context1">

         <Tabs>

           <syncfusion:RibbonTab Text="Home" Name="RibbonTab1">

             <Groups>

                <syncfusion:RibbonGroup Text="Clipboard" ShowExpander ="false" >

                   <Division>

                      <syncfusion:RibbonGroupDivison>

                         <Content>

                              <syncfusion:ButtonAdv  DisplayType="ImageAboveText"                                          runat="server" ID="OfficeUIButton5" ScreenTip="<b> Paste(Ctrl + V)</b><br /><br />Paste the contents of the clipboard"  Text="Paste" ImageUrl="Img/paste.png">     

                         </syncfusion:ButtonAdv>

                       </Content>

                   </syncfusion:RibbonGroupDivison>

                  <syncfusion:RibbonGroupDivison Name="division1">

                         <Content>

                                <syncfusion:ButtonAdv DisplayType="ImageBeforeText" runat="server" ID="OfficeButton1"  Text="Cut" ScreenTip="<b> Cut(Ctrl + X)</b><br /><br /> Cut the selection and put it on the clipboard"  ImageUrl = "Img/Cut.png">

                                  </syncfusion:ButtonAdv>

                           </Content>

                             </syncfusion:RibbonGroupDivison>

                          </Division>

                       </syncfusion:RibbonGroup> 

            </Groups>

      </syncfusion:RibbonTab>

    </Tabs>

</syncfusion:RibbonTabContext>

 

3.   Call the methods by using the following syntax in the .cs file.

4.   Build and run the solution.  The changes are displayed as follows:

 

 

[C#]

 

this.Ribbon1.GetTabContext("context1").Name = "Context2";

this.Ribbon1.GetRibbonTab("Home").Text = "PageLayout";

this.Ribbon1.GetRibbonGroup("Clipboard").Text = "Styles";        this.Ribbon1.GetRibbonDivision("division1").Name = "division2";        this.Ribbon1.GetRibbonItem<Syncfusion.Web.UI.WebControls.Shared.ButtonAdv>("OfficeButton1").Text = "Cuts the text";

 

[VB]

 

Me.Ribbon1.GetTabContext("context1").Name = "Context2"

Me.Ribbon1.GetRibbonTab("Home").Text = "PageLayout"

Me.Ribbon1.GetRibbonGroup("Clipboard").Text = "Styles"

Me.Ribbon1.GetRibbonDivision("division1").Name = "division2"

Me.Ribbon1.GetRibbonItem(Of Syncfusion.Web.UI.WebControls.Shared.ButtonAdv)("OfficeButton1").Text = "Cuts the text"
