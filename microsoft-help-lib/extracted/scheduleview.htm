ScheduleView

ScheduleView for Schedule WPF now enables you to view the time slots horizontally.

Basic property

 

·      ScheduleType—It is the enum type which should be selected as ScheduleView.

 

The following code illustrates how to set Schedule View.

 

[XAML]

 

<schedule:Schedule x:Name="Schedule" ScheduleType="ScheduleView" />
