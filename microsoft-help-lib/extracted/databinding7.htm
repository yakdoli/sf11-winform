Data Binding

This section discusses the support for various types of data binding and how the data source can be bound with the control.

 

5.6.2.2.5.1 Datasource Binding

 

Binding AccessDataSource to the control is illustrated below:

 

1.   To the application add the rotator and an AccessDataSource controls. This launches the editor to configure the data source.

 

Figure 350: Configure AccessDataSource

5.6.2.2.5.2 DataTable Binding

 

Binding data table to the Rotator control is illustrated below.

 

 

Figure 351: Contents bounded using DataTable

 

1.   On Page Load event of your application, create an instance of the DataTable and add data to appear in the slides. Finally bind the table with Rotator using DataSource property.

 

[C#]

   

DataTable table = new DataTable();

table.Columns.Add("Title");

table.Columns.Add("Date");

table.Columns.Add("Text");

 

table.Rows.Add(new string [] {"Syncfusion CEO Stefan Hoenig appears in SD Times", "September 30, 2005","Stefan discussed Syncfusion's line of components, and he explained how our solutions stand apart in their ability to solve problems and save time."} );

 

table.Rows.Add(new string [] {" Excellence is our goal!!", "September 30, 2005", "Here we talk to Mr.Daniel Jebaraj, Vice President of Syncfusion. His company uncompromisingly strive for excellence in order to offer the very best value to their customers."} );

 

Rotator1.DataSource = table;

Rotator1.DataBind();

 

[VB]

   

Private table As DataTable = New DataTable()

table.Columns.Add("Title")

table.Columns.Add("Date")

table.Columns.Add("Text")

 

table.Rows.Add(New String () {" Excellence is our goal!!", "September 30, 2005", "Here we talk to Mr.Daniel Jebaraj, Vice President of Syncfusion. His company uncompromisingly strive for excellence in order to offer the very best value to their customers."})

 

table.Rows.Add(New String () {"Syncfusion CEO Stefan Hoenig appears in SD Times", "September 30, 2005","Stefan discussed Syncfusion's line of components, and he explained how our solutions stand apart in their ability to solve problems and save time."})

 

Private Rotator1.DataSource = table

Rotator1.DataBind()

 

26.  In the aspx file, bind the details to the label controls inside the rotator. Also set the Height and ScrollInterval properties for the rotator control.

 

[aspx]

 

<cc1:rotator id = "Rotator1" runat = "server" ScrollInterval = "15" Height = "100px" Width = "550px" BackColor = "#EDF0F6">

    <SlideTemplate>

        <TABLE id="Table3" height="100" cellPadding="5" width="550">

            <TR><TD>

                <IMG style = "BORDER-RIGHT: medium none; BORDER-TOP: medium none; BORDER-LEFT: medium none; WIDTH:12px;

BORDER-BOTTOM: medium none; HEIGHT: 10px" height = "10" alt = "" src = "images/simplerotator.gif" width = "12">

                <asp:Label id = Label5 width = "308" runat = "server" Text = '<%# DataBinder.Eval(Container.DataItem,"Title")%>'>

                </asp:Label></SPAN>

            </TD>

            <TD class="NewsDate" align="right">

                <asp:Label id=Label2 runat="server" Width="191px" Text='<%# DataBinder.Eval(Container.DataItem,"Date")%>'>

                </asp:Label>

            </TD></TR>

                </asp:Label>

            </TD></TR>

        </TABLE>

    </SlideTemplate>

</cc1:rotator>

 

5.6.2.2.5.3 XML Binding

 

Binding XML file to the Rotator is illustrated below.

 

1.   Create an xml file and add it to your application with name as 'slides.xml'.

 

[XML]

 

<?xml version="1.0" encoding="utf-8" ?>

<Products>

  <Product>

    <Title>Essential Diagram with Source</Title>

  </Product>

  <Product>

    <Title>Essential Edit with Source</Title>

  </Product>

  <Product>

    <Title>Essential Grouping with Source</Title>

  </Product>

  <Product>

    <Title>Essential Chart with Source</Title>

  </Product>

  <Product>

    <Title>Essential Tools with Source</Title>

  </Product>

  <Product>

    <Title>Essential Grid with Source</Title>

  </Product>

</Products>

 

27.  Set the XmlContentFile to the path of the xml file, and bind it to the label inside the slide template.

 

[aspx]

 

<cc1:rotator id = "Rotator1" runat = "server" ScrollInterval = "5" Height = "20" Width = "300" XmlContentFile = "slides.xml">

  <SlideTemplate>

    <asp:Label id=Label1 runat="server" Text='<%# DataBinder.Eval(Container.DataItem,"Title") %>' Width="300" Height="30">

    </asp:Label>

  </SlideTemplate>

</cc1:rotator>
