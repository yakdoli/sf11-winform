SeriesToolTipFormat

 

Specifies the format for tooltip display in series.

 

 

Details

Possible Values

{0}  -  Series Name

{1}  -  Series Style tooltip

Default Value    

{0}

2D / 3D Limitations

No

Applies to Chart Element

Any Series

Applies to Chart Types

Area Charts, Radar Chart, Polar Chart, ThreeLineBreak Chart,PointAndFigure Chart, StepLine Chart, Spline Chart, HiloOpenClose(3D), RotatedSpline, Kagi Chart

 

Here is some sample code.

 

[C#]

 

this.ChartWebControl1.Series[1].SeriesToolTipFormat = "{0}";

 

[VB.NET]

 

Private Me.ChartWebControl1.Series(1).SeriesToolTipFormat = "{0}"
