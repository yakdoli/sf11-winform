GroupBar

 

GroupBar provides advanced navigation features and is used for building Outlook style collapsible group bars in your web pages.

 

Features

 

·      CSS styles: look and feel of the control can be enhanced to exhibit a variety of looks

·      Server and Client side Events: server and client side events enables you to customize the behavior of groupbar control both on the server and the client

·      Databinding: the groupbar provides flexibility to bind groupbar items with an xml file

·      Template: any control can be integrated inside groupbar using Template support

·      Browser: GroupBar can be hosted in Safari browser too
