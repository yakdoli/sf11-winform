Creating a Schedule Control

To create a Schedule Control:

1.   Create a new Silverlight 4 Application project in Visual Studio.

 

 

Figure 4: Create New Silverlight Application

 

2.   Add the following assemblies to the project References folder.

·      Syncfusion.Schedule.Silverlight

·      Syncfusion.Linq.Silverlight

·      Syncfusion.Shared.Silverlight

 

3.   Add the following XAML reference to access the schedule related controls.

[XAML]

xmlns:schedule="clr-namespace:Syncfusion.Windows.Controls.Schedule;assembly=Syncfusion.Schedule.Silverlight"

 

4.   Declare the Schedule control by using the following code.

[XAML]

<schedule:Schedule x:Name="Schedule" />

 

5.   Add appointments to the Schedule control by using the Appointments property.

[XAML]

<schedule:Schedule.Appointments>

      <schedule:ScheduleAppointment StartTime="6/18/2010 12:00:00 AM" EndTime="6/18/2010 8:00:00 AM" Subject="Meet the doc"  Location="Hutchison road" AllDay="False"/>

      <schedule:ScheduleAppointment StartTime="6/19/2010 12:00:00 AM" EndTime="6/19/2010 4:00:00 AM" Subject="Going to Park" Location="Park road" AllDay="False"/>

      <schedule:ScheduleAppointment StartTime="6/20/2010 12:00:00 AM" EndTime="6/20/2010 6:00:00 AM" Subject="Visit to Mary's house" Location="Hutchison road" AllDay="False"/>

      <schedule:ScheduleAppointment StartTime="6/21/2010 12:00:00 AM" EndTime="6/21/2010 4:00:00 AM"  Subject="Meeting with William" Location="Park road" AllDay="False"/>

</schedule:Schedule.Appointments>

 

6.   Alternatively, you can bind to an ItemsSource to generate appointments. Make sure you specify the mapping properties so that the Schedule control can read the objects from the bound source.

[XAML]

<schedule:Schedule x:Name="Schedule" ItemsSource="{Binding}" Grid.Row="1" CalendarVisibility="Visible">

    <schedule:Schedule.AppointmentMapping>

        <schedule:ScheduleAppointmentMapping SubjectMapping="Subject" LocationMapping="Location" StartTimeMapping="StartTime" EndTimeMapping="EndTime" AllDayMapping="IsAllDay" />

    </schedule:Schedule.AppointmentMapping>

</schedule:Schedule>

 

7.   Run the application to view the current appointments.

8.   Schedule control is now created in your Silverlight application.
