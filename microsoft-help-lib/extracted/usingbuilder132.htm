Using Builder

The following steps explain the addition of a dialog to an application using Builder.

1.   In View, invoke the tab helper with the Control ID as the first argument and add the Tab items using the items Add() method.

<% Html.MobSyncfusion().StyleManager()

                      stylesheets.Add(MobComponentType.Tab);

                  }).Render();
