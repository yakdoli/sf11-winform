MS Office Simulation

 

Essential Grid supports MS Office features like dynamic splitters and undo/redo. Following table lists the available features.

 

Feature

Description

Accelerated Scrolling

Accelerate scrolling.

Shared Scrollbars

Share scroll bars with other windows.

Access Emulation

Scroll through records.

ScrollTips/Thumbtracking

Display scroll tips when the user performs the drag-and-drop operation.

Multilevel Undo/Redo

Allows multilevel undo/redo.

IntelliMouse Scrolling

Supports intellipoint mouse scrolling.

Excel-like Behavior

Has excel-like behavior with full features.

Workbook and Sheets

Has a tabbed workbook format.
