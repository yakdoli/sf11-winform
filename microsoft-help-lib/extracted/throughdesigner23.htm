Through Designer

 

A simple popup container can be created which can be shown and hidden using the client methods for any user action. Here a popup is displayed when mouse is moved over the div container.

 

To create PopupControlContainer through designer

 

1.   Drag the PopupControlContainer onto the application's Web Form.

2.   Set the client side event for the target control to call the client method to pop-up the control, when some user action is performed (here, on mouseover, popup is displayed).

 

[Aspx]

 

<ssw:PopupControlContainer ID="PopupControlContainer1" runat="server" Height="50px"

            Width="125px">

        </ssw:PopupControlContainer>

 

<div>

    <table>

        <tr>

            <td>

                <div id="div1" style="width: 50; height: 50; border: solid, 1px, red;" onmouseover="show()">

                    Bring the mouse over this div element to invoke the popup control

                </div>                       

            </td>

        </tr>       

    </table>

 

    <cc1:PopupControlContainer ID="PopupControlContainer1" runat="server" BackColor="#FFE0C0" Height="94px" Width="149px" BorderColor="Black" BorderStyle="Solid" BorderWidth="1px">

        <table>

            <tr>

                <td style="left: 25px; width: 108px; position: relative">

                    <asp:Label ID="Label2" runat="server" Text="Popup has been called" Width="105px" Font-Size="Large">

                   </asp:Label>

                </td>

            </tr>

        </table>

    </cc1:PopupControlContainer>

</div>

 

Here, the OnMouseOver event is assigned to a script function which executes the ShowPopup method and displays the control on mouse over action.

 

[script]

 

function show()

{

    _sfPopupControlContainer1.ShowPopup();

}

 

Note: While referring to the popup control, '_sf' must be prefixed to the id of the control. Alternatively ClientObjectID can be set and be used to refer to the popup control.

 

3.   Build and run the application to see the control popup when mouse is passed over the div container.
