Orientation

Generic drop-down supports customizing the orientation of the pop-up panel and its contents.

Properties

Name

Description

Type of the property

Value it accepts

Dependency

PopupContentsAlignment

 

Sets the alignment of the pop-up contents

enum

GenericDropDownPopupContentsAlignment.Center, GenericDropDownPopupContentsAlignment.Justify, GenericDropDownPopupContentsAlignment.Right, GenericDropDownPopupContentsAlignment.Left

NA

PopupDirection

 

Sets the direction of the pop-up to open up.

enum

GenericDropDownPopupDirection.Down,

GenericDropDownPopupDirection.Up

NA

PopupHorizontalDistance

 

Sets the horizontal distance of the pop-up panel

enum

GenericDropDownPopupHorizontalDistance

.Near,

GenericDropDownPopupHorizontalDistance

.Far

NA

Using Properties Model

The following steps explain the setting of the orienataion for the genreric drop-down using the Properties model.

1.   In the Controller, create an instance of the GenericDropDownModel, set the Enable and Text properties and pass the instance through View Specific Data to View as given below.

 

[Controller]

 

public ActionResult Index()

        {

             GenericDropDownModel myModel = new GenericDropDownModel();           

             myModel.TargetContentId = "drop-down-contents";

myModel.PopupContentsAlignment =    GenericDropDownPopupContentsAlignment.Center;

              myModel.PopupDirection = GenericDropDownPopupDirection.Up;

myModel.PopupHorizontalDistance = GenericDropDownPopupHorizontalDistance.Far;

 

            ViewData["myDropDown"] = myModel;

            return View();

        }

 

 

 

2.   In View, create the drop-down contents and invoke the generic drop-down helper with the View Data key as the control ID.
