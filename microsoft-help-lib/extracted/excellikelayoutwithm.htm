Excel-like Layout with Member Properties

The Excel-like with Member Properties layout is used to display member properties along with dimension members. The properties appear adjacent to each member.

 

Figure 12: OLAP Grid in Excel-like Layout with Member Properties

 

[C#]

/// Excel-like Grid Layout with Member Properties.

this.OlapGrid1.Layout = GridLayout.ExcelLikeLayoutWithMemberProperties;

 

[VB]

' Excel-like Grid Layout with Member Properties.

Me.OlapGrid1.Layout = GridLayout.ExcelLikeLayoutWithMemberProperties
