Built-In Property

The OlapGrid control uses its own AJAX engine when the IsAsyncRequestData property is enabled.

The following code shows how to enable the IsAsyncRequestData property:

[C#]

this.OlapGrid1.IsAsyncRequestData = true;

 

[VB]

Me.OlapGrid1.IsAsyncRequestData = True

 

To make the in-built AJAX engine work properly, the following HttpHandler should be added in the Web.config file:

 

[Web.config]

<system.web>

    .....

    <httpHandlers>

        <add verb="GET" path="*UpdateOlap*" type="Syncfusion.Web.UI.WebControls.Grid.Olap.Handlers.OLAPDataHandler, Syncfusion.OlapGrid.Web, Version=XX.XXX.X.XX, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89

"/>

    </httpHandlers>

</system.web>
