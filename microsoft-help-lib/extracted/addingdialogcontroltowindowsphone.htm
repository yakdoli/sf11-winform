Adding Dialog control to Windows Phone

To create a Windows Phone application and deploy Essential Tools for Windows Phone, refer to section 3 Getting Started. This section covers how to add Dialog control to this application.

 

The Dialog control can be added to the application using either Xaml or procedural code. The following code illustrartes this:

 

[XAML]

    <syncfusion:Dialog  AnimationType="None" Height="400" Width="400" VerticalOffset="-200" x:Name="dialog" IsDrag="True" IsBackKeyClose="True" IsTapOutside="True">

    </syncfusion:Dialog>

 

[C#]

 

Dialog dialog = new Dialog() { AnimationType = AnimationType.None, Height = 400, Width = 400, VerticalOffset = -200, IsDrag = true, IsBackKeyClose = true, IsTapOutside = true };
