Using Properties Model

The following steps explain the addition of Accordion to an application using the Properties model:

1.   In the Controller, create an instance of the MobAccordionModel, define the properties and pass the instance through View Specific Data to View as given below.

 

[Controller ]

public ActionResult Accordion()

        {

            MobAccordionModel model = newMobAccordionModel();

            model.AutoFormat = MobSkins.DarkNight;

            -------

            ViewData["AccordionModel"] = model;

            return View();

        }

 

 

2.   In View, invoke the Accordion helper with the view data key as the control ID.

 

View[ASPX]

<% {

  Html.MobSyncfusion().Accordion("AccordionControl1")

 

      .Items((item) =>

       {

            item.Add().Text("About Syncfusion")

                .Content((Accordion) =>

                 {%><div><p>

                    Syncfusion, a world leader in software components have thousands of      satisfied customers world-wide who have used our products to ship award winning software.

                   </p></div>

                  <%});

            item.Add().Text("Technology")

                      .Content((Accordion) =>

                  {%><div><p>

                    Syncfusion products are smartly designed to cope with the fast-changing technology  environment. </p></div>

       .Render();

}%>
