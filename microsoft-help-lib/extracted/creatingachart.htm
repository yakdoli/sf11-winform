Creating a Chart

 

Here are the step-by-step instructions for creating a chart in a Silverlight application. The procedure is elaborated under the following sections:

 

1.   Creating a Silverlight application.

2.   Deploying Essential Chart to the application.

3.   Intialization of basic chart and its child control.  

4.   Creating a Chart control.

 

Creating a Silverlight Application

 

1.   Open Microsoft Visual Studio. Go to File menu and click New Project.

 

Figure 6: Start Page

 

 

2.   In the New Project dialog, select Silverlight Application template, name the project and click OK.

 

Figure 7: Project Window

 

A new Silverlight application is created.

 

 

Deploying Essential Chart to the Application

 

1.   Go to Solution Explorer. Right-click References folder and click Add Reference.

 

Figure 8: Solution Explorer

 

2.   Add the following assemblies to the project References folder.

 

Syncfusion.Chart.Silverlight.dll

 

Figure 9: Add Reference

 

3.   Add Syncfusion.Chart.Silverlight reference in XAML or C# code as follows.

 

[XAML]

 

xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Chart;assembly=Syncfusion.Chart.Silverlight"

 

[C#]

 

using Syncfusion.Windows.Chart;

 

Essential Chart is deployed in your application.

 

Intialization of Basic Chart and Its Child Control 

The following steps illustrate the initialization of basic chart and its child control in both XAML and C# based on the requirement of your application.

 

1.   To add a Chart control in Silverlight application, use the code below.

 

[XAML]

 

<syncfusion:Chart x:Name="MyChart">

                <!--Area control code-->

</syncfusion:Chart>

 

[C#]

 

using Syncfusion.Windows.Chart;

Chart chart = new Chart();

 

2.   To add Chart Area in chart control, use the code below.

 

[XAML]

 

<syncfusion:Chart x:Name="MyChart">

    <syncfusion:ChartArea GridBackground="LightBlue">

             <!--Area Header, Legends, Axes, Series Controls code-->

    </syncfusion:ChartArea>

</syncfusion:Chart>

 

[C#]

 

Chart MyChart = new Chart();

ChartArea area = new ChartArea();

area.GridBackground = new SolidColorBrush(Colors.LightGray);

MyChart.Areas.Add(area);

 

3.   Add Chart Area Header and Legends in the Chart Area, using the code below.

 

[XAML]

 

<syncfusion:ChartArea GridBackground="LightBlue">

                    <syncfusion:ChartArea.Header>

                        <TextBox Text="Area Header" FontWeight="Bold" HorizontalAlignment="Center"/>

                    </syncfusion:ChartArea.Header>

 

                 <syncfusion:ChartArea.Legends>

                        <syncfusion:ChartLegend CheckboxVisibility="Collapsed" IconVisibility="Visible"/>

                    </syncfusion:ChartArea.Legends>

                </syncfusion:ChartArea>

 

[C#]

 

//To Initialize the Header and Legends

TextBox headerdata = new TextBox();

ChartLegend chartlegend = new ChartLegend();

chartlegend.CheckboxVisibility = Visibility.Collapsed;

chartlegend.IconVisibility = Visibility.Visible;

headerdata.Text = "Area Header";

 

//To Add Header and Legend in chart Area

MyChart.Areas[0].Header = headerdata;

MyChart.Areas[0].Legends = chartlegend;

 

4.   Add chart axes in Chart Area, using the code below.

 

[XAML]

 

<syncfusion:ChartArea GridBackground="LightBlue">

                    <syncfusion:ChartArea.PrimaryAxis>

                        <syncfusion:ChartAxis Header="X-Axis" IsAutoSetRange="True" GridLineStroke="White"/>

                    </syncfusion:ChartArea.PrimaryAxis>

 

                    <syncfusion:ChartArea.SecondaryAxis>

                        <syncfusion:ChartAxis Header="Y-Axis" IsAutoSetRange="False" Range="0,30" Interval="5"/>

                    </syncfusion:ChartArea.SecondaryAxis>

                </syncfusion:ChartArea>

 

[C#]

 

//To Initialize the Primary Axis

ChartAxis primary = new ChartAxis();

primary.IsAutoSetRange = true;

primary.Header = "X-Axis";

primary.GridLineStroke = new SolidColorBrush(Colors.White);

 

//To Initialize the Secondary Axis

ChartAxis secondary = new ChartAxis();

secondary.IsAutoSetRange = false;

secondary.Range = new DoubleRange(0, 50);

secondary.Interval = 10;

 

//To add Axes in Chart Area

MyChart.Areas[0].PrimaryAxis = primary;

MyChart.Areas[0].SecondaryAxis = secondary;

 

5.   Add series in the Chart Area.

 

[XAML]

 

<syncfusion:ChartArea GridBackground="LightBlue">

                <syncfusion:ChartSeries Data="1,4,2,7,3,8,4,3,5,9" Interior="Blue" />

            </syncfusion:ChartArea>

 

[C#]

 

//To Initialize the Series

ChartSeries series = new ChartSeries();

ChartPointsCollection datas = new ChartPointsCollection();

datas.Add(new ChartPoint(1, 4));

datas.Add(new ChartPoint(2, 7));

datas.Add(new ChartPoint(3, 8));

datas.Add(new ChartPoint(4, 3));

datas.Add(new ChartPoint(5, 9));

series.Data = datas;

series.Interior= new SolidColorBrush(Colors.Blue);

//To add Series in chart Area

SyncfusionChart.Areas[0].Series.Add(series);

 

The basic chart and its child control are initialized.

 

Creating a Chart Control

The following code snippet illustrates the creation of chart control in Silverlight application.

[XAML]

 

<UserControl x:Class="GettingStarted.MainPage"

    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"

    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"

    xmlns:d="http://schemas.microsoft.com/expression/blend/2008" xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"

    xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Chart;assembly=Syncfusion.Chart.Silverlight"

    xmlns:local="clr-namespace:GettingStarted"

    mc:Ignorable="d" d:DesignWidth="640" d:DesignHeight="480">

    <UserControl.Resources>

        <local:StockData x:Key="data1">

            <local:FinancialStock StockId="101" MaxStockPrice="300" />

            <local:FinancialStock StockId="102" MaxStockPrice="260" />

            <local:FinancialStock StockId="103" MaxStockPrice="450" />

            <local:FinancialStock StockId="104" MaxStockPrice="210" />

            <local:FinancialStock StockId="105" MaxStockPrice="250" />

            <local:FinancialStock StockId="106" MaxStockPrice="200" />

        </local:StockData>

    </UserControl.Resources>

   

  <Grid x:Name="LayoutRoot">

        <syncfusion:Chart x:Name="chart" Margin="2" Background="LightBlue">

            <syncfusion:ChartArea Margin="4">

                <syncfusion:ChartArea.Header>

                    <TextBlock Text="Stock Price Analysis" HorizontalAlignment="Center" VerticalAlignment="Center" FontSize="13" FontWeight="Bold"/>

                </syncfusion:ChartArea.Header>

 

                <syncfusion:ChartArea.PrimaryAxis>

                    <syncfusion:ChartAxis LabelFontWeight="Bold" HidePartialLabel="True">

                        <syncfusion:ChartAxis.Header>

                            <TextBlock Text="Date" FontWeight="Bold"/>

                        </syncfusion:ChartAxis.Header>

                    </syncfusion:ChartAxis>

                </syncfusion:ChartArea.PrimaryAxis>

 

                <syncfusion:ChartArea.SecondaryAxis>

                    <syncfusion:ChartAxis LabelFontWeight="Bold">

                        <syncfusion:ChartAxis.Header>

                            <TextBlock Text="Stock Price" FontWeight="Bold"/>

                        </syncfusion:ChartAxis.Header>

                    </syncfusion:ChartAxis>

                </syncfusion:ChartArea.SecondaryAxis>

 

                <syncfusion:ChartArea.Legends>

                    <syncfusion:ChartLegend IconVisibility="Visible"/>

                </syncfusion:ChartArea.Legends>

 

                <!--Initialize the Chart data by using the DataSource property and X and Y axis values are initialize by using BindingPathX and BindingPathsY property-->

 

                <syncfusion:ChartSeries Type="Column" Label="Stock 1" Stroke="Black" StrokeThickness="2" DataSource="{StaticResource data1}" BindingPathX="StockId" BindingPathsY="MaxStockPrice" />

            </syncfusion:ChartArea>

        </syncfusion:Chart>

    </Grid>

</UserControl>

 

[C#]

 

using System;

using System.Collections.Generic;

using System.Linq;

using System.Net;

using System.Windows;

using System.Windows.Controls;

using System.Windows.Documents;

using System.Windows.Input;

using System.Windows.Media;

using System.Windows.Media.Animation;

using System.Windows.Shapes;

using System.Collections.ObjectModel;

 

 

namespace GettingStarted

{

    public partial class MainPage : UserControl

    {

        public MainPage()

        {

            InitializeComponent();

        }

    }

       

    //Business Object

    public class FinancialStock

    {

        public double StockId

        {

            get;

            set;

        }

 

        public double MaxStockPrice

        {

            get;

            set;

        }

    }

 

    //Business Object collection

    public class StockData : ObservableCollection<FinancialStock>

    {

    }

}
