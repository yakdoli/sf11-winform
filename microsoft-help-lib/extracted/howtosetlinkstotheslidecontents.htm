How to set links to the slide contents

 

We can give links to any of our contents present in a Rotator control. This tutorial has given a small sample to do this.

 

1.   Create an xml file with name products.xml. Add it into your project.  

 

[C#]

 

Ticker ticker1 = new Ticker();

form1.Controls.Add(ticker1);

ticker1.Text = "This is a sample text";

 

[VB]

 

Private ticker1 As Ticker = New Ticker()

form1.Controls.Add(ticker1)

Private ticker1.Text = "This is a sample text"

 

[XML]

 

<?xml version="1.0" encoding="utf-8" ?>

<Products>

  <Product>

    <Title>Essential Diagram with Source</Title>

    <Url>http://syncfusion.com/Products/product.aspx?p=2</Url>

  </Product>

  <Product>

    <Title>Essential Edit with Source</Title>

    <Url>http://syncfusion.com/Products/product.aspx?p=3</Url>

  </Product>

  <Product>

    <Title>Essential Grouping with Source</Title>

    <Url>http://syncfusion.com/Products/product.aspx?p=6</Url>

  </Product>

  <Product>

    <Title>Essential XlsIO Binary</Title>

    <Url>http://syncfusion.com/Products/product.aspx?p=4</Url>

  </Product>

  <Product>

    <Title>Essential Chart with Source</Title>

    <Url>http://syncfusion.com/Products/product.aspx?p=1</Url>

  </Product>

  <Product>

    <Title>Essential Tools with Source</Title>

    <Url>http://syncfusion.com/Products/product.aspx?p=7</Url>

  </Product>

  <Product>

    <Title>Essential Grid with Source</Title>

    <Url>http://syncfusion.com/Products/product.aspx?p=5</Url>

  </Product>

</Products>

 

35.  Add the following lines in .aspx file.

 

[aspx]

 

<cc1:rotator id = "Rotator1" runat  "server" Width = "200px" Height = "50px" XmlContentFile = "Products.xml" ScrollInterval = "15"  SlidePause = "2000" RotationType ="SmoothScroll" PauseOnMouseOver = "True">

   <SLIDETEMPLATE>

      <TABLE height="50" width="200" bgColor="#edf0f6" border="0">

         <TR><TD>             

            <A onclick="window.open(this.href,'_blank');return false;" href='<%# DataBinder.Eval(Container.DataItem, "url") %>'>

            <asp:Label id=Label2 Text='<%# DataBinder.Eval(Container.DataItem, "Title") %>' Runat="server">

            </asp:Label></A>

         </TD></TR>

      </TABLE>

   </SLIDETEMPLATE>

</cc1:rotator>

 

36.  Build and run the application.
