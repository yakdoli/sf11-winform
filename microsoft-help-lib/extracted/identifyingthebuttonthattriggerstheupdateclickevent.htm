Identifying the Button that Triggers the UpdateClick event

 

The UpdateClick event can either be triggered by Update button in the edit mode or the Edit button in preview mode. The button which triggers the UpdateClick event can be identified by using the ClickedButtonType property of the RichTextEditor event args. This property returns either Update or Edit of string type.

The following table provides details on the property and its description:

 

Property

Description

ClickedButtonType

Returns a string to identify the button which invokes UpdateClick serverside event:

·      Update

·      Edit

 

Add the following code to identify the button:

 

[ASPX]

 

<Syncfusion:RichTextEditor id="RichTextEditor1" runat="server" ShowHelpToolbar="True"

                    ShowStandardToolbar="True" ShowTableToolbar="True" ShowToolsToolbar="True"

                    onupdateclick="RichTextEditor1_UpdateClick1" UpdateButtonText="Click Here" AutoFormat="Office2007 Blue"></cc1:RichTextEditor>

 

[C#]

 

protected void RichTextEditor1_UpdateClick(object sender, Syncfusion.Web.UI.WebControls.Tools.RichTextEditorEventArg e)

    {

        this.RichTextEditor1.Text = "You have clicked " + e.ClickedButtonType.ToString();

    }

 

[C#]

 

Protected Sub RichTextEditor1_UpdateClick(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.RichTextEditorEventArg)

              Me.RichTextEditor1.Text = "You have clicked " & e.ClickedButtonType.ToString()

End Sub
