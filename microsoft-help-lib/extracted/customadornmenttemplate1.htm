Custom Adornment Template

 

The Adornment Label can be customized by using the LabelTemplate property of the Chart AdornmentInfo class. The following code example illustrates how to create a custom adornment template.

 

[XAML]

 

  <syncfusion:ChartSeries Type="Area" Interior="Green" DataSource="{StaticResource data1}" BindingPathX="StockId" BindingPathsY="MaxStockPrice">

                    <syncfusion:ChartSeries.AdornmentsInfo>

                        <syncfusion:ChartAdornmentInfo Visible="True" LabelContentPath="DataPoint.Y" VerticalAlignment="Top"

        SegmentLabelFontSize="13" SegmentLabelFontWeight="Bold">

                            <syncfusion:ChartAdornmentInfo.LabelTemplate>

                                <DataTemplate>

                                    <Border BorderBrush="White" BorderThickness="1" Background="Transparent" >

                                        <TextBlock Text="{Binding Path=Content, RelativeSource={RelativeSource TemplatedParent}}"

                        FontWeight="Bold" Foreground="Yellow" />

                                    </Border>

                                </DataTemplate>

                            </syncfusion:ChartAdornmentInfo.LabelTemplate>

                        </syncfusion:ChartAdornmentInfo>

                    </syncfusion:ChartSeries.AdornmentsInfo>

                </syncfusion:ChartSeries>

 

 

[C#]

 

ChartAdornmentInfo adornment = new ChartAdornmentInfo();

adornment.Visible = true;

adornment.LabelTemplate = this.Resources["adornmenttemplate"] as DataTemplate;
