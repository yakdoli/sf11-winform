Chart Axis Orientation

 

Chart for Windows Phone enables to set the orientation of the Chart Axis. The default orientation of the ChartAxis is Horizontal. This property is mostly used in Multiple Axes scenarios.

 

[XAML]

 

</syncfusion:Chart>

<syncfusion:Chart Background="Wheat">

                <syncfusion:ChartArea GridBackground="LightGray">

                    <syncfusion:ChartArea.PrimaryAxis>

                        <syncfusion:ChartAxis ShowGridLines="False"/>

                    </syncfusion:ChartArea.PrimaryAxis>

 

                    <syncfusion:ChartArea.SecondaryAxis>

                        <syncfusion:ChartAxis Header="Y-Axis" ShowGridLines="False"/>

                    </syncfusion:ChartArea.SecondaryAxis>

 

                    <syncfusion:ChartSeries Data="1,9,2,18,3,13" Interior="{StaticResource Series1}"/>

                    <syncfusion:ChartSeries Data="1,5,2,8,3,12" Interior="{StaticResource Series2}">

 

                        <syncfusion:ChartSeries.YAxis>

                            <syncfusion:ChartAxis Orientation="Vertical" ShowGridLines="False" Header="Values"/>

                        </syncfusion:ChartSeries.YAxis>

 

                    </syncfusion:ChartSeries>

                </syncfusion:ChartArea>

</syncfusion:Chart>
