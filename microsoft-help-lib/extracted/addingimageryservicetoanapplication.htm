Adding Imagery Service to an Application

Imagery service has been implemented in the imagery layer of the Map control. By adding the imagery layer in the layers of the Map control, imagery service will be enabled. Imagery layer can be added in the following ways.

·      XAML

·      Code Behind

 

[XAML]

<syncfusion:MapControl x:Name="Map" Grid.Row="1" LatitudeLongitudeType="Decimal" LayeredContent="{Binding ElementName=bingLayer}">

            <syncfusion:MapControl.Layers>

                <syncfusion:Layers>

                    <syncfusion:ImageryLayer  x:Name="bingLayer"  BingMapKey="Bing Map Key" Background="White"  MapStyle="AerialWithLabels">

                        <syncfusion:ImageryLayer.LabelCollections>

                            <syncfusion:MapLabel LabelText="Tamil Nadu" LabelForeground="White" Latitude="11" Longitude="78"/>

                        </syncfusion:ImageryLayer.LabelCollections>

                    </syncfusion:ImageryLayer>

                </syncfusion:Layers>

            </syncfusion:MapControl.Layers>

</syncfusion:MapControl>

 

 

 

[C#]

MapControl mapControl = new MapControl();

ImageryLayer layer = new ImageryLayer { BingMapKey = "Bing Map Key" };

mapControl.Layers.Items.Add(layer);

mapControl.LayeredContent = layer;

About Bing Maps Key:

Bing Maps Key is important to enable the Imagery Service. With a Bing Maps Key, users will be validated by Microsoft. Invalid keys will not be accepted. For more information about obtaining a Bing Maps Key and using Bing Maps Services, please visit

http://www.microsoft.com/maps/product/licensing.aspx

Zooming and Panning

Zoom level of the Imagery Service enabled map will be increased by 1. The map will be zoomed based on the zoom level. If the zoom level is increased, the map will be drilled in (zoomed in). If the zoom level is decreased, the map will be drilled out (zoomed out). Zooming can be done through the mouse scroll and the Navigation control of the maps.

Panning is used to navigate through the map. Panning can be done by click-and-drag on the map or through the Navigation control.

For information about the Navigation control, refer to Chapter 11.
