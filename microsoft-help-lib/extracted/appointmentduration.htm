Appointment Duration

 

When an appointment is added, it is necessary to specify the duration for the appointment. This will indicate when the appointment begins and ends. Once this is done, the appointment will be displayed under the specified resource for the specified duration.

 

Appointment Property

Description

EndTime

Specifies the end of the appointment duration.

StartTime

Specifies the start of the appointment duration.

 

The appointment duration (For eg: Date: 20/02/2007 and Time: 10 to 11 AM) can be set programmatically as follows

 

[ASPX]

 

<Appointments>

<Syncfusion:ScheduleWebAppointment UniqueID="22" StartTime="01/08/2008 05:23:00" EndTime="01/08/2008 06:53:00">

</Syncfusion:ScheduleWebAppointment>

</Appointments>

 

[C#]

 

app1.StartTime = new DateTime(2008, 08, 01, 05, 23, 00);

app1.EndTime = new DateTime(2008, 08, 01, 06, 53, 00);

 

[VB]

 

Private app1.StartTime = New DateTime(2008, 08, 01, 05, 23, 00)

Private app1.EndTime = New DateTime(2008, 08, 01, 06, 53, 00)
