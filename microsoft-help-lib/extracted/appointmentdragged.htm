AppointmentDragged

AppointmentDragged occurs when the appointment has been dragged.

The following code illustrates this:

[XAML]

<schedule:Schedule x:Name="schedule" AppointmentDragged="schedule_AppointmentDragged" ScheduleType="Week" />

[C#]

private void schedule_AppointmentDragged(object sender, ScheduleAppointmentEventArgs args)

{

      MessageBox.Show("AppointmentDragged");

}
