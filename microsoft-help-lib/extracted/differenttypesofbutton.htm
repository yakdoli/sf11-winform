Different types of button

Types of Orientation

The type of the button can be chosen from the options of the DisplayType property. The options provided for the display types are given as follows.

 

Property

Description

DisplayType

Specifies the orientation of text and image in a button. Default value is ImageBeforeText. The other options are:

 

·      ImageBeforeText

·      ImageAboveText

·      ImageOnly

·      TextOnly

 

 

5.1.11.3.1.1        Image before text

To render the button with image before text, set the Display Type property to Image before text. The code snippets are given as follows:

 

[ASPX]

<syncfusion:ButtonAdv ID ="Button1" ImageUrl ="Img/Save16.png" runat ="server" CustomClass ="buttonback" Text ="Save the text" DisplayType ="ImageBeforeText"> </syncfusion:ButtonAdv>

 

 

[C#]

 

ButtonAdvance.DisplayType = Syncfusion.Web.UI.WebControls.Shared.DisplayType.ImageBeforeText;

 

 

[VB]

ButtonAdvance.DisplayType= Syncfusion.Web.UI.WebControls.Shared.DisplayType.ImageBeforeText
