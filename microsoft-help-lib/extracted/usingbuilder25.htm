Using Builder

The following steps show you how to handle the addition of a custom shape to the symbol palette through Builder.

1.   In the view, invoke the Diagram helper with the control ID as the first argument. 

 

 

View

 <% Node node1 = new Node()

   {

       Name = "Node1",

       Label = "Node1",

       OffsetX=100,

       OffsetY=100,

       Width=100,

       Height=100

 

   };  

   SymbolPaletteItem item4 = new SymbolPaletteItem();

   item4.ContentId = "TextBox_Content";

   item4.Name = "TextBox";

   item4.SymbolPaletteItemType = ItemType.Content;

 

   SymbolPaletteItem item5 = new SymbolPaletteItem();

   item5.Name = "Shape1";

   item5.SymbolPaletteItemType = ItemType.CustomShape;

 

   SymbolPaletteGroup g1 = new SymbolPaletteGroup();

   g1.HeaderName = "Custom Shapes";

   g1.Index = 2;

   g1.Items.Add(item4);

   g1.Items.Add(item5);

%>

<%{

      Html.Syncfusion().Diagram("FlatDiagram")

          .Nodes(nodes => nodes.Add(node1))          

          .SymbolPalette(sp=>sp.Groups(gr=>gr.Add(g1)))        

          .Width(900)

          .Height(500)

         .DiagramMode(DiagramMode.Canvas)         

          .ClientSideOnCustomShapeDrawing("OnCustomShapes")

          .Render();

  }

%>

 

 

[JavaScript] 

<script type="text/javascript">

       function OnCustomShapes (sender,args) {

          // args:

          // _Context    - Canvas context of the custom shape node

          // _Width      - node width of the custom shape

          // _Height     - node Height of the custom shape

          // _NodeName   – name of the custom shape node

          // _LineWidth; - linewidth of the custom shape node

 

        }

</script> 

 

2.   Build and run the application
