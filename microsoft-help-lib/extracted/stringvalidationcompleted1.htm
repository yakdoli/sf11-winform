StringValidationCompleted

 

Occurs after validating the value with the ValidationString.

 

XAML

 

<syncfusion:MaskedTextBox x:Name="maskedTextBox" Width="200" Height="25"

                            ValidationString="^([\w-\.]+)@((\[[0-9]{1,3}\.[0-9]{1,3}\.[0-

                                 9]{1,3}\.)|(([\w-]+\.)+))([a-zA-Z]{2,4}|[0-9]{1,3})"

                            StringValidation="OnLostFocus"                      

                           StringValidationCompleted=

                                     "maskedTextBox_StringValidationCompleted"/>

 

You can handle the TextChanged event as follows:

 

C#

 

private void maskedTextBox_StringValidationCompleted(object sender, StringValidationEventArgs e)

        {

            if (e.IsValidInput)

            {

                MessageBox.Show("String validation succeeded");

            }

            else

            {

                MessageBox.Show("String validation Failed");

            }

        }

 

StringValidation property is set to “OnLostFocus”. So when the control Lost the Focus, the entered value is Validated with the ValidationString property because the Mask property is empty.
