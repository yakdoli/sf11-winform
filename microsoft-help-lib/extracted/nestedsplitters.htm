Nested Splitters

 

We can create Nested Splitters with more complex structures, containing both horizontal and vertical split bars. By using the AnchorWithParentPane property, we can resize the inner Splitter also, when the parent pane is resized.

The following example demonstrates how to configure a Nested Splitters.

 

[aspx]

 

<cc1:Splitter ID="RootSplitter" Layout="Horizontal" runat="server" Height="300px" Width="500px">

    <cc1:SplitPane ID="LeftSplitPane" runat="server" Width="120px">

        <span>Left SplitPane</span>

    </cc1:SplitPane>

    <cc1:SplitterBar ID="SplitterBar1" CollapseMode="Both" runat="server" />

    <cc1:SplitPane ID="CenterSplitPane" runat="server" Width="190px">

        <cc1:Splitter ID="ChildSplitter" runat="server" Layout="Vertical" AnchorWithParentPane="true">

            <cc1:SplitPane ID="TopSplitPane" runat="server" Height="120px">

                <span>Top SplitPane</span>

            </cc1:SplitPane>

            <cc1:SplitterBar ID="SplitterBar3" CollapseMode="Both" runat="server" />

            <cc1:SplitPane ID="BottomSplitPane" runat="server">

                <span>Bottom SplitPane</span>

            </cc1:SplitPane>

        </cc1:Splitter>

    </cc1:SplitPane>

    <cc1:SplitterBar ID="SplitterBar2" CollapseMode="Both" runat="server" />

    <cc1:SplitPane ID="RightSplitPane" runat="server" Width="180px">

        <span>Right SplitPane</span>

    </cc1:SplitPane>

</cc1:Splitter>
