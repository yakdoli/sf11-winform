Range

 

This property specifies the selected range of the Range Slider. Range can be specified using two values namely Start and End.

 

The following code snippet illustrates this:

 

[XAML]

 

<Syncfusion:RangeSliderControl x:Name="rangeSlider" Range="25,65" TickFrequency="10">

</Syncfusion:RangeSliderControl>

 

[C#]

 

RangeSliderControl RangeSlider = new RangeSliderControl();

RangeSlider.TickFrequency = 10;

RangeSlider.Range = new DoubleRange(25, 65);
