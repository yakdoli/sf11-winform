ClientSideRecordHoverEvent

 

Triggered for every row in the grid when the mouse pointer is moved over it.

getRow() // contains the row object (DOM)

getRecord() // contains the record object (JSON)     

row // contains the row object (DOM)

record  // returns the record object (JSON)     

 

ClientSideRecordSelectionEvent

 

Triggered for every row in the grid when it is clicked.

getRow() // contains the row object (DOM)

getRecord() // contains the record object (JSON)     

row // contains the row object (DOM)

record  // returns the record object (JSON) 

 

ClientSideDoubleClickEvent

 

Triggered for every row in the grid when it is double-clicked.

getRow() // contains the row object (DOM)

getRecord() // contains the record object (JSON)     

row // contains the row object (DOM)

record  // returns the record object (JSON) 

 

ClientSideRecordsUnselectionEvent

 

Triggered for every row in the grid when it is unselected.

getRow() // contains the row object (DOM)

getRecord() // contains the record object (JSON)     

row // contains the row object (DOM)

record  // returns the record object (JSON) 

 

OnRowDragStarted

 

Triggered for every row in the grid when it is Drag started.

JSonRecord, // returns the record object (JSON)

OnRowDropping

 

Triggered for every row in the grid when it is dropping to other elements.

Event // returns event

Data // returns the record object (JSON)

 

OnRowDropped

 

Triggered for every row in the grid when it is dropped.

Event // returns event

Data // returns the record object (JSON)

 

 

OnGridRowDragEvent

 

Triggered while dragging in any of grid rows.

Data // returns the record object (JSON)

Triggered while dropped in any of grid rows.

Event // returns event

Data // returns the record object (JSON)

 

DragElement // returns drag element

Triggered when the grid is initialized in client side.

OnActionFailure

 

Triggered when the grid actions get failed.

Triggered for every grid action before its starts.
