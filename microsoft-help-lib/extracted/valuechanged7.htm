ValueChanged

 

ValueChanged – The event occurs when the Value property of the MaskedTextBox is changed.

 

XAML

 

<syncfusion:MaskedTextBox x:Name="maskedTextBox"

                          ValueChanged="maskedTextBox_ValueChanged"/>

 

C#

 

MaskedTextBox maskedTextBox = new MaskedTextBox();

maskedTextBox.ValueChanged+=new PropertyChangedCallback(maskedTextBox_ValueChanged);

 

You can handle the event as follows:

 

C#

 

private void maskedTextBox_ValueChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)

        {

            //Insert code to do some operations when value of MaskedTextBox changes.

        }
