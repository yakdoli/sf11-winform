PivotItem

 

PivotItem requires the following things to be defined in it:

·      Field Header - Defines the title you want to see in the header for this pivot item

·      Field Mapping Name - Defines the property's mapping name

·      Format - Defines the format which should be applied

·      Total Header - Gets or sets the string that you want to append to the pivot item's summary cells.

·      Comparer - Gets or sets the IComparer object used for sorting
