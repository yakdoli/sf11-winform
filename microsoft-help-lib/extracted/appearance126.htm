Appearance

The appearance of the OlapPager can be customized using the CssClass property. The custom CssClass style should have the following CSS styles associated with it:

·      MovePrev—Defines styles for the Move Previous button

·      MoveNext—Defines styles for the Move Next button

·      MovePrevDisabled—Defines styles for the Move Previous button’s disabled state

·      MoveNextDisabled—Defines styles for the Move Next button’s disabled state

·      PagerPanel—Defines styles for the Pager panel

·      PageBox—Defines styles for the CurrentPage text box

·      Text—Defines styles for spans used in the pager

 

An example of CSS styles for the pager is given in the following code snippet:

 

CSS

 

.PagerOffice2010Black

{

    cursor:default;

}

.PagerOffice2010Black div

{

    display:inline-block;

    margin-right:5px;

    padding:2px;

    border: 1px solid #4E4E4E;

}

.PagerOffice2010Black .MovePrev, .PagerOffice2010Black .MoveNext, .PagerOffice2010Black .MovePrevDisabled, .PagerOffice2010Black .MoveNextDisabled

{

    padding: 2px 10px;

    background-image: url('Images/black.png');

    background-repeat:no-repeat;

}

.PagerOffice2010Black .MovePrev

{

    background-position: 0 -229px;

}

.PagerOffice2010Black .MoveNext

{

    background-position: 0 -206px;

}

.PagerOffice2010Black .MovePrevDisabled

{

    background-position: 0 -44px;

    opacity:0.3;

}

.PagerOffice2010Black .MoveNextDisabled

{

    background-position: 0 -21px;

    opacity:0.3;

}

.PagerOffice2010Black .PageBox

{

    width:30px;

    font-family:Verdana;

    font-size:12px;

}

.PagerOffice2010Black .Text

{

    font-family:Verdana;

    font-size:12px;

    margin:0 5px;

}
