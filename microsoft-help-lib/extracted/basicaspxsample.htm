Basic ASPX Sample

A sample that demonstrates a basic Chart control can be downloaded from the following link.

Aspx Sample:

http://www.syncfusion.com/downloads/Support/DirectTrac/87213/MobileChart_ASPXrSample-814443255.zip

Note:The version number for the assemblies has been set to 9.4.0.62 in the Web.config file of the attached sample. Change the version number to the appropriate version in the Web-2008.config or Web-2010.config files (available in root directory) and those will automatically be updated in the Web.config file.
