How to enable/disable Header Cell tooltip?

Header cell tooltip can be enabled by:

[C#]

 

// Enabling HeaderCell Tooltip

this.OlapGrid1.ShowHeaderCellsToolTip = true;

 

 

[VB]

 

' Enabling HeaderCell Tooltip

Me.OlapGrid1.ShowHeaderCellsToolTip = True

 

 

Header cell tooltip can be disabled by:

[C#]

 

// Disabling HeaderCell Tooltip

this.OlapGrid1.ShowHeaderCellsToolTip = false;

 

 

[VB]

' Disabling HeaderCell Tooltip

Me.OlapGrid1.ShowHeaderCellsToolTip = false
