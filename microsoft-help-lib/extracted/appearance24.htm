Using Builder

The following steps explain how to set themes for the percent text box through the builder.

1.   In View, invoke the percent text box helper followed by the AutoFormat method with the desired theme as an argument.

 

View [ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent")

.AutoFormat(Skins.Sandune)%>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent")

.AutoFormat(Skins.Sandune).ToString()))

 

 

2.   Build and run the application.

 

Using Properties Model

 

The following steps explain the setting of the themes for the percent text box through the properties model.

1.   In the controller, create an instance of PercentTextBoxModel.

2.   Define the AutoFormat property and pass the instance through the view-specific data to the view.

 

[Controller]

 

public ActionResult Index()

        {

            //Creating an instance of PercentTextBoxModel.

            PercentTextBoxModel myModel = new PercentTextBoxModel();

            myModel.AutoFormat = Skins.Sandune;

 

            //Passing the instance through the view data to the view.

            ViewData["myPercent"] = myModel;

            return View();

        }

 

 

3.   In View, invoke the percent text box helper with the view data key as the control ID.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent") %>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent").ToString()))

 

 

4.   Build and run the application.
