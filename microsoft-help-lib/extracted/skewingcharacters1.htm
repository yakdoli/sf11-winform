Skewing characters

 

The following properties are discussed in this section:

 

·      SkewAngleX

·      SkewAngleY

 

 Setting SkewAngleX

 

The user can set the angle to skew the character along the X-axis using SkewAngleX property. The following code snippets illustrate setting this property for a Digital gauge.

 

[XAML]

 

<syncfusion:DigitalGauge  Name="digitalGauge"    Height="100" Width="300"                                         

CharacterHeight="30"  Background="Gray"                               

SegmentWidth="3" SegmentBrush="Black" SkewAngleX="30"

CharacterCount="10"

Value="Syncfusion" CharacterType="SegmentFourteen" />

 

 

[C#]

 

DigitalGauge digitalGauge = new DigitalGauge();

digitalGauge.Value = "Syncfusion";

digitalGauge.SegmentSpacing = 1;

digitalGauge.SkewAngleX = 30;

digitalGauge.CharacterCount = 10;

digitalGauge.CharacterHeight = 30;

digitalGauge.CharacterSpacing = 4;

digitalGauge.CharacterType = CharacterType.SegmentFourteen;
