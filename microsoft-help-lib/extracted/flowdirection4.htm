FlowDirection

 

The FlowDirection property specifies the flow direction for the control. It can be set to one of the following values:

         

·      LeftToRight

·      RightToLeft

 

The following code illustrates this:

 

[XAML]

 

<syncfusion:NumericUpDown x:Name="NumericUIpDown" FlowDirection="LeftToRight" />

 

[C#]

 

NumericUpDown numericUpDown = new NumericUpDown();

numericUpDown.FlowDirection = EnumFlowDirection.LeftToRight;
