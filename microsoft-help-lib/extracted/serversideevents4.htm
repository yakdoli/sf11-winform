Server- side Events

 

The server-side events can be handled to execute a function on some user action. The server-side event of GenericDropDown control has been given below.

 

Server-Side Event

Description

TextChanged

Specifies the function to be executed when the text in the input area of the GenericDropDown control changes. This event is handled only when the AutoPostBackOnTextChanged property is set to True.

 

The following procedure shows how to process and handle the server-side event.

 

1.   Add the following code snippet in the html view of your project.

 

[ASPX]

 

<cc1:GenericDropDown ID="GenericDropDown1" runat="server" Width="340px" TextBoxCssClass="Textcss" TextBoxHoverCssClass="Textcss" Text=" - Select -" OnTextChanged="GenericDropDown1_TextChanged" AutoPostBackOnTextChanged="True" AutoFormat="Office2007 Blue">

<table style=" color: #333365; font-family: Trebuchet MS;font-size: 12px;

background-color: #f6f9ff;">

<tr>

<td style="background-color: #cbd3e2; font-weight: bold;"> Essential Studio Enterprise </td>

</tr>

<tr>

<td> <input id="EnterpriseBin" runat="server" type="checkbox" value="Enterprise Edition Binary with TestStudio;" /> Essential Studio Enterprise Edition Binary with TestStudio </td>

</tr>

</table>

</cc1:GenericDropDown>

 

2.   Add the following code snippets in the code view of your project.

 

[C#]

 

protected void GenericDropDown1_TextChanged(object sender, Syncfusion.Web.UI.WebControls.Shared.GenericDropDownTextChangeEventArg e)

{

this.Label1.Text= "Server Side Text Changed Event is handled"; 

}  

 

[VB]

 

Protected Sub GenericDropDown1_TextChanged(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Shared.GenericDropDownTextChangeEventArg)

Me.Label1.Text = "Server Side Text Changed Event is handled"

End Sub

 

3.   Build and run the application.

 

On changing the text of the GenericDropDown control, the corresponding server-side events are handled and the action performed is displayed in the label.
