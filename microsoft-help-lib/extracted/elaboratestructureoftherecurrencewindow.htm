Elements and Features of the Recurrence Window

The elements and features of the Recurrence window are:

·      Recurrence OK: This button is used to apply the selected recurrence details for the appointment.

·      Recurrence Cancel: This button is used to close the recurrence window.

·      Remove Recurrence: This button is used to remove the recurrence option from an appointment.

·      Appointment Duration: This frame is used to get the recurrence appointment start time and end time duration.

·      Appointment Pattern: This frame used to get the recurrence frequency and recurrence interval.

·      Appointment Range: This frame is used to get the range of recurrence.
