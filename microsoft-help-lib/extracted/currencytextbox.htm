CurrencyTextBox

 

 The CurrencyTextBox is a control that allows you to display only currency values within a textbox. 

 

Figure 34

 

Features

·      Supports client side validation of key strokes.

·      Supports setting of minimum and maximum values.

·      Uses globalization features of .NET platform to provide locale-specific formatting.
