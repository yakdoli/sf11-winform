Deployment Requirements

The following assemblies should be referenced in your application for using OLAP Gauge Silverlight control:

·      Syncfusion.Core

·      Syncfusion.Gauge.Silverlight

·      Syncfusion.Shared.Silverlight

·      Syncfusion.Themeing.Silverlight

·      Syncfusion.Olap.Base

·      Syncfusion.OlapGauge.Silverlight

·      Syncfusion.OlapSampleUtils

·      Syncfusion.OlapSilverlight.Base

·      Syncfusion.OlapSilverlight.BaseWrapper

·      Syncfusion.SampleBrowserUtils.Silverlight
