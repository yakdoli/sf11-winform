AJAX Support

 

The ToolBar control can be refreshed using callback and client side functions can be raised to perform some user defined actions. The various callback events supported are listed below.

 

Server-Side Event

Description

CallbackRefresh

Refreshes the control without a postback.

 

 

Client-Side Event

Description

AfterCallbackResponseProcessedScript

Specifies the script to be executed after the callback result gets processed.

AfterCallbackScript

Specifies the script to be executed after a callback request is sent to the server.

BeforeCallbackResponseProcessingScript

Specifies the script to be executed before the callback result is processed.

BeforeCallbackScript

Specifies the script that will be executed before a callback request is sent to the server.

 

 

Note: Make sure that EnableCallbacks property is set to True which specifies the control to be refreshed through callback.

 

Invoking Callback

 

A callback can be invoked using the Refresh method. This invokes the various above listed client side events during this process.

 

 

Method

 

Parameter

 

Description

Refresh

string

Sends CallBack to server without page refreshing.Handle this event to change the contents of the panel according to the event args the client sent.

 

·      Define the various funtions that are to be executed. Here, ClientObjectId is used to access the control's object model in OnRefresh method and alert messages are displayed while the various events are triggered.

 

[script]

 

function OnRefresh()

{

    toolBar.Refresh();

}

function BeforeStart()

{

    alert('BeforeCallbackScript is fired');

}

function AfterStart()

{   

    alert('AfterCallbackScript is fired');

}

function BeforeProcess()

{

    alert('BeforeCallbackProcessingScript is fired');

}

function AfterProcess()

{

    alert('AfterCallbackProcessedScript is fired');

}

 

Client-Side Events

 

Set the client events to the respective function names that should be invoked appropriately.

[aspx]

 

<cc1:ToolBar ID="ToolBar1" runat="server" AutoFormat="Office2007 Luna Blue" OnCallbackRefresh="ToolBar1_CallbackRefresh" ClientObjectId="toolBar" ClientSideOnDockElementClick="ElementClick(this)" ClientSideOnDrag="OnDrag(this)" ClientSideOnDragStart="OnDragStart(this)" ClientSideOnDragEnd="OnDragEnd(this)" EnableCallbacks="True" AfterCallbackResponseProcessedScript="AfterProcess()" AfterCallbackScript="AfterStart()" BeforeCallbackResponseProcessingScript="BeforeProcess()" BeforeCallbackScript="BeforeStart()" Caption="Syncfusion">

.....

</cc1:ToolBar>

<br />

<br />

<br />

 

<asp:button id="Button1" style="width: 106px" runat="server" OnClientClick="OnRefresh();return false;" Text="Click to add item">

</asp:button>

 

 

Server-Side Event

 

Here, when the button is clicked, the OnRefresh method will be invoked and the Refresh method will be called which raises the CallbackRefresh server side event. When this event is raised, a new toolbar item will be added to the control, without any occurrence of postback.

 

[C#]

 

protected void ToolBar1_CallbackRefresh(object sender, Syncfusion.Web.UI.WebControls.Tools.CallbackEventArgs e)

{

    ToolBarItem item = new ToolBarItem();

    item.Text = "check";

    ToolBar1.Items.Add(item);

}

 

 

StatusBarText

 

StatusBarText property allows to change the display text on the browser window during the callback process. The default value is Refreshing.
