How to Hide Summary Elements at Different Levels

Summary element visibility can be controlled by its level name or level depth/number using this feature.

 

Refer to the following steps to hide summary elements:

1    Bind the RowBound and QueryColumnInfo event to the OlapGrid.

2    In the event function, hide the required summary row or column using the e.Hide() function.

 

[ASPX]

<Syncfusion:OlapGrid ID="OlapGrid1" runat="server" Style="overflow: auto" Width="700px" OnRowBound="OlapGrid1_RowBound" OnQueryColumnInfo="OlapGrid1_QueryColumnInfo">   

</Syncfusion:OlapGrid>

 

 

[C#]

public void OlapGrid1_RowBound(object sender, RowBoundEventArgs e)

    {

        if (e.IsSummaryRow && e.GetMember().LevelDepth.In(2, 0))

        {

            e.Hide();

        }

    }

 

    public void OlapGrid1_QueryColumnInfo(object sender, ColumnInfoEventArgs e)

    {

        if (e.IsSummaryColumn && e.GetMember().Caption.In("Canada", "Germany", "United States"))

        {

            e.Hide();

        }

    }
