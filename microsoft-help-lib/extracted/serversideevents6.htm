Server-Side Events

 

The server side events for the Calendar control are listed in the below table.

 

Server-Side Event

Description

SelectedDateChanged

Occurs when the user had changed the selected date.

VisibleMonthChanged

Occurs when the user clicks the next/previous month navigator buttons on the title heading.

RenderDay

Occurs when each day cell in the current calendar month is being rendered.

 

To execute the server side events, the AutoPostBackOnSelectedDateChanged and the AutoPostBackOnVisibleMonthChanged properties must be enabled for the respective events, which triggers a postback and handles the server side event.

 

Property

Description

AutoPostBackOnSelectedDateChanged

Indicates whether to perform a postback on the page, when a selected date is changed.

AutoPostBackOnVisibleMonthChanged

Indicates whether to perform a postback on the page, when a visible month is changed.

 

The following code example demonstrates how to handle VisibleMonthChanged event to display whether the Calendar control has moved some months, forward / backward.

 

[ASPX]

 

<ssw:Calendar ID="Calendar1" runat="server" AutoPostBackOnVisibleMonthChanged="True" OnVisibleMonthChanged="Calendar1_VisibleMonthChanged"/>

<br />

<asp:Label ID="Label1" runat="server" Text="Starting month."></asp:Label>

 

[C#]

 

protected void Calendar1_VisibleMonthChanged( object sender, System.Web.UI.WebControls.MonthChangedEventArgs e )

{

       int nMonths = ( e.NewDate.Year - e.PreviousDate.Year )*12 + ( e.NewDate.Month - e.PreviousDate.Month );

 

       int nMonthsCount = Math.Abs( nMonths );

       string sDirection = ( nMonths > 0 ) ? "forward" : "backward";

 

       string sMessage = string.Format( "You moved {0} {1} month{2}.",

              sDirection, nMonthsCount, ( 1 < nMonthsCount ) ? "s" : "" );

       Label1.Text = sMessage;

}

 

The following code example demonstrates how to handle SelectedDateChanged event to display new selected date.

 

[ASPX]

 

<ssw:Calendar ID="Calendar1" runat="server" AutoPostBackOnSelectedDateChanged="True" OnSelectedDateChanged="Calendar1_SelectedDateChanged"/>

<br />

<asp:Label ID="Label1" runat="server" Text="Starting month."></asp:Label>

 

[C#]

 

protected void Calendar1_SelectedDateChanged(object sender, Syncfusion.Web.UI.WebControls.Shared.DateChangedEventArgs e)

{

       Label1.Text = "Selected date: " + e.NewDate.ToShortDateString();

}

 

 

The following sample demonstrates how to handle RenderDay event to customize individual days in Calendar control.

 

[ASPX]

 

<ssw:Calendar ID="Calendar1" VisibleMonth="01/01/2008" runat="server" AutoPostBackOnVisibleMonthChanged="true" OnRenderDay="Calendar1_RenderDay"/>

 

[C#]

 

protected void Calendar1_RenderDay(object sender, RenderDayEventArgs e)

{

       if(( e.CalendarDay.Day == 12 )&&( e.CalendarDay.Month == 1 ) )

       {

              e.Cell.Font.Bold = true;

              e.Cell.Font.Underline = true;                  

              e.Cell.Text = e.CalendarDay.Day + "<br/>" + "Birthday";

       }

}
