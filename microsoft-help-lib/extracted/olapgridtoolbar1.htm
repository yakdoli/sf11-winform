OLAP Grid Tool Bar

 

By using the menus in the OLAP Grid Tool Bar, the user can customise the appearance and style of the Grid.

Figure 65: OLAP Grid Tool Bar

 

The following are the options in the OLAP Grid Tool Bar.

Icon

Name

Description

Grid Style

Displays the Grid Style Dialog to change the current style of the Grid

Show header tooltip

Show/Hide the Header cell tool tip.

Show value cell tooltip

Show/Hide the value cell tool tip.

Freeze Headers

Freeze the Header cells of the Grid

Grid Layout

Lists different types of grid layout to change the current layout

Export to Excel

Export the Grid to Excel

Export to word

Export the Grid to Word

Export to Pdf

Export the Grid to PDF
