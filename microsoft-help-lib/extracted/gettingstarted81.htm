Feature Summary

 

·      ValueStringFormat - Allows different timespan formats.

·      FormatString - Displays the selected timespan in string format

·      MaxValue - Allows setting the maximum range of the timespan.

·      MinValue - Allows setting the minimum range of the timespan.

·      StepValue - Allows setting the incremental value of the timespan.
