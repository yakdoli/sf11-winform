Customization

 

Rolling Gauge can be customized in the following levels.

 

Segment Customization

Create a Rolling Gauge with Customized Segment, by using the following code.

 

 

 

           

<!--Creating rolling gauge with four segment-->

<syncfusion:RollingGauge SegmentCount="4" Value="0000" Height="50"

HorizontalAlignment="Stretch" VerticalAlignment="Stretch">

<!--Writing DataTemplate for Segments-->

<syncfusion:RollingGauge.SegmentTemplate>

<DataTemplate>

<Border>

<TextBlock Text="{Binding}" Foreground="Blue"

     HorizontalAlignment="Center"

                            VerticalAlignment="Center"/>

</Border>

</DataTemplate>

</syncfusion:RollingGauge.SegmentTemplate>

</syncfusion:RollingGauge>

           

 

When the code runs, the following output displays.

 

 

Figure 139: Customized Segment

 

 

 

Setting Style for Particular Segment

Customize the Style setting of a particular segment, by using the following code.

 

           

 

<!--Creating rolling gauge with four segment-->

<syncfusion:RollingGauge SegmentCount="4" Height="50" Unit="KM"

UnitPosition="End">

<!--Apply Style for one particular segment-->

<syncfusion:RollingGauge.Segments>

<!--Based on the CharacterIndex the Style is applied-->

<syncfusion:RollingCharacter Value="X" CharacterIndex="2"

     HorizontalAlignment="Center" VerticalAlignment="Center"

Margin="1" FontSize="20"                                

FontWeight="Bold">

                    <!--cutomize the color of the third segment(CharacterIndex = 2)-->

                    <syncfusion:RollingCharacter.Background>

                        <LinearGradientBrush EndPoint="0.5,0"

                             StartPoint="0.5,1">

                            <GradientStop Color="#FF959595" Offset="0"/>

                            <GradientStop Color="sc#1, 0.23793754,

                             0.23948577, 0.243536577"

                             Offset="0.074432373046875"/>

                            <GradientStop Color="sc#1, 0.1839543,

                             0.186837509, 0.194381177"

                             Offset="0.16609090566635132"/>

                            <GradientStop Color="sc#1, 0.140305564,

                             0.1442682, 0.15463607"

                             Offset="0.28974699974060059"/>

                            <GradientStop Color="sc#1, 0.110575363,                                       0.115273222,0.127564728"

Offset="0.5042881965637207"/>

                            <GradientStop Color="sc#1, 0.104616493,

                             0.10946171, 0.122138768" Offset="1"/>

                            <GradientStop Color="#FF5B5D62" Offset="1"/>

                        </LinearGradientBrush>

                    </syncfusion:RollingCharacter.Background>

</syncfusion:RollingCharacter>

</syncfusion:RollingGauge.Segments>

</syncfusion:RollingGauge>
