Zoom with Zoom Mode

 

There are two ZoomModes available in the Map Control. They are:

 

·      SingleClick

·      DoubleClick

 

Select Zoom mode as SingleClick and click on the Map. Ten Map will be get ZoomedIn.

Select Zoom mode as DoubleClick and click twice on the Map. Ten Map will be get ZoomedIn.

 

[XAML]

       <maps:MapControl ZoomMode="SingleClickx:Name="Map" LayeredContent="{Binding ElementName=shapeControl}" EnableColorPalette="True">

                        <maps:MapControl.Layers>

                            <maps:Layers>

                                <maps:ShapeFileLayer Uri="SilverlightApplication1.ShapeFiles.wv.shp" TranslateZoomFactor="1" x:Name="shapeControl"  EnableColorPalette="True">

                                </maps:ShapeFileLayer>

                               </maps:Layers>

                        </maps:MapControl.Layers>           

      </maps:MapControl>

 

[C#]

            MapControl map = new MapControl();

            ShapeFileLayer shapeLayer = new ShapeFileLayer();

            shapeLayer.Uri = "SilverlightApplication1.ShapeFiles.wv.shp";

            map.Layers.Items.Add(shapeLayer);

            map.LayeredContent = shapeLayer;

            map.ZoomMode = ZoomingMode.SingleClick;

            LayoutRoot.Children.Add(map);
