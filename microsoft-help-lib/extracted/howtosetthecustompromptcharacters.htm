How to set the Custom Prompt Characters

 

You can set the Custom Prompt Characters by using the Prompt Char property. Here is a simple example to set the prompt char property:

 

XAML

 

<syncfusion:MaskedTextBox Name="maskedTextBox1" Height="25" Width="150"

                          Mask="00/00/0000" PromptChar="_"/>

 

C#

 

maskedTextBox1.PromptChar = "_";
