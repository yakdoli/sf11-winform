Adding OlapPager to an Application

To enable paging in the application:

1.   Drag and drop OlapGrid to the page.

2.   Bind the OlapDataManager to the grid.

3.   Drag and drop the OlapPager to the page.

4.   Set the OlapControlID to Pager.

5.   Call the DataBind() of OlapGrid method.

 

The following code snippets demonstrate how to enable paging.

 

[ASPX]

 

<syncfusion:OlapGrid ID="OlapGridControl1" runat="server" IsAsyncRequestData="false" />

<syncfusion:Pager ID="pager1" runat="server" OlapControlID="OlapGridControl1" />

 

[C#]

 

var dataProvider = new AdomdDataProvider(connectionString);

var DataManager = new OlapDataManager(dataProvider);

DataManager.SetCurrentReport(CreateOlapReport());

this.OlapGridControl1.OlapDataManager = DataManager;

this.OlapGridControl1.DataBind();

 

[VB]

 

Dim dataProvider = New AdomdDataProvider(connectionString)

DataManager = New OlapDataManager(dataProvider)

DataManager.SetCurrentReport(CreateOlapReport())

Me.OlapGridControl1.OlapDataManager = DataManager

Me.OlapGridControl1.DataBind()
