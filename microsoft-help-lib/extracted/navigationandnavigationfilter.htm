Navigation and NavigationFilter

The following steps explain the Navigation of Accordion items.

 

Properties

Name

Description

Type of the  Property

Value it accepts

Dependency

Navigation

If set, looks for the anchor that matches location.href and activates it. Great for href-based state-saving

bool

 

True

False

NA

NavigationFilter

Gets or Sets Navigation Filters. Overwrites the default location.href-matching with your own matcher

String

Any Function Handler

Navigation

 

1.   In View, invoke the Accordion helper with the control id as the first argument.

 

Site.Master

< div id ="ControlSection" style =" height :180px;">

            <%Html.RenderPartial("Navigation"); %>

</ div >

 

< div id ="ScriptSection">

  <scripttype="text/javascript">

   Sys.Application.add_load(function () {

        $('#AccordionControl1').sfAccordion("option", "Navigation", true);

        $('#AccordionControl1').sfAccordion("option", "NavigationFilter", function () {

         var locationHrefArray = location.href.split("/");

         var locationLastString = locationHrefArray[locationHrefArray.length - 1].toLowerCase();

         var sidebarHrefArray = this.href.split("/");

         var sideBarLastString = sidebarHrefArray[sidebarHrefArray.length - 1].toLowerCase();

return locationLastString == sideBarLastString;

       });

  });

</ script >

 

PartialView[Navigation.ascx]

      Html.MobSyncfusion().Accordion("AccordionControl1")

               item.Add().Text("LogOn")

                             </div><%});                                                 

           })

      .Render();

  }%>
