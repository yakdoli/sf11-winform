How to validate an email address

 

You can validate the email address by using the ValidatingString property. You have to set the regular expression of the email address to the ValidationString property and then the text entered by the end-user is validated based on the Validation string given by you.

 

XAML

 

<syncfusion:MaskedTextBox x:Name="maskedTextBox" Width="200"

                            ValidationString="^([\w-\.]+)@((\[[0-9]{1,3}\.[0-9]{1,3}\.[0-

                                 9]{1,3}\.)|(([\w-]+\.)+))([a-zA-Z]{2,4}|[0-9]{1,3})"

                            InvalidValueBehavior="DisplayErrorMessage"

                            StringValidation="OnLostFocus"/>

 

In the LostFocus if the given Value does not match with the ValidationString it will display an error message because the InValidInputBehaviour is set as “OnLostFocus”.

You can use the MaskCompleted property to know the status of the validation.
