Caption Button

 

Users can customize the Caption button by setting background, border brush, border thickness and corner radius of caption as well as the visibility of the caption using appropriate properties. You can also customize the Gallery items by setting the height and width of the item. Use the following code for setting these properties.

 

[XAML]

 

<!-- Adding Gallery -->

<syncfusion:Gallery Name="gallery" ItemWidth="100" ItemHeight="100" CaptionAlignment="Bottom"

CaptionBackground="Transparent" CaptionBorderThickness="1" CaptionCornerRadius="2"

CaptionBorderBrush="Transparent" IsAlwaysShownCaption="True">

 

  <!-- Adding GalleryGroup -->

  <syncfusion:GalleryGroup Name="galleryGroup" Header="Photos">

 

    <!-- Adding GalleryItems -->

    <syncfusion:GalleryItem  Caption="HR" Description="HR Department">

      <Image Source="hr.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp5.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp2.jpg"/>

    </syncfusion:GalleryItem>

  </syncfusion:GalleryGroup>

</syncfusion:Gallery>
