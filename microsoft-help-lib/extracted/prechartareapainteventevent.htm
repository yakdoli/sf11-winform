PreChartAreaPaint Event Event

 

PreChartAreaPaint event is raised before the Chart Area is painted.

 

[C#]

 

this.ChartWebControl1.PreChartAreaPaint+=new System.Windows.Forms.PaintEventHandler(ChartWebControl1_PreChartAreaPaint);

 

protected void ChartWebControl1_PreChartAreaPaint(object sender, System.Windows.Forms.PaintEventArgs e)

{

      this.ChartWebControl1.BackColor = Color.Yellow;      

}
