Using Properties Model

The following steps explain the setting of the rating range through the properties model:

1.   In the controller, create an instance of RatingModel.

2.   Define the MaximumValue and Increment Step properties and pass the instance through the view-specific data to the view.

 

 [Controller]

 

        publicActionResult Rating()

        {

            MobRatingModel myModel = newMobRatingModel();

 

            myModel.AutoFormat = MobSkins.DarkNight;

 

            myModel.MaximumValue = 50;

 

            myModel.IncrementStep = 5;

 

            myModel.ShapeHeight = 40;

 

            myModel.ShapeWidth = 40;

 

            myModel.CurrentValue = 3;

 

            myModel.EditMode = true;

 

            //Passing the instance through the view data to the view.

 

            ViewData["myRating"] = myModel;

            return View();

        }

 

 

3.   In View, invoke the rating helper with the view data key as the control ID.

 

 [ASPX]

 

<% = Html.MobSyncfusion().Rating("myRating") %>

 

 

 

[Razor]

@{ Html.MobSyncfusion(). Rating ( " myRating " ).Render();}

 

 

4.   Build and run the application in emulator.
