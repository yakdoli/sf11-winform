Enabling Inline appointments

In order to enable inline appointments in schedule, use the AllowInline property as shown in the code snippets below:

 

[ASPX]

<syncfusion:Schedule ID="Schedule1" AllowInline="true" AutoFormat="Office2007Blue" ViewStrip="true" runat="server”>

</syncfusion:Schedule>

 

 

[C#]

 

this.Schedule1.AllowInline = true;

 

 

[VB]

Me.Schedule1.AllowInline = true
