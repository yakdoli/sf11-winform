Adding to ScrollPanel to an Mobile ASP.NET MVC application

Refer to the Getting Startedsection for the prerequisites needed to add a mobile scroll panel control to an ASP.NET MVC application.

The following steps explain how to add a ScrollPanel:

1.   In View, invoke the ScrollPanel helper with the control ID as the first argument and set its target id to render the scrollable content.

 

 

 [ASPX]

 

    <% = Html.MobSyncfusion().ScrollPanel("ScrollPanel")

             .ScrollBarWidth(10)

             .ScrollType(ScrollType.Both)

             .TargetId("scrollContent")

    %>

 

 

[Razor]

 

    @{ Html.MobSyncfusion().ScrollPanel("ScrollPanel")

             .ScrollBarWidth(10)

             .ScrollType(ScrollType.Both)

             .TargetId("scrollContent")

           .Render();

    }
