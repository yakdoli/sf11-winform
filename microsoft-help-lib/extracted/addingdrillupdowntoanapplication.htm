Adding Drill Up-Down to an Application

 

This can be enabled by setting the following properties to OlapReport

 

For Drill Member

 

[CS]

report.DrillType = DrillType.DrillMember;

 

 

For Drill Position

 

[CS]

report.DrillType = DrillType.DrillPosition;
