Adding the HeatMap Control to the Application

 

You have now created a Silverlight application and deployed Essential Chart Silverlight assembly. Let's see how to add HeatMap control to this application.

 

Following code snippets explains how to add the HeatMap control to an application.

 

[XAML]

 

<syncfusion:HeatMapControl x:Name="heatMap" Background="Transparent">

<syncfusion:HeatMapItem Weight="150" FontSize="12" Foreground="White" Header="India" ColorWeight="50" Level="2"/>

<syncfusion:HeatMapItem Weight="150" FontSize="12" Foreground="White" Header="Nigeria" ColorWeight="350" Level="2"/>

</syncfusion:HeatMapControl >

 

Figure 55: HeatMap Control

 

Things to be considered

 

·      Specify the ItemsSource property.

·      Specify the ColorWeightValuePath and WeightValuePath properties.

·      Specify the Template, if needed.

 

[XAML]

 

<syncfusion:HeatMapControl x:Name="heatMap" ColorCalculationLevel="2" LowestWeightColor="Green" MedianWeightColor="Yellow" HighestWeightColor="Cyan" Background="Transparent" WeightValuePath="Sales" ColorWeightValuePath="Expense" />

 

[C#]

 

this.heatMap.ItemsSource = Datasourcename;
