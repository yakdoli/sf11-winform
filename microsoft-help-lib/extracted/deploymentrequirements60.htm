Deployment Requirements

For using the Essential Report Viewer for Silverlight, you need to deploy the following list of assemblies with your product.

·      Syncfusion.Chart.Silverlight

·      Syncfusion.Gauge.Silverlight

·      Syncfusion.Grid.Silverlight

·      Syncfusion.GridCommon.Silverlight

·      Syncfusion.Linq.Base

·      Syncfusion.ReportControls.Silverlight

·      Syncfusion.ReportViewer.Silverlight

·      Syncfusion.Shared.Silverlight

 

For using Essential Report Viewer for Silverlight to load RDL or SSRS reports, you need to deploy the following list of assemblies with your product in WCF service.

·      Syncfusion.Reports.Server

·      Syncfusion.Core

·      Syncfusion.Chart.WPF

·      Syncfusion.Compression.Base

·      Syncfusion.DocIO.Base

·      Syncfusion.Gauge.WPF

·      Syncfusion.Grid.WPF

·      Syncfusion.GridCommon.WPF

·      Syncfusion.Linq.Base

·      Syncfusion.Pdf.Base

·      Syncfusion.ReportControls.WPF

·      Syncfusion.ReportWriter.Base

·      Syncfusion.Shared.WPF

·      Syncfusion.XlsIO.Base
