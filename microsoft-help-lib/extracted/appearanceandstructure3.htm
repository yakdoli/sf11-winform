Feature Summary

·      This control is used to hold a set of  images in a container.                

·      The height and width of the GalleryView control can be customized. 

·      The height and width of an item can be customized using the ItemHeight and ItemWidth properties.

·      The pop-up container height can be customized.

·      The number of items to be shown can be customized using ItemToShow property.
