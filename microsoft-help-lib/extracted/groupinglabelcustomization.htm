Grouping Label Customization

 

The font family, font size and font style of the grouping label can be set through the LabelFont property.

 

[C#]

this.olapChart1.LabelFont = new Font("Verdana", 7f, FontStyle.Strikeout);

this.olapChart1.LabelForeColor = Color.Red;

this.olapChart1.LabelBackColor = Color.Wheat;

this.olapChart1.LabelsBorderColor = Color.DarkGreen;

 

[VB]

Me.olapChart1.LabelFont = New Font("Verdana", 7f, FontStyle.Strikeout)

Me.olapChart1.LabelForeColor = Color.Red

Me.olapChart1.LabelBackColor = Color.Wheat

Me.olapChart1.LabelsBorderColor = Color.DarkGreen
