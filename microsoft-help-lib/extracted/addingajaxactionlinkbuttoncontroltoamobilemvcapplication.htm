Adding AjaxActionLink Button Control to a Mobile MVC Application

In the Getting Started section, we discussed how to create a Mobile MVC application and add the Tools package to an application. This section guides you to add the AjaxActionLink Button control to an application.

1.   In the view, invoke the AjaxActionLink Button helper with the text of the button as the first argument.

[ASPX]

        <% = Ajax.MobSyncfusion().ActionLink("Show Current Time", "ShowTime", new { }, newAjaxOptions { UpdateTargetId = "ShowTime", InsertionMode = InsertionMode.Replace }, new { }).AutoFormat(MobSkins.DarkNight)%>

        <divid="ShowTime"class="sf-show-time">

            <divstyle="text-align: center">

                <divstyle="font-size: 4em;">

                    <%Response.Write(DateTime.Now.ToShortTimeString());%>

                </div>

                <strongstyle="font-size: 10pt;">                    <%Response.Write(DateTime.Now.ToLongDateString());%></strong>

                <spanstyle="font-size: 0.75em;">Eastern Standard Time (EST) -0500 UTC </span>

            </div>

        </div>

[Razor]

@{ Ajax.MobSyncfusion().ActionLink("Show Current Time", "ShowTime", new { }, newAjaxOptions { UpdateTargetId = "ShowTime", InsertionMode = InsertionMode.Replace }, new { }).AutoFormat(MobSkins.DarkNight);}

    <divid="ShowTime"class="sf-show-time">

        <divstyle="text-align: center">

            <divstyle="font-size: 4em;">

                @{Response.Write(DateTime.Now.ToShortTimeString());}

            </div>

            <strongstyle="font-size: 10pt;">

                @{Response.Write(DateTime.Now.ToLongDateString());}

            </strong>

            <spanstyle="font-size: 0.75em;">Eastern Standard Time (EST) -0500 UTC </span>

        </div>

    </div>

 

 

Controller

        public ActionResult AjaxActionLink()

        {

            return View();

        }

        publicActionResult ShowTime()

        {

            return PartialView("ShowTime");

        }

    

 

Partial View

< div id ="ShowTime" class ="sf-show-time">

    <divstyle="text-align: center">

        <divstyle="font-size: 4em;">

            <%Response.Write(DateTime.Now.ToShortTimeString());%>

        </div>

        <strongstyle="font-size: 10pt;">

            <%Response.Write(DateTime.Now.ToLongDateString());%></strong>

        <spanstyle="font-size: 0.75em;">Eastern Standard Time (EST) -0500 UTC </span>

    </div>

</ div >
