Chart Area

Chart Area is the major section of a chart control, where the series points are plotted. The sub topics under this section discusses about the various features that control the appearance of the chart area. They are:

 

·      Adding Chart Area- Illustrates the procedure to add chart area to a chart control with simple code snippets.

·      Background- Describes the background setting for the chart area.

·      Grid Background- Describes the background setting for the grid in the chart area.

·      Chart Area Header- Guides you to set the headers for the chart area.
