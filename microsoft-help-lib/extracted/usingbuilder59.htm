Using Builder

The following steps explain the addition of Accordion to an application using Builder.

1.   In View, invoke the Accordion helper with the control id as the first argument.

View[ASPX]

<% {

  Html.MobSyncfusion().Accordion("AccordionControl1")

 

      .Items((item) =>

       {

            item.Add().Text("About Syncfusion")

                .Content((Accordion) =>

                 {%><div><p>

                    Syncfusion, a world leader in software components have thousands of      satisfied customers world-wide who have used our products to ship award winning software.

                   </p></div>

                  <%});

            item.Add().Text("Technology")

                      .Content((Accordion) =>

                  {%><div><p>

                    Syncfusion products are smartly designed to cope with the fast-changing technology  environment. </p></div>                                                                  

                   <%});

            item.Add().Text("Cantact Us")

                     .Content((Accordion) =>

                   {%><div><p>

                   Company Headquarters 9001 Aerial Center Parkway Suite 110 Morrisville, NC 27560 USA.</p></div>

                  <%});

       })

 

       .Render();

}%>

 

Style Manager:

<% {

     Html.MobSyncfusion().StyleManager()

         .Register(stylesheets =>

                  {

                      stylesheets.Add(MobComponentType.Accordion)

                                 .Theme(MobSkins.Spinach);

                  }).Render();

}%>
