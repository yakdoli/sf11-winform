EventMechanism

 

This section will describe the events of the Map Control. When the events are triggered the Parameters for that event will be passed to event handler function.

The following table consists of Map control events:

 

Table 8: Maps Control Event

Event

Description

Arguments

Type

PreviewZoomIn

Triggered before zooming-in the Map

Double Latitude,Double Longitude,and  Double ZoomFactor

Event

PreviewZoomOut

Triggered before zooming-out the Map

Double Latitude,Double Longitude, and Double ZoomFactor

Event

ZoomedIn

Triggered after Map is zoomed-in

Double Latitude,Double Longitude, and Double ZoomFactor

Event

ZoomedOut

Triggered after Map is zoomed-out

Double Latitude,Double Longitude, and Double ZoomFactor

Event

Panning

Triggered while panning the Map

Double Latitude,Double Longitude, and PanMode panMode

Event

Panned

Triggered after panning the Map

Double Latitude,Double Longitude, and PanMode panMode

Event

Triggered when the selection is changed in the Map

List RemovedItems, and List AddedItems

Registering Events

Events can be registered through XAML and CodeBehind. The following code examples will describe how to raise the events through XAML and CodeBehind.

 

PreviewZoomIn Event

The PreviewZoomIn event will be triggered before zooming in the Map as shown in the following code

 

[XAML]

           <maps:MapControl x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}”>

                            <maps:MapControl.Layers>

                                <maps:Layers>

                                <maps:ShapeFileLayer Uri="EventsDemo.ShapeFiles.wv.shp" PreviewZoomIn="Map_PreviewZoomIn”>

                                    </maps:ShapeFileLayer>

                                </maps:Layers>

                            </maps:MapControl.Layers>

             </maps:MapControl>

 

[C#]

        this.shapeControl.PreviewZoomIn += new ZoomEventHandler(shapeControl_PreviewZoomIn);

  

        void shapeControl_PreviewZoomIn(object sender, ZoomEventArgs args)

        {

            // User Code

        }
