AllowResizing

This property allows you to choose if you would want to resize the content in a particular cell or not.
If not, this feature’s properties and its other settings will be disabled.

bool

·      True

·      False

NA

AllowAutoWrap

Specifies whether the autowrap is enabled

 

Content will wrap to the next line if the content exceeds the boundary of the Column Cells

bool

·      True

·      False

Depends on the AllowResizing property.

If AllowResizing is true, then you have the option of enabling the AllowAutoWrap property.

ResizeSettings

Specifies if content is resizable or not.

If it is resizable, the ResizeToFit sub-property is enabled.

If it is not resizable, the ClipContent sub-property is enabled.

enum

·      ResizeToFit

·      ClipContent

Depends on the AllowResizing property.

If AllowResizing is true, then you have the option of enabling the AllowAutoWrap property.

ResizeToFit

Sets whether the resize to fit content  is enabled

 

Double-clicking the resize handle will have the column automatically resized to fit the widest cell content without wrapping

bool

·      True

·      False
