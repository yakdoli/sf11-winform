 Decorator Shapes

Head and tail decorator shape properties provide options to add arrows and to customize these arrows. End point decorator can be provided for all types of connectors. There are a number of shapes available for head and tail decorators.

Properties

HeadDecoratorShape

Gets or sets the head decorator shape of the connection.

Four values can be specified, namely None, Arrow, Diamond, and Circle.

Default value: HeadDecoratorShape.None

TailDecoratorShape

Gets or sets the head decorator shape of the connection.

Four values can be specified, namely None, Arrow, Diamond, and Circle.

Default value: TailDecoratorShape.Arrow

Arrow settings can be changed using the HeadDecoratorShape and TailDecoratorShape properties. Both head and tail decorators consist of the same set of properties that allow one to customize the settings as required.

Types of decorator shapes

·      Arrow

·      Diamond

·      Circle

 

The following code can be used to change the decorator shape type.

public LineConnector AddConnector(string name, Node headNode,

 Node tailNode, ConnectorType conn, DecoratorShape headdec,

 DecoratorShape taildec)

        {

            LineConnector lineConnector = new LineConnector()

            {

                Name = name,

                HeadNode = headNode,

                TailNode = tailNode,

                HeadDecoratorShape = headdec,

                TailDecoratorShape = taildec,

                ConnectorType = conn,

                LineColor = "#7a7772",

                LineWidth = 2,

                HeadDecoratorHeight=12,

                HeadDecoratorWidth=12,

                TailDecoratorHeight=12,

                TailDecoratorWidth=12

            };

            return lineConnector;

        }
