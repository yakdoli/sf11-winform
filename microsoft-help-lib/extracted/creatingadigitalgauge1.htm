Creating a Digital Gauge

 

You have now created a Silverlight application and deployed Essential Gauge. Lets see how to create a Digital Gauge in this application. This is done either by using XAML code or with C# code.

 

Here are the step-by-step instructions for creating a Digital gauge in XAML or C# code.

 

1.   Add the Digital gauge to the panel using XAML    or C# code as follows.

 

[XAML]

 

<Grid x:Name="LayoutRoot" Background="White">

 <!--Adding Gauge to the application-->

<syncfusion:DigitalGauge  Name="digitalGauge" />

</Grid>

 

[C#]

 

DigitalGauge digitalGauge = new DigitalGauge();

LayoutRoot.Children.Add(digitalGauge);

 

a)   To add a complete Digital gauge along with properties in Silverlight Application, use the code below.

 

[XAML]

 

<Grid x:Name="LayoutRoot" Background="White">

 

 <!--Adding Gauge to the application-->

 <syncfusion:DigitalGauge  Name="digitalGauge"    Height="100" Width="400"                                         

CharacterHeight="30"                                  

SegmentWidth="3" SegmentBrush="Black"

SegmentSpacing="1"

CharacterSpacing="5"  CharacterCount="10"

Value="Syncfusion" CharacterType="SegmentFourteen" >

</syncfusion:DigitalGauge>

</Grid>

 

[C#]

 

DigitalGauge digitalGauge = new DigitalGauge();

digitalGauge.SegmentBrush=new SolidColorBrush(Colors.Black);

digitalGauge.Value = "Syncfusion";

digitalGauge.SegmentSpacing = 1;

digitalGauge.SegmentWidth = 2;

digitalGauge.CharacterCount = 10;

digitalGauge.CharacterHeight = 30;

digitalGauge.CharacterSpacing = 4;

digitalGauge.CharacterType = CharacterType.SegmentFourteen;

LayoutRoot.Children.Add(digitalGauge);

 

2.   b) To add a InnerFrameContent to the Digital gauge in Silverlight Application, use the code below.

 

[XAML]

 

<Grid x:Name="LayoutRoot" Background="White">

 <!--Adding Gauge to the application-->

 <syncfusion:DigitalGauge  Name="digitalGauge"    Height="100" Width="400"                                         

CharacterHeight="30"                                 

SegmentWidth="3" SegmentBrush="Black"

SegmentSpacing="1"

CharacterSpacing="5"  CharacterCount="10"

Value="Syncfusion" CharacterType="SegmentFourteen" >

<syncfusion:DigitalGauge.InnerFrameContent>

<Rectangle Fill="Blue"/>

</syncfusion:DigitalGauge.InnerFrameContent>

</syncfusion:DigitalGauge>

</Grid>

 

[C#]

 

DigitalGauge digitalGauge = new DigitalGauge();

digitalGauge.SegmentBrush=new SolidColorBrush(Colors.Black);

digitalGauge.DimmedBrush = new SolidColorBrush(Colors.Gray);

digitalGauge.Value = "Syncfusion";

digitalGauge.SegmentSpacing = 1;

digitalGauge.SegmentWidth = 2;

digitalGauge.CharacterCount = 10;

digitalGauge.CharacterHeight = 30;

digitalGauge.CharacterSpacing = 4;

digitalGauge.CharacterType = CharacterType.SegmentFourteen;

digitalGauge.CharacterType = CharacterType.SegmentSeven;

Rectangle rect = new Rectangle();

rect.Fill = new SolidColorBrush(Colors.Blue);

digitalGauge.InnerFrameContent = rect;

LayoutRoot.Children.Add(digitalGauge);

 

A Digital Gauge is added to the application.
