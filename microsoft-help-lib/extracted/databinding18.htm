Data Binding

Essential Schedule for Silverlight supports full data binding to any type of "IEnumerable" source. It has an internal ICollectionViewAdv that keeps in sync with the Schedule UI appointments. You must specify the attributes for the AppointmentMapping property, to map the properties in the underlying data source to the Schedule appointments.

The various attributes of the AppointmentMapping property are as follows.

·      Subject

·      Location

·      StartTime

·      EndTime

·      AllDay

·      ID

 

The following code example illustrates the adding of appointments by using the ItemsSource property.

 

[XAML]

<schedule:Schedule x:Name="Schedule" ItemsSource="{Binding}">

    <schedule:Schedule.AppointmentMapping>

        <schedule:ScheduleAppointmentMapping SubjectMapping="Subject"    LocationMapping="Location" StartTimeMapping="StartTime"                     EndTimeMapping="EndTime" AllDayMapping="IsAllDay" IDMapping="ID"  />

    </schedule:Schedule.AppointmentMapping>

</schedule:Schedule>
