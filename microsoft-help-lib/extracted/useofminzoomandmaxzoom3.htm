Use of MinZoom and MaxZoom

MinZoom value is used to set a minimum ZoomFactor value. Below the MinZoom value the Map cannot be zoomed out.

MaxZoom value is used to set a Maximum ZoomFactor value. After the MinZoom value the Map cannot be zoomed in.

[XAML]

      <maps:MapControl ZoomMode="SingleClick" MinZoom="1" MaxZoom="10" x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}">

                       <maps:MapControl.Layers>

                            <maps:Layers>

                                <maps:ShapeFileLayer Uri="WpfApplication1.ShapeFiles.wv.shp" TranslateZoomFactor="1" x:Name="shapeControl"  EnableColorPalette="True">

                                </maps:ShapeFileLayer>

                              </maps:Layers>

                       </maps:MapControl.Layers>

       </maps:MapControl>

 

[C#]

            MapControl map = new MapControl();

            ShapeFileLayer shapeLayer = new ShapeFileLayer();

            shapeLayer.Uri = "WpfApplication1.ShapeFiles.wv.shp";

            map.Layers.Items.Add(shapeLayer);

            map.LayeredContent = shapeLayer;

            map.MinZoom=1d;

            map.MaxZoom=10d

            LayoutRoot.Children.Add(map);
