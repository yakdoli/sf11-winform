Quarter Circular Gauge Type

 

Essential Gauge now supports quarter circular gauge frames with a multiple directional display.

The following code snippet illustrates on how to create a quarter circular gauges.

 

[XAML]

 

<sfgauge:CircularGauge Height="Auto" Width="Auto" Radius="170" Name="circularGauge1" FrameType="QuarterCircular" Margin="3" GaugeFrameDirection="NorthEast"  > </sfgauge:CircularGauge>

 

[C#]

 

CircularGauge circulargauge1 = new CircularGauge();

circulargauge1.FrameType = CircularFrameType.QuarterCircular;

PivotItem pivotitem = new PivotItem();

pivotitem.Content = circulargauge;

LayoutRoot.Children.Add(pivotitem);
