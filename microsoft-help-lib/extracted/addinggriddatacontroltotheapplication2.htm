Adding GridData Control to the Application

 

Now that we have Created a WPF application and we have seen the basic steps to be followed before adding our Grid controls.

 

In this section, we will see how to add a GridData control to the WPF application and load data from the database.

Step-by-step Procedure to Create a GridData control and Load it with Sample Data

The following steps will add a GridData control and load it with Northwind Customers table.

1.   Setup a data source. Here the data source is a Northwind Table:

 

Figure 7:  Northwind Customers table

 

The preceding screen shot shows a sample data from the Northwind Customers table.

Note: This table is available in your sample installation path:

 

...\My Documents\Syncfusion\EssentialStudio\<Version Number>\Common\Data

 

2.   The binding source is created in XAML code using Object Data Provider (For detailed info, see Data Providers section).

 

[C#]

 

// Connect to a data table.

public class Data

{       

  public static DataTable GetDataTable()       

  {           

    using (SqlCeConnection con = new SqlCeConnection(string.Format(@"Data Source = {0}", LayoutControl.FindFile("Northwind.sdf"))))

    {                

      con.Open();               

      SqlCeDataAdapter sda = new SqlCeDataAdapter("SELECT * FROM Customers", con);               

      DataSet ds = new DataSet();               

      sda.Fill(ds);               

      return ds.Tables[0];           

    }       

  }   

}

 

3.   Creating a binding source using Object Data Provider.

 

[XAML]

 

<Window.Resources>       

<ObjectDataProvider x:Key="CustomerTable" MethodName="GetDataTable" ObjectType="{x:Type local:Data}" />        <CollectionViewSource x:Key="orderSource" Source="{StaticResource CustomerTable}" >       

</CollectionViewSource>   

</Window.Resources>

 

4.   Instantiate a GridData control and bind it to the above data table as follows:

 

[XAML]

 

<syncfusion:GridDataControl x:Name="dataGrid" AutoPopulateColumns="True"    AutoPopulateRelations="False" ShowAddNewRow="False"  ItemsSource="{StaticResource orderSource}">

</syncfusion:GridDataControl>

 

5.   Run the application.
