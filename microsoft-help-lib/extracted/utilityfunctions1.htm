Utility Functions

 

Listed below are some common statistical formulas that are implemented in the Utilities type.

 

 

Statistical Formulas

 

Description

Beta Function

The BetaFunction method returns the beta function for a given value.

Beta Cumulative Distribution

The Beta Cumulative Distribution method returns the Beta cumulative distribution for a given value.

Inverse Beta Cumulative Distribution

The Inverse Beta Cumulative Distribution method returns the Inverse Beta cumulative distribution for a given value.

Gamma Function

The GammaFunction method returns the gamma function for a given value.

Gamma Cumulative Distribution

The Gamma Cumulative Distribution method returns the Gamma cumulative distribution for a given value.

FCumulative Distribution

The F Cumulative Distribution method returns the FCumulative distribution for a given value.

Inverse FCumulative Distribution

The Inverse F Cumulative Distribution method returns the Inverse F Cumulative distribution for a given value.

TCumulative Distribution

The T Cumulative Distribution method returns the T Cumulative distribution for a given value.

Inverse TCumulative Distribution

The Inverse T Cumulative Distribution method returns the Inverse T Cumulative distribution for a given value.

Normal Distribution

The Normal Distribution method returns the Normal distribution for a given value.

Inverse Normal Distribution

Returns the inverse of the standard normal cumulative distribution. The distribution has a mean of 0 (zero) and a standard deviation of one.

Normal Distribution Density

The Normal Distribution Density method returns the Normal distribution density for a given value.

Binomial

The Binomial method returns the Binomial coefficient for a given Value.

Factorial

The Factorial method returns the Factorial for a given Value.(eg 2!=2).

Error Function

The Erf method returns the Error Function for a given Value.

Inverse Error Function

The Inverse Erf method returns the Inverse Error Function for a given Value.
