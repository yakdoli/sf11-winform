Size

The RadioButton and RadioButtonFor controls support three sizes:

·      Larger

·      Medium

·      Smaller

Using Builder

The following steps explain the appearance of the Radio Button and RadioButtonFor controls using Builder.

1.   In the view, invoke the RadioButton and RadioButtonFor helpers with the group name of the radio button as the first argument, followed by the size of radio button and the AutoFormat method with the desired theme as the argument.

[ASPX]

<% Html.MobSyncfusion(). Size ( ButtonSize .Larger) . RadioButton("group1", "large").AutoFormat(MobSkins.BlueLight ).Render(); %>

                RadioButton Larger

                <br/>

<% Html.MobSyncfusion(). Size ( ButtonSize .Medium) . RadioButton("group1", "medium").AutoFormat(MobSkins.BlueLight ).Render(); %>

                RadioButton Medium

                <br/>

    <% Html.MobSyncfusion(). Size( ButtonSize .Smaller) . RadioButton("group1", "small").AutoFormat(MobSkins.BlueLight ).Render(); %>

                RadioButton Smaller

 [Razor]

      @{ Html.MobSyncfusion(). Size ( ButtonSize .Larger) . RadioButton("group1", "large").AutoFormat(MobSkins.BlueLight ).Render(); }

                RadioButton Larger

                <br/>

@{ Html.MobSyncfusion(). Size ( ButtonSize .Medium) . RadioButton("group1", "medium").AutoFormat(MobSkins.BlueLight ).Render(); }

                RadioButton Medium

                <br/>

    @{ Html.MobSyncfusion(). Size( ButtonSize .Smaller) . RadioButton("group1", "small").AutoFormat(MobSkins.BlueLight ).Render(); }

                RadioButton Smaller

 

 

RadioButtonFor

 

[ASPX]

<% foreach (var data in Model)

           { %>     <% Html.MobSyncfusion().RadioButtonFor(model => data.id, data.value, new { name = data.name, @checked = data.ischecked, id = data.id }).OnTouchStart("onStart").OnTouchStop("onStop").Render();%>

        <br/>       <% } %>

[Razor]

@{ foreach (var data in Model)

                @{ Html.MobSyncfusion().RadioButtonFor(model => data.id, data.value, new { name = data.name, @checked = data.ischecked, id = data.id }).OnTouchStart("onStart").OnTouchStop("onStop").Render();         }

 

2.   Build and run the application.
