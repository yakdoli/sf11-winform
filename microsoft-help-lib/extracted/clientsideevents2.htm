Client-Side Events     

 

The various client side events supported by the Editor control are given below.

 

Client-Side Event

Description

OnClientCancel

Specifies the client side function to execute on clicking the Cancel button.

 

This event is cancelable. If false is returned, postback / callback is not performed.

 

Example:

 

<cc1:RichTextEditor ID="RTE1" runat="server" OnClientCancel="OnEditorCancelClick(this)" />

 

[javascript]

function OnEditorCancelClick(EventData)

{

    var bCancel = confirm("Do you want to cancel your changes?");   

    if(!bCancel)return false;

}

OnClientLoad

Specifies the client side function to execute, when the editor is loaded and it is ready for the user to use.

 

Example:

 

<cc1:RichTextEditor ID="RTE1" runat="server" OnClientLoad="OnEditorLoad(this)" />

 

[javascript]

 

function OnEditorLoad(EventData)

{

    alert("RichTextEditor is ready for work");

}

OnClientTextChange

Specifies the client side function to execute, when the text is changed in the editor area.

OnClientUpdate

Specifies the client side function to execute before submit button is initiated.

 

This event is cancelable. Return false to cancel the action.

 

Example:

 

<cc1:RichTextEditor ID="RTE1" runat="server" OnClientUpdate="OnSubmitChanges(this)" />

 

[javascript]

function OnSubmitChanges(EventData)

{

    var bSubmitChanges = confirm("Do you want to submit your changes?");   

    if(!bSubmitChanges)return false;

}

 

 

The following sample demonstrates how to edit an HTML element using RichTextEditor.

 

[aspx]

 

<table>

    <tr>

        <td id="EditElement" ondblclick="ShowRTE()" style="border: 2px solid gray; background-color: #EEEEEE;">

            To edit this html double click on it

        </td>

    </tr>

</table>

<ssw:WaitingPopup ID="Popup" runat="server" Alignment="MiddleCentre">

    <cc1:RichTextEditor ID="RichTextEditor1" runat="server" OnClientLoad="OnRTELoad(this)"

        OnClientUpdate="OnRTEUpdateClick(this)" OnClientCancel="OnRTECancelClick(this)"

        ShowInsertToolbar="False" ShowStyleToolbar="False" Height="186px" Width="557px" />

</ssw:WaitingPopup>

 

[javascript]

var bIsRTEReady = false;

function ShowRTE()

{

    if( bIsRTEReady )

    {

        _sfPopup.ShowPopup();

       

        var sHTML = document.getElementById("EditElement").innerHTML;

        _sfRichTextEditor1.SetHTML( sHTML );

    }

}

 

function HideRTE()

{

    _sfPopup.HidePopup();

}

 

function OnRTELoad(EventData)

{

    bIsRTEReady = true;

}

 

function OnRTEUpdateClick()

{

    document.getElementById("EditElement").innerHTML = _sfRichTextEditor1.GetHTML();

    HideRTE();

    return false;

}

 

function OnRTECancelClick(EventData)

{

    HideRTE();

    return false;

}
