Disabling Spin Buttons

The numeric text box supports disabling spin buttons so that end-users can be prevented from increasing or decreasing values.

Description

Type of property

ShowSpinButton

When set to False, it prevents the spin button from appearing.

Using Builder

The following steps describe how to disable the spin buttons through the builder.

1.   In the View, invoke the numeric text box helper followed by the ShowSpinButton method with the argument set to False.

 

View [ASPX]

<%=Html.Syncfusion().NumericTextBox("myNumeric")

.ShowSpinButton(false)%>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().NumericTextBox("myNumeric")

.ShowSpinButton(false).ToString()))

 

 

2.   Build and run the application.

 

Using Properties Model

The following steps describe how to disable spin buttons through the properties model.

1.   In the Controller, create an instance of NumericTextBoxModel; reset the ShowSpinButton property and pass the instance through the View-Specific Data to the View.

 

[Controller]

public ActionResult Index()

        {

            //Creating instance of NumericTextBoxModel

            NumericTextBoxModel myModel = new NumericTextBoxModel();

            myModel.ShowSpinButton = false;

 

            //pass the instance through view data to the view

            ViewData["myNumeric"] = myModel;

            return View();

        }

 

 

2.   In View, invoke the numeric text box helper with the view data key as the control ID.

 

View[ASPX]

 

<%=Html.Syncfusion().NumericTextBox("myNumeric") %>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().NumericTextBox("myNumeric").ToString()))

 

3.   Build and run the application.

 

Note: Disabling the spin button will disable the spin button only, and not the mouse wheel action that is used to increase or decrease the value.
