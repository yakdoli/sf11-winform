Add CallbackPanel control to a page and then add controls and static text to the control.

The CallbackPanel control can be created as follows.

 

1.   Create a new ASP.NET Web application. For details, see Creating ASP.NET Web Application.

12.  Drag the CallbackPanel control onto the Web Form. Refer to the Concepts and Features section to customize the various settings of the control.

13.  Add controls to the CallbackPanel. (For details, see How to add controls into the panel.)

14.  In Java Script, in response to some event, say button click, for example, call 'callback' method with some arguments on this control's client side object.

15.  Listen to the CallbackPanel's CallbackRefresh server side event for updating and refreshing its child controls.

 

The following code sample demonstrates how to use a CallbackPanel to display server side date, time or day of week.

 

[ASPX]

 

<input type="button" value="Get Server Date" onclick="_sfCallbackPanel1.callback('date')" />

<input type="button" value="Get Server Week Day" onclick="_sfCallbackPanel1.callback('day')" />

<input type="button" value="Get Server Time" onclick="_sfCallbackPanel1.callback('time')" />

<ssw:CallbackPanel ID="CallbackPanel1" runat="server" ClientObjectId="_sfCallbackPanel1"

    OnCallbackRefresh="CallbackPanel1_CallbackRefresh">

    <asp:Label ID="ServerDataLabel" runat="server" Text="Server Info: Select an option above "></asp:Label>

</ssw:CallbackPanel

 

[C#]

 

protected void CallbackPanel1_CallbackRefresh(object sender, Syncfusion.Web.UI.WebControls.Shared.CancellableCallbackEventArgs e)

{

       switch(e.CallbackArgument)

       {

              case "date":

                     this.ServerDataLabel.Text = "Server Date: " + DateTime.Now.Date.ToShortDateString();

                     break;

              case "day":

                     this.ServerDataLabel.Text = "Server Day: " + DateTime.Now.DayOfWeek.ToString();

                     break;

              case "time":

                     this.ServerDataLabel.Text = "Server Time: " + DateTime.Now.TimeOfDay.ToString();

                     break;

       }

}
