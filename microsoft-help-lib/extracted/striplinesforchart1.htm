Striplines For Chart

You can add Striplines (horizontal and vertical) to areas within the plot. You can also optionally repeat these Striplines at specific intervals. Set IsSegmented property to True, to create segmented strip lines.

Adding Striplines

The following code illustrates how to add Striplines (horizontal and vertical) to areas within the plot.

 

[Xaml]

 

<syncfusion:ChartArea.PrimaryAxis>

                                            <syncfusion:ChartAxis ValueType="DateTime" IsAutoSetRange="True">

                                                                  <syncfusion:ChartAxis.StripLines>

                            <syncfusion:ChartStripLine StartFromAxis="True" Offset="2" ContentWidth="50" ContentOrientation="Horizontal" Interior="RosyBrown" StriplineContent="Strip" RepeatEvery="3"  Width="30"/>

                        </syncfusion:ChartAxis.StripLines>

 

                                            </syncfusion:ChartAxis>

                            </syncfusion:ChartArea.PrimaryAxis>

 

[C#]

 

           ChartStripLine cs = new ChartStripLine();

                        cs.StartFromAxis = true;

                        cs.Offset = 2;

                        cs.RepeatEvery = 3;

                        cs.Interior = new SolidColorBrush(Colors. AliceBlue);

                        cs.Content = "StriplineDemo";

                        cs.ContentWidth=40;

                        cs.Width = 30;

                        this.chart1.Areas[0].PrimaryAxis.StripLines.Add(cs);
