Themes

Themes for Schedule Silverlight provide different skins to make the look and feel attractive.

Four themes are available in Schedule Silverlight. They are:

·      Office14Silver - Look like Microsoft Office14 Silver style.

·      Office14Black - Look like Microsoft Office14 Black style.

·      Office14Blue - Look like Microsoft Office14 Blue style.

·      Blend - Look like a Microsoft Blend style.

 

Basic property

 

·      VisualStyle: Sets the themes of the Schedule, the default value is Office14Silver
