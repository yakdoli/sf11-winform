Rotator

 

The Rotator component is used to implement dynamic content of images, text and also other server controls using SlideTemplate.

 

·      Easily creates news scroller, product slideshows, feature highlights, and so on.

·      Displays different content fragments each time a user visits or refreshes the page.

·      Supports data binding to the datasources like XML content file, dataset, datatable, and so on.

·      Supports multiple instances in a page.

·      The content can be scrolled in any of the four directions by setting the ScrollDirection property to either Up, Down, Left or Right.

·      In content scrolling or slideshows, the transition can be made to pause when the mouse hovers over the control.

·      Allows to easily apply transition effects such as fading, pixelate, and so on.

·      The speed of scrolling and smooth-scrolling can be adjusted.

·      Rotator control can be hosted in Safari browser too.
