Chart Font Settings

Font settings of each and every part of Chart such as Chart, ChartArea, ChartLegend and ChartAreaLegend can be customized with the below given properties.

 

·      FontFamily

·      FontSize

·      FontStretch

·      FontStyle

·      FontWeight

·      Foreground

 

Note: Font settings set to the Chart will be applied to all the units of chart. However, properties set separately for those units such as ChartArea, ChartAxis, ChartLegend will override, these settings.
