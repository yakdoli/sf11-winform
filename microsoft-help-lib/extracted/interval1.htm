Interval

 

The Interval property is used to specify the step value for the control. When the Up button or Down button is clicked, the value in the control will be incremented / decremented according to the step value. The following code illustrates this.

 

[XAML]

 

<syncfusion:NumericUpDown x:Name="NumericUpDown1" Interval="10" />

 

[C#]

 

NumericUpDown numericUpDown = new NumericUpDown();

numericUpDown.Interval = 10;
