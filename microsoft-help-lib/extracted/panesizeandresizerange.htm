PaneSize and ResizeRange

These properties allow you to set the size and resize range of each splitter pane added in the Splitter control.

 

Properties

Name

Description

Type

Value Accepted

Dependencies

PaneSize

 

This property contains all splitter pane-related properties such as PaneSize, Resizable, ContentTemplate, Scrollable, SplitterBar.

SplitterPanesActionMethod

Add the collection of splitterpanes

NA

ResizeRange

Specifies the resizing range for panes.

Double

Any integer value.

Default value is 20.

Should be less than pane size.

 

You can set the PaneSize and ResizeRange properties in both ASPX and Razor engine modes.

 

[ASPX]

 

<%=Html.Syncfusion().Splitter("splitter").SplitterPanes(panes1=>{

 

panes1.Add().PaneSize(Unit.Percentage(50)).ResizeRange(40).ContentTemplate(()=>{%>

 

             <p>inner first pane</p>

 

<%}).SplitterBar(b=>b.AllowSplitterBar(true));

 

panes1.Add()().PaneSize(Unit.Percentage(50)).ResizeRange(40).ContentTemplate(()=>{%>

 

             <p>inner second pane</p>

 

   <%});

})

.Orientation(SplitterOrientation.Horizontal) %>

 

   

 

[Razor]

 

@{Html.Syncfusion().Splitter("splitter").SplitterPanes(panes1=>{

 

panes1.Add().PaneSize(Unit.Percentage(50)).ResizeRange(40).ContentTemplate(

 

@<p>inner first pane</p>

 

).SplitterBar(b=>b.AllowSplitterBar(true));

 

panes1.Add().PaneSize(Unit.Percentage(30)).ResizeRange(70).ContentTemplate(

         @<p>inner second pane</p>

  );

})

.Orientation(SplitterOrientation.Horizontal).Render() }
