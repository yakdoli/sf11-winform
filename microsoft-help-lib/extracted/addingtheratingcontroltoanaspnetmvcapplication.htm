Adding the Rating Control to an ASP.NET MVC application

Refer to the Getting Started section for the prerequisites needed to add a rating control to an ASP.NET MVC application.

The following steps explain how to add a rating control.

1.   In View, invoke the rating helper with the control ID as the first argument.

 

 View[ASPX]

 

<%=Html.Syncfusion().Rating("myRating")%>

 

 

 View[cshtml]

 

@{ Html.Syncfusion().Rating("myRating").Render();}

 

 

2.   Build and run the application.
