Setting ItemSource to Jumplist

 

DataSource for JumpList can be set using the ItemSource property. This property gets or sets a collection that is used to generate the content for the JumpList control.

 The following code illustrates how to set the ItemSource for the JumpList

 

[C#]

   

    //Creating a list Collection 

            List<string> contactlist = new List<string>(128);

            contactlist.Add("Byron Contreras");

            contactlist.Add("Sylvester Martinez");

            contactlist.Add("Wylie Love");

            contactlist.Add("Kamal Cooke");

            contactlist.Add("Channing Mccullough");

            contactlist.Add("Robert Chapman");

            contactlist.Add("Reese Hale");

            contactlist.Add("Stephen Crane");

            contactlist.Add("Lester Robertson");

            contactlist.Add("Nolan Maxwell");

            contactlist.Add("Wade Randolph");

            contactlist.Add("August Dean");

            contactlist.Add("Hasad Duncan");

            contactlist.Add("Ali Battle");

            contactlist.Add("Xenos Hammond");

 

       //Setting the ItemSource to Jumplist

            jumplist.ItemsSource = contactlist;
