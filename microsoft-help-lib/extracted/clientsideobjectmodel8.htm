Client-Side Object Model

 

Method

Description

Parameters

Return Type

ShowContextTab(name)

Shows the contextual tab for the selected items in the page.

Name of the contextual tab

NA

ShowTab(name)

Shows the ribbon tab

Name of the ribbon tab

NA

HideContext(name)

Hides the contextual tab for the selected items in the page

Name of the contextual tab

NA

HideTab(name)

Hides the ribbon tab

Name of the ribbon tab

NA

 

To raise and process the client-side methods:

 

1.   Add a new Web Page in your project.

2.   Drag the Ribbon Control and add the required items in the .aspx page.

[ASPX]

<syncfusion:Ribbon ID="Ribbon1"  AutoFormat="office2010blue"  ClientObjectId="ribbon" runat="server" Width="635px">

<TabContext>

<syncfusion:RibbonTabContext Name="context2" Text="Settings" ContextColor ="#FDEA12">

                      <Tabs>

                        <syncfusion:RibbonTab Text="Design" Name="RibbonTab11">

                            <Groups>                                

                                <syncfusion:RibbonGroup Text="Links" ShowExpander="false">

                                <Division>

                                    <syncfusion:RibbonGroupDivison Name="division18">

                                        <Content>

                                            <syncfusion:ButtonAdv  OnClientClick="OnChange" DisplayType="ImageAboveText" runat="server" ID="OfficeUIButton27"   Text="Hyper Link " ImageUrl="/Ribbon/Hyperlink32.png">

                                            </syncfusion:ButtonAdv>

                                        </Content>

                                    </syncfusion:RibbonGroupDivison>

                                    <syncfusion:RibbonGroupDivison Name="division19">

                                        <Content>

                                            <syncfusion:ButtonAdv OnClientClick="OnChange" DisplayType="ImageAboveText" runat="server" ID="OfficeUIButton29"  Text="Book Mark" ScreenTip="<b>Book mark</b>" ImageUrl="Ribbon/Bookmark32.png">

                                                <Items>

                                                </Items>

                                            </syncfusion:ButtonAdv>

                                        </Content>

                                    </syncfusion:RibbonGroupDivison>

                                </Division>

                            </syncfusion:RibbonGroup>

                            </Groups>

                        </syncfusion:RibbonTab>

                    </Tabs>

    </syncfusion:RibbonTabContext>

 </TabContext>

</syncfusion:Ribbon>

<syncfusion:ButtonAdv ID="OfficeUIButton2" Text ="Show Contextual Menu" OnClientClick ="ShowContext" CustomClass ="contextbutton" runat ="server" DisplayType ="TextOnly" ></syncfusion:ButtonAdv>

 

[JavaScript]

<script type="text/javascript">

function ShowContext() {

            ribbon.ShowContextTab("context2");

            ribbon.ShowTab("RibbonTab11");

        }

        function HideContext() {

            ribbon.HideContext("context2");

            ribbon.HideTab("RibbonTab11");

        }

</script>
