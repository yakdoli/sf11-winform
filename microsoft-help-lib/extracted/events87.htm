Events

 

The following events are associated with the CheckedListBox control.

 

Event

Description

SelectionChanged

This event is raised when the selection is changed.

CheckedItemsChanged

This event is raised when checked items are changed.

 

The following code examples illustrate how to handle some of the preceding events.

 

[XAML]

 

<syncfusion:CheckedListBox Name="checklistbox" Height="300" Width="200" CheckedItemsChanged="CheckedListBox_CheckedItemsChanged" SelectionChanged="CheckedListBox_SelectionChanged">

<syncfusion:CheckedListBoxItem Content="Mexico" LeftImageSource="Image/mexi.jpg" />

<syncfusion:CheckedListBoxItem Content="Canada" LeftImageSource="Image/can.jpg" />

<syncfusion:CheckedListBoxItem Content="Bermuda" LeftImageSource="Image/ber.jpg" />

</syncfusion:CheckedListBox>

 

[C#]

 

checklistbox.CheckedItemsChanged += new PropertyChangedCallback(CheckedListBox_CheckedItemsChanged);

checklistbox.SelectionChanged += new PropertyChangedCallback(CheckedListBox_SelectionChanged);
