Appointment Content

 

Text can be set for an appointment using the Subject property.

 

Text can also be set using the Location property, but it will be displayed inside '()' brackets.

 

Appointment Property

Description

Subject

Specifies the text to be displayed in an appointment.

Location

Specifies the text to be displayed in an appointment, inside '()'.

 

Note: The Location text appears after the Subject text.

 

[ASPX]

 

<Appointments>

<Syncfusion:ScheduleWebAppointment UniqueID="22" StartTime="01/08/2008 05:23:00" EndTime="01/08/2008 06:53:00"

Subject= "Meeting with Andrew" LocationValue="Text that appears inside brackets">

</Syncfusion:ScheduleWebAppointment>

</Appointments>

 

[C#]

 

app1.Subject = "Meeting with Andrew";

app1.Location = "Text that appears inside brackets";

 

[VB]

 

Private app1.Subject = "Meeting with Allen"

Private app1.Location = "regarding product release"
