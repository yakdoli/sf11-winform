Doughnut Chart

 

Doughnut chart is similar to the Pie chart. The only difference is that there is a hole at the center of the Doughnut chart. The Doughnut chart supports all Pie chart features. It can render only one series in the Chart Area. The value of the "hole" can be set by using the DoughnutCoefficient property of ChartDoughnutType class.

 

The following code example illustrates how to create a Doughnut Chart.

 

[XAML]

 

<syncfusion:ChartSeries Type="Doughnut" Label="Student Marks" syncfusion:ChartPieType.ExplodedAll="True" syncfusion:ChartDoughnutType.DoughnutCoefficient="0.5" Interior="{StaticResource Series1}" StrokeThickness="0" >

    <syncfusion:ChartSeries.AdornmentsInfo>

        <syncfusion:ChartAdornmentInfo Visible="True" SegmentLabelContent="Percentage" SegmentLabelFontSize="12"

        SegmentLabelFontWeight="Bold" SegmentIsOut="True"/>

    </syncfusion:ChartSeries.AdornmentsInfo>

</syncfusion:ChartSeries>

 

[C#]

 

ChartArea area = new ChartArea();

 

// Create Doughnut Chart.

ChartSeries series = new ChartSeries();

series.Type = ChartTypes.Doughnut;

ChartDoughnutType.SetExplodedAll(series, true);

ChartDoughnutType.SetDoughnutCoefficient(series, 0.5);

 

// Create and initialize the Series Segment Label.

ChartAdornmentInfo adornment = new ChartAdornmentInfo();

adornment.Visible = true;

adornment.SegmentLabelContent = LabelContent.Percentage;

series.AdornmentsInfo = adornment;

area.Series.Add(series);
