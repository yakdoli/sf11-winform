SetCurrentReport

The following code snippet explains setting an OlapReport to CurrentReport of an OlapDataManager using SetCurrentReport method:

[C#]

OlapDataManager.SetCurrentReport(olapReport);

 

[VB]      

OlapDataManager.SetCurrentReport(olapReport)
