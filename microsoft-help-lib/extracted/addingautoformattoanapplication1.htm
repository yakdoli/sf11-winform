Adding AutoFormat to an Application

 

This can be enabled by setting the following properties to OlapGrid.

 

[ASPX]

 

<%=Html.Syncfusion().Olap().OlapGrid("olapgrid",(OlapDataManager)ViewData["DataManager"])

                .ActionMode(ActionMode.Ajax);

 %>
