Linear Marker Pointer

Linear Marker Pointer is used to represent the values in the same manner like a bar pointer. But we can specify the placement of the marker pointer and marker style. The following are few important properties of Linear Marker Pointers.

 

Table 20: Property Table

Property

Description

BackgroundBrush

To set the Background brush for the pointer.

BorderBrush

To set the Border brush for the pointer.

BorderWidth

To set the Border width of the pointer cap. Default value is 0.

MarkerStyle

To specify the Marker style of the pointer. Default value is Rectangle.

PointerWidth

To set width of the pointer. Default value is 0.

PointerLength

To set the length of the pointer. Default value is 0.

PointerPlacement

To set the placement where the pointer will show on the scale.

 

Cross-draw on middle of the scale.

Inside-draw inside the scale.

Outside-draw outside the scale.

 

Default value is Cross.

Value

To set the value of the pointer. Default value is 0.

MarkerCustomGeometry

To specify a custom geometry for the marker pointer.

EnablePointerInteraction

Using this property, the Linear Pointer can be  dynamically changed using the keyboard or mouse.

 

Marker can be customized using the MarkerStyle property. Following are the in-built styles available for the MarkerStyle property.

 

·      Ellipse—marker displays in elliptical form.

·      Diamond—marker displays in diamond form.

·      Trapezoid—marker displays in trapezoidal form.

·      Pentagon—marker displays in pentagonal form.

 

The following code examples illustrate how to set these properties:

 

[XAML]

 

<my:LinearGauge Grid.Column="1" Height="310" Name="linearGauge1" Width="131.188" Margin="15.36,3,27,10">

    <my:LinearGauge.Scales>

        <my:LinearScale BorderWidth="3" MajorIntervalValue="10" Maximum="100" Minimum="0" MinorIntervalValue="2" ScaleBarLength="220"             ScaleBarSize="15" ScaleStyle="Rectangle" ShadowOffset="0">

            <my:LinearScale.Pointers>

                <my:LinearMarkerPointer BorderWidth="1" MarkerStyle="Triangle" PointerLength="30" PointerWidth="8" />

            </my:LinearScale.Pointers>

        </my:LinearScale>

    </my:LinearGauge.Scales>

</my:LinearGauge>

 

[C#]

 

LinearScale scale = new LinearScale();

scale.BackgroundBrush = Brushes.GreenYellow;

scale.BorderBrush = Brushes.DarkGreen;

scale.BorderWidth = 2;

scale.Minimum = 0;

scale.Maximum = 50;

scale.MinorIntervalValue = 2;

scale.MajorIntervalValue = 10;

scale.ScaleBarLength = 220;

scale.ScaleBarSize = 25;

scale.ScaleStyle = LinearScaleStyle.RoundedRectangle;

this.lineargauge1.Scales.Add(scale);

 

// Adding Linear Marker Pointer to the Linear Scale.

LinearMarkerPointer markerPointer = new LinearMarkerPointer();

markerPointer.BorderBrush = Brushes.Gold;

markerPointer.BorderWidth = 1;

markerPointer.BackgroundBrush = Brushes.Goldenrod;

markerPointer.MarkerStyle = MarkerStyle.Triangle;

markerPointer.PointerLength = 30;

markerPointer.PointerWidth = 8;

markerPointer.EnablePointerInteraction = true;

markerPointer.PointerPlacement = ScalePlacement.Outside;

markerPointer.Value = 10;

scale.Pointers.Add(markerPointer);
