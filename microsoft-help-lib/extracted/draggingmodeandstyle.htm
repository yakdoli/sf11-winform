Dragging Mode and Style

 

Window Control can be set with different dragging modes and dragging styles.

 

Dragging Modes

 

Dragging Mode

Description

FreeStyle (Default)

Window Control can be moved in any direction.

Horizontal

Window Control can be moved in horizontal direction only.

Vertical

Window Control can be moved in vertical direction only.

None

Window Control is fixed at its position. It cannot be moved.

 

Dragging Styles

 

Dragging Style

Description

Original

Entire Window can be seen when dragged.

SolidOutline (Default)

Outline of the Window can be seen when dragged.

DashedOutline

Dashed Outline can be seen when dragged.

TransparentRectangle

Transparent Rectangle can be seen when dragged.

None

No rectangle can be seen when dragged.
