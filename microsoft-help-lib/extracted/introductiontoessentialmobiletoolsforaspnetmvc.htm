Introduction to Essential Mobile Tools for ASP.NET MVC

Essential Tools for Mobile MVC contains a comprehensive set of light weight, AJAX-enabled, stable and feature-rich professional user interface components that are built to suit the programming model of ASP.NET MVC framework.

 

List of Controls

The following controls have been implemented in Essential Mobile Tools for MVC:

·      Dialog

·      Header and Footer

·      Listbox

·      Menu

·      Progressbar

·      Rating

·      ScrollPanel

·      Slider

·      Tabs

·      Toolbar

 

 

Key Features

Some of the important features of Mobile Tools for MVC are listed below:

 

·      HTML 5 support.

·      Touch support

·      Databinding support.

·      ClientSide filtering support in listbox.

·      Context menu support in menus

·      Exact, half and full precision support for better user experience and feedback

·      Range slider and multiple handle support in the Slider control

·      Rich set of client side events and methods in all the controls

·      Four built-in themes that make Mobile tools look attractive, while giving an option to users to customize visuals
