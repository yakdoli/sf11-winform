Date Time Format

 

The following Date and Time formats are available in RichTextEditor control.

 

Format

Description

DD-MM-YYYY

Date- Month-Year (01-12-2008).

MM-DD-YYYY

Month- Date- Year (12-01-2008).

YYYY-MM-DD

Year- Month- Date (2008-12-01).

DD/MM/YYYY

Date/Month/ Year (01/12/2008).

MM/DD/YYYY

Month/Date/Year (12/01/2008).

YYYY/MM/DD

Year/ Month/ Date (2008/12/01).

DDD MMM DD YYYY

Short Day Short Month Date Year(Mon Dec 01 2008).

DDDD, MMMM DD, YYYY

Long Day, Long Month Date Long Year(Monday, December 01, 2008) (Default Property).

HH:MM:SS AM/PM

Hours:Minutes:Seconds AM/PM (12:01:45 PM).

HH:MM:SS

Hours:Minutes:Seconds(12:01:45).

HH:MM:SS:MS

Hours:Minutes:Seconds:Milli Second(12:01:45 :540).

HH:MM:SS:MS AM/PM

Hours:Minutes:Seconds:Milli Second AM/PM (12:01:45 :540 PM).

HH:MM:SS TZ

Hours:Minutes:Seconds Time Zone(12:01:45 EST).

 

[ASPX]

 

<syncfusion:RichTextEditor ID="RichTexteditor1" runat="server" DateFormat="DD-MM-YYYY" TimeFormat="HH:MM:SS AM/PM"> </syncfusion:RichTextEditor>

 

[Client Side API]

 

_sfRichTexteditor1.SetDateFormat('DD-MM-YYYY');

_sfRichTexteditor1.SetTimeFormat(' HH:MM:SS AM/PM ');

 

[C#]

 

protected void Page_Load(object sender, EventArgs e)

{

    this.RichTexteditor1.DateFormat = "DD-MM-YYYY";

    this.RichTexteditor1.TimeFormat = "HH:MM:SS AM/PM";

}

 

[VB.NET]

 

Protected Sub Page_Load(ByVal sender As Object, ByVal e As EventArgs)

{

    Me.RichTexteditor1.DateFormat = "DD-MM-YYYY"

    Me.RichTexteditor1.TimeFormat = "HH:MM:SS AM/PM"

}
