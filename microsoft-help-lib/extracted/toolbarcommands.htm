Toolbar Commands

 

The Editor contains a rich set of tool options included in the built-in toolbars of the RichTextEditor to allow the users edit content comprehensively. The buttons incorporated in the toolbar and its functionalities are listed below.

 

Image

Icon Name

Insert Toolbar

Description

_Insert_InsertSmiley

Insert Smiley

Inserts emote icons in the editor.

_Insert_Upload

UploadImage

Uploads image to server.

_Insert_InsertImage

Insert Image

Inserts images in the editor.

_Insert_InsertSymbol

Insert Symbol

Inserts symbols into the editor.

_Insert_PageBreak

Insert Page Break

Inserts a page break in the current cursor position.

_Insert_InsertDate

Insert Date

Inserts current date.

_Insert_InsertTime

Insert Time

Inserts current time.

_Insert_InsertRule

Insert Horizontal Rule

Inserts horizontal rule in the current cursor position.

_Insert_InsertParagraph

Insert Paragraph

Positions the cursor at new paragraph.

_Insert_Link

Link

Creates a link to the file in the internet or your local system.

_Insert_Unlink

UnLink

Removes hyperlink from the selected text or image.

_Insert_InsertFormElement

Insert Form Element

Inserts the form element from the set of predefined options.

 

Image

Icon Name

Edit Toolbar

Description

_Edit_SpellCheck

Spell Check

Does a spell checking.

_Edit_Undo

Undo (Ctrl+Z)

Undo the last action.

_Edit_Redo

Redo (Ctrl+Y)

Repeats the last action which has been undone.

_Edit_Cut

Cut

Cuts selected text from the editor.

_Edit_Copy

Copy

Copies the selected text from the editor.

_Edit_Paste

Paste

Pastes the cut or copied text in the editor.

_Edit_PasteWord

Paste From word

Pastes as plain text.

_Edit_SelectAll

Select All

Selects entire content of the editor.

_Edit_FindAndReplace

Find and Replace

Finds the specified text and replaces it with the given text.

Standard Toolbar

Description

_Standard_New

Create New Document

Opens a new Editor.

_Standard_OpenRemote

Open remote document

Opens the Open dialog box to choose a file to be opened.

_Standard_SaveLocal

Save local document

_Standard_PrintPreview

Print Preview

_Standard_Print

Print

Icon Name

Table Toolbar

Description

_Table_InsertTable

Insert Table

Inserts a table.

_Table_InsertTableRow

Insert Table Row

Inserts a row in the table.

_Table_InsertTableCell

Insert Table Column

Inserts a column in the table.

_Table_DeleteTableRow

Delete Table Row

Deletes a row from the table.

_Table_DeleteTableCell

Delete Table Column

Deletes a column from the table.

_Table_SplitTableCell

Split Table Cell

Splits the cell into two.

_Table_MergeTableCell

Merge Table Cells

Merges the adjacent cells.

_Table_ShowTableBorder

Show/Hide Table Border

Shows or hide the border of the table.

 

Image

Icon Name

Format Toolbar

Description

_Format_Bold

Bold (Ctrl+B)

Bolds the highlighted text, if the text is already in bold, then it will be removed.

_Format_Italic

Italic (Ctrl+I)

Italicizes the highlighted text in the editor, if the text is already in italicized, then it will be removed.

_Format_Underline

Underline (Ctrl+U)

Underlines the highlighted text in the editor, if the text is already in underlined, then it will be removed.

_Format_Strike

Strikethrough

Strikes the selected text.

_Format_LeftAligment

Align Left

Aligns the selected text to the left.

_Format_CenterAligment

Center

Aligns the selected text at the center.

_Format_RightAligment

Align Right

Aligns the selected text to the right.

 

_Format_JustifyAligment

Justify

Justifies the selected text.

_Format_OrderList

Numbering

Creates a numbered list for the selection.

_Format_UnorderList

Bullets

Creates a bulleted list for the selection.

_Format_Indent

Increase Indent

Applies indents to the paragraph.

_Format_Outdent

Decrease Indent

Applies negative indent to the paragraph.

_Format_Superscript

Superscript

Reduces font size of the selected text and raises the text above the baseline.

_Format_Subscript

Subscript

Reduces font size of the selected text and lowers the text below the baseline.

_Format_DirLeft

Left-To-Right

Enters text from left to right.

_Format_DirRight

Right-To-Left

Enters text from right to left.

_Format_Upper

To Uppercase

Converts text to upper case.

_Format_Lower

To Lowercase

Converts text to lower case.

_Format_CleanHTML

Clean HTML

Move cursor to the end.

_Format_Remove

Remove Formatting

Clears any format applied to the selected text.
