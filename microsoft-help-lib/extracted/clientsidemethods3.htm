The following steps explain the use of client side methods of generic drop-down.

1.   In View, create the drop-down contents and invoke the generic drop-down helper with the Control ID as the first argument followed by the TargetContentId method with the drop-down contents ID as the argument.

 

View[ASPX]

 

<div id="drop-down-contents" style="visibility: hidden">

        <div>

            <img src='<%= Url.Content("~/Content/taj.jpg")%>' />

            <a href="#">Taj Mahal</a></div>

        <div>

            <img src='<%= Url.Content("~/Content/colosseum.jpg")%>' />

            <a href="#">Colosseum</a></div>

        <div>

            <img src='<%= Url.Content("~/Content/greatwall.jpg")%>' />

            <a href="#">Great Wall </a>

        </div>

        <div>

            <img name="Machu Picchu" src='<%= Url.Content("~/Content/machu.jpg")%>' />

            <a href="#">Machu Picchu</a></div>

        <div>

            <img name="Petra" src='<%= Url.Content("~/Content/petra.jpg")%>' />

            <a href="#">Petra</a></div>

        <div>

            <img name="Pyramid" src='<%= Url.Content("~/Content/pyramid.jpg")%>' />

            <a href="#">Pyramids </a>

        </div>

       </div>

       <%=Html.Syncfusion().GenericDropDown("myDropDown")

       .TargetContentId("drop-down-contents")

.AutoFormat(Skins.Monochrome)%>

2.   In Javascript, use the client side methods as given below.

 

[Javascript]

 

<script type="text/javascript">

       

        //Event to change the text of generic drop-down on

        //every click of its contents

        $("#drop-down-contents div").bind('click', function () {

            $find("myDropDown").setText($(this).find('img')[0].name);

        });

 

        //method to get the previously displayed text

        function GetOldText() {

            var oldText = $find("myDropDown").getOldText();

        }

 

        //method to display the popup panel

        function ShowPopupPanel() {

            $find("myDropDown").showPopup();

        }

 

        //method to hide the popup panel

        function HidePopupPanel() {

            $find("myDropDown").hidePopup();

        }

 

       </script>

 

 

3.   Build and run the application.

You can observe the text box value changing for every click of the drop-down items.
