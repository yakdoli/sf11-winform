Segment Customization

You can set the distance between character segments using SegmentSpacing property. This property is used to set the width of character segments. The below code snippets illustrates this property.

 

[XAML]

 

<syncfusion:DigitalGauge Name="digitalGauge" Width="400" Height="100" Value="12.356 RPM" CharacterSpacing="4.5" SegmentSpacing="0.9" SegmentWidth="2"/>

 

[C#]

 

digitalGauge.SegmentSpacing = 0.9;

digitalGauge.SegmentWidth = 2;
