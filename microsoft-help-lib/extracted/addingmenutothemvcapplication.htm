Adding Menu to the MVC application

In the Getting Started section, we discussed how to create an MVC application and add Tools package to the application. This section guides you to add Menu control to an application.

1.   In View, create ul-li hierarchy of menu items and invoke the menu helper with the menu contents ID as the first argument.

 

View[ASPX]

<ul id="myMenu" style="visibility: hidden">

        <li id="Products">

            <img src='<%= Url.Content("~/Images/products.png")%>' />

            <a>Products</a>

            <ul>

                <li><a>ASP.NET MVC</a> </li>

                <li><a>ASP.NET</a></li>

                <li><a>Windows Forms</a> </li>

            </ul>

        </li>

        <li class="separator"></li>

        <li id="Support">

            <img src='<%= Url.Content("~/Images/help.png")%>' />
            <a>Support</a>

            <ul>

                <li><a>Direct-Trac Support</a></li>

                <li><a>Knowledge Base</a></li>

                <li><a>Community Forums</a></li>

            </ul>

        </li>

        <li class="separator"></li>

        <li id="Sales">

            <img src='<%= Url.Content("~/Images/Buy.png")%>' />
            <a>Sales</a>

            <ul>

                <li><a>Order Online</a></li>

                <li><a>FAQ</a></li>

                <li><a>Price List</a></li>

            </ul>

        </li>

        <li class="separator"></li>

        <li id="Downloads">

            <img src='<%= Url.Content("~/Images/download.png")%>' />
            <a>Downloads</a>

            <ul>

                <li><a>Evaluation</a></li>

                <li><a>Latest Version</a></li>

                <li><a>Version History</a></li>

            </ul>

        </li>

        <li class="separator"></li>

        <li id="Company">

            <img src='<%= Url.Content("~/Images/company.png")%>' />
            <a>Company</a>

            <ul>

                <li><a>About Us</a> </li>

                <li><a>News</a> </li>

                <li><a>Careers</a> </li>

            </ul>

        </li>

    </ul>

    <%=Html.Syncfusion().Menu("myMenu") %>

 

 

 

View[cshtml]

            </ul>

        </li>

    </ul>

    @{ Html.Syncfusion().Menu("myMenu").Render(); }

 

 

Note: The style attribute visibility of the menu contents is set to hidden for better rendering on page load. The visibility will be reset internally once the resources related to the control gets loaded completely. The <li> tags with class attribute set to “separator” are optional and are used to render separators between the two menu items.

 

2.   Run the application.
