Bubble Chart

 

Bubble Chart is an extension of the Scatter Chart (or XY Chart) where each data marker is represented by a circle whose dimension forms a third variable. Consequently, bubble charts allow three-variable comparisons, allowing easy visualization of complex interdependencies that are not apparent in two-variable charts. Bubble charts are frequently used in market and product comparison studies.

The following code snippets illustrate how to create a Bubble Chart.

 

[XAML]

 

  <syncfusion:ChartSeries Type="Bubble" syncfusion:ChartBubbleType.MinRadius="10" syncfusion:ChartBubbleType.MaxRadius="30" EnableEffects="True"   x:Name="Series1" Label="2009" Width="auto"  StrokeThickness="2" />

              

 <syncfusion:ChartSeries Type="Bubble" syncfusion:ChartBubbleType.MinRadius="10" syncfusion:ChartBubbleType.MaxRadius="20" EnableEffects="True"    x:Name="Series2" Label="2010" Width="auto"  StrokeThickness="2" />

 

 

[C#]

 

Chart1.Areas[0].Series[0].Type = ChartTypes. Bubble;

Chart1.Areas[0].Series[1].Type = ChartTypes. Bubble;
