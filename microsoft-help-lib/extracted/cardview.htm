Card View

 

The Card View shows how to use data row templates to create a custom cell layout within rows.

The Eval function is used to define one-way (read-only) binding. It takes the name of a data field and returns a string containing the value of that field from the current record in the datasource.

 

Figure 106

 

Steps to Create a Card View Template

 

1.   Drag and drop the GridGrouping control to the page and establish the connectivity to the database.

2.   Define the columns to be visible within the TableDescriptor tag.

 

[ASPX]

 

<VisibleColumns>

<syncfusion:GridVisibleColumnDescriptor Name="SmallPhoto">

</syncfusion:GridVisibleColumnDescriptor>

<syncfusion:GridVisibleColumnDescriptor Name="City">

</syncfusion:GridVisibleColumnDescriptor>

</VisibleColumns>

 

3.   Create a blank ColumnDescriptor, and define an ItemTemplate with the display requirements.

 

[ASPX]

 

<syncfusion:GridColumnDescriptor MappingName="City" HeaderText="Card View Template">

<ItemTemplate>

    <div style="padding: 5px">

        <table class="CardTable" cellpadding="3" cellspacing="2">

            <tr>

                <td class="CardHeader">

                    First Name

                </td>

                <td>

                    <%#GetFName(Container)%>

                </td>

                <td class="CardHeader">

                    Last Name

                </td>

                <td>

                    <%#GetLName(Container)%>

                </td>

            </tr>

            <tr>

                <td class="CardHeader">

                    Title

                </td>

                <td colspan="3">

                    <%#GetTitle(Container)%>

                </td>

            </tr>

            <tr>

                <td class="CardHeader">

                    Birth Date

                </td>

                <td>

                    <%#GetBirth(Container)%>

                </td>

                <td class="CardHeader">

                    Hire Date

                </td>

                <td>

                    <%#GetHire(Container)%>

                </td>

            </tr>

        </table>

    </div>

</ItemTemplate>

</syncfusion:GridColumnDescriptor>

 

4.   Display the data in the record dynamically, using the GetValue function.

 

[C#]

 

//for retrieving Name to the TemplateColumn

protected string GetFName(GridCell container)

{

string name;

Record rowRecord = container.Row.Record;

name = rowRecord.GetValue("FirstName").ToString();

return name;

}

 

protected string GetLName(GridCell container)

{

string name;

Record rowRecord = container.Row.Record;

name = rowRecord.GetValue("LastName").ToString();

return name;

}

 

//for retrieving Title to the TemplateColumn
