Adding Ticker control inside Rotator

 

This tutorial shows how to use Ticker control inside the Rotator.

 

1.   Add Ticker control inside the Rotator control's slide template.

30.  Bind the data to the ticker control as shown below. Refer to Databinding support for Rotator control.

 

[aspx]

   

<cc1:rotator id = Rotator1 runat = "server" ScrollInterval = "5" width = "300" height = "100" DataSource = "<%# dataSet11 %>" DataMember = "Categories" SlidePause = "1000"  BackColor = "#FFFFC0" ScrollDirection = "Down">

   <SlideTemplate>

       <table height="100" width="300" border="0">

           <tr width="300" height="50">

           <td width="150">

              <cc1:Ticker id="Ticker1" runat="server" Text='<%# DataBinder.Eval(Container.DataItem,"CategoryName") %>'>

              </cc1:Ticker>

           </td>

           </tr>

           <tr width="300">

           <td width="300" colspan="2" height="50">

              <cc1:Ticker id="Ticker2" runat="server" Text='<%# DataBinder.Eval(Container.DataItem,"Description") %>'>

              </cc1:Ticker>

           </td>

           </tr>

      </table>

   </SlideTemplate>

</cc1:rotator>
