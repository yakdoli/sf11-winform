Style Settings

 

CSS definitions can be applied for setting the look and feel of the dropdown. The various style properties supported by AutoCompleteTextBox are given below.

 

Property

Description

DDBackColor

Specifies the back color of the dropdown.

DDcssClass

Specifies the styles to be applied to the dropdown.

 

 

Figure 32: AutoComplete with style settings

 

1.   The CSS definitions must be defined. Below is listed the CSS definitions used for the header and mouse over action.

 

[C#]

 

<head runat="server">

   <title>Templates</title>

    

    <style  type="text/css"  >

        .CaptionClass

        {

            Color:white;

            text-align:left ;

            background-color:#666E98;

        }

       .MouseSelection

       {

            background-color:#ff9933;

            cursor:hand;

        }

    </style> 

</head>

 

2.   The styles must be applied to the respective style properties.

 

[C#]

 

<body bgcolor="#f6f9ff">

  <form id="form1" runat="server">

    <table>

      <tr>

        <td><asp:Label ID="Label5" runat="server" Font-Bold="False" Text="Select Product:"></asp:Label></td>

        <td>

          <cc1:AutoCompleteTextBox ID="AutoCompleteTextBox1" runat="server" DataSourceID="AccessDataSource2" Width="323px" DDcssClass="MouseSelection" DataKeyField="productname">

<%--Template Definition--%>                       

          </cc1:AutoCompleteTextBox>

        </td>

      </tr>

    </table>

  </form>

</body>
