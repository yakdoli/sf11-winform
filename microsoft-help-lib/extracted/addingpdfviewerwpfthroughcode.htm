Adding PDF Viewer WPF through code

Add the following references:

·      Syncfusion.Compression.Base

·      Syncfusion.Core

·      Syncfusion.Pdf.Base

·      Syncfusion.PdfViewer.Wpf

·      Syncfusion.Shared.Wpf

 

Add the following namespace in XAML:

[XAML]

xmlns:syncfusion="clr-namespace:Syncfusion.Windows.PdfViewer;assembly=Syncfusion.PdfViewer.WPF"

 

Add the following code in XAML:

[XAML]

<syncfusion:PdfViewerControl Name="pdfViewerControl1"/>

 

 

For more information on viewing PDF files, refer to Viewing PDF Files.
