Animation

 

You can set animation for the content in the gallery, when the gallery size is changing, by using the AllowedAnimation property.

 

You can set the animation to the following six layouts.

 

·      All

·      Layout

·      Drag

·      New

·      None

·      Resize

 

Use the following code to set the animation option to All.

 

[XAML]

 

<!-- Adding Gallery -->

<syncfusion:Gallery Name="gallery" AllowedAnimations="All">

 

  <!-- Adding GalleryGroup -->

  <syncfusion:GalleryGroup Name="galleryGroup" Header="Photos">

 

    <!-- Adding GalleryItems -->

    <syncfusion:GalleryItem  Caption="HR" Description="HR Department">

      <Image Source="hr.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp5.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp2.jpg"/>

    </syncfusion:GalleryItem>

  </syncfusion:GalleryGroup>

</syncfusion:Gallery>

 

[C#]

 

//Setting the animation feature

gallery.AllowedAnimations = AllowedAnimations.All;
