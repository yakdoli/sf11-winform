Setting FlowDirection for Magnifier

 

 

The flow direction for the Magnifier control is set through the FlowDirection property.

 

Property

Description

FlowDirection

Sets the flow direction for the Magnifier control. The options provided are as follows.

 

LeftToRight

RightToLeft

 

[C#]

 

// Flow direction from left to right.

magnifier1.FlowDirection = FlowDirection.LeftToRight;
