Watermarking

The numeric text box supports watermarking, allowing null values to be displayed as watermark text.

 

Properties

Name

Description

Type of property

Value it accepts

Dependency

WaterMarkText

Sets the watermark text to be displayed for null values.

string

Any string

NA

 

Using Builder

The following steps describe how to set watermark text through the builder for a numeric text box.

1.   In View, invoke the numeric text box helper followed by the WaterMarkText method with the desired text as an argument.

 

 View[ASPX]

 

<%=Html.Syncfusion().NumericTextBox("myNumeric")

.WaterMarkText("Enter") %>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().NumericTextBox("myNumeric")

.WaterMarkText("Enter").ToString()))

 

 

2.   Build and run the application.

 

Using Properties Model

The following steps explain how to set watermark text for a numeric text box through the properties model.

1.   In the Controller, create an instance of NumericTextBoxModel; define the WaterMarkText property and pass the instance through the view-specific data to the view.

 

[Controller]

 

public ActionResult Index()

        {

            //Creating instance of NumericTextBoxModel

            NumericTextBoxModel myModel = new NumericTextBoxModel();

            myModel.WaterMarkText = "Enter";

 

            //pass the instance through view data to the view

            ViewData["myNumeric"] = myModel;

            return View();

        }

 

 

2.   In the View, invoke the numeric text box helper with the view data key as the control ID.

View[ASPX]

 

<%=Html.Syncfusion().NumericTextBox("myNumeric") %>

 

 

View[cshtml]

 

 

@(new HtmlString(Html.Syncfusion().NumericTextBox("myNumeric").ToString()))

 

 

3.   Build and run the application.

 

When an end-user enters a null value, or when the control loses focus, the value of the text box will be set with the watermark text.
