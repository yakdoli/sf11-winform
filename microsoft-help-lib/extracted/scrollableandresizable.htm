Scrollable and Resizable

These properties allow you to set thebrowser default scroll bar and resize the splitter panes.

Properties

Name

Description

Type

Value Accepted

Dependencies

Resizable

Specifies the splitter bar to be draggable.

Boolean

True/False

Default value is true.

NA

Scrollable

Allows you to enable scrollable pane.

Boolean

True/False

Default value is true.

NA

 

You can set the Scrollable and Resizable properties in both ASPX and Razor engine modes.

 

[ASPX]

 

<%=Html.Syncfusion().Splitter("splitter").SplitterPanes(panes1=>{

 

panes1.Add().PaneSize(Unit.Percentage(50)).ContentTemplate(()=>{%>

 

             <p>inner first pane</p>

 

<%}).Resizable(true).Scrollable(true).SplitterBar(b=>b.AllowSplitterBar(true));

 

panes1.Add().PaneSize(Unit.Percentage(30)).Resizable(true).Scrollable(true) .ContentTemplate(()=>{%>

 

             <p>inner second pane</p>

 

   <%});

})

.Orientation(SplitterOrientation.Horizontal) %>

 

   

 

 

[Razor]

 

@{Html.Syncfusion().Splitter("splitter").SplitterPanes(panes1=>{

 

panes1.Add().PaneSize(Unit.Percentage(50)).Resizable(true).Scrollable(true) .ContentTemplate(

 

@<p>inner first pane</p>

 

).SplitterBar(b=>b.AllowSplitterBar(true));

 

panes1.Add().PaneSize(Unit.Percentage(30)).Resizable(true).Scrollable(true) .ContentTemplate(

         @<p>inner second pane</p>

  );

})

.Orientation(SplitterOrientation.Horizontal).Render() }
