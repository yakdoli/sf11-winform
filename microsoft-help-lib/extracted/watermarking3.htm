Watermarking

The percent text box control supports watermarking, allowing null values to be displayed as specified watermark text.

 

Properties

Name

Description

Type of property

Value it accepts

Dependency

WaterMarkText

Sets the watermark text to be displayed when entering null values.

string

Any string

NA

 

Using Builder

The following steps explain how to set the watermark text for the percent text box through the builder.

1.   In View, invoke the percent text box helper followed by the WaterMarkText method with the desired text as an argument.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent")

.WaterMarkText("Enter") %>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent")

.WaterMarkText("Enter").ToString()))

 

 

 

2.   Build and run the application.

 

Using Properties Model

The following steps explain the using of the watermark text for the percent text box through the properties model.

1.   In the controller, create an instance of PercentTextBoxModel.

2.   Define the WaterMarkText property and pass the instance through the view-specific data to the view.

 

[Controller]

 

public ActionResult Index()

        {

            //Creating instance of PercentTextBoxModel

            PercentTextBoxModel myModel = new PercentTextBoxModel();

            myModel.WaterMarkText = "Enter";

 

            //pass the instance through view data to the view

            ViewData["myPercent"] = myModel;

            return View();

        }

 

 

3.   In View, invoke the percent text box helper with the view data key as the control ID.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent") %>

 

 

View[cshtml]

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent").ToString()))

 

 

4.   Build and run the application.
