Adding a Mobile Slider control to MVC application

Refer to the Getting Started section to know the pre-requisites before stepping in to add a Mobile Slider Control to MVC application.

The following steps explain how to add a Slider Control to an application.

1.   In View, invoke the slider helper with control id as the first argument.

 

[ASPX]

 

<% = Html.MobSyncfusion().Slider("slider")

    .Value(20)

    %>

 

 

[Razor]

 

    @{ Html.MobSyncfusion().Slider("slider")

    .Value(20)

    .Render();

    }

 

 

 

 

2.   Build and run the application in emulator.
