HiLo Open Close Chart

 

HiLo Open Close chart is a special kind of chart that is normally used in stock analysis. This chart expects four Y values for every point in the series. These values should represent the High, Low, Open and Close values of the stock, in that order, for that period.

The following code example illustrates how to create a HiLo Open Close Chart.

 

 

 

[XAML]

 

<syncfusion:ChartSeries Type="HiLoOpenClose" Label="Stock 1" Interior="Green" Stroke="Black" DataSource="{StaticResource data1}" BindingPathX="StockDate" BindingPathsY="MaxStockPrice, MinStockPrice, OpenPrice, ClosePrice">

</syncfusion:ChartSeries>

 

<syncfusion:ChartSeries Type="HiLoOpenClose" Label="Stock 2" Interior="Blue" Stroke="Black" StrokeThickness="2"

DataSource="{StaticResource data2}" BindingPathX="StockDate" BindingPathsY="MaxStockPrice, MinStockPrice, OpenPrice, ClosePrice">

</syncfusion:ChartSeries>

 

[C#]

 

// Create HiLo Open Close Chart.

ChartSeries series = new ChartSeries();

series.Type = ChartTypes.HiLoOpenClose;

ChartSeries series2 = new ChartSeries();

series2.Type = ChartTypes.HiLoOpenClose;

 

// Initialize chart data.

series.DataSource = this.Resources["data1"] as StockData;

series.BindingPathX = "StockDate";

series.BindingPathsY = new List<string>() { "MaxStockPrice", "MinStockPrice", "OpenPrice", "ClosePrice" };

 

series2.DataSource = this.Resources["data2"] as StockData;

series2.BindingPathX = "StockDate";

series2.BindingPathsY = new List<string>() { "MaxStockPrice", "MinStockPrice", "OpenPrice", "ClosePrice" };

area.Series.Add(series);

area.Series.Add(series2);
