Chart Axis Tooltip

 

You can also set the tooltip for the axis. The following code snippet shows how to set the tooltip for the axis.

[C#]

            chartModel.PrimaryXAxis.ToolTip = "XAxis";

            chartModel.PrimaryYAxis.ToolTip = "YAxis";
