Client-Side Methods

The numeric text box control supports a rich set of client-side methods to control its behavior.

 

Methods

 

Name

Parameters

Return type

Description

NA

string

Returns the current value of the text box as string.

setValue

 

Value – the value to be displayed in the text box.

NA

 

The following steps explain the using of the client-side methods.

1.   In View, invoke the numeric text box helper with the control ID as the first argument.

 

View[ASPX]

 

=Html.Syncfusion().NumericTextBox("myNumeric") %>

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().NumericTextBox("myNumeric").ToString()))

 

 

 

2.   In JavaScript, use the methods as they are given in the following code.

 

[JavaScript]

 

<script type="text/javascript">

        function Value() {

            //create instance of numeric texbox client side object

            var numericObj = $find("myNumeric");

            //Code to get the current value

            var currentValue = numericObj.getValue();

            //Code to set the value

            numericObj.setValue(100);

        }   

       </script>

 

 

3.   Build and run the application.
