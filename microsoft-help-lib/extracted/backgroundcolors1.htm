Background Colors

Essential Schedule supports customizing the background colors. The following properties are used to change the colors.

Property

Type

Description

SelectionBackground

Brush

It can be used to change the Selection Background Color of the Schedule Control.

ShadedBackground

Brush

It can be used to change the Shaded Background Color of the Schedule Control.

ScheduleBackground

Brush

It can be used to change the Schedule Background Color of the Schedule Control.

HeaderBrush

Brush

It can be used to change the Header Background Color of the Schedule Control.

StrokeLine

Brush

It can be used to change the Border Color of the Schedule Control.

AppointmentBackground

Brush

It can be used to change the Appointment Background Color of the Schedule Control.

 

The following code illustrates the above properties.

 

[XAML]

<Schedule:Schedule x:Name="schedule" StrokeLine="Black" ScheduleBackground="#FFDADADA" SelectionBackground="#FF747474" ShadedBackground="#FFAFAFAF" HeaderBrush="DarkGray">

<schedule:Schedule.AppointmentBackground>

      <LinearGradientBrush EndPoint="0.5,1" StartPoint="0.5,0">

          <GradientStop Color="#FF858585" Offset="0"/>

          <GradientStop Color="#FFCDCDCD" Offset="0.687"/>

          <GradientStop Color="#FFE1E1E1" Offset="0.978"/>

      </LinearGradientBrush>

</schedule:Schedule.AppointmentBackground>

</Schedule:Schedule>
