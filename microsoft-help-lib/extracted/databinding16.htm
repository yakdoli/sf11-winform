Data Binding

 

Chart Series data points and the axes labels are the ones that can be databound in a chart.

 

The most common and convenient approach to populate a Chart Series is by simply data binding the chart series to a business object list. The following properties help you do that.

 

Properties

Description

DataSource

Takes any IEnumerable instance as the DataSource.

BindingPathX

This specifies the member / field in the specified data source that contains the x-values for the series.

BindingPathsY

This specifies the members / fields in the specified data source that contains the Y-values for the series.  This property is the type of List of strings.

 

[XAML]

 

<UserControl.Resources>

  <util:Sports x:Name="SportsData"/>

</UserControl.Resources>

 

<syncfusion:Series ChartType="Column" LegendLabel="Sports Interest"  Foreground="{StaticResource Series1}" DataSource="{StaticResource SportsData}" BindingPathX="SportID" BindingPathsY="Interest" />

 

[C#]

 

ChartArea area = new ChartArea();

ChartSeries series = new ChartSeries();

 

//Intialize the Series Data Source

series.DataSource = SpordsData;

series.BindingPathX = "SportID";

series.BindingPathsY = new List<string>() { "Interest" };

 

//Initialize the Axis Label Source

area.PrimaryAxis.LabelsSource = SpordsData;

area.PrimaryAxis.ContentPath = "SportID";

area.PrimaryAxis.PositionPath = "SportID";
