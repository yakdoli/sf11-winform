Auto-complete textbox

Essential Tools Auto-complete textbox for MVC provides an automatic prediction system wherethe  word or phrase that the user is typing is predicted by the system without the user actually typing it completely. This feature is built on MVC principles and can be used in web browsers, for address bars, in search engine's text search boxes and so on.

 

Key Features

The following are the key features:

·      Supports Get and Post request.

·      Supports search for more than a word for mailing using a delimiter.

·      Displays the required size of result using List size feature.

·      Allows setting of minimum characters for a search.

·      Supports delayed word search.

·      Supports the JSON data result.

·      Supports search conditions with case sensitivity.

·      Supports display of all the results in a drop-down.

·      Allows access to cached information.

·      Supports the Watermarking in text box.

·      Supports user templates to be displayed as suggested results.
