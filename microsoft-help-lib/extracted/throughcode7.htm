Through Code

 

To create the control programmatically:

 

1.   Add the following namespaces to the code behind the file.

 

[C#]

 

using Syncfusion.Web.UI.WebControls.Tools.CaptchaControl;

using Syncfusion.Web.UI;

 

[VB]

 

Imports  Syncfusion.Web.UI.WebControls.Tools.CaptchaControl

Imports Syncfusion.Web.UI

 

10.  Instantiate the Captcha control, and add it to the page to display it.

 

[C#]

 

Captcha captchaControl = new Captcha();

captchaControl.ID = "Captcha2";

this.Page.Controls.Add(captchaControl);

 

[VB]

 

Dim captchaControl As Captcha = New Captcha()

captchaControl.ID = "Captcha2"

Me.Page.Controls.Add(captchaControl)

 

11.  Add the following httpHandlers to the Web.Config file, to generate image on the fly. When the dlls are referred from the GAC, the version must be specified.

 

[Web.Config]

 

<httpHandlers>

<add path="Captcha.axd" verb="*" type="Syncfusion.Web.UI.WebControls.Tools.CaptchaControl.ImageCaptchaHandler,Syncfusion.Tools.Web, Version=X.X.X.X, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89" />

</httpHandlers>

 

Note: You might have to change the version number in the tags to whatever version you are linking to.

 

12.  Check if the code in the image matches the code you have entered by using the IsValid method of Captcha control.

 

[C#]

 

protected void Validate_Click(object sender, EventArgs e)

{

if (Captcha1.IsValid(TextBox1.Text))

{

this.msgLabel.Text = "Message Sent Successfully!";

}

else

{

this.msgLabel.Text = "Invalid Anti-spam number!";

Captcha1.RenderNewChallenge();

}

}

 

[VB]

 

Protected Sub Validate_Click(ByVal sender As Object, ByVal e As EventArgs)

If Captcha1.IsValid(TextBox1.Text) Then

Me.msgLabel.Text = "Message Sent Successfully!"

Else

Me.msgLabel.Text = "Invalid Anti-spam number!"

Captcha1.RenderNewChallenge()

End If

End Sub

 

13.  Build and run the project to view the control.
