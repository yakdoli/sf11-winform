Dragging Dialog

Dialog control provides support to drag the dialog box to a desired location. This helps you move the dialog if you want to refer to the application behind the dialog.

      

Enabling Dragging Support

To enable dragging support, set the IsDrag property to true. By default this is set as false.

 

The following code illustrates how to enable dragging support:

 

[XAML]

<syncfusion:Dialog IsDrag="True" x:Name="dialog" Width="300" Height="400" />

 

 

[C#]

 

Dialog dialog = new Dialog() { IsDrag=true,Width=300,Height=400 };
