Built-in ColorPalettes

ColorPalette is similar to ShapeFill, ShapeStroke and ShapeStrokeThickness.The different between Color Palettes and ShapeFill,ShapeStroke,ShapeStrokeThickness is that the ColorPalette is a set of predefined colors and each shape in the Map has different colors.But if the ShapeFill,ShapeStroke and ShapeStrokeThickness are set, it will be applied to all the shapes in the Map.The available ColorPalette are as follows:

·      None

·      ColorPalette1

·      ColorPalette2

·      ColorPalette3

·      ColorPalette4

·      ColorPalette5

·      CustomColorPalettePalette

 

In order to show the ColorPalette, the EnableColorPalette property should be true.

 

Figure 23: ColorPalette in Sequential Mode

 

 

[XAML]

      <maps:MapControl x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}" ColorPalette="ColorPalette2" EnableColorPalette="True">

                        <maps:MapControl.Layers>

                            <maps:Layers>

                                <maps:ShapeFileLayer Uri="WpfApplication1.ShapeFiles.wv.shp" TranslateZoomFactor="1" x:Name="shapeControl"  EnableColorPalette="True">

                                </maps:ShapeFileLayer>

                               </maps:Layers>

                        </maps:MapControl.Layers>

       </maps:MapControl>

 

 

[C#]

            MapControl map = new MapControl();

            map.ColorPalette = ColorPalettes.ColorPalette1;

            map.EnableLayerTransitionEffects = true;

            ShapeFileLayer shapeLayer = new ShapeFileLayer();

            shapeLayer.Uri = "WpfApplication1.ShapeFiles.wv.shp";

            map.LayeredContent = shapeLayer;

            LayoutRoot.Children.Add(map);

 

ColorPalette Mode

There are two types of ColorPaletteModes. They are:

·      Sequential

·      Random

 

In sequential color palette mode, mode color will be applied sequentially, in random mode colors will be applied in a random manner.

 

 

Figure 24: ColorPalette in Random mode

 

 

[XAML]

      <maps:MapControl  ColorPaletteMode="Random"

  x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}" ColorPalette="ColorPalette2" EnableColorPalette="True">

                        <maps:MapControl.Layers>

                            <maps:Layers>

                                <maps:ShapeFileLayer Uri="WpfApplication1.ShapeFiles.wv.shp" TranslateZoomFactor="1" x:Name="shapeControl"  EnableColorPalette="True">

                                </maps:ShapeFileLayer>

                               </maps:Layers>

                        </maps:MapControl.Layers>

       </maps:MapControl>

 

 

[C#]

            MapControl map = new MapControl();

            map.ColorPalette = ColorPalettes.ColorPalette1;

            map.EnableLayerTransitionEffects = true;

            map.ColorPaletteMode = ColorPaletteMode.Random;

            ShapeFileLayer shapeLayer = new ShapeFileLayer();

            shapeLayer.Uri = "WpfApplication1.ShapeFiles.wv.shp";

            map.LayeredContent = shapeLayer;

            LayoutRoot.Children.Add(map);
