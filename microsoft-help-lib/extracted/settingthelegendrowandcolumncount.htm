Setting the Legend Row and Column Count

 

The number of legend row items and column items can be set by assigning an appropriate value to the RowCount and ColumnCount property.

 

[C#]

 

this.olapChart1.Legend.RowsCount = 3;

this.olapChart1.Legend.ColumnsCount = 2;

 

[VB]

 

Me.olapChart1.Legend.RowsCount = 3

Me.olapChart1.Legend.ColumnsCount = 2
