Using Properties Model

The following steps, explains the Footer Template customization using Properties model:

1.   In the Controller, create an instance of MobFooterModel, set the TargetId, AutoFormat, Title and pass the instance through ViewData to View as given below:

 

 

[Controller]

 

public ActionResult CoreFeatures()

        {

            MobFooterModel model = newMobFooterModel()

            {

                TargetId = "targetFooter",

                Title = "Select an action",

                AutoFormat = MobSkins.MetroBlue,

            };

            ViewData["Footer"] = model;

            return View();

        }

 

2.   In View, invoke the Footer helper with the View Data key as the first argument the set the LeftButton and RightButton methods with desired arguments.

 

[ASPX]

                <%{

                      Html.MobSyncfusion().Footer("Footer").AutoFormat(MobSkins.MetroBlue)

                        .TargetId("targetHeader")

                        .Template(() =>

                        {%>

                <div>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/left.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/right.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/playback.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/clipboard.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/wrench.png")%>"class="footer-img"/>

                </div>

                <%})

                .Render();

                  } %>

 [Razor]

 

  @{

            Html.MobSyncfusion().Footer("Footer").AutoFormat(MobSkins.MetroBlue)

                .TargetId("targetHeader")

                .Template(@<div>

                    <imgalt=""src="@Url.Content("~/Content/Footer/Images/left.png")"class="footer-img"/>

        }

 

 

3.   Build and run the application.
