Customizing Pointer Border Color

 

You can use the PointerSelectionBrush property to alter the pointer border color. The following code example illustrates this.

 

[XAML]

 

<syncfusion:LinearBarPointer EnablePointerInteraction="True" PointerSelectionBrush="Yellow" Foreground="Silver" BorderThickness="1" Height="10" Width="5" PointerWidth="10" IncreamentKey="F5" DecreamentKey="D">

 

 

Figure 110: Linear Gauge Pointer Color set to "Yellow"
