Deployment Requirements

 

Dll List

 

While deploying an application that references Syncfusion Essential Chart Silverlight assembly, the following dependencies must be included in the distribution.

 

·      Syncfusion.Chart.Silverlight.dll

·      Syncfusion.Shared.Silverlight.dll

·      Syncfusion.Linq.Silverlight.dll
