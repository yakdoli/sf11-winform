Data Binding

 

ToolBar provides a flexible approach for binding data from various data sources. ToolBar supports data binding with the following data sources.

 

·      AccessDatasource

·      ObjectDatasource

·      SQLDatasource

·      XML Datasource

·      SiteMapDatasource

 

In order to bind to a DataSource component, the DataSourceID property of the toolbar must be set to the ID of the DataSource component. You should also set the TextField and DataMember properties of the toolbar, to map the Text and Value properties to the respective columns / fields from the data source.

 

AccessDataSource

 

AccessDataSource is designed to work with Microsoft Access. It uses the OleDb data provider internally. OleDb data provider classes are defined in the System.Data.OleDb namespace. To bind AccessDataSource to Toolbar, use the below given code.

 

[ASPX]

 

<cc1:ToolBar ID="ToolBar5" runat="server"  DataSourceID="AccessDataSource1" AutoFormat="Office2007 Blue">

<DataBindings>

<cc1:ToolBarItemBinding DataMember="DefaultView" IDField="id" ParentIDField="parentId" TextField="Text" />

</DataBindings>

</cc1:ToolBar>

 

<asp:AccessDataSource ID="AccessDataSource1" runat="server" DataFile="~/App_Data/data.mdb" SelectCommand="SELECT * FROM [Links]">

</asp:AccessDataSource>

SqlDataSource

 

SqlDataSource is designed to work with SQL Server databases. It uses the SQL Server .NET data provider internally. SQL Server .NET data provider classes are defined in the System.Data.SqlClient namespace. To bind the SqlDataSource to ToolBar, use the below given code.

 

[ASPX]

 

<cc1:ToolBar ID="ToolBar1" runat="server" DataSourceID="SqlDataSource1">

<DataBindings>

<cc1:ToolBarItemBinding DataMember="DefaultView" IDField="ID" ParentIDField="ParentID" TextField="Text" />

</DataBindings>

</cc1:ToolBar>

 

<asp:SqlDataSource ID="SqlDataSource1" runat="server" ConnectionString="<%$ ConnectionStrings:HierarchyDataConnectionString %>"

SelectCommand="SELECT * FROM [Table1]">

</asp:SqlDataSource>

XmlDataSource

 

XmlDataSource is used to work with XML documents. To bind the XmlDataSource to ToolBar, use the below given code.

 

[ASPX]

 

<cc1:ToolBar ID="ToolBar2" AutoFormat="Office2007 Blue" runat="server" DataSourceID="XmlDataSource1">

<DataBindings>

<cc1:ToolBarItemBinding DataMember="RootItem" TextField="Text" />

</DataBindings>

</cc1:ToolBar>

 

<asp:XmlDataSource ID="XmlDataSource1" runat="server" DataFile="~/XMLFile.xml">

</asp:XmlDataSource>

ObjectDatasource

 

The ObjectDataSource control lets you bind a specific data layer in the same manner by which you bind to the database using other controls. The ObjectDataSource control can bind to any method that returns a DataSet or an IEnumerable object (for example, a DataReader or a collection of Classes). The major advantage of binding via ObjectDataSource is, only records that are required in the current view are retrieved from the database, greatly optimizing the performance and runtime memory usage. To bind the ObjectDatasource to ToolBar, use the below given code.

 

[ASPX]

 

<cc1:ToolBar ID="ToolBar6" runat="server"  DataSourceID="ObjectDataSource1" AutoFormat="Office2007 Blue">               

<DataBindings>

<cc1:ToolBarItemBinding DataMember="DefaultView" IDField="id" ParentIDField="parentId" TextField="Text" />

</DataBindings>

</cc1:ToolBar>

 

<asp:ObjectDataSource ID="ObjectDataSource1" runat="server" TypeName="EmployeeList"  SelectMethod="GetRecords">

</asp:ObjectDataSource>
