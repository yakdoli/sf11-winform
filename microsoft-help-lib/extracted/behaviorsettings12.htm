Behavior Settings

 

The behavior of the jQueryUITabs is controlled by using the following properties.

 

 

Property

 

Description

Cache

Enables to cache the remote tab contents.

Collapsible

Collapses all the tabs at once.

Event

The event at which the tabs are selected.

Selected

Sets the index of the tab to be selected on page load.

Spinner

Specifies the content to be displayed while the remote content is loading.

Disabled

Gets an array containing the position of the tabs (zero-based index) that should be disabled on initialization.

 

[ASPX]

 

<Syncfusion:jQueryUITab ID="JQueryUITab1" runat="server" Cache="true" Collapsible="true" Event="MouseOver" Selected="1" Spinner="Content Is Loading">

<Syncfusion:jQueryUITabItem Text="Header1">This the content for the Header1.</Syncfusion:jQueryUITabItem>

<Syncfusion:jQueryUITabItem Text="Header2">This the content for the Header2.</Syncfusion:jQueryUITabItem>

<Syncfusion:jQueryUITabItem Text="Header3">This the content for the Header3.</Syncfusion:jQueryUITabItem>

</Syncfusion:jQueryUITab>

 

[C#]

 

JQueryUITab1.Cache = true;

JQueryUITab1.Collapsible = true;

JQueryUITab1.Event = TabEvents.MouseOver;

JQueryUITab1.Selected = 1;

JQueryUITab1.Spinner = "Content Is Loading";

int[] arr = new int[] { 1,2 };

Tab.Disabled = arr;

 

[VB]

 

JQueryUITab1.Cache = True

JQueryUITab1.Collapsible = True

JQueryUITab1.Event = TabEvents.MouseOver

JQueryUITab1.Selected = 1

JQueryUITab1.Spinner = "Content Is Loading"

Dim arr As Integer() = New Integer() {1, 2}

Tab.Disabled = arr
