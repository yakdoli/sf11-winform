Adding Drill Position to an Application

 

Adding Drill position feature to an application is described in the following code snippet:

 

[CS]

 

dataManager.CurrentReport.DrillType = DrillType.DrillPosition;

 

 

[VB]

 

dataManager.CurrentReport.DrillType = DrillType.DrillPosition
