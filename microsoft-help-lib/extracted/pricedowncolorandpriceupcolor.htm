PriceDownColor and PriceUpColor

 

PriceDownColor:

PriceDownColor specifies a color for the financial item for which the price is down.

Details

Possible values

Any valid color.

Default value    

Color.Red

2D/3D limitations

No

Application to chart element

Any series

Application to chart types

Kagi chart, Point and Figure chart, Renko chart, and Three Line Break chart.

 

PriceUpColor:

PriceUpColor specifies a color for the financial item for which the price is up.

Details

Possible values

Any valid color.

Default value    

Color.Green

2D/3D limitations

No

Application to chart element

Any series

Application to chart types

Kagi chart, Point and Figure chart, Renko chart, and Three Line Break chart.

 

PriceDownColor and PriceUpColor in any Financial chart can be created through two ways:

·      Builder

·      ChartModel
