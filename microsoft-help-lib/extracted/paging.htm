Paging

Essential Grid includes a pager bar that can be used to easily navigate to the required page when the grid has data that spans several pages. See Paging.

 

a.   Pager bar

Essential Grid for ASP.NET MVC includes a pager bar that can be used to navigate to a specific page. There are also options to control the number of pages displayed.

 

Figure 65: Multi-Page Grid

 

 

b.   JSON mode paging

The JSON mode of paging provides an efficient way to retrieve paged data as JSON objects. The advantage of this approach is that only data is refreshed and the client-side grid refreshes itself to display the updated data. This results in vastly improved scalability.
