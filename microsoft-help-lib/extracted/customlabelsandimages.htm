Custom Labels and Images

Using the CustomLabels property, you can add text labels to the Essential Gauge. And also we can add images (Gauge Image) in circular gauge to present gauge with more visual image elements. The below are some of the major properties using which we can customize the Essential Gauge.

 

Table 13: Property Table

Property

Description

LabelValue

Text value for the label. Default value is String.Empty.

Location

Location of the label and image can be specified. Default value is Center.

TextAngle

Customize the angle of the text rendering. Default value is set to 0.

ImageWidth

Specifies the image width. Default value is set to 0.

ImageHeight

Specifies the image height. Default value is set to 0.

ImageSource

Lets you specify the image source for image element.

 

The following code example illustrates the above property settings.

 

[XAML]

 

<syncfusion:CircularGauge Name="circularGauge1">

   

    <!--Adding images in gauge.-->

    <syncfusion:CircularGauge.Images>

        <syncfusion:GaugeImage Location="40,35" ImageWidth="32" ImageHeight="32" ImageSource="{StaticResource Pan}" />

    </syncfusion:CircularGauge.Images>

   

    <!-- Adding circular labels on gauge.-->

    <syncfusion:CircularGauge.CustomLabels>

        <syncfusion:CircularCustomLabel Name="One" BackgroundBrush="GhostWhite" FontSize="15" TextAngle="0" Location="50,20"

        LabelValue="SampleText"/>

        <syncfusion:CircularCustomLabel  BackgroundBrush="GhostWhite" FontSize="15" TextAngle="180" Location="80,90"

        LabelValue="Angle-180"/>

    </syncfusion:CircularGauge.CustomLabels>

</syncfusion:CircularGauge>

 

[C#]

 

// Add image on Gauge.

GaugeImage gaugeImage = new GaugeImage();

gaugeImage.ImageWidth = 32;

gaugeImage.ImageHeight = 32;

BitmapImage bm = new BitmapImage(newUri(@"pack://application:,,,/Images/synclogo.png"));

gaugeImage.ImageSource = bm;

gaugeImage.Location = new Point(50, 35);

gaugeImage.ResizeMode = GaugeImageResizeMode.Stretch;

circularGauge1.Images.Add(gaugeImage);

 

// Add custom label on gauge.

CircularCustomLabel labelCustom = new CircularCustomLabel();

labelCustom.FontSize = 15;

labelCustom.BackgroundBrush = Brushes.GhostWhite;

labelCustom.Location = new Point(50, 60);

labelCustom.LabelValue = "SampleText";

labelCustom.TextAngle = 0;

circularGauge1.CustomLabels.Add(labelCustom);

 

// Adding custom label with angle value of 180.

CircularCustomLabel labelCustom1 = new CircularCustomLabel();

labelCustom1.FontSize = 15;

labelCustom1.BackgroundBrush = Brushes.GhostWhite;

labelCustom1.Location = new Point(50, 60);

labelCustom1.LabelValue = "Angle-180";

labelCustom1.TextAngle = 180;

circularGauge1.CustomLabels.Add(labelCustom1);
