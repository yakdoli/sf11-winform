Cell Templates

 

The Cell Templates feature of PivotGrid allows you to define the templates and change the appearance of elements, such as column, row, summary, and value cells, present in the Grid. The style for each element in the Grid should be defined of type PivotGridTemplateCell. The custom template can be defined for the following properties of PivotGrid.

 

·      ColumnHeaderCellStyle

·      RowHeaderCellStyle

·      SummaryHeaderStyle

·      SummaryCellStyle

·      ValueCellStyle

 

The Expander’s in the grid can also be customized with any UI element and it should be named as “PART_Expander” to perform the drill-up and drill-down operations.

 

Adding Cell Template

ColumnHeaderStyle of PivotGrid can be customized by using the Template, as shown in the following XAML.

[XAML]

 

  <Style x:Key="colStyle" TargetType="syncfusion:PivotGridTemplateCell">

            <Setter Property="Template">

                <Setter.Value>

                    <ControlTemplate TargetType="syncfusion:PivotGridTemplateCell">

                        <StackPanel Grid.Column="1" Orientation="Horizontal" Background="#4A88C6">

                            <!--Image block-->

                            <Image Margin="2,4" Grid.Column="1" VerticalAlignment="Top" HorizontalAlignment="Left" Stretch="Uniform" Width="32" Height="20" Source="{Binding Converter={StaticResource imageConverter}}">

 

                            </Image>

 

                            <TextBlock Grid.Column="1" Margin="3,4,2,0"

                                           Text="{Binding Path=Text, RelativeSource={RelativeSource TemplatedParent}}"

                                           TextWrapping="Wrap" HorizontalAlignment="Center"

                                           VerticalAlignment="Center" FontFamily="Calibri" FontSize="12"/>

                        </StackPanel>

                    </ControlTemplate>

                </Setter.Value>

            </Setter>

        </Style>
