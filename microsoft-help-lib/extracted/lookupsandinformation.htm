LookUps and Information

 

This section lists the LookUp and Information functions included with Essential calculate in the below table.

 

Table 8: LookUp and Information functions

Function Name

Description

HLookUp

Finds a value in one row and returns the corresponding value in another row.

VLookUp

Finds a value in one column and returns the corresponding value in another column.

IsError

Returns True if cell holds an error.

IsNumber

Returns True if cell holds a number.
