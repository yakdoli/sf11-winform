Blocking Appointment

 

This section discusses how appointments can be blocked in a Schedule control.

There is a new property, Blocked, that has been included with normal Schedule Web appointments. By setting this property to True, you can block a particular appointment for a period of time and make sure that no other appointment overrides the blocked appointment.

 

 

Appointment Property

 

Description

Blocked

Specifies whether to block a particular appointment.

 

[ASPX]

 

<cc1:ScheduleWebAppointment AllowDrag="true" BackColor="Azure" Blocked="true" EndTime="08/12/2008 14:00:00" Owner="1"

StartTime="08/12/2008 13:00:00" Subject="Lunch with CEO" TimeSpanColor="DarkGray" UniqueID="30"/>

 

[C#]

 

ScheduleWebAppointment appt = new ScheduleWebAppointment();

appt.AllowDrag = true;

appt.BackColor = Color.Azure;

appt.Blocked = true;

appt.EndTime = new DateTime(2008, 08, 12, 14, 00, 00);

appt.Owner = 1;

appt.StartTime = new DateTime(2008, 08, 12, 13, 00, 00);

appt.Subject = "Lunch with CEO";

appt.UniqueID = 30;

this.Schedule1.Appointments.Add(appt);

 

[VB]

 

Dim appt As ScheduleWebAppointment = New ScheduleWebAppointment()

appt.AllowDrag = True

appt.BackColor = Color.Azure

appt.Blocked = True

appt.EndTime = New DateTime(2008, 08, 12, 14, 00, 00)

appt.Owner = 1

appt.StartTime = New DateTime(2008, 08, 12, 13, 00, 00)

appt.Subject = "Lunch with CEO"

appt.UniqueID = 30

Me.Schedule1.Appointments.Add(appt)
