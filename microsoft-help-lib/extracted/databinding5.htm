Data Binding

 

TabStrip provides a flexible approach to bind data from various data sources. TabStrip supports data binding with the following data sources.

 

 

In order to bind to a DataSource component, the DataSourceID property of the TabStrip must be set to the ID of the DataSource component. You should also set the TextField and DataMember properties of the TabStrip, to map the Text and Value properties to the respective columns / fields from the data source. Also, you can use the ID-ParentID relation to establish a hierarchy among the TabStrip items.

5.5.1.2.7.1 AccessDataSource

 

AccessDataSource is designed to work with Microsoft Access. It uses internally, the OleDb data provider. OleDb data provider classes are defined in the System.Data.OleDb namespace. To bind the AccessDataSource to TabStrip, use the below given code snippet.

 

[aspx]

 

<cc1:TabStrip ID="TabStrip5" runat="server"  DataSourceID="AccessDataSource1" AutoFormat="Office2007 Blue">

<DataBindings>

<cc1:TabStripItemBinding DataMember="DefaultView" IDField="id" ParentIDField="parentId" TextField="Text" />

</DataBindings>

</cc1:TabStrip>

 

<asp:AccessDataSource ID="AccessDataSource1" runat="server" DataFile="~/App_Data/data.mdb" SelectCommand="SELECT * FROM [Links]">

</asp:AccessDataSource>

5.5.1.2.7.2 ObjectDataSource

 

The ObjectDataSource control allows you to bind a specific data layer, in a similar manner to which other controls bind to the database. The ObjectDataSource control can bind to any method that returns a DataSet or an IEnumerable object (for example, a DataReader or a collection of Classes). The major advantage of binding via ObjectDataSource is, only the records that are required in the current view are retrieved from the database, greatly optimizing the performance and runtime memory usage. To bind an ObjectDatasource to the TabStrip, use the below given code snippet.

 

[aspx]

 

<cc1:TabStrip ID="TabStrip6" runat="server"  DataSourceID="ObjectDataSource1" AutoFormat="Office2007 Blue">               

<DataBindings>

<cc1:TabStripItemBinding DataMember="DefaultView" IDField="id" ParentIDField="parentId" TextField="Text" />

</DataBindings>

</cc1:TabStrip>

 

<asp:ObjectDataSource ID="ObjectDataSource1" runat="server" TypeName="EmployeeList" SelectMethod="GetRecords">

</asp:ObjectDataSource>

 

 

Figure 299: TabStrip control bound to ObjectDataSource

 

5.5.1.2.7.3 SqlDataSource

 

SqlDataSource is designed to work with SQL Server databases. It uses internally, the SQL Server .NET data provider. SQL Server .NET data provider classes are defined in the System.Data.SqlClient namespace. To bind an SqlDataSource to TabStrip, use the below given code snippet.

 

[aspx]

 

<cc1:TabStrip ID="TabStrip1" runat="server" DataSourceID="SqlDataSource1">

<DataBindings>

<cc1:TabStripItemBinding DataMember="DefaultView" IDField="ID" ParentIDField="ParentID" TextField="Text" />

</DataBindings>

</cc1:TabStrip>

 

<asp:SqlDataSource ID="SqlDataSource1" runat="server" ConnectionString="<%$ ConnectionStrings:HierarchyDataConnectionString %>"

SelectCommand="SELECT * FROM [Table1]">

</asp:SqlDataSource>

 

 

Figure 300: TabStrip control bound to SqlDataSource

 

5.5.1.2.7.4 XmlDataSource

 

XmlDataSource is used to work with XML documents. To bind an XmlDataSource to TabStrip, use the below given code snippet.

 

[aspx]

 

<cc1:TabStrip ID="TabStrip2" AutoFormat="Office2007 Blue" runat="server" DataSourceID="XmlDataSource1">

<DataBindings>

<cc1:TabStripItemBinding DataMember="RootItem"  TextField="Text" />

</DataBindings>

</cc1:TabStrip>

 

<asp:XmlDataSource ID="XmlDataSource1" runat="server"  DataFile="~/XMLFile.xml">

</asp:XmlDataSource>

5.5.1.2.7.5 SiteMapDataSource

 

The SiteMapDataSource control enables you to declaratively data bind to site navigation data that exists in your pages. The SiteMapDataSource control is associated with a data-bound control through the control's DataSourceID property.

 

[aspx]

 

<cc1:TabStrip id="TabStrip4" runat="server" Width="400px" AutoFormat="TerminalTheme" DataSourceID="SiteMapDataSource1" >

</cc1:TabStrip>

 

<asp:SiteMapDataSource ID="SiteMapDataSource1" runat="server" />
