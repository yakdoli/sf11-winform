Through Designer

 

You can create the Calendar control using the designer as follows.

 

1.   Create a new ASP.NET Web application. For details, see Creating ASP.NET Web Application.

2.   Drag the Calendar control onto your page from the controls toolbox.

 

[ASPX]

 

<ssw:Calendar ID="Calendar1" runat="server" AutoFormat="Classic Blue" Font-Bold="True" />

 

 

Figure 115: Calendar control dragged onto the Web Form

 

3.   Customize the look and feel, behavior and the culture settings of the control as required. Please refer to Concepts and Features which discusses the various customization and control settings.

4.   Run the application to view the output.

 

 

Figure 116: Calendar control created Through Designer

 

The following example demonstrates how to configure a Splitter to look like the screenshot above.

 

[ASPX]

 

<ssw:Calendar ID="Calendar1" runat="server" AutoFormat="Silver" HorizontalMonthsCount="2" VerticalMonthsCount="2" VisibleMonth="01/01/2007" SelectedDate="02/02/2007" Culture="English (United States)""/>
