Using Properties Model

The following steps explain the setting of the display conditions to an application using the Properties model.

1.   In the Controller, create an instance of the GenericDropDownModel, set the IntiallyPopupShown and Text properties and pass the instance through view specific data to View as given below.

 

 

[Controller]

public ActionResult Index()

        {

            GenericDropDownModel myModel = new GenericDropDownModel();           

            myModel.TargetContentId = "drop-down-contents";

            myModel.InitiallyPopupShown = true;

            myModel.Text = "[Select]";

 

            ViewData["myDropDown"] = myModel;

            return View();

        }

 

 

2.   In View, create the drop-down contents and invoke the generic drop-down helper with view data key as the Control ID.
