Customizing a Chart

This section will outline some of the property settings which plays a major role in customizing the appearance of the Chart for WPF.

 

The following screenshot shows a customized chart.

 

Figure 51: Customized Chart

 

Lets see the properties to be set to get the above chart appearance:

 

[XAML]

 

<!--Customizing Border Settings-->

<syncfusion:Chart Name="Chart1" Grid.Row="1" Margin="20" Grid.Column="0" BorderThickness="4">

       

            <syncfusion:Chart.BorderBrush>

                    <SolidColorBrush Color="Blue"></SolidColorBrush>

             </syncfusion:Chart.BorderBrush>

      <syncfusion:ChartArea IsContextMenuEnabled="True"  CornerRadius="4"

            BorderThickness="1" Name="Area1" BorderBrush="Coral"

              />

   </syncfusion:Chart>

 

<!--Customizing Background Setting-->

 

<syncfusion:Chart Name="Chart1" Background="SkyBlue">

<syncfusion:ChartArea  Background="LightYellow" GridBackground="Pink" >

 

<!--Font Settings-->

<syncfusion:ChartArea.PrimaryAxis>

              

                        <syncfusion:ChartAxis IsAutoSetRange="True" RangePadding="Normal" LabelFontFamily="Aharoani"

                                           LabelFontWeight="Bold"

                                            >

            <syncfusion:ChartAxis.LabelForeground>

                                <SolidColorBrush Color="SlateBlue"></SolidColorBrush>

                            </syncfusion:ChartAxis.LabelForeground>

                         

                        </syncfusion:ChartAxis>

                    </syncfusion:ChartArea.PrimaryAxis>

 

                <syncfusion:ChartArea.SecondaryAxis>

 

                        <syncfusion:ChartAxis RangePadding="Normal" LabelFontFamily="Aharoani"

                                           LabelFontWeight="Bold">

        

                            <syncfusion:ChartAxis.LabelForeground>

                                <SolidColorBrush Color="SlateBlue"></SolidColorBrush>

                            </syncfusion:ChartAxis.LabelForeground>

                          

                        </syncfusion:ChartAxis>

</syncfusion:ChartArea.SecondaryAxis>

 

<!--Customizing Series Setting-->

<syncfusion:ChartSeries  Interior="DarkSeaGreen" />

      <syncfusion:ChartSeries.Stroke>

              <SolidColorBrush Color="Brown"></SolidColorBrush>

       </syncfusion:ChartSeries.Stroke>

 <syncfusion:ChartSeries.AdornmentsInfo>

       <syncfusion:ChartAdornmentInfo Symbol="Square" Visible="True"></syncfusion:ChartAdornmentInfo>

       </syncfusion:ChartSeries.AdornmentsInfo>

</syncfusion:ChartSeries>

 

[C#]

 

//Customizing Border Settings

Chart1.BorderThickness = "4";

Chart1.BorderBrush=Brushes.Black;

Chart1.Areas[0].BorderThickness = "1";

Chart1.Areas[0].BorderBrush = Brushes.Coral;

 

//Customizing Background Setting

Chart1.Background = Brushes.SkyBlue ;

Chart1.Areas[0].Background = Brushes.LightYellow ;

Chart1.Areas[0].GridBackground = Brushes.Pink;

 

//Font Settings
Chart1.Areas[0].PrimaryAxis.LabelFontFamily = "Aharoani";

Chart1.Areas[0].PrimaryAxis.LabelFontWeight = "Bold";

Chart1.Areas[0].PrimaryAxis.LabelForeground = Brushes.SlateBlue ;

Chart1.Areas[0].SecondaryAxis.LabelFontFamily = "Aharoani";

Chart1.Areas[0].SecondaryAxis.LabelFontWeight = "Bold";

Chart1.Areas[0].SecondaryAxis.LabelForeground = Brushes.SlateBlue ;

 

//Customizing Series Setting

Chart1.Areas[0].ColorModel.CustomPalette= Brushes.DarkSeaGreen ;

Chart1.Areas[0].ColorModel.Stroke.= Brushes.Brown;

Chart1.Areas[0].Series[0].AdornmentsInfo.Symbol = Symbol.Square;

 

The chart is customized with the above property settings.
