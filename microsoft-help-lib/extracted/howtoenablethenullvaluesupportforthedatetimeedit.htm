How to enable the Null Value support for the DateTimeEdit

NullValue support in the DateTimeEdit control can be enabled by setting the IsEmptyDateEnabled property to true. You can also specify the Value when you set the null to the DateTime property by using the NullValue property.  You can set the WatermarkText when the Null Value is set to the DateTime property.

 

C#

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="200"

                         IsEmptyDateEnabled="True" NullValue="{x:Null}">

 

Figure 294: DateTimeEdit with null value

 

Here is an example to change the DateTime property by using the NullValue property when you set null to the DateTime property.

In the example displayed below when you set null to the DateTime property, then automatically the value of the NullValue property is set to the DateTime property.

 

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="200"

                         IsEmptyDateEnabled="True" NullValue="07/05/2010">
