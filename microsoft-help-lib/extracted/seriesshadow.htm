Series Shadow

 

The shadow of each chart series can be set by DisplayShadow property. The following code snippets deliver the output:

[C#]

foreach (ChartSeries series in this.olapChart1.Series)

    series.Style.DisplayShadow = true;           

 

[VB]

For Each series As ChartSeries In Me.olapChart1.Series

series.Style.DisplayShadow = true          

Next series
