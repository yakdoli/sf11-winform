Visual Mode

 

Gallery control supports two types of visual modes. They are as follows.

 

·      Standard

·      Detailed

 

When the VisualMode property is set to Standard, the gallery will contain only the content. The following code illustrates this.

 

[XAML]

 

<!-- Adding Gallery -->

<syncfusion:Gallery Name="gallery" VisualMode="Standard">

 

  <!-- Adding GalleryGroup -->

  <syncfusion:GalleryGroup Name="galleryGroup" Header="Photos">

 

    <!-- Adding GalleryItems -->

    <syncfusion:GalleryItem  Caption="HR" Description="HR Department">

      <Image Source="hr.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp5.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp2.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp6.jpg"/>

    </syncfusion:GalleryItem>

  </syncfusion:GalleryGroup>

</syncfusion:Gallery>

 

[C#]

 

//Setting Visual mode as Standard

gallery.VisualMode = GalleryVisualMode.Standard;

 

Figure 501: VisualMode = "Standard"

 

When the VisualMode property is set to Detailed, the gallery will contain all details such as content, caption and description. The following code illustrates this.

 

[XAML]

 

<!-- Adding Gallery -->

<syncfusion:Gallery Name="gallery" VisualMode="Detailed">

 

  <!-- Adding GalleryGroup -->

  <syncfusion:GalleryGroup Name="galleryGroup" Header="Photos">

 

    <!-- Adding GalleryItems -->

    <syncfusion:GalleryItem  Caption="HR" Description="HR Department">

      <Image Source="hr.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp5.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp2.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp6.jpg"/>

    </syncfusion:GalleryItem>

  </syncfusion:GalleryGroup>

</syncfusion:Gallery>

 

[C#]

 

//Setting Visual mode as Detailed

gallery.VisualMode = GalleryVisualMode.Detailed;
