Chart Area Header

 

Chart enables the user to add a header for the chart area object. A text box element, for example, can be added as the chart Area header using the Header property. The following lines of code illustrates setting this property using XAML.

 

 

Note: Any element can be added as a chart Area header.

 

[XAML]

 

<syncfusion:Chart>

<syncfusion:ChartArea Background="LightSkyBlue" GridBackground="White">                

<!--Initializing the Chart area header for chart control-->

<syncfusion:ChartArea.Header>

<TextBox FontSize="16" Foreground="Green" FontWeight="Bold" Text="Sales Analysis" Background="Orange"                                HorizontalAlignment="Center"/>

</syncfusion:ChartArea.Header>

<syncfusion:ChartSeries Data="1,5,2,8,3,6,4,9" Interior="{StaticResource SeriesColor}"/>

</syncfusion:ChartArea>

</syncfusion:Chart>
