How to Cancel Postback?

 

TreeView control has server side events such as NodeSelected, NodeRenamed, NodeExpanded, NodeCollapsed, NodeDropped, NodeCheckChanged events. TreeView has some properties (such as AutoPostOnNodeSelect, AutoPostBackOnNodeRename, AutoPostBackOnNodeExpand, AutoPostBackOnNodeCollapse, AutoPostBackOnNodeDrop, AutoPostBackOnNodeCheckChanged) that indicate whether to postback the page and fire server side event, after the node is changed.

 

For instance, for cancelling postback after the node is selected, AutoPostBackOnNodeSelect property must be set to False.

 

[ASPX]

 

<cc1:TreeView ID="TreeView1" runat="server" AutoPostBackOnNodeSelect="true" ClientSideOnNodeSelect="NodeOnSelect(this)" EditNode="false">

    <Items>

        <cc1:TreeViewNode Expanded="True" Text="Root Node1">

            <cc1:TreeViewNode Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode Text="Child Node1">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode>

        <cc1:TreeViewNode Expanded="True" Text="Root Node2">

            <cc1:TreeViewNode Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode Text="Child Node2">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode>

    </Items>

</cc1:TreeView>

 

[JavaScript]

 

function NodeOnSelect( NodeEvent )

{   

    if( NodeEvent.Level == 0 ) //root nodes have Level=0

    {

        //postback will not occur

        return false;       

    }

    else

    {

        //postback will occur

        return true;

    }

}
