Header Bar Customization

 

This section discusses the settings supported by the Schedule control to customize the appearance of the header.

 

Figure 97

 

Header Resource Row Style

 

This property specifies style settings for the header resource row.

 

[ASPX]

 

<Syncfusion:Schedule id="Schedule1" runat="server">

<HeaderbarResourcerowstyle ForeColor="Goldenrod" BackColor="LightYellow"  BorderColor="Goldenrod" BorderStyle="Dotted"

Font-Bold="true"/>

</Syncfusion:Schedule>

 

[C#]

 

Schedule1.HeaderResourceRowStyle.BackColor = System.Drawing.Color.LightYellow;

Schedule1.HeaderResourceRowStyle.ForeColor = System.Drawing.Color.Goldenrod;

Schedule1.HeaderResourceRowStyle.BorderColor = System.Drawing.Color.Goldenrod;

Schedule1.HeaderResourceRowStyle.BorderStyle = Dotted;

Schedule1.HeaderResourceRowStyle.Font.Bold = true;

 

[VB]

 

Private Schedule1.HeaderResourceRowStyle.BackColor = System.Drawing.Color.LightYellow

Private Schedule1.HeaderResourceRowStyle.ForeColor = System.Drawing.Color.Goldenrod

Private Schedule1.HeaderResourceRowStyle.BorderColor = System.Drawing.Color.Goldenrod

Private Schedule1.HeaderResourceRowStyle.BorderStyle = Dotted

Private Schedule1.HeaderResourceRowStyle.Font.Bold = True

 

 

Figure 98: HeaderResourceRowStyle - BackColor = "LightYellow"; ForeColor = "Goldenrod"; BorderColor = "Goldenrod"; BorderStyle = "Dotted"; FontBold = "True"

Show or Hide Header Bar

 

You can toggle the visibility of the header bar using the property given below.

 

 

Schedule Property

 

Description

 

ShowHeaderBar

 

Specifies whether the header bar with date and navigation button is visible. Default value is set to True.

 

[ASPX]

 

<Syncfusion:Schedule id="Schedule1" runat="server" ShowHeaderBar="True">

</Syncfusion:Schedule>

 

[C#]

 

Schedule1.ShowHeaderBar = true;

 

[VB]

 

Private Schedule1.ShowHeaderBar = True

 

Header Bar Text Alignment and Style

 

You can align the header bar text using the options provided by the HeaderBarVerticalAlign property given below. Also, you can add style to the header bar using the HeaderBarStyle property.

 

 

Schedule Property

 

Description

HeaderBarVerticalAlign

Gets / sets text vertical align in header row. The options included are as follows:

 

·      NotSet

·      Top

·      Middle

·      Bottom

HeaderBarStyle

Specifies the style settings for header bar.

 

[ASPX]

 

<Syncfusion:Schedule id="Schedule1" runat="server" HeaderBarVerticalAlign="Middle">

   <headerbarstyle font-bold="True" BackColor="Goldenrod" ForeColor="LightYellow" font-names="Times New Roman" font-size="X-Small"/>

</Syncfusion:Schedule>

 

[C#]

 

Scheduler1.HeaderBarVerticalAlign = VerticalAlign.Middle;

 

Scheduler1.HeaderBarStyle.BackColor = Color.FromArgb(244, 204, 57);

Scheduler1.HeaderBarStyle.ForeColor = Color.Yellow;

Scheduler1.HeaderBarStyle.Font.Bold = true;

Scheduler1.HeaderBarStyle.Font.Name = "TimesNewRoman";

Scheduler1.HeaderBarStyle.Font.Size = 12;

 

[VB]

 

Private Scheduler1.HeaderBarVerticalAlign = VerticalAlign.Middle

 

Private Scheduler1.HeaderBarStyle.BackColor = Color.FromArgb(244, 204, 57)

Private Scheduler1.HeaderBarStyle.ForeColor = Color.Yellow

Private Scheduler1.HeaderBarStyle.Font.Bold = True

Private Scheduler1.HeaderBarStyle.Font.Name = "TimesNewRoman"

Private Scheduler1.HeaderBarStyle.Font.Size = 12

Header Text Formatting

 

You can set the header text format to any one of the pre-defined options supported by the Schedule control by using the HeaderFormat property given below.

 

Schedule Property

Description

HeaderFormat

Gets / sets the format type. Default value is Long. The options included are as follows:

·      Long

·      Short

·      CustomChar

·      CustomString

HeaderCustomFormatChar

Gets or sets custom format character.

HeaderCustomFormat

Gets or sets custom format string.

HeaderFormatString

Gets format pattern string.

 

By default, the Long (Ex: Tuesday, 20th February 2007) option will be set. The Short option will display the date in numbers (Ex: 02/21/2007).

 

When the HeaderFormat is set to the CustomChar option, the format will be obtained from the HeaderCustomFormatChar property.

 

The various valid character entries are listed in the below table.

 

 

CustomFormatChar Option

 

Format

d

01/20/2007

D

Monday, 01 January 2007

g/G

01/01/2007 00:00

f

Monday, 01 January 2007 00:00

F/U

Monday, 01 January 2007 00:00:00

m/M

January 01

t

00.00

T

09:00:00

u

2007-01-01 09:00:00z

y/Y

2007 January

r/R

Mon, 01 Jan 2007 09:00:00 GMT

s

2007-01-01 T09:00:00

 

Programmatically the properties can be set as follows.

 

[ASPX]

 

<Syncfusion:Schedule id="Schedule1" runat="server" HeaderFormat="CustomChar" HeaderCustomFormatChar="r">

</Syncfusion:Schedule>

 

[C#]

 

Schedule1.HeaderFormat = SchedulerDateTimeFormatType.CustomChar;

Schedule1.HeaderCustomFormatChar = 'r';

 

[VB]

 

Private Schedule1.HeaderFormat = SchedulerDateTimeFormatType.CustomChar

Private Schedule1.HeaderCustomFormatChar = "r"c

 

 

Figure 101: HeaderFormat = "CustomChar" and HeaderCustomFormatChar = "r"

 

Customized Header Text

 

When the HeaderFormat is set to the CustomString option, it displays the date in the format obtained from the HeaderCustomFormat property.

 

The various valid string entries are listed in the below table.

 

CustomFormat Option

Description

ffffff

The fraction of a second in six-digit precision. The remaining digits are truncated. The number of f's can be specified from 1 to 6, where those many digits will be displayed thereby truncating the remaining digits.

hh:mm:ss:ff

The hour in a 12-hour clock.

Single-digit hours/min/sec/fraction of a second, will have a leading zero.

HH:mm:ss:ff

The hour in a 24-hour clock.

Single-digit hours/min/sec/fraction of a second, will have a leading zero.

h:m:s:f

Single-digit hours/min/sec/fraction of a second will not have a leading zero.

MMMM/dddd/yyyy

The full name of the month/day/year will be displayed.

ddd/MMM

The abbreviated name of the day/month will be displayed.

dd/yy/MM

The first two letters of the day and month will be displayed.

Year will be displayed without the century. If the year without the century is less than 10, the year is displayed with a leading zero.

 

Programmatically the properties can be set as follows.

 

[ASPX]

 

<Syncfusion:Schedule id="Schedule1" runat="server" HeaderFormat="CustomString" HeaderCustomFormatChar="MMMM/dddd/yyyy">

</Syncfusion:Schedule>

 

[C#]

 

Schedule1.HeaderFormat = SchedulerDateTimeFormatType.CustomString;

Schedule1.HeaderCustomFormat = "MMMM/dddd/yyyy";

 

[VB]

 

Private Schedule1.HeaderFormat = SchedulerDateTimeFormatType.CustomString

Private Schedule1.HeaderCustomFormat = "MMMM/dddd/yyyy"

 

 

Figure 102: HeaderFormat = "CustomString" and HeaderCustomFormat = "MMMM/dddd/yyyy"

Schedule Property

 

Description

Schedule1.HorizontalAlign = Syncfusion.Web.UI.TextAlign.Right

Navigator Button

 

Navigator for Days

 

The left and right navigator buttons, to traverse through the days, can be set on either side of the header text, or can be positioned in the left indent cell (to the left of the header) by using the DayNavigatorPosition property given below.

 

Schedule Property

Description

DayNavigatorPosition

Specifies the navigator button position. Default value is HeaderLeftRight. The options included are as follows:

·      HeaderLeft

·      HeaderLeftRight

ShowNavigator

Gets / sets the boolean value whether to display the navigator buttons. Default value is False.

 

[ASPX]

 

<Syncfusion:Schedule id="Schedule1" runat="server" ShowNavigator="true" DayNavigatorPosition="HeaderLeftRight">

</Syncfusion:Schedule>

 

[C#]

 

Schedule1.DayNavigatorPosition = NavigatorPosition.HeaderLeftRight;

Schedule1.ShowNavigator = true;

 

[VB]

 

Private Schedule1.DayNavigatorPosition = NavigatorPosition.HeaderLeftRight

Private Schedule1.ShowNavigator = True

 

 

Figure 104: Navigator Buttons displayed on the Left and Right of the Header

 

Navigator Button Image

 

You can change the standard image displayed for the navigator buttons using the below given properties.

 

Schedule Property

Description

NextDayNavigatorImgUrl

Gets / sets image URL of next day navigator.

PreviousDayNavigatorImgUrl

Gets / sets image URL of previous day navigator.

</Syncfusion:Schedule>

 

[C#]

 

Schedule1.NextDayNavigatorImgUrl = "Desktop\Syncfusion\Company\IconCollection\navigate_right.ico";

Schedule1.PreviousDayNavigatorImgUrl = "Desktop\Syncfusion\Company\IconCollection\navigate_right.ico";

 

[VB]

 

Schedule1.NextDayNavigatorImgUrl = "Desktop\Syncfusion\Company\IconCollection\navigate_right.ico"

Schedule1.PreviousDayNavigatorImgUrl = "Desktop\Syncfusion\Company\IconCollection\navigate_right.ico"
