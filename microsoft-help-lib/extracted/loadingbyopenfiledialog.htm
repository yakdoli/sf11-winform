Loading by OpenFileDialog

 

LoadFromStream method:

The file that is selected by OpenDialog will be converted to FileStream and then the FileStream will be set as a parameter for the method along with the file name. Then, the method will convert the FileStream as Shapes or Polygons.

The following code snippet will describe how to load the shape files:

 

[XAML]

                     <maps:MapControl x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}>

                <maps:MapControl.Layers>

                    <maps:Layers>

                        <maps:ShapeFileLayer Uri="SilverlightApplication.ShapeFiles.wv.shp" x:Name="shapeControl" EnableHoverEffects="True" >

                        </maps:ShapeFileLayer>

                    </maps:Layers>

                </maps:MapControl.Layers>

            </maps:MapControl>

            <StackPanel>

            <Button HorizontalAlignment="Left" Content="LoadShape" Name="loadShapeButton" Click="loadShapeButton_Click" Width="72" />

            </StackPanel>  

 

[C#]

            OpenFileDialog openfileDialog=new OpenFileDialog();

            openfileDialog.Filter ="Shape Files (*.shp)|*.shp|All Files (*.*)|*.*";

            openfileDialog.ShowDialog();

            if (openfileDialog.File != null)

            {

                (this.Map.LayeredContent as ShapeFileLayer).LoadFromStream(openfileDialog.File.OpenRead(), openfileDialog.File.Name);

            }
