Through Code

 

Spell check can be performed on the text programmatically as follows.

 

1.   In the code behind file of the application, the following namespace should be added.

 

[C#]

 

using Syncfusion.Web.UI.WebControls.Tools;

 

[VB]

 

Imports Syncfusion.Web.UI.WebControls.Tools

 

2.   An instance of the SpellCheckControl has to be created and added to the form.

 

[C#]

 

SpellCheckControl SpellCheck = new SpellCheckControl();

form1.Controls.Add(SpellCheck);

 

[VB]

 

Private SpellCheck As SpellCheckControl = New SpellCheckControl()

form1.Controls.Add(SpellCheck)

 

3.   Set the ControlIDToCheck property to the control on which the spell check has to be performed. Also to customize the various settings for the control, refer to the Concepts and Features topic.

 

[C#]

 

SpellCheck.ControlIdToCheck = "TextBox3";

TextBox3.TextMode = TextBoxMode.MultiLine;

 

[VB]

 

Private SpellCheck.ControlIdToCheck = "TextBox3"

Private TextBox3.TextMode = TextBoxMode.MultiLine

 

4.   Build and run the application, to view the control.
