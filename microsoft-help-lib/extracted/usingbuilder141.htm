Using Builder

The following steps explain the addition of a chart to an application using Builder.

1.   In View, invoke the chart helper with the Control ID as the first argument.

                         

[ASPX]

<% = Html.MobSyncfusion().Chart("Chart")

              .Series(series =>

              {

                  series.Add().Name("Series 1").Type(SeriesType.Column).Points(p =>

                  {

                      p.Add(1, 75);

                      p.Add(2, 82);

                      p.Add(3, 87);

                      p.Add(4, 84);

                      p.Add(5, 84);

                      ...         

                  });

              }).Axes(axes => {

                  axes.PrimaryX(xaxis =>

                  {

                      xaxis.Title("X-Title");

                  }).PrimaryY(yaxis =>

                  {

                      yaxis.Title("Y-Title");

                  });

              }).Size(new System.Drawing.Size(700,500)).Text("Simple Chart").Font(newChartFont("Arial", "15px", ChartFontStyle.Bold)).ElementSpacing(10)

    %>

 

2.   Build and run the application.
