Navigation Control Positions

Navigation control can be positioned at following places on the Maps control.

·      Top

·      Right

·      Bottom

·      Left

 

NavigationControlPosition is the property which is used to set position of the Navigation control on the Map control.

The following code snippet will demonstrate how to set position for the Navigation control.

 

Setting at Top

[XAML]

            <maps:MapControl x:Name="Map" ShowNavigationControl="True" NavigationControlPosition="Top” LayeredContent="{Binding ElementName=shapeControl}">

                <maps:MapControl.Layers>

                    <maps:Layers>

                       <maps:ShapeFileLayer  Uri="MapsDemo.ShapeFiles.world.shp" x:Name="shapeControl"  EnableColorPalette="True">

                        </maps:ShapeFileLayer>

                    </maps:Layers>

                </maps:MapControl.Layers>

            </maps:MapControl>

 

 

[C#]

            MapControl map = new MapControl();

            map.ShowNavigationControl = true;

            map.NavigationControlPosition = NavigationControlPositions.Top;
