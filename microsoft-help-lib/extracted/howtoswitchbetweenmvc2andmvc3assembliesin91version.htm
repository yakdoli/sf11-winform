How to switch between MVC2 and MVC3 assemblies in 9.1version?

MVC3 to MVC2:

1.   Run the SwitchMVC2.bat file (<Install Location>\Syncfusion\Essential Studio\9.1.0.20\Utilities\MVCVersionSwitcher). It will move MVC2 assemblies to the precompiled assemblies folder and will configure the sample browser to MVC2.

2.   Run the Assembly Manager from the dashboard manually to place the MVC2 assemblies in GAC.

 

MVC2 to MVC3:

1.   Run the SwitchMVC3.bat file (<Install Location>\Syncfusion\Essential Studio\9.1.0.20\Utilities\MVCVersionSwitcher). It will move MVC3 assemblies to the precompiled assemblies folder and will configure the sample browser to MVC3.

2.   Run the Assembly Manager from the dashboard manually to place the MVC3 assemblies in GAC.
