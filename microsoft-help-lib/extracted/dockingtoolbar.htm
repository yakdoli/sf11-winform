Docking Toolbar

Top

[XAML]

 

        <sync:ToolBar ToolBarDockPosition="Top" x:Name="toolbar" >

            <sync:ToolBar.ToolBarItems>

                <sync:ToolBarItem Caption="item 1"/>

                <sync:ToolBarItem Caption="item 2"/>

            </sync:ToolBar.ToolBarItems>

        </sync:ToolBar>

 

 

[C#]

 

ToolBar toolbar = new ToolBar();

toolbar.ToolBarDockPosition = Dock.Top;

 

Figure 67: Top Docking Position
