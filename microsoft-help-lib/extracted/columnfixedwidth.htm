ColumnFixedWidth

 

Specifies the width of each column when ColumnWidthMode property is set to FixedWidthMode.

 

Details

Possible Values

An integer value

Default Value    

20

2D / 3D Limitations

None

Applies to Chart Element

All Series

Applies to Chart Types

Column Charts, BoxAndWhiskerChart, Candle Chart

 

Here is some sample code.

 

[C#]

 

ChartSeries series1 = new ChartSeries("Series");

series1.Points.Add(1, new double[] { 24});

series1.Points.Add(2, new double[] { 36});

series1.Points.Add(3, new double[] { 48});

ChartWebControl1.Series.Add(series1);

ChartWebControl1.ColumnWidthMode = ChartColumnWidthMode.FixedWidthMode;

ChartWebControl1.ColumnFixedWidth = 45;

 

[VB.NET]

 

Dim series1 As ChartSeries = New ChartSeries("Series")

series1.Points.Add(1, New Double() { 24})

series1.Points.Add(2, New Double() { 36})

series1.Points.Add(3, New Double() { 48})

ChartWebControl1.Series.Add(series1)

ChartWebControl1.ColumnWidthMode = ChartColumnWidthMode.FixedWidthMode

ChartWebControl1.ColumnFixedWidth = 45

 

Note: The ColumnFixedWidth property can be overridden by specifying a second y value in the data point. See ColumnWidthMode for a sample.
