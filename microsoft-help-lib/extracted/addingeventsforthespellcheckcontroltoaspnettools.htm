Adding events for the SpellCheck Control to ASP.NET Tools

Client-Side Events

To raise and process the Client-side events, follow the steps given below-

1.   Add a new web-page in your project.

2.   Drag the SpellCheckControl and assign the “Complete” function to the “ClientSideOnSpellCheckComplete” event.

3.   Assign the “Started” function to the “ClientOnSpellCheckStarted” event.

4.   Add the required items (e.g.: TextBox1, TextBox2, etc.) to the ASPX page.

 

 

[ASPX]

 

<syncfusion:SpellCheckControl ClientSideOnSpellCheckComplete = "Complete"

            ClientSideOnSpellCheckStarted = "Started" ID = "SpellCheck1"

            ControlsToCheck = "TextBox1,TextBox2,TextBox3" runat = "server"

syncfusion:SpellCheckControl>

 

 

[Script]

  <script type ="text/javascript">

         function Complete(sender, value) {

alert(value.ID);            

         }

         function Started(sender, value) {  

             alert(value.ID);

 

         }

         });

 

 

5.   Build and run the application.

Server-side events

To raise and process the Server-side events, follow the steps given below-

1.   Add a new web-page in your project.

2.   Drag the SpellCheckControl and assign the “SpellCheck1_SpellCheckComplete” function to the “OnSpellCheckComplete” event.

 

 

[ASPX]

 

<syncfusion:SpellCheckControl ID = "SpellCheck1" Autopostback = "true"  ControlsToCheck = "TextBox1,TextBox2,TextBox3" runat = "server" onspellcheckcomplete="SpellCheck1_SpellCheckComplete"></syncfusion:SpellCheckControl>

 

 

 

[CS]

 

this.SpellCheck1.SpellCheckComplete +=new Syncfusion.Web.UI.WebControls.Tools.SpellCheckControl.SpellCheckCompleteEventHandler(SpellCheck1_SpellCheckComplete);

 

protected void SpellCheck1_SpellCheckComplete(object Sender, EventArgs e)

    {

       

    }

 

 

[VB]

 

Protected Sub SpellCheckControl1_SpellCheckComplete(ByVal Sender As Object, ByVal e As System.EventArgs) Handles SpellCheckControl1.SpellCheckComplete

Me.TextBox1.Text = "Server Side event"

    End Sub

 

3.   Build and run the application.
