ScatterConnectType

ScatterConnectType specifies the connection type of the Scatter charts.

 

Details

Possible values

None - Scatter Connect Type will be none.

Line - Scatter Connect Type will be line.

Spline - Scatter Connect Type will be spline.

Default value    

None

2D/3D limitations

No

Application to chart element

All series

Application to chart types

Scatter chart
