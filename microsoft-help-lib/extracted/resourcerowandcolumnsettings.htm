Resource Row and Column Settings

 

Customize the Resource Header

 

This section describes how to customize the resource header.

 

Row Settings

 

You can customize the resource rows by using the following properties.

 

 

Resource Property

 

Description

 

ResourceNoneRowName

 

Specifies the ResourceNone row name.

 

ResourceRowStyle

 

Specifies the style settings for resource row.

 

[ASPX]

 

<Syncfusion:schedule viewstrip="true" enableviewstate="true" id="Schedule1" height="600px" width="700px" runat="server">

<ResourceRowStyle forecolor="yellow" Font.Name="TimesNewRoman" Font.Size="12" Font.Bold="True"/>

</Syncfusion:schedule>

 

[C#]

 

Schedule1.ResourceNoneRowName = "Resource None";

 

Schedule1.ResourceRowStyle.BackColor = System.Drawing.Color.Gold;

Schedule1.ResourceRowStyle.ForeColor = System.Drawing.Color.Yellow;

Schedule1.ResourceRowStyle.Font.Name = "TimesNewRoman";

Schedule1.ResourceRowStyle.Font.Size = 12;

Schedule1.ResourceRowStyle.Font.Bold = true;

 

[VB]

 

Schedule1.ResourceNoneRowName = "Resource None"

 

Private Schedule1.ResourceRowStyle.BackColor = System.Drawing.Color.Gold

Private Schedule1.ResourceRowStyle.ForeColor = System.Drawing.Color.Yellow

Private Schedule1.ResourceRowStyle.Font.Name = "TimesNewRoman"

Private Schedule1.ResourceRowStyle.Font.Size = 12

Private Schedule1.ResourceRowStyle.Font.Bold = True

Column Settings

 

You can customize the resource columns using the following properties.

 

 

Resource Property

 

Description

ResourceColumn

Gets / sets value (in pixels) that indicates the width of the resource column in horizontal Schedule.

ResourceDescriptionColumnName

Specifies the ResourceDescription column name.

ResourceInfoColumnName

Specifies the ResourceInfo column name.

ResourceNameColumnName

Specifies the ResourceName column name.

 

[C#]

 

this.Schedule1.ResourceColumn = new ScheduleResourceColumn();

 

Schedule1.ResourceDescriptionColumnName = "Resource Description";

Schedule1.ResourceInfoColumnName = "Resource Info";

Schedule1.ResourceNameColumnName = "Resource Name";

 

[VB]

 

Me.Schedule1.ResourceColumn = New ScheduleResourceColumn()

 

Schedule1.ResourceDescriptionColumnName = "Resource Description"

Schedule1.ResourceInfoColumnName = "Resource Info"

Schedule1.ResourceNameColumnName = "Resource Name"

 

Show / Hide Resources

 

The number of resources for a day that should be visible to the user can be set by specifying the numeric value to the VisibleResources property (For ex: When the value is set to 2, two resources will be displayed for a single day).

Also, the first resource that should be visible for a day can be set using the ResourceIndex property.

 

Note: The ResourceIndex property will take effect only when the following condition holds true: VisibleResources > 0.

 

[ASPX]

 

<Syncfusion:schedule viewstrip="true" enableviewstate="true" id="Schedule1" runat="server" VisibleDays="2" ResourceIndex="1">

</Syncfusion:schedule>

 

[C#]

 

Schedule1.VisibleResources = 2;

Schedule1.ResourceIndex = 1;

 

[VB]

 

Private Schedule1.VisibleResources = 2

Private Schedule1.ResourceIndex = 1
