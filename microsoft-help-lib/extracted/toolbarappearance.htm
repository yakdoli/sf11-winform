Toolbar Appearance

 

You can set different styles for the toolbar using the AutoFormat property through designer or programmatically. The default is Windows Classic.

 

[C#]

 

this.ChartWebControl1.AutoFormat = AutoFormatEnum.Office2007LunaBlue;

 

[VB.NET]

 

Me.ChartWebControl1.AutoFormat = AutoFormatEnum.Office2007LunaBlue
