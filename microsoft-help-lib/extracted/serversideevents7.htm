Server-Side Events

 

The server-side events can be handled to execute a function on some user action. The various server-side events are listed below.

 

 

Server-Side Event

 

Description

TextChanged

Specifies the function to be executed when the text in the input area of MultiSelectionDropDown changes. This event is handled only when the AutoPostBackOnTextChanged property is set to True.

ItemCheckChanged

Specifies the function to be executed when the checkbox selection is changed. This event is handled only when the AutoPostBackOnItemCheckChanged property is set to True.

 

The following procedure shows how to process and handle the server-side events.

 

1.   Add the following code snippet in the html view of your project.

 

[ASPX]

 

<cc1:MultiSelectionDropDown ID="MultiSelectionDropDown1"  runat="server" DataSourceID="XmlDataSource1"  DataTextField="Title" DataValueField="Title"   AutoPostBackOnItemCheckChanged=”true”       OnItemCheckChanged="MultiSelectionDropDown2_ItemCheckChanged"  OnTextChanged="MultiSelectionDropDown2_TextChanged" AutoPostBackOnTextChanged="true"  >

<CheckBoxListStyle BackColor="#DAE5F5"  Font-Names="Verdana" Font-Size="12px" ForeColor="#000033" />

</cc1:MultiSelectionDropDown>

 

4.   Add the following code snippets in the code view of your project.

 

[C#]

 

protected void MultiSelectionDropDown2_ItemCheckChanged(object sender, Syncfusion.Web.UI.WebControls.Tools.MultiSelectionDropDownCheckChangedEventArgs e)

{

this.Label1.Text = e.ListItem.Text;

}

 

protected void MultiSelectionDropDown2_TextChanged(object sender, Syncfusion.Web.UI.WebControls.Shared.GenericDropDownTextChangeEventArg e)

{

this.Label1.Text = e.OldText;

}

 

[VB]

 

Protected Sub MultiSelectionDropDown2_ItemCheckChanged(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.MultiSelectionDropDownCheckChangedEventArgs)

Me.Label1.Text = e.ListItem.Text

End Sub

 

Protected Sub MultiSelectionDropDown2_TextChanged(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Shared.GenericDropDownTextChangeEventArg)

Me.Label1.Text = e.OldText

End Sub

 

5.   Build and run the application.

 

On changing the text and status of the CheckBox in the MultiSelectionDropDown control, the corresponding server-side events are handled.
