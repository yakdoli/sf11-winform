Properties

 

The following table lists the properties of Scales along with their description.

 

Property

Description

ShadowOffset

Sets the shadow off set value for the Linear Scale.

Minimum

Sets the minimum value for the Linear Scale.

Maximum

Sets the maximum value for the Linear Scale.

MinorIntervalValue

Indicates the value for the minor intervals.

MajorIntervalValue

Indicates the value for the major intervals.

ScaleBarSize

ScaleBarSize sets the size for the Scale bar.

Radius

Radius sets the radius for the Linear Gauge.

BorderWidth

BorderWidth sets the border width for the linear scale.

BorderBrush

BorderBrush sets the border brush values.

BackgroundBrush

BackgroundBrush sets the background brush for the linear scale.

ScaleType

Sets the Scale type as Linear or Thermometer
