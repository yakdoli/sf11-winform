Through Designer

 

To create a Snap control:

 

1.   Add a new ASP.NET page to your project.

2.   In design view, from the toolbox, drag a Snap control onto the design surface.

3.   In HTML view, insert the following code snippet between the <cc1:Snap ID="Snap1"> and </cc1:snap> tags.

 

<cc1:snap id="Snap1" runat="server" ExpandCollapseElementIDs = "imgExpSnap1, imgCollSnap1" MustBeDocked = "False" DraggingStyle= "GhostCopy"  DockingStyle = "TransparentRectangle" CollapseDuration = "300" ExpandDuration = "300" IsCollapsed = "false"  CssClass= "Snap">

   <CollapsedHeaderTemplate>

      <div style="CURSOR: move;">

         <table cellSpacing="0" cellPadding="0" width="100%" border="0">

            <tr>

               <td class="SnapHeaderClosed">Developer Tools</td>

               <td width="10" style="cursor: hand" align="right"><img id="imgCollSnap1" src="images/i_closed.gif" width="22" height="19"></td>

            </tr>

         </table>

      </div>

   </CollapsedHeaderTemplate>

 

   <ContentTemplate>

      <div class="SnapContent">

         <table class="maintext" cellpadding="0" cellspacing="0" border="0">

            <tr>

               <td><img src="images/bullet.gif" width="13" height="13" border="0">&nbsp;Essential Tools</td>

            </tr>

         </table>

      </div>

   </ContentTemplate>

 

   <HeaderTemplate>

      <div style="CURSOR: move;">

         <table cellSpacing="0" cellPadding="0" width="100%" border="0">

            <tr>

               <td class="SnapHeader">Developer Tools</td>

               <td width="10" style="cursor: hand" align="right"><img id="imgExpSnap1" src="images/i_open.gif" width="22" height="19" border="0"></td>

            </tr>

         </table>

      </div>

   </HeaderTemplate>

 

4.   Build and view the page in the browser.

5.   The Snap element (Developer Tools) can be dragged to any location on the page.

 

Note: Also refer to Template Support for Snap for details on the various templates of Snap.
