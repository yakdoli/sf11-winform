Client-side APIs

 

The various client-side APIs of the ColorPicker control are illustrated below.

 

·      ShowPicker(X, Y, AbsoluteParent)

 

Shows the ColorPicker pop-up.

 

Params

 

X: X-Cord of ColorPicker.

 

Y: Y-Cord of ColorPicker.

 

AbsoluteParent

 

Setting True for this value, will display the ColorPicker pop-up in the given X & Y coordinates with respect to the parent position. Setting False for this value, will display the ColorPicker pop-up in the given X & Y coordinates with respect to the page.

 

[ASPX]

 

<Input type="button" ID="Button1" value="Button1" OnClick="show" />

<Syncfusion:ColorPicker ID="ColorPicker1" runat="server" ParentControlID="Button1" DisplayMode="PopupWithoutPickerButton" />

<Script type="text/javascript" >

function show()

{

var color=$find('ColorPicker1');

color.ShowPicker(10,15,true);

}

</Script>

 

·      HidePicker

 

Hides the ColorPicker pop-up.

 

·      SelectedColor

 

Returns the selected color.

 

·      PreviousColor

 

Returns the previously selected color.

 

[ASPX]

 

<Input type="text1" ID="Text1" />

<Input type="button" ID="Button1" value="Button1" OnClick="select" />

<Syncfusion:ColorPicker ID="ColorPicker1" runat="server" ParentControlID="Button1" />

<Script type="text/javascript" >

function select()

{

var color=$find('ColorPicker1');

var txt=$get('Text1');

txt.innerHTML=color.SelectedColor+color.PreviousColor;

}

</Script>
