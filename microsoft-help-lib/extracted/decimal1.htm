Decimal

The percent text box control can be configured to allow double values. The range of the double values allowed in the percent text box can also be set.

 

Properties

Description

Type of property

Value it accepts

Dependency

Decimal

Sets the number of decimal digits.

int

0 to int.MaxValue

NA

 

Using Builder

The following steps explain how to configure a percent text box through the builder to allow double values.

1.   In View, invoke the percent text box helper followed by the Decimal method with the desired value as an argument.

 

View[ASPX]

<%=Html.Syncfusion().PercentTextBox("myPercent")

.MinValue(10)

.MaxValue(100)

.Decimal(1)%>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent")

.MinValue(10)

.MaxValue(100)

.Decimal(1).ToString()))

 

 

2.   Build and run the application

 

Using Properties Model

The following steps explain how to configure a percent text box through the properties model to allow double values.

1.   In the controller, create an instance of PercentTextBoxModel.

2.   Define the Decimal property and pass the instance through the view-specific data to the view.

 

[Controller]

 

public ActionResult Index()

        {

            //Creating instance of PercentTextBoxModel

            PercentTextBoxModel myModel = new PercentTextBoxModel();

            myModel.MinValue = 10;

            myModel.MaxValue = 100;

            myModel.Decimal = 1;

 

            //pass the instance through view data to the view

            ViewData["myPercent"] = myModel;

            return View();

        }

 

 

3.   In View, invoke the percent text box helper with the view data key as the control ID.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent") %>

 

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent").ToString()))

 

 

4.   Build and run the application.
