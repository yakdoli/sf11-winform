TextAlignment        

 

The TextAlignment property specifies the alignment for the content of the control. It can set to one of the following values:

 

·      Left

·      Center

·      Right

 

The following code illustrates this.

 

[XAML]

 

<syncfusion:DomainUpDown x:Name="DomainUpDown1" TextAlignment="Left" />

 

[C#]

 

DomainUpDown domainUpDown = new DomainUpDown();

domainUpDown.TextAlignment = TextAlignment.Left;
