Adding ActionLink Button Control to a Mobile MVC Application

 

In the Getting Started section, we discussed how to create a Mobile MVC application and how to add the Tools package to the application. This section guides you to add the ActionLink Button control to an application.

 

1.   In the view, invoke the ActionLink Button helper with the text of the button as the first argument.

 

[ASPX]

        <%= Html.MobSyncfusion() .ActionLink("Link Button", "ActionLink", "Button").AutoFormat(MobSkins.Spinach)

         %>

[Razor]

        @{ Html.MobSyncfusion() .ActionLink("Link Button", "ActionLink", "Button").AutoFormat(MobSkins.Spinach). Render();
        }

 

2.   Run the application.
