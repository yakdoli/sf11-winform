Circular Gauge Properties

Some of the important properties of Circular Gauge are listed in the following table.

 

Table 14: Property Table

Property

Description

IsColorMergeWithBase

Specifies whether the brushes given to the FirstFrameFillColor, SecondFrameFillColor and the CenterFrameFillColor properties should be merged with that of the default colors. Note that the default value is set to true for backward compatibility.

InnerFrameContent

Enables to host any content inside the circular gauge control.

SizeToContainer

Specifies whether the circular gauge should be scaled to fit the container.

HalfCircleInnerRadius

Specifies the inner circle radius of half circle. Effective for only half circle frame type.

HalfCircleInnerSweepDirection

Specifies the inner circle sweep direction of half circle frame. Effective for only half circle frame type.

HalfCircleSweepDirection

Specifies the half circle sweep direction.
