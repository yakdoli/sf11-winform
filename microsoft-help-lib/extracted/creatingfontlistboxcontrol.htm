Creating FontListBox Control

 

You can add FontListBox to both Windows WPF and XBAP applications by using either XAML or C# code. Using the following code, you can add a FontListBox control to a WPF application.

 

[XAML]

 

<syncfusion:FontListBox x:Name="fontListBox" Foreground="Black" />

 

[C#]

 

FontListBox fontlistbox = new FontListBox();

fontlistbox.Name = "fontListBox";

 

Note: To display the FontListBox using C# code, you must already have the Panel in which you are going to add the control. Otherwise, the control cannot be displayed.
