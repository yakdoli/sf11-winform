Linear Gauge Control Template

The default Linear gauge template can be overwritten to provide custom visual style. For instance, create control template with single border as root element and bind the required properties with the template binding logic to supply values through setter method in style.

 

[XAML]

 

<!--Control template for linear gauge.-->

<ControlTemplate x:Key="customTemplate" TargetType="{x:Type syncfusion:LinearGauge}">

    <AdornerDecorator>

       

        <!--Border, property values with template binding.-->

        <Border Name="PART_ContainerBorder" Width="{TemplateBinding Width}" Height="{TemplateBinding Height}" CornerRadius="10"

        Background="{TemplateBinding Background}"/>

    </AdornerDecorator>

</ControlTemplate>

 

<!--Apply template for gauge using style property or through application level scope.-->

<!--Style for gauge.-->

<Style TargetType="{x:Type syncfusion:LinearGauge}">

   

    <!--Applying custom template.-->

    <Setter Property="Template" Value="{StaticResource customTemplate}"/>

   

    <!--Width and Height of the gauge.-->

    <Setter Property="Width" Value="300" />

    <Setter Property="Height" Value="300" />

   

    <!--Background for border. Value can be any brush type.-->

    <Setter Property="Background" Value="{StaticResource bg_Green}"/>

</Style>

 

Note:Resource bg_Green is a custom Visual Brush which is declared in App.xaml.

Note: While adding custom templates, the <ControlTemplate> tag should be followed by the <AdornerDecorator> tag, and the <Border> tag of name "PART_ContainerBorder", for proper rendering of elements.
