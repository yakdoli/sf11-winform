Display Setting for Week Days

 

The week days can be either represented in short form or just the first two letters by setting the corresponding options to the DayNameFormat property.

 

Property

Description

DayNameFormat

Specifies the weekday format for the CalendarControl. Default value is Short. The options included are as follows:

·      Short

·      FirstLetter

·      FirstTwoLetter

 

[ASPX]

 

<syncfusion:calendar ID="Calendar3" runat="server" DayNameFormat="Short" AutoFormat="Office2007 Blue"/>

<syncfusion:Calendar ID="Calendar1" runat="server" DayNameFormat="FirstTwoLetter" AutoFormat="Office2007 Blue"/>

<syncfusion:Calendar ID="Calendar2" runat="server" DayNameFormat="FirstLetter" AutoFormat="Office2007 Blue"/>

 

[C#]

 

Calendar1.DayNameFormat = Syncfusion.Web.UI.WebControls.Shared.DayNameFormat.Short;

Calendar2.DayNameFormat = Syncfusion.Web.UI.WebControls.Shared.DayNameFormat.FirstTwoLetter;

Calendar3.DayNameFormat = Syncfusion.Web.UI.WebControls.Shared.DayNameFormat.FirstLetter;

 

[VB.NET]

 

Private Calendar1.DayNameFormat = Syncfusion.Web.UI.WebControls.Shared.DayNameFormat.Short

Private Calendar2.DayNameFormat = Syncfusion.Web.UI.WebControls.Shared.DayNameFormat.FirstTwoLetter

Private Calendar3.DayNameFormat = Syncfusion.Web.UI.WebControls.Shared.DayNameFormat.FirstLetter
