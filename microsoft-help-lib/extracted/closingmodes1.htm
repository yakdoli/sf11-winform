Closing modes

This feature enables you to close the tooltip by tapping outside the tooltip or by hard ware back key. This help you the exit the tooltip easily.

 

Enabling Closing Modes

To enable closing the tooltip by tapping outside, set the IsTapOutside property to true. By default this is set to false.

The following code illustrates how to enable closing the tooltip by tapping outside:

 

[xaml]

 

<syncfusion:ToolTip  RelativeTo="Button1"  IsTapOutside="True" RelativePlacement="Bottom"  x:Name="tooltip" Content="Tooltip is placed over the Relative element at the Relative position specified by the user"

  />

 

 

[C#]

 

Syncfusion.Phone.Tools.Controls.ToolTip _tooltip=new Syncfusion.Phone.Tools.Controls.ToolTip();

_tooltip.RelativeTo="Button1";

_tooltip.RelativePlacement=Syncfusion.Phone.Tools.Controls.Placement.Bottom;

_tooltip.IsTapOutside=true;

  _tooltip.Content="Tooltip is placed over the Relative element at the Relative position specified by the user";

 

 

 

To enable closing the tooltip by tapping hard ware back key, set the IsBackKeyClose property to true. By default this is set to false.

 

The following code illustrates how to enable closing the tooltip by tapping hard ware back key:

 

[xaml]

          <syncfusion:ToolTip  RelativeTo="Button1" IsBackKeyClose="True" RelativePlacement="Bottom"  x:Name="tooltip" Content="Tooltip is placed over the Relative element at the Relative position specified by the user"

  />         

 

[C#]

 Syncfusion.Phone.Tools.Controls.ToolTip _tooltip=new Syncfusion.Phone.Tools.Controls.ToolTip();

         _tooltip.RelativeTo="Button1";

            _tooltip.RelativePlacement=Syncfusion.Phone.Tools.Controls.Placement.Bottom;

            _tooltip.IsBackKeyClose=true;

            _tooltip.Content="Tooltip is placed over the Relative element at the Relative position specified by the user";
