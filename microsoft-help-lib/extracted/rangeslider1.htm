Range Slider

Range Slider is a dual-thumb slider control highlighting the selected range between the thumbs. This enables you to specify a range as an input value. You can set the range by dragging the thumb or clicking on the slider bar. Range Slider accepts only numeric value. You can orient the slider vertically or horizontally as needed.

 

IT Scenarios

Using this control you can set a price range to select products, or specify a time range to filter the list of album published in a specific period of time.
