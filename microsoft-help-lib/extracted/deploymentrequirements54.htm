Deployment Requirements

 

The following assemblies need to be referenced in the application to use the Essential PivotGrid Silverlight:

 

·      Syncfusion.Compression.Silverlight

·      Syncfusion.DocIO.Silverlight

·      Syncfusion.Grid.Silverlight

·      Syncfusion.GridCommon.Silverlight

·      Syncfusion.Linq.Silverlight

·      Syncfusion.Pdf.Silverlight

·      Syncfusion.XlsIO.Silverlight

·      Syncfusion.PivotAnalysis.Base.Silverlight

·      Syncfusion.PivotAnalysis.Silverlight
