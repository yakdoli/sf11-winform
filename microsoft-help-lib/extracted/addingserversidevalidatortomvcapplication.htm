Adding Server Side Validator to MVC application

Refer to the Getting Started section to know the pre-requisites before stepping in to add a rich text editor control to MVC application application.

The following steps explain adding the server side validator to an application.

1.   In View, create a form with input fields followed by the validation message as below.

 

 

View[ASPX]

<%using (Html.BeginForm()){ %>

       Email Address:

              <%=Html.Syncfusion().TextBox("Email") %>

              <%= Html.Syncfusion().ValidationMessage("Email")%>

              <input type="submit" value="Submit" />

       <%} %>

 

 

View[cshtml]

 

 

@{using (Html.BeginForm( )){

   

              @Html.TextBox("Email")

              @Html.ValidationMessage("Email")

 

              <input type="submit" value="Submit" />

       } }

 

 

 

 

2.   In the Controller, invoke the validation method in the post action as below.

 

[Controller]

public ActionResult Index()

        {           

            return View();

        }

 

        //Post Action for the form

        [AcceptVerbs(HttpVerbs.Post)]       

        public ActionResult Index(string Email)

        {

             //Invoke the Validate method with the appropriate arguments

ModelState.Validate("Email", "Invalid Email!", ModelStateExtensions.ValidationType.Email, Email);

              return View();

 

        } 

 

 

3.   Build and run the application
