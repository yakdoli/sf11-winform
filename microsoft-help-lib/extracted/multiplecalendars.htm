Multiple Calendars

 

Essential Tools Calendar control can be displayed with multiple months by using the following properties.

 

HorizontalMonthsCount

 

This will increase the number of columns in which the calendars should be displayed.

 

Figure 121

 

VerticalMonthsCount

 

This will increase the number of rows in which the calendars should be displayed.

 

 

The following code example demonstrates how to increase / decrease horizontal and vertical months count programmatically.

[C#]

 

protected void Page_Load(object sender, EventArgs e)

{

       if (!this.IsPostBack)

    {

        Button3.Enabled = Calendar1.HorizontalMonthsCount > 1;

        Button1.Enabled = Calendar1.VerticalMonthsCount > 1;

    }

}

 

protected void Button1_Click(object sender, EventArgs e)

{

    Calendar1.VerticalMonthsCount--;

    Button1.Enabled = Calendar1.VerticalMonthsCount > 1;

}

protected void Button2_Click(object sender, EventArgs e)

{

    Calendar1.VerticalMonthsCount++;

    Button1.Enabled = Calendar1.VerticalMonthsCount > 1;

}

protected void Button4_Click(object sender, EventArgs e)

{

    Calendar1.HorizontalMonthsCount++;

    Button3.Enabled = Calendar1.HorizontalMonthsCount > 1;

}

protected void Button3_Click(object sender, EventArgs e)

{

    Calendar1.HorizontalMonthsCount--;

    Button3.Enabled = Calendar1.HorizontalMonthsCount > 1;

}
