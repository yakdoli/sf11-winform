SplitterBar

This property allows you to add the splitter bar for each pane and contains all splitter bar-related properties.

Properties

Name

Description

Type

Value Accepted

Dependencies

SplitterBar

This porperty contains splitter bar-related properties such as

CollapseMode, AllowSplitterBar

SplitterBarActionMethod

NA

This is part of SplitterPane properties.

 

You can set the SplitterBar property in both ASPX and Razor engine modes.

[ASPX]

 

<%=Html.Syncfusion().Splitter("splitter").SplitterPanes(panes1=>{

 

panes1.Add().PaneSize(Unit.Percentage(50)).ContentTemplate(()=>{%>

 

             <p>inner first pane</p>

 

<%}).SplitterBar(b=>b.AllowSplitterBar(true));

 

panes1.Add().PaneSize(Unit.Percentage(30)).ContentTemplate(()=>{%>

 

             <p>inner second pane</p>

 

   <%});

})

.Orientation(SplitterOrientation.Horizontal) %>

 

   

 

[Razor]

 

@{Html.Syncfusion().Splitter("splitter").SplitterPanes(panes1=>{

 

panes1.Add().PaneSize(Unit.Percentage(50)).ContentTemplate(

 

@<p>inner first pane</p>

 

).SplitterBar(b=>b.AllowSplitterBar(true));

 

panes1.Add().PaneSize(Unit.Percentage(30)).ContentTemplate(

         @<p>inner second pane</p>

  );

})

.Orientation(SplitterOrientation.Horizontal).Render() }

 

   

 

Run the application.
