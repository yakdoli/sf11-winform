Using Builder

The following steps will explain the customization of Footer templates using Builder:

1.   In View, invoke the Footer helper with the Control ID as the first argument followed by theLeftButton and RightButtonmethods with their arguments.

 

[ASPX]

                <%{

                      Html.MobSyncfusion().Footer("Footer").AutoFormat(MobSkins.MetroBlue)

                        .TargetId("targetFooter")

                        .Title("Select an action")

                        .AutoFormat(MobSkins.MetroBlue)

                        .Template(() =>

                        {%>

                <div>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/left.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/right.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/playback.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/clipboard.png")%>"class="footer-img"/>

                    <imgalt=""src="<%=Url.Content("~/Content/Footer/Images/wrench.png")%>"class="footer-img"/>

                </div>

                <%})

                .Render();

                  } %>

 

 [Razor]

         @{

            Html.MobSyncfusion().Footer("Footer").AutoFormat(MobSkins.MetroBlue)

                 .TargetId("targetFooter")

                .Title("Select an action")

                .AutoFormat(MobSkins.MetroBlue)

                .Template(@<div>

                    <imgalt=""src="@Url.Content("~/Content/Footer/Images/left.png")"class="footer-img"/>

                    <imgalt=""src="@Url.Content("~/Content/Footer/Images/right.png")"class="footer-img"  />

                    <imgalt=""src="@Url.Content("~/Content/Footer/Images/playback.png")"class="footer-img"/>

                    <imgalt=""src="@Url.Content("~/Content/Footer/Images/clipboard.png")"class="footer-img"  />

                    <imgalt=""src="@Url.Content("~/Content/Footer/Images/wrench.png")"class="footer-img"/></div>)

                .Render();

        }

 

 

2.   Build and run the application.
