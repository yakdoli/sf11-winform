Digital Value Support

 

Essential Linear gauge Silverlight facilitates usage of a Digital gauge component within a Linear gauge component to display the character or numeric value of the pointed reading in the Linear gauge.

 

The following code snippet illustrates on how to set a Digital gauge component in a Linear gauge.

 

[XAML]

 

<syncfusion:LinearGauge Height="350" Width="150" ShowDigitalValue="True" Grid.Column="1" Grid.RowSpan="2" VerticalAlignment="Center"  HorizontalAlignment="Center"  Name="linearGauge1" Orientation="Vertical" Margin="3" >

                            <syncfusion:LinearGauge.DigitalValue>

                                <syncfusion:DigitalGauge CharacterCount="3" Background="Transparent" CharacterType="SegmentFourteen" InnerFrameBrush="Transparent" OuterFrameBrush="Transparent" CharacterHeight="15" Margin="50,250,0,0" VerticalAlignment="Center" HorizontalAlignment="Center" Value="{Binding ElementName=linearGauge1, Path=Scales[0].Pointers[0].Value,Mode=OneWay,Converter={StaticResource ValueRound}}" SegmentBrush="Black"/>

                            </syncfusion:LinearGauge.DigitalValue>

</syncfusion:LinearGauge>
