Event Mechanism

This section describes the events of the Map control. When the events are triggered, parameters for  the events will be passed to the event handling function.

There tabulated events that exist in Map control:

 

Event

Description

Arguments

Type

PreviewZoomIn

Triggered before zoomin gthe Map

Double Latitude,Double Longitude, Double ZoomFactor

Routed Event

PreviewZoomOut

Triggered before zoomingout the Map

Double Latitude,Double Longitude, Double ZoomFactor

Routed Event

ZoomedIn

Triggered after Map is zoomed in

Double Latitude,Double Longitude, Double ZoomFactor

Routed Event

ZoomedOut

Triggered after Map zoomed out

Double Latitude,Double Longitude, Double ZoomFactor

Routed Event

Panning

Triggered while Panning the Map

Double Latitude,Double Longitude, PanMode panMode

Routed Event

Panned

Triggered after Panned the Map

Double Latitude,Double Longitude, PanMode panMode

Routed Event

SelectionChanged

Triggered when Selection is changed in the Map

List RemovedItems, List AddedItems

Routed Event

 

Registering Events

Events can be registered via XAML and CodeBehind. The following code snippet describes how to raise the events through XAML and CodeBehind.

 

PreviewZoomIn Event

PreviewZoomIn event will be triggered before Zooming in the map as shown in the following code.

[XAML]

           <maps:MapControl x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}”>

                            <maps:MapControl.Layers>

                                <maps:Layers>

                                <maps:ShapeFileLayer Uri="EventsDemo.ShapeFiles.wv.shp" PreviewZoomIn="Map_PreviewZoomIn”>

                                    </maps:ShapeFileLayer>

                                </maps:Layers>

                            </maps:MapControl.Layers>

             </maps:MapControl>

 

[C#]

        this.shapeControl.PreviewZoomIn += new ZoomEventHandler(shapeControl_PreviewZoomIn);

  

        void shapeControl_PreviewZoomIn(object sender, ZoomEventArgs args)

        {

            // User Code

        }
