Different types of Display Modes

There are two different types of Display Modes in Gallery View.

1.  Gallery View

2.  List View

 

Property

Description

DisplayMode

Specifies display mode of the gallery view. Default value is GalleryView. The Options Included are as follows:

·      GalleryView

·      ListView

 

Gallery View renders the list of images in the Gallery mode which has rich look like in office 2010 in which the List View renders the list of images in the list types.

5.6.5.2.1.1 Gallery View Mode

The Gallery View is rendered as Gallery mode by setting the DisplayMode Property to GalleryView. The following code snippet explains this:

 

[ASPX]

 

<syncfusion:GalleryView ID="Gallery" Height="96px" Width="370px" ItemsToShow="4" runat="server" DisplayMode="GalleryView">

 <Items>

  <syncfusion:GalleryViewItem Name="Heading1" ImageUrl="Img/Heading1.png" />

  <syncfusion:GalleryViewItem Name="Heading2" ImageUrl="Img/Heading2.png" />

  <syncfusion:GalleryViewItem Name="Heading3" ImageUrl="Img/Heading3.png" />

  <syncfusion:GalleryViewItem Name="Intense" ImageUrl="Img/Intense.png" />

  <syncfusion:GalleryViewItem Name="IntenseRef" ImageUrl="Img/IntenseRef.png" />

  <syncfusion:GalleryViewItem ImageUrl="Img/NoSpacing.png" Name="NoSpacing" />

  <syncfusion:GalleryViewItem ImageUrl="Img/Title.png" Name="Title " />

</Items>

  <ExtraItems>

<syncfusion:GalleryViewExtraItem Text="Save Selection as new quick style" />

     <syncfusion:GalleryViewExtraItem Text="Clear Formatting" />

     <syncfusion:GalleryViewExtraItem Text="Apply Styles" />

</ExtraItems>

</syncfusion:GalleryView>

 

[C#]

 

Gallery.DisplayMode = Syncfusion.Web.UI.WebControls.Shared.GalleryViewDisplayMode.GalleryView;

 

[VB]

 

Gallery.DisplayMode = Syncfusion.Web.UI.WebControls.Shared.GalleryViewDisplayMode.GalleryView

5.6.5.2.1.1.1      Customizing Items in Gallery Mode

To customize the number of items to be displayed in the parent gallery, set the respective number of items in the ItemsToShow property. The code snippet below explains this.

 

[ASPX]

 

<syncfusion:GalleryView ID="GalleryView1" Height="353px" Width="532px" ItemsToShow="6" runat="server" DisplayMode="GalleryView">

            <Items>

                <syncfusion:GalleryViewItem Name="Heading1" ImageUrl="Img/Heading1.png" />

                <syncfusion:GalleryViewItem Name="Heading2" ImageUrl="Img/Heading2.png" />

                <syncfusion:GalleryViewItem Name="Heading3" ImageUrl="Img/Heading3.png" />

                <syncfusion:GalleryViewItem Name="Intense" ImageUrl="Img/Intense.png" />

                <syncfusion:GalleryViewItem Name="IntenseRef" ImageUrl="Img/IntenseRef.png" />

                <syncfusion:GalleryViewItem ImageUrl="Img/NoSpacing.png" Name="NoSpacing" />

                <syncfusion:GalleryViewItem ImageUrl="Img/Title.png" Name="Title " />

            </Items>

            <ExtraItems>

                <syncfusion:GalleryViewExtraItem ImageUrl="Img/Save16.png" Text="Save Selection as new quick style" />

                <syncfusion:GalleryViewExtraItem ImageUrl="Img/ClearFormatting16.png" Text="Clear Formatting" />

            </ExtraItems>

</syncfusion:GalleryView>

 

[C#]

 

GalleryView Gallery = new GalleryView();

Gallery.ID = "GalleryView1";

Gallery.ItemsToShow = 6;

 

[VB]

 

Dim Gallery As New GalleryView()

Gallery.ID = " GalleryView1"

Gallery.ItemsToShow = 6

 

When you build and run the application, the result will be displayed as:

Figure 373: Customised Gallery mode

                <syncfusion:GalleryViewItem  ImageUrl="Img/NoSpacing.png" Name="NoSpacing" />

                <syncfusion:GalleryViewItem  ImageUrl="Img/Title.png" Name="Title " />

            <ExtraItems>
