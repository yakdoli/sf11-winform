HeightByAreaDepth

 

Indicates whether to draw series using the ChartArea.Depth property.

 

 

Details

Possible Values

True or False

Default Value    

False

2D / 3D Limitations

3D Only

Applies to Chart Element

All series

Applies to Chart Types

Pie Chart

 

Here is some sample code.

 

[C#]

 

this.ChartWebControl1.Series[0].ConfigItems.PieItem.HeightByAreaDepth = true;

this.ChartWebControl1.ChartArea.Depth = 25f;

 

[VB.NET]

 

Me.ChartWebControl1.Series(0).ConfigItems.PieItem.HeightByAreaDepth = True

Me.ChartWebControl1.ChartArea.Depth = 25f
