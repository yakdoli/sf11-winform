Border Settings

 

This section discusses the border settings available for an appointment row.

 

Border Style and Color

 

The border style and color for an appointment row can be set by using the below given properties.

 

 

Schedule Property

 

Description

 

AppointmentRowBorderStyle

 

Specifies the border style of appointments rows. The options included are as follows:

·      NotSet

·      None

·      Dotted

·      Dashed

·      Solid

·      Double

·      Groove

·      Ridge

·      Inset

·      Outset

 

AppointmentRowBorderColor

 

Specifies the border color of appointments rows.

 

[ASPX]

 

<Syncfusion:schedule id="Schedule1" runat="server" AppointmentRowBorderColor="Red" AppointmentRowBorderStyle="Dashed">

</Syncfusion:schedule>

 

[C#]

 

Schedule1.AppointmentRowBorderStyle = BorderStyle.Dashed;

Schedule1.AppointmentRowBorderColor = System.Drawing.Color.DeepPink;

 

[VB]

 

Private Schedule1.AppointmentRowBorderStyle = BorderStyle.Dashed

Private Schedule1.AppointmentRowBorderColor = System.Drawing.Color.DeepPink
