Using Builder

The following steps enable three different date picker modes using Builder.

 

1.  In the view, invoke the DatePicker helper with the control ID as the first argument followed by the Mode with the desired mode as an argument.

a.  Simple Mode

View [ASPX]

<% {Html.MobSyncfusion().DatePicker("DatePicker")

                  ------

                  .Mode(Mode.Simple)

                  ------

                  .Render();

}%>

 

 

View [Razor]

@ {Html.MobSyncfusion().DatePicker("DatePicker")

                  ------

                  .Mode(Mode.Simple)

                  ------

                  .Render();

}

 

 

b.  Android Mode

View [ASPX]

<% {Html.MobSyncfusion().DatePicker("DatePicker")

                  ------

                  .Mode(Mode.Android)

                  ------

                  .Render();

}%>

 

 

 

View [Razor]

@ {Html.MobSyncfusion().DatePicker("DatePicker")

                  ------

                  .Mode(Mode.Android)

                  ------

                  .Render();

}

 

 

c.  Advanced Mode: In this mode, we can able to switch between both simple and android modes by simple touching the calendar header.

View [ASPX]

<% {Html.MobSyncfusion().DatePicker("DatePicker")

                  ------

                  .Mode(Mode.Advanced)

                  ------

                  .Render();

}%>

 

 

View [Razor]

@ {Html.MobSyncfusion().DatePicker("DatePicker")

                  ------

                  .Mode(Mode.Advanced)

                  ------

                  .Render();

}
