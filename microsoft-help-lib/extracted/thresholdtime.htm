Threshold Time

·      Essential Schedule will remind you of an appointment when it is scheduled to start. You can set a reminder to alert you before an appointment begins, and you can modify how far in advance you should be reminded.

·      To control how far in advance a reminder should occur, modify the time in the RemainderThresholdTime property to set reminders for all appointments to occur before the appointment start time, as illustrated in the following code.

 

[XAML]

<schedule:Schedule x:Name="schedule" ReminderThresholdTime="00:10:00"/>

 

[C#]

Schedule schedule = new Schedule();

schedule.RemainderThresholdTime = new TimeSpan(0, 10, 0);

 

Threshold Time for Individual Appointments

·      The schedule control enables you to set the threshold time for individual appointments. A particular appointment will be reminded depending on its specified threshold time. For this, set the ThresholdTime property in an individual appointment.

·      If the threshold time is not set for an appointment, then the appointment accepts the time in the schedule control.

The following code illustrates the setting of threshold time for individual appointments.

 

[XAML]

<schedule:Schedule.Appointments>

       <schedule:ScheduleAppointment Subject="Meeting" ThresholdTime="00:30:00"/>                   

</schedule:Schedule.Appointments>
