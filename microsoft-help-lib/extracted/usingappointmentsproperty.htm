Using Appointments Property

·      Add recurrence appointments to the Schedule control directly using the Appointment property.

Set IsRecurrenceAppointment to true to enable the appointment as recurrence appointment.

The following code illustrates this:

 

[XAML]

<schedule:Schedule.Appointments>

      <schedule:ScheduleAppointment  IsRecurrenceAppointment="True"                        StartRecurrenceTime="6/8/2010" StartTime="6/8/2010 08:00:00 AM" EndTime="6/8/2010 09:30:00 AM" Subject="Recurrence Appointment"/>       </schedule:Schedule.Appointments>
