Adding the Ribbon Control to an MVC Application

Refer to the Getting Started section for the prerequisites needed to add a ribbon control to an ASP.NET MVC application.

 

Using Builder

The following steps explain how to add a ribbon control.

1.   In the view, invoke the Ribbon helper with the control ID as the first argument.

 

[ASPX]

<% Html.Syncfusion().Ribbon("ribbon1").Height(Unit.Pixel(155))

.Width(Unit.Pixel(500)).ApplicationMenuType(AppMenuType.ApplicationMenu).ApplicationMenuText("File").ApplicationMenu(applicationMenu =>

    {

        applicationMenu.Add().Text("Save").SpriteCSS("text").Children(item =>

            {

                item.Add().Text("SaveAs").Children(child =>

                    {

                        child.Add().Text("Print");

                    });

            });

        applicationMenu.Add().Text("Print").Children(item =>

        {

            item.Add().Text("SaveAs").Children(child =>

            {

                child.Add().Text("Print");

            });

        });

        applicationMenu.Add().Text("Open");

    })

   .TabContext(ribbonTabContext =>

    {

        ribbonTabContext.Add().Tabs(ribbonTab =>

            {

                ribbonTab.Add().Text("Home").Groups(ribbonGroup =>

                    {

ribbonGroup.Add().ShowExpander(true).Text("Group1").GroupDivision(groupDivision =>

                            {                               

                                groupDivision.Add().ContentTemplate(() =>

                               {%>

                                <%=Html.Syncfusion().Button("button11").Text("Paste ").ContentType(ContentTypes.TextAndImage).ImageUrl("images/Copy.png") %>

                                <%=Html.Syncfusion().Button("button111").Text("Close").ContentType(ContentTypes.TextAndImage).ImageUrl("images/folder.png") %>

                                <% });

                            });

                    });                      

            });

    }).Render();%>
