Customizing the Height and Width

This feature enables you to set the size of the dialog as needed. By default height and width of the dialog will be based on the size of the content. You can also set the height and width of the dialog using the Height and the Width properties.           

The following code illustrates how to set height and width of the dialog:

 

[XAML]

 

<syncfusion:Dialog  AnimationType="None" Height="450" Width="300" VerticalOffset="-200" x:Name="dialog" IsDrag="True" IsBackKeyClose="True" IsTapOutside="True">

                    </syncfusion:Dialog>

 

 

[C#]

Dialog dialog = new Dialog() { AnimationType = AnimationType.None, Height = 450, Width = 300, VerticalOffset = -200, IsDrag = true, IsBackKeyClose = true, IsTapOutside = true };
