Customization of Navigation

 

The customization of this default navigation can be done by using the properties, methods and events mentioned below.

 

Properties

 

The following table lists the properties associated with this feature.

 

Property

Type

Description

Value Accepted

Property Syntax

IncrementKey

Dependency

Increase the pointer value.

Key

Propertyname=Key.key

DecrementKey

Dependency

Decrease the pointer value.

Key

Propertyname=Key.key

PointerSelectionBrush

Dependency

Allows differentiation of the pointer when it is focused and unfocused by changing the border color.

SolidColorBrush

Propertyname=color

 

Methods

 

The following table lists the methods associated with this feature.

 

Method

Description

KeyDown

Changes the value with appropriate key press.

GotFocus

Selection is made when pointer gets focus.

LostFocus

Pointer loses focus.
