Adding a Numeric Tex Box to MVC Applications

Refer to the Getting Started section for all prerequisites needed before adding a numeric text box control to an ASP.NET MVC application.

 

1.   In View, invoke the numeric text box helper with the control ID as the first argument.

 

View[ASPX]

 

<%=Html.Syncfusion().NumericTextBox("myNumeric") %>

 

View[cshtml]

 

 

@(new HtmlString(Html.Syncfusion().NumericTextBox("myNumeric").ToString()))

 

 

2.   Build and run the application.

A numeric text box will be rendered with default settings. The output is shown in the following figure.

 

Figure 158: Numeric Text Box

 

A sample that demonstrates a basic numeric text box control can be downloaded from the Numeric text box compressed folder online.

Note: The version number for the assemblies has been set to 8.3.0.20 in the Web.config file of the sample. Please change the version number to the appropriate version in the Web-2008.config or Web-2010.config file (available in the root directory) and the version numbers will automatically be updated in the Web.config file.
