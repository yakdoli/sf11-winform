How to Enable/Disable the Value Cell ToolTip

By default, the ShowValueCellToolTip property is set to true. It can be disabled as shown in the following code:

 

[C#]

// Disabling Value Cell ToolTip.

this.OlapGrid1.ShowValueCellTooltip = false;

 

[VB]

' Disabling Valuecell Tooltip.

Me.OlapGrid1.ShowValueCellTooltip = false
