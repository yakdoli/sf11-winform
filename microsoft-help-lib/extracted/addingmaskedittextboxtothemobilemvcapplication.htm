Adding MaskEdit textbox to the Mobile MVC application

In the Getting Started section, we discussed how to create a Mobile MVC application and how to add Tools package to an application. This section guides you to add MaskEdit textbox control to an application.

To add the MaskEdit to an application:

1.   In View, Invoke the MaskEdit textbox helper with the control ID as first argument.

 

[ASPX]

  <% {                               

        Html.MobSyncfusion().MaskEditTextbox("MaskEdit").Mask("+1 (999) 999-9999").WaterMarkText("+1 (999) 999-9999").Render();

       }%>

[Razor]

    @{

           Html.MobSyncfusion().MaskEditTextbox("MaskEdit").Mask("+1 (999) 999-9999").WaterMarkText("+1 (999) 999-9999").Render();

       }

 

2.   Run the application.
