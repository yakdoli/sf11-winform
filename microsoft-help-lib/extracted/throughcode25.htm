Through Code

 

Window Control can be created through code as follows.

 

1.   Add the following assembly in the aspx page.

 

[aspx]

 

<%@ Register Assembly="Syncfusion.Shared.Web" Namespace="Syncfusion.Web.UI.WebControls.Tools" TagPrefix="syncfusion" %>

 

2.   Now, create the Window control using the below code.

 

[aspx]

 

<ssw:Window ID="Window1" runat="server" ClientObjectId="_sfWindow" Height="100px" Width="250px"></ssw:Window>
