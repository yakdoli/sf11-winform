How to show a popup window to display the node's information when a node is clicked?

 

When a node is clicked, the OnClientNodeClick public event is handled. Using this event we can display a popup window.

 

<script language="javascript" type="text/javascript">

 

Function OnDiagramMouseDown(ByVal oData)

{

      alert(oData.El.InModelName); // shows alert window with node name

}

 

</script>

 

 

Figure 76

Note: Using the OnDiagramMouseDown function, users can write their own code to show the popup window or do some other things. Data.El is an HTML <IMG> element.
