Client-Side Methods

 

Captcha supports a client-side method to refresh the Captcha image at run time.

The following steps explain how to use this method.

1.   In the view, invoke the Captcha helper with the control ID as its argument.

 

[ASPX] 

<%=Html.Syncfusion().CaptchaControl("myCaptcha")

.EnableRefreshImage(true)

.RequestMapper("RefreshCaptcha")%>

 

 

View [cshtml] 

@{ Html.Syncfusion().CaptchaControl("myCaptcha")

.EnableRefreshImage(true)

.RequestMapper("RefreshCaptcha")%>

.Render();

}

 

 

       2.   In JavaScript, use the methods as seen in the following code.

 

[JavaScript] 

<script type="text/javascript">       

        function Refresh() {

            //Create an instance of the Captcha client-side object.

            Var captchaObj = $find("myCaptcha ");

            // Code to refresh the captcha.

           captchaObj.Refresh();

        }       

      </script>

 

3.   Build and run the application.
