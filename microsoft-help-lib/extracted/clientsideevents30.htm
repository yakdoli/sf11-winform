Using Builder

The following steps explain the handling of client side events of the dialog using Builder.

1.   In the View, create the contents of the dialog and invoke the dialog helper with the Control ID as the first argument followed by the event handler methods with the desired hanlders as argument.

 

View[ASPX]

 

<div id="myDialog" title="Syncfusion Dialog" style="visibility: hidden">

This is the Syncfusion Dialog control with the 'x' icon. The dialog    window can be moved, resized and closed.

       </div>

       <%=Html.Syncfusion().Dialog("myDialog")

.TargetControlId("dialogContents")

              .ClientSideBeforeClose("DialogBeforClose")

              .ClientSideClose("DialogClose")

              .ClientSideDragStart("DialogDragStart")

              .ClientSideDrag("DialogDrag")

              .ClientSideResize("DialogResize")

              .ClientSideDragStop("DialogDragStop")

              .ClientSideFocus("DialogFocus")

              .ClientSideOpen("DialogOpen")

              .ClientSideResizeStart("DialogResizeStart")

              .ClientSideResizeStop("DialogResizeStop")%>

Using Properties Model

The following steps explain the handling of the client side events of the dialog through the Properties model.

1.   In the Controller, create an instance of DialogModel, define the the event handler properties and pass the instance through View Specific Data to View as given below.

 

 

 

[Controller]

 

public ActionResult Index()

        {

            //create an instance of DialogModel

            DialogModel myModel = new DialogModel();

            myModel.ClientSideBeforeClose = "DialogBeforClose";

            myModel.ClientSideClose = "DialogClose";

            myModel.ClientSideDragStart = "DialogDragStart";

            myModel.ClientSideDrag = "DialogDrag";

            myModel.ClientSideResize = "DialogResize";

            myModel.ClientSideDragStop = "DialogDragStop";

            myModel.ClientSideFocus = "DialogFocus";

            myModel.ClientSideOpen = "DialogOpen";

            myModel.ClientSideResizeStart = "DialogResizeStart";

            myModel.ClientSideResizeStop = "DialogResizeStop";

 

            //pass the instance through view data to the view

            ViewData["myDialog"] = myModel;

            return View();

        }

 

 

 

2.   In View, create the dialog contents and invoke the dialog helper with the view data key as the first argument.

 

View[ASPX]

 

<div id="myDialog" title="Syncfusion Dialog" style="visibility: hidden">

This is the Syncfusion Dialog control with the 'x' icon. The dialog    window can be moved, resized and closed.

       </div>

<%=Html.Syncfusion().Dialog("myDialog")%>

 

View[cshtml]

 

<div id="myDialog" title="Syncfusion Dialog" style="visibility: hidden">

This is the Syncfusion Dialog control with the 'x' icon. The dialog    window can be moved, resized and closed.

       </div>

@{ Html.Syncfusion().Dialog("myDialog").Render();}

Adding handlers at run time

Open

This event will be triggered when the dialog is opened.

[JavaScript]

 $("#myDialog").dialog({

                  open: function(event, ui) {

                        alert("Dialog is opened");

                  }

        });
