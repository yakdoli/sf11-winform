Description

This event occurs when the BorderColor property is changed.

BorderSingleChanged

This event occurs when the value of the BorderSingle property is changed.

This event occurs when the value of the BorderStyle property is changed.

Border3DStyleChanged

This event occurs when the value of the Border3DStyle property is changed.

GradientBackgroundChanged

This event occurs when the value of the GradientBackground property is changed.

GradientColorsChanged

This event occurs when the value of the GradientColors property is changed.

ThemeChanged

This event occurs when the value of the ThemesEnabled property is changed.

VerticalGradientChanged

This event occurs when the value of the VerticalGradient property is changed.
