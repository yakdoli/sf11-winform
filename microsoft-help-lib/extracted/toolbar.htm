ToolBar

 

The ToolBar package consists of high-performance, feature rich ToolBar control with comprehensive design time support. The Toolbar structure can be designed either by using the Toolbar Designer in the design time or created programmatically.

 

Through a highly scalable object model, the control provides the features.

 

·      Different toolbar item modes (TextOnly, ImageOnly and ImageAndText).

·      ToolBar item button types (Regular, Toggle and DropDown).

·      Integrated client side and server side object models and keyboard shortcuts.

·      An extensive look and feel customization capabilities using CustomCSS property.

·      Ability to embed any server side control within the ToolBar structure using templates.

·      Support for cross browsers compatibility.

·      ToolBar control can be hosted in Safari Browser too.
