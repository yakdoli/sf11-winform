Digital Gauge Frames

You can set some properties to the gauge to control the frame appearance. Rather than setting properties on the digital gauge individually, you can use resources to define gauge properties for the entire application. Define App.Resources block to specify the style for the digital gauge control and add following markup to it.

 

[XAML]

 

<Application x:Class="TestApplication.App" xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"

xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" xmlns:syncfusion="http://schemas.syncfusion.com/wpf" StartupUri="Window1.xaml">

    <Application.Resources>

        <Style TargetType="{x:Type syncfusion:DigitalGauge}">

            <Setter Property="FirstFrameFillColor" Value="Orange" />

            <Setter Property="SecondFrameFillColor" Value="SteelBlue" />

            <Setter Property="CenterFrameFillColor" Value="Black" />

        </Style>

    </Application.Resources>

</Application>

 

The TargetType property specifies that the style applies to all objects of type DigitalGauge. Each Setter sets a different property value for the Style. In the application all the digital gauge has a FirstFrameFillColor as Orange, SecondFrameFillColor as SteelBlue and InnerFrameFillColor as Black.

 

Figure 45: Digital Gauge with Fill Colors

 

Note: Fill colors will be merged on the existing color of the frame. To give a custom color, use the corresponding frame style property and set  ApplyFrameStyles="True".
