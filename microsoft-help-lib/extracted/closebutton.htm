Close Button

 

The TabStrip enables you to close tabs by making use of the ShowCloseButton property. You can set the Close image to the TabStrip Item using the CloseImageURL property. CloseImageURL Property is available for the following.

 

·      StateDataPushed

·      StateDataHover

·      StateDataDefault

 

Property

Description

ShowCloseButton

Specifies to show the close button in the tab item.

CloseImageURL

Specifies the corresponding close button image to be used for the tab item.

 

[aspx]

 

<cc1:Tabstrip id="TabStrip1" ShowCloseButton="True" ControlRootTableCSSClass=" " CustomCSS="css/tabstrip_office2007black.css" Style="font-family:Verdana; font-size:8;" ControlRootCSSClass="tabRoot_Office2007Black" runat="server" OnClick="TabStrip1_Click" Height="23px" Width="442px" >

</DefaultItemLook>
