Built-in Context Menu Items

Essential Grid for MVC context menu support provides the following built-in context menu items:

Context menu index (zero based)

Context menu item

Action

0

 

Item = ContextMenuItems.AddRecord

HeaderCss = "addrecord"

TargetElement = GridElements.Record
Text = "Add Record"

 

Adds a new record to the grid.

1

 

Item = ContextMenuItems.EditRecord

HeaderCss = "editrecord"

TargetElement = GridElements.Record
Text = "Edit Record"

 

Edits the current record in the grid.

2

Item = ContextMenuItems.DeleteRecord

HeaderCss = "deleterecord"

TargetElement = GridElements.Record
Text = "Delete Record"

 

Deletes the current record in the grid.

3

Item = ContextMenuItems.Save

HeaderCss = "save"

TargetElement = GridElements.Record
Text = "Save Request"

 

Calls the save request in the grid.

4

Item = ContextMenuItems.Cancel

HeaderCss = "cancel"

TargetElement = GridElements.Record
Text = "Cancel Request"

 

Calls the cancel request in the grid.

5

Item = ContextMenuItems.SortByAsc

HeaderCss = "sortbyasc"

TargetElement = GridElements.ColumnHeader
Text = "Sort By Ascending"

 

Sorts the column in ascending order.

6

Item = ContextMenuItems.SortByDesc

HeaderCss = "sortbydesc"

TargetElement = GridElements.ColumnHeader
Text = "Sort By Descending"

 

Sorts the column in descending order.

7

Item = ContextMenuItems.ClearSorting

HeaderCss = "clearsorting"

TargetElement = GridElements. ColumnHeader
Text = "Clear Sorting"

 

Clears the sorting from  the column in the grid.

8

Item = ContextMenuItems.GroupBy

HeaderCss = "groupby"

TargetElement = GridElements.ColumnHeader
Text = "Group By"

 

Groups the column.

9

Item = ContextMenuItems.ClearGrouping

HeaderCss = "cleargrouping"

TargetElement = GridElements. ColumnHeader
Text = "Clear Grouping"

 

Clears the grouping from the current column.

10

Item = ContextMenuItems.Expand

HeaderCss = "expand"

TargetElement = GridElements.GroupCaption
Text = "Expand"

 

Expands the current group in the grid.

11

Item = ContextMenuItems.Collapse

HeaderCss = "collapse"

TargetElement = GridElements. GroupCaption
Text = "Collapse"

 

Collapses the current column in the grid.

12

Item = ContextMenuItems.ClearFilter

HeaderCss = "clearfilter"

TargetElement = GridElements. ColumnHeader
Text = "Clear Filter"

 

Clears the filtering descriptors from the column.

13

Item = ContextMenuItems.HideColumn

HeaderCss = "hidecolumn"

TargetElement = GridElements. ColumnHeader
Text = "Hide column"

 

Hides the current column.

14

Item = ContextMenuItems.NextPage

HeaderCss = "nextpage"

TargetElement = GridElements. Pager
Text = "Next Page"

 

Navigates to the next page of the grid.

15

Item = ContextMenuItems.PreviousPage

HeaderCss = "previouspage"

TargetElement = GridElements. Pager
Text = "Previous Page"

 

Navigates to the previous page of the grid.

16

Item = ContextMenuItems.LastPage

HeaderCss = "lastpage"

TargetElement = GridElements. Pager
Text = "Last Page"

 

Navigates to the last page of the grid.

17

Item = ContextMenuItems.FirstPage

HeaderCss = "firstpage"

TargetElement = GridElements. Pager
Text = "First Page"

 

Navigates to the first page of the grid.

18

Item = ContextMenuItems.NextPager

HeaderCss = "nextpager"

TargetElement = GridElements. Pager
Text = "Next Pager"

 

Navigates to the next pager of the grid.

19

Item = ContextMenuItems.PreviousPager

HeaderCss = "previouspager"

TargetElement = GridElements. Pager
Text = "Previous Pager"

 

Navigates to the previous pager of the grid.

20

Item = ContextMenuItems.RefreshPager

HeaderCss = "refreshpager"

TargetElement = GridElements. Pager
Text = "Refresh Pager"

 

It refreshes the pager of the grid.

21

Item = ContextMenuItems.VisibleColumns

HeaderCss = "columnheader"

TargetElement = GridElements. Pager
Text = "Visible Columns"

 

Gets or sets the visible columns—this means you can choose which columns should be visible.
