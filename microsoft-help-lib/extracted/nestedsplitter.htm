Nested Splitter

The Splitter control supports a nested splitter bar structure.

The following steps explain how to define a nested splitter control.

1.   In the view, invoke the Splitter helper with the control ID as the first argument.

2.   Add the splitter panes to the outer splitter control and in any one of the panes nest another splitter control to make a nested structure. In ContentTemplate add the Splitter control to be nested and set its HTML attribute border to 0 pixels.

 

[ASPX]

 

<%Html.Syncfusion().Splitter("splitter").Orientation(SplitterOrientation .Horizontal).Height(400).Width(700)

    .SplitterPanes(panes=>{       

      <p>Outer first pane</p>

panes.Add()   

      .PaneSize(Unit.Percentage(30)).ContentTemplate(()=>{%> <p>Outer Pane</p>

                                                           

                                              <%})

      .SplitterBar(bar=>bar.AllowSplitterBar(true).CollapseMode(CollapseType.Both);    

     

      panes.Add().PaneSize(Unit.Percentage(20)).ContentTemplate(()=>{%>

 

                                    <%Html.Syncfusion().Splitter("innerSplitter", new { style = "border: 0" }).Height(Unit.Percentage(100)).Width(Unit.Percentage(100)).Orientation(SplitterOrientation.Vertical)

                                    .SplitterPanes(panes1=>{       

                                                            panes1.Add().PaneSize(Unit.Percentage(50)).ContentTemplate(()=>{%>

                                                            <p>inner first pane</p>

                                                            <%}).SplitterBar(b=>b.AllowSplitterBar(true).CollapseMode(CollapseType.Both);

          

                                                            panes1.Add().PaneSize(Unit.Percentage(30)).ContentTemplate(()=>{%>

                                                            <p>inner second pane</p>

                                                            <%});

          

                                     }).AutoFormat(Skins.Midnight).Render(); %>

    

      <%});

     }).AutoFormat(Skins.Midnight).Render();

 %>
