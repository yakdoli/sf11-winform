Through Designer

1.   To create ribbon control Through Designer: Create a new ASP.NET Web application. For details, see Creating ASP.NET Web Application

2.   Drag the Ribbon Control onto the webform in the new web application.

3.   Give the necessary details in the .aspx page HTML view, as shown in the following code snippet.

[ASPX]

<syncfusion:ribbon id="Ribbon1" AutoFormat ="office2010blue" runat="server" extratext="Extra Text" ApplicationMenuColor ="#F9A403" ApplicationMenuType="ApplicationMenu" ApplicationMenuText="File" ExpanderClientClick="expandclick" width="990px">

 <ApplicationMenu>

    <MenuItem>

       <Item>

         <syncfusion:ApplicationMenuItem Text="Save" ImageUrl="Img/Save16.png">                      

         </syncfusion:ApplicationMenuItem>

      </Item>

   </MenuItem>

  </ApplicationMenu>

     <TabContext>

       <syncfusion:RibbonTabContext Name="context1">

         <Tabs>

           <syncfusion:RibbonTab Text="Home" Name="RibbonTab1">

             <Groups>

                <syncfusion:RibbonGroup Text="Clipboard" ShowExpander ="false" >

                   <Division>

                      <syncfusion:RibbonGroupDivison>

                         <Content>

                              <syncfusion:ButtonAdv  DisplayType="ImageAboveText"                                          runat="server" ID="OfficeUIButton5" ScreenTip="<b> Paste(Ctrl + V)</b><br /><br />Paste the contents of the clipboard"  Text="Paste" ImageUrl="Img/paste.png">                       

                              </syncfusion:ButtonAdv>

                                   </Content>

                           </syncfusion:RibbonGroupDivison>

                       <syncfusion:RibbonGroupDivison Name="division1">

                             <Content>

                                <syncfusion:ButtonAdv DisplayType="ImageBeforeText" runat="server" ID="OfficeButton1"  Text="Cut" ScreenTip="<b> Cut(Ctrl + X)</b><br /><br /> Cut the selection and put it on the clipboard"  ImageUrl = "Img/Cut.png">

                                  </syncfusion:ButtonAdv>                           

                                 </Content>

                             </syncfusion:RibbonGroupDivison>

                          </Division>

                       </syncfusion:RibbonGroup>                      

                   </Groups>

                </syncfusion:RibbonTab>                  

            </Tabs>

       </syncfusion:RibbonTabContext>

    </TabContext>

 </syncfusion:ribbon>

 

4.   Build and run the application. The result will be displayed as shown in the following  screenshot:
