Button Settings

 

The below given property can be used to set a custom image for the button.

 

Property

Description

ButtonImageSrc

Specifies name of the custom image to use for the button.

 

[C#]

 

multiSelectionDropDown1.ButtonImageSrc = "buton.gif";

 

[VB]

 

Private multiSelectionDropDown1ButtonImageSrc = "buton.gif"
