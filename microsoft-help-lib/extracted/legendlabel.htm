Legend Label

 

Legend contains the legend items, which are nothing but the series representation. You can set unique labels for those series using the LegendLabel property of the particular series, so that can be easily identified by the end user.

 

[XAML]

 

            <syncfusion:Chart Background="Alice Blue">

                <syncfusion:ChartArea>

                    <syncfusion:ChartArea.Legends>

                        <syncfusion:ChartLegend/>

                    </syncfusion:ChartArea.Legends>

 

                    <syncfusion:ChartArea.PrimaryAxis>

                        <syncfusion:ChartAxis Header="ProductID"/>

                    </syncfusion:ChartArea.PrimaryAxis>

 

                    <syncfusion:ChartArea.SecondaryAxis>

                        <syncfusion:ChartAxis Header="Sales"/>

                    </syncfusion:ChartArea.SecondaryAxis>

 

                    <syncfusion:ChartSeries Data="1,4,2,5,3,8" Label="2008" Interior="{StaticResource Series1}"/>

                    <syncfusion:ChartSeries Data="1,8,2,12,3,6" Label="2009" Interior="{StaticResource Series2}"/>

                </syncfusion:ChartArea>

            </syncfusion:Chart>

 

[C#]

 

ChartSeries series1 = new ChartSeries();

ChartSeries series2 = new ChartSeries();

 

//To Set the Legends data

series1.Label = "2008";

series2.Label = "2009";
