Check Box Support

 

The following properties can be used to set check box for the tree nodes and to handle the status of the check box.

 

 

Item Property

 

Description

Checked

Gets / sets check box for the node. Default value is False.

ShowCheckBox

Specifies whether to display check box for a node. Default value is False.

 

Check box can be provided for every single node or you can customize only for the required nodes. Enabling the ShowCheckBox property in the TreeView Designer dialog for an item, displays a check box for that node.

Setting the Checked property to True, by default applies a tick mark indicating the checked state of the check box.

These properties can be programmatically set as follows.

 

[C#]

 

Node.ShowCheckBox = true;

Node.Checked = true;

 

[VB]

 

Private Node.ShowCheckBox = True

Private Node.Checked = True

Supported Events for Check Box

 

Server-Side Event

 

• NodeCheckChanged Event

 

Client-Side Event

 

• ClientSideOnNodeCheckChange Event

 

Unchecking a node by checking another node

 

You may want to have a TreeView where only a single node can be checked (the check boxes mimicking the behavior of radio buttons), when user selects a node, any previously selected check box should uncheck automatically. The following code snippet illustrates this.

 

[VB]

 

<cc1:TreeView ID="TreeView1" ClientSideOnNodeCheckChanged="NodeOnCheckChanged(this)"  runat="server">

    <Items>

        <cc1:TreeViewNode Expanded="True" Text="Root Node1">

            <cc1:TreeViewNode ShowCheckBox="True" Checked="true" Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode ShowCheckBox="True" Text="Child Node2">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode ShowCheckBox="True" Text="Child Node3">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode ShowCheckBox="True" Text="Child Node4">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode>

        <cc1:TreeViewNode Text="Root Node2">

            <cc1:TreeViewNode ShowCheckBox="True" Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode ShowCheckBox="True" Text="Child Node2">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode ShowCheckBox="True" Text="Child Node3">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode ShowCheckBox="True" Text="Child Node4">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode>

    </Items>

</cc1:TreeView>

 

[JavaScript]

var oOldCheckedNode = null;

 function NodeOnCheckChanged( NodeEventData )

 {

    if( null == oOldCheckedNode )

    {

        //ensure to uncheck all nodes recursive.

        UnCheckAllNodes();

    }

    else

    {

        oOldCheckedNode.UnCheck();

    }   

    NodeEventData.Check();

    oOldCheckedNode = NodeEventData;

 }

 

function UnCheckAllNodes()

{

    UnCheckNodesRecursive( null );

}

 

function UnCheckNodesRecursive( oNode )

{

    var arrChildNodes = ( null == oNode ) ? _sfTreeView1.GetRootNodes() : oNode.Nodes;

    if( null != arrChildNodes )

    {

        for( var i = 0; i < arrChildNodes.length; i++ )

        {

            var oChildNode = arrChildNodes[i];

            oChildNode.UnCheck();

            UnCheckNodesRecursive( oChildNode );

        }

    }

}
