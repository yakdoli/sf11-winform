Server-Side Events

 

To raise and process the server side event when an item is selected, follow the below given steps.

 

 

1.   Drag the Menu control and a label called 'lblActionPerformed' onto your Web Page.

81.  Create the menu structure, by adding the required items.

 

<Items>

    <cc1:MenuItem Text="Products">

      .....

    </cc1:MenuItem>

    <cc1:MenuItem  Text="Services">

      <cc1:MenuItem Text="Consulting" NavigateUrl="http://www.syncfusion.com/Services/consulting.aspx"></cc1:MenuItem>

      <cc1:MenuItem Text="Training" NavigateUrl="http://www.syncfusion.com/Services/training.aspx"></cc1:MenuItem>

    </cc1:MenuItem>

</Items>

 

82.  The following code behind file shows the event handler and the server side events.

 

[C#]

 

private void InitializeComponent()

{   

    this.Menu1.ItemCommand += new Syncfusion.Web.UI.WebControls.Tools.Menus.Menu.ItemCommandEventHandler(this.Menu1_ItemCommand);

    this.Menu1.ItemSelect+=new Syncfusion.Web.UI.WebControls.Tools.Menus.Menu.ItemSelectEventHandler(this.Menu1_ItemSelect);         

}

 

protected bool Menu1_ItemSelect(object oSender, Syncfusion.Web.UI.WebControls.Tools.Menus.MenuCommandEventArgs e)

{

    if (e.Item.Text=="Consulting")

    {

        lblActionPerformed.Text = e.Item.Text;

        return true;

    }

    else

    {

        return false;

    }

private void Menu1_ItemCommand(object oSender, Syncfusion.Web.UI.WebControls.Tools.Menus.MenuCommandEventArgs e)

{

   //This event will be called when a menu item selection is not canceled. Fires right before navigation to item's URL occurs.

}

 

[VB]

 

Private Sub InitializeComponent()

    AddHandler Menu1.ItemCommand, AddressOf Menu1_ItemCommand AddHandler Menu1.ItemSelect, AddressOf Menu1_ItemSelect

End Sub

 

Protected Function Menu1_ItemSelect(ByVal oSender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.Menus.MenuCommandEventArgs) As Boolean Handles Menu1.ItemSelect

    If e.Item.Text == "Consulting" Then

        lblActionPerformed.Text = e.Item.Text

        Return True

    Else

        Return False

    End If

End Function

 

Private Sub Menu1_ItemCommand(ByVal oSender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.Menus.MenuCommandEventArgs) Handles Menu1.ItemCommand

    'This event will be called when a menu item selection is not canceled. Fires right before navigation to the item's URL.

End Sub

 

In the above code, ItemSelect event gets triggered whenever a menu item is selected and returns a boolean value. If it returns True, then ItemCommand event will be triggered. Else if it returns False, ItemCommand event will not be triggered, and in which case, even if NavigateUrl has been used for an item, it will not navigate to the given link.

 

Here, if the selected menu text(item) is 'Consulting', then the ItemCommand event will get triggered navigates to the url

 

'http://www.syncfusion.com/Services/consulting.aspx'. The ItemCommand event will not be fired on selecting any other menu items.
