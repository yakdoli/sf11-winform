Through Designer

 

To create the control through designer, follow the below given steps.

 

UploadBox

 

1.   Drag the UploadBox control from the toolbox onto the Web Form.

 

[Aspx]

 

<cc1:UploadBox ID="UploadBox1" runat="server" />

        <cc1:UploadProgress ID="UploadProgress1" runat="server">

        </cc1:UploadProgress>

 

2.   Set the UploadFolder path or provide appropriate write permission to the target folder and customize the control settings if required. Refer Concepts and Features for the various features supported by the UploadBox.

3.   Add the following httpModules to the web.config file to allow the files to be uploaded to the target folder. When the dlls are referred from GAC, the version must be specified.

 

[web.config]

 

<httpModules>

  <add name="UploadModule" type="Syncfusion.Web.UI.WebControls.Tools.UploadControl.UploadModule, Syncfusion.Tools.Web, Version=x.x.x.x, Culture=neutral, PublicKeyToken=3D67ED1F87D44C89"/>

</httpModules>

 

Note: You might have to change the version number in the tags to whatever version you are linking to.

 

Adding the Http Module for IIS7

 

When hosting the application in IIS7, http modules should be added in the System.WebServer tag also. Refer to the following code snippet.

[Web.Config]

<system.webServer>

            <validation validateIntegratedModeConfiguration="false"/>

      <modules>

      <add name="UploadModule" type="Syncfusion.Web.UI.WebControls.Tools.UploadControl.UploadModule,  Syncfusion.Tools.Web, Version=x.x.x.x, Culture=neutral, PublicKeyToken=3D67ED1F87D44C89"/>

      </modules>

                  </system.webServer>

 

 

UploadProgress

 

1.   To use the UploadProgress control to popup and display the details of the files that are being uploaded, add the control to your application. To customize the control settings, refer to UploadProgress Customization topic.

2.   Build and run the project.
