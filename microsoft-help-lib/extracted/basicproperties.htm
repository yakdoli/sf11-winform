Basic properties

The Recurrence Appointment control exposes the following properties in the top level.

Option Features

·      IsRecurrenceAppointment – It is set to true for creating the recurrence appointment. The default value is false.

·      CurrentRecurrencePatternMode - This enables users to choose any one of the Recurrence Types.

o  The Values are Daily, Weekly, Monthly and Yearly

Note: Daily Recurrence Type is selected by Default

 

·      EndOccurenceCount - Provides the number of recurrences happen.

·      EndRecurrenceTime - This is a DateTime property, which is used to disable the recurrence appointment.
