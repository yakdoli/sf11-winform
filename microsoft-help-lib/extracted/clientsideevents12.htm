Client-Side Events

 

The client side events can be triggered on selecting a tab element.

 

Property

Description

ClientSideOnItemMouseOut

Specifies the client side function to call when the mouse leaves a tab item.

ClientSideOnItemMouseOver

Specifies the client side function to call when the mouse enters a tab item.

ClientSideOnItemSelect

Specifies the client side function to call when an item is selected.

 

Note: Make sure the AutoPostBackOnSelect property is set to False.

 

1.   Define the script functions that are to be executed when the tab events are triggered.

 

<script language="javascript" type="text/javascript">

  function OnItemSelect(obj)

  {

    document.getElementById("Textarea1").value+="Select Event fired from "+obj["Text"]+"\n";       

    return false;       

  }

  function OnMouseOver(obj)

  {

    document.getElementById("Textarea1").value+="MouseOver Event fired from "+obj["Text"]+"\n";                   

    return false;       

  }

  function OnMouseOut(obj)

  {

    document.getElementById("Textarea1").value+="MouseOut Event fired from "+obj["Text"]+"\n";       

    return false;       

  }

</script>

 

114.   Set the client events to the respective java script function names. Here, the ClientSideOnItemSelect, ClientSideOnItemMouseOver, ClientSideOnItemMouseOut properties are set to the corresponding client side java script function shown below. This will get executed whenever a tab is selected and passes the selected tab instance as a parameter to the subroutine.

 

<cc1:TabStrip id = "TabStrip1" runat = "server" ImageBaseURL = "images" CustomCSS = "css/TabDesign.css" ClientSideOnItemSelect = "OnItemSelect(this)" ClientSideOnItemMouseOver = "OnMouseOver(this)" ClientSideOnItemMouseOut="OnMouseOut(this)">

 

  <Looks>

    <cc1:TabStripItemLook ID="TabLook">

      <!-- ItemLooks definition !-->

  </Looks>

                                                       

  <Items>

    <cc1:TabStripItem ID="Products" Text="Products" Look="TabLook"></cc1:TabStripItem>

    <cc1:TabStripItem ID="services" Text="Services" Look="TabLook"></cc1:TabStripItem>

    <cc1:TabStripItem ID="support" Text="Support" Look="TabLook"></cc1:TabStripItem>

    <cc1:TabStripItem ID="sales" Text="Sales" Look="TabLook"></cc1:TabStripItem>

  </Items>

</cc1:TabStrip>

 

115.   Build and run the application and click the tab items to trigger the events.
