Commands

Map control contains the following commands:

·      Reset Command

·      Refresh Command

·      SelectedItemNull Command

·      ZoomIn Command

·      ZoomOut Command

·      Pan Command

·      ZoomReset Command

·      PanReset Command

 

Reset Command

Reset command will reset contents of the ShapeFileLayer. It removes all the contents of the ShapeFileLayer.

[XAML]

<maps:MapControl NavigationControlPosition="Right" x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}">

                <maps:MapControl.Layers>

                    <maps:Layers>

                        <maps:ShapeFileLayer  x:Name="shapeControl" Uri="CommandsDemo.ShapeFiles.wv.shp">

                        </maps:ShapeFileLayer>

                    </maps:Layers>

                </maps:MapControl.Layers>

            </maps:MapControl>

  <Button Grid.Column="0" Grid.Row="2" Content="ResetMap" Command="{Binding ElementName=Map,Path=ResetCommand}" Name="resetMap"/>

Pan Command

Pan Command will be used to navigate on the Map Control. Direction of the Navigation will be the Command parameter for the Pan Command.

 

[XAML]

<maps:MapControl NavigationControlPosition="Right" x:Name="Map" LayeredContent="{Binding ElementName=shapeControl}">

                <maps:MapControl.Layers>

                    <maps:Layers>

                        <maps:ShapeFileLayer  x:Name="shapeControl" Uri="CommandsDemo.ShapeFiles.wv.shp">

                        </maps:ShapeFileLayer>

                    </maps:Layers>

                </maps:MapControl.Layers>

            </maps:MapControl>

                  <Button Width="50" Height="20" Grid.Row="1" Grid.Column="0" Content="Left" Name="LeftPanButton" Command="{Binding ElementName=Map,Path=PanCommand}" CommandParameter="left" />

                  <Button Width="50" Height="20" Grid.Row="1" Grid.Column="2" Content="Right"  Name="RightPanButton"  Command="{Binding ElementName=Map,Path=PanCommand}" CommandParameter="right"/>

                  <Button Width="50" Height="20"  Grid.Row="0" Grid.Column="1" Content="Top" Name="topPan" Command="{Binding ElementName=Map,Path=PanCommand}" CommandParameter="top"/>

                  <Button Width="75" Height="20" Grid.Row="2" Grid.Column="1" Content="Bottom" Name="bottomPan" Command="{Binding ElementName=Map,Path=PanCommand}" CommandParameter="bottom"/>
