Menu

 

The Menu control provides a high-performance, feature rich control with comprehensive design time support. The core features are given below.

 

·    Framework support: Menu control works seamlessly with 1.x and 2.0 framework

·    Client side functionalities: the client side javascript functions can be handled that allows to control the behavior of the Menu

·    Data Binding: supports to data bind the menu items with xml file

·    Templates: provides the flexibility to nest ASP.NET or any controls

The controls can be embedded in the text part or the entire menu item.

·    Context Menu: supports to pop up the menu wherever you right click on the page or on a control

·    Scrolling Menu: renders the up and down scroll arrows to the menu that enables the users to scroll through the menu items

·    Static and Dynamic Menus: allows the user to display static menu, with the root level and the user-defined sub levels, by default

Also styles can be set for static and dynamic menu using properties.

·    Keyboard Shortcut: allows to easily access the menu items with shortcut keys and mnemonics

·    Layout: enables the user to position the root and sub panels horizontally or vertically

·    Images: images can either be set to the left and / or right of the text

Images on menu items can be changed on mouse hover by simply setting the ImageHoverPath property.

·    Transition effects: transition effects and durations can be set for menu expand / collapse

·    Reading Order: the menu reading order can be made to display from right to left

·    Themes and Skins: allows to customize the visual appearance of user interfaces and apply a distinctive look and feel for your pages using themes and skins

·    Styles: the look and feel of the Menu can be enriched using the custom or default css styles

Also Menu allows you to set shadow effects to the root and sub panel.

·    Browser: Menu control can be hosted in Safari Browser too
