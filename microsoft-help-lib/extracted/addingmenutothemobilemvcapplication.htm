Adding Menu to the Mobile MVC application

In the Getting Started section, we discussed how to create an Mobile MVC application and add Tools package to the application. This section guides you to add Menu control to an application.

1.   In View, Invoke the menu helper with the menu ID as the first argument.

[ASPX]

  <% = Html.MobSyncfusion().Menu("mobTab")

           .Items(items =>

           {

               items.Add()

                   .Text("Windows");

               items.Add()

                   .Text("Linux");

               items.Add()

                   .Text("Ubuntu");

               items.Add()

                   .Text("Solaris");

               items.Add()

                   .Text("Android");

               items.Add()

                   .Text("Eclipse");

               items.Add()

                   .Text("Unix");

           })

    

    %>

 

 

[Razor]

    @{

        Html.MobSyncfusion().Menu("mobTab")

           .Items(items =>

           {

               items.Add()

                   .Text("Windows");

               items.Add()

                   .Text("Linux");

               items.Add()

                   .Text("Ubuntu");

               items.Add()

                   .Text("Solaris");

               items.Add()

                   .Text("Android");

               items.Add()

                   .Text("Eclipse");

               items.Add()

                   .Text("Unix");

           })

                .Render();

    }

 

 

 

2.   Run the application.
