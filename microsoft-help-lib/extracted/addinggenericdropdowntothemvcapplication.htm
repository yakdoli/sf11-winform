Adding Generic Drop-Down to the MVC application

Refer to the Getting Started section to know the pre-requisites before stepping in to add a generic drop-down control to the MVC application.

 

Using Builder

The following steps explain the addition of a generic drop-down control to an application using Builder.

In View, create the drop-down contents and invoke the generic drop-down helper with Control ID as the first argument, followed by the TargetContentId method with the drop-down Contents ID as argument.

 

View[ASPX]

 

<div id="drop-down-contents" style="visibility: hidden">

        <div>

            <img src='<%= Url.Content("~/Content/taj.jpg")%>' />

            <a href="#">Taj Mahal</a></div>

        <div>

            <img src='<%= Url.Content("~/Content/colosseum.jpg")%>' />

            <a href="#">Colosseum</a></div>

        <div>

            <img src='<%= Url.Content("~/Content/greatwall.jpg")%>' />

            <a href="#">Great Wall </a>

        </div>

        <div>

            <img name="Machu Picchu" src='<%= Url.Content("~/Content/machu.jpg")%>' />

            <a href="#">Machu Picchu</a></div>

        <div>

            <img name="Petra" src='<%= Url.Content("~/Content/petra.jpg")%>' />

            <a href="#">Petra</a></div>

        <div>

            <img name="Pyramid" src='<%= Url.Content("~/Content/pyramid.jpg")%>' />

            <a href="#">Pyramids </a>

        </div>

       </div>

       <%=Html.Syncfusion().GenericDropDown("myDropDown")

       .TargetContentId("drop-down-contents")

.AutoFormat(Skins.Monochrome)%>

 

 

View[cshtml]

 

<div id="drop-down-contents" style="visibility: hidden">

        <div>

            <img src='@Url.Content("~/Content/taj.jpg")' />

            <a href="#">Taj Mahal</a></div>

        <div>

            <img src='@Url.Content("~/Content/colosseum.jpg")' />

            <a href="#">Colosseum</a></div>

        <div>

            <img src='@Url.Content("~/Content/greatwall.jpg")' />

            <a href="#">Great Wall </a>

        </div>

        <div>

            <img name="Machu Picchu" src='@Url.Content("~/Content/machu.jpg")' />

            <a href="#">Machu Picchu</a></div>

        <div>

            <img name="Petra" src='@= Url.Content("~/Content/petra.jpg")' />

            <a href="#">Petra</a></div>

        <div>

            <img name="Pyramid" src='@Url.Content("~/Content/pyramid.jpg")' />

            <a href="#">Pyramids </a>

        </div>

       </div>

       @{ Html.Syncfusion().GenericDropDown("myDropDown")

       .TargetContentId("drop-down-contents")

.AutoFormat(Skins.Monochrome).Render();}

 

 

Note: The style attribute visibility of the drop-down contents is set to be hidden for better rendering on page load. The visibility will be reset internally once the resources related to the control get loaded completely.

3.   Build and run the application.

 

Using Properties Model

The following steps explain the addition of a generic drop-down control to an application using Properties model.

 

1.   In the Controller, create a instance of GenericDropDownModel, define the TargetContentId property and pass the instance through View Specific Data to View as given below.

 

[Controller]

 

public ActionResult Index()

        {

            GenericDropDownModel myModel = new GenericDropDownModel();

            myModel.AutoFormat = Skins.Monochrome;

            myModel.TargetContentId = "drop-down-contents";

 

            ViewData["myDropDown"] = myModel;

            return View();

        }

 

 

2.   In View, create the drop-down contents and invoke the generic drop-down helper with the view data key as the control ID.

 

View[ASPX]

 

<div id="drop-down-contents" style="visibility: hidden">

        <div>

            <img src='<%= Url.Content("~/Content/taj.jpg")%>' />

        <div>

            <img src='<%= Url.Content("~/Content/colosseum.jpg")%>' />

            <a href="#">Colosseum</a></div>

        <div>

            <img src='<%= Url.Content("~/Content/greatwall.jpg")%>' />

            <a href="#">Great Wall </a>

        </div>

        <div>

            <img name="Machu Picchu" src='<%= Url.Content("~/Content/machu.jpg")%>' />

            <a href="#">Machu Picchu</a></div>

        <div>

            <img name="Petra" src='<%= Url.Content("~/Content/petra.jpg")%>' />

<%=Html.Syncfusion().GenericDropDown("myDropDown")%>
