Through XAML and C#

You can also add Spreadsheet control to a Silverlight application through XAML and C#. The following code example illustrates this.

 

[XMAL]

<syncfusion:SpreadsheetControl HorizontalAlignment="Left"  Name="spreadsheetControl1" VerticalAlignment="Top" />

 

 

[C#]

 

SpreadsheetControl Spreadsheet1 = new SpreadsheetControl();

LayoutRoot.Children.Add(Spreadsheet1);

 

 

[VB]

 

Dim Spreadsheet1 As SpreadsheetControl = New SpreadsheetControl()

LayoutRoot.Children.Add(Spreadsheet1)
