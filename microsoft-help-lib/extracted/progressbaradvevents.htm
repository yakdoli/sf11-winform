ProgressBarAdv Events

 

The list of events and a detailed explanation about each of them is given in the following sections.

 

ProgressBarAdv Events

Description

DrawWaitingCustomRender

This event can be handled to draw a custom waiting render. WaitingCustomRender must be set to 'True'.

ValueChanged

This event is handled to set the text of the ProgressBarAdv when the value changes.

 

The TextStyle property should be set to 'Custom'.
