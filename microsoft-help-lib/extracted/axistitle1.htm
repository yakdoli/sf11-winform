Axis Title

Essential Chart provides properties to set the custom titles for the axes. Set the title text for an axis by using the Title property. Customize this text by using the TitleColor and TitleFont properties.

 

Chart Axis Property

Description

TitleColor

Sets the color for the title text of the axis.

TitleFont

Sets the font style for the title text.

 

Axis Title in any chart type can be created in two ways:

·      Builder

·      ChartModel
