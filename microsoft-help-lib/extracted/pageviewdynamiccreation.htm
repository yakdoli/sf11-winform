Pageview Dynamic Creation

 

Multipage control allows you to create a dynamic page and maintain it after postback. When pages are added to MultiPage dynamically, the controls of each page view have to be added in the OnPageAdded event. For example: If the page view is created dynamically in a LinkButton's server side event, then the controls to be added to the page view must be added in any method invoked by OnPageAdded event of the pages.

 

Creating Dynamic Page View

 

1.   Open a new ASP.NET Web application.

126.   Drag the MultiPage and TabStrip controls onto the Web Form.

127.   In the HTML view, add the following coding. To integrate the controls, MultiPageId property of the TabStrip should be set to the id of the MultiPage as shown below.

 

[ASPX]

 

<syncfusion:TabStrip ID="TabStrip1" runat="server" Width="100" MultiPageID="MultiPage1">

<Items>

<syncfusion:TabStripItem Selected="True" Text="Current Folder" PageViewID="PageView1 ">

</syncfusion:TabStripItem>

</Items>

</syncfusion:TabStrip>

 

<syncfusion:MultiPage ID="MultiPage1" runat="server" EnableXHTML="False" EnableViewState="true">

<syncfusion:PageView ID="PageView1" runat="server" EnableViewState="true">

<asp:LinkButton ID="LinkButton1" runat="server" OnClick="LinkButton1_Click"> LinkButton</asp:LinkButton><br />

<asp:LinkButton ID="LinkButton2" runat="server" OnClick="LinkButton2_Click"> LinkButton</asp:LinkButton><br />

<asp:LinkButton ID="LinkButton3" runat="server"  OnClick="LinkButton3_Click"> LinkButton</asp:LinkButton><br />

<asp:LinkButton ID="LinkButton4" runat="server"  OnClick="LinkButton4_Click"> LinkButton</asp:LinkButton><br />                   </syncfusion:PageView>                    </syncfusion:MultiPage>

 

128.   Add the following event handlers in the PageLoad or PageInit event.

 

[C#]

 

private void Page_Init(object sender, System.EventArgs e)

{      

this.MultiPage1.Pages.OnPageAdded += new Syncfusion.Web.UI.WebControls.Tools.MultiPageControl.PageViewCollection.PageViewAdded(Pages_OnPageAdded);

}

 

[VB.NET]

 

Protected Sub Page_Init(ByVal sender As Object, ByVal e As System.EventArgs) Handles Me.Init

AddHandler Me.MultiPage1.Pages.OnPageAdded, AddressOf Pages_OnPageAdded

End Sub

 

129.   Add the following code in the code behind file.

 

[C#]

 

void Pages_OnPageAdded(object obj)

    {

        PageView pg = obj as PageView;

        if (pg != null)

        {

            Label lbl = new Label();

            lbl.Text = pg.ClientID;

            pg.Controls.Add(lbl);           

        }

    }

protected void LinkButton1_Click(object sender, EventArgs e)

    {

        PageView p = new PageView();

        p.ID = "Link1Page";

       

        this.MultiPage1.Pages.Add(p);

 

        TabStripItem t = new TabStripItem();

        t.Text = "Link1Page";

        t.PageViewID = p.ID;

        this.TabStrip1.Items.Add(t);

    }

 

[VB.NET]

 

Private Sub Pages_OnPageAdded(ByVal obj As Object)

        Dim pg As PageView = TryCast(obj, PageView)

        If pg IsNot Nothing Then

            Dim lbl As Label = New Label()

            lbl.Text = pg.ClientID

            pg.Controls.Add(lbl)

        End If

    End Sub

Protected Sub LinkButton1_Click(ByVal sender As Object, ByVal e As System.EventArgs) Handles LinkButton1.Click

        Dim p As PageView = New PageView()

 

        p.ID = "LinkPage1"

 

        Me.MultiPage1.Pages.Add(p)

 

        Dim t As TabStripItem = New TabStripItem()

        t.Text = "Link1Page"

        t.PageViewID = p.ID

        Me.TabStrip1.Items.Add(t)

    End Sub

 

A dynamic page view is created.
