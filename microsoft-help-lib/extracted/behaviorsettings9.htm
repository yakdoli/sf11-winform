Behavior Settings

 

The behavior of the jQueryUIDialog is controlled by using the following properties.

 

 

Property

 

Description

HeaderText

Sets the dialog title in the jQueryUIDialog in string format.

AutoOpen

Opens the dialog control automatically during page load. The default value is false.

CloseOnEsc

Closes the dialog control on pressing the escape button. The default value is true.

Draggable

Enables to drag the jQueryUIDialog. The default value is true.

Resizable

Enables to resize the jQueryUIDialog. The default value is true.

Modal

Sets the jQueryUIDialog as a modal dialog. Its background will be inaccessable. The default value is false.

Stack

Stacks all the dialogs. The default value is true.

ZIndex

Sets the ZIndex of the jQueryUIDialog. The default value is 1000.

Show

Sets the effects to be shown when the dialog is displayed.

Hide

Sets the effects to be shown when the dialog is hidden.

DialogPosition

Sets the dialog position of the jQueryUIDialog control at run time.

EnablePostback

Allows the controls inside the jQueryUIDialog to initiate postback.

 

[ASPX]

 

<syncfusion:jQueryUIDialog ID="JQueryUIDialog1" runat="server" EnablePostback="true" HeaderText="DialgTitle" AutoOpen="true" CloseOnEsc="true" Draggable="true" Resizable="true"                        Modal="true" Stack="true" ZIndex="1001" Show="Blind" Hide="Slide" DialogPosition="MiddleCenter">                        <DialogContent> This is a Dialog Content</DialogContent></syncfusion:jQueryUIDialog>

 

[C#]

 

jQueryUIDialog1.AutoOpen = true;

jQueryUIDialog1.HeaderText = "DialogTitle";

jQueryUIDialog1.CloseOnEsc = true;

jQueryUIDialog1.Draggable = true;

jQueryUIDialog1.Resizable = true;

jQueryUIDialog1.Modal = true;

jQueryUIDialog1.Stack = true;

jQueryUIDialog1.Show = DialogEffects.Blind;

jQueryUIDialog1.Hide = DialogEffects.Slide;

jQueryUIDialog1.DialogPosition = DialogPosition.MiddleCenter;

JQueryUIDialog1.EnablePostback = true;

 

[VB]

 

jQueryUIDialog1.AutoOpen = True

jQueryUIDialog1.HeaderText = "DialogTitle"

jQueryUIDialog1.CloseOnEsc = True

jQueryUIDialog1.Draggable = True

jQueryUIDialog1.Resizable = True

jQueryUIDialog1.Modal = True

jQueryUIDialog1.Stack = True

jQueryUIDialog1.Show = DialogEffects.Blind

jQueryUIDialog1.Hide = DialogEffects.Slide

jQueryUIDialog1.DialogPosition = DialogPosition.MiddleCenter

JQueryUIDialog1.EnablePostback = true;

 

The position of the jQueryUIDialog control is set by using the following property.

 

Property

Description

PixelPosition

sets the positon of the dialog control in pixels. Index to use the DialogPosition property will be set to PixelPosition.

 

[C#]

 

jQueryUIDialog1.DialogPosition = DialogPosition.PixelPosition;

int[] arr = new int[2] { 220, 400 };

jQueryUIDialogPosition.PixelPosition = arr;

 

[VB]

 

jQueryUIDialog1.DialogPosition = DialogPosition.PixelPosition

Dim arr As Integer() = New Integer(2) {220, 400}

jQueryUIDialogPosition.PixelPosition = arr
