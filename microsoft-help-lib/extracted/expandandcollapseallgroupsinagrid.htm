Expand and Collapse all groups in a Grid?

 

To expand groups in a grid, refer the following code:

 

[C#]

// To collapse all groups in a grid.

this.PivotGridControl1.ExpandAllGroup();

 

 

[VB]

' To collapse all groups in a grid.

Me.PivotGridControl1.ExpandAllGroup()

 

To expand groups in a grid, refer the following code:

 

[C#]

 

// Collapse all group in Grid.

this.PivotGridControl1.CollapseAllGroup();

 

 

[VB]

' Collapse all group in Grid.

Me.PivotGridControl1.CollapseAllGroup()
