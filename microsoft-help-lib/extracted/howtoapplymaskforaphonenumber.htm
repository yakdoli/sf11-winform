How to apply mask for a phone number

 

You can validate a phone number by using the Mask property. You have to set the Mask for a phone number (000-0000).

 

XAML

 

<syncfusion:MaskedTextBox Name="maskedTextBox1" Height="25" Width="150" Mask="000-0000" PromptChar="_" LostFocus="maskedTextBox1_LostFocus"/>

 

C#

 

    private void maskedTextBox1_LostFocus(object sender, RoutedEventArgs e)

        {

            if (maskedTextBox1.MaskCompleted)

            {

                MessageBox.Show("Validation succeeded");

            }

            else

            {

                MessageBox.Show("Validation Failed");

            }

        }
