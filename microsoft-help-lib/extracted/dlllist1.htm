DLL List

While deploying an application that references the Syncfusion Essential Mobile Grid MVC controls assembly, the following dependencies must be included in the distribution:

•   Syncfusion.Core.dll

•   Syncfusion.Linq.Base.dll

•   Syncfusion.Mobile.Shared.Mvc.dll

•   Syncfusion.Mobile.Grid.Mvc.dll

•   AjaxMin.dll
