Using Properties Model

The following steps explain how to delete a node from the diagram page through the properties model.

1.   In the controller, create an object for the Node class and set the AllowDelete property.

2.   Create an object for the DiagramPropertiesModel class and set the Nodes property. Pass this model class to the view data.

 

 

Controller

 

DiagramPropertiesModel model = new DiagramPropertiesModel();

        public ActionResult FlatDiagram()

        {

            Node node1 = new Node()

            {

                Name = "Node1",               

                AllowDelete =true

            };

            Node node2 = new Node()

            {

                Name = "Node2",               

                AllowDelete =true

            };

            Node node3 = new Node()

            {

                Name = "Node3",               

                AllowDelete =true

            };

 

           LineConnector line1 = new LineConnector()

           {

       Name="line1",

       HeadNode = node1,

       TailNode = node2,

       HeadDecoratorShape = DecoratorShape.None,

       TailDecoratorShape = DecoratorShape.None,

       ConnectorType = ConnectorType.Orthogonal,

       LineColor = "black",

       LineWidth = 2,

       Label="Line1"

 };

    LineConnector line2 = new LineConnector()

    {

       Name = "line2",

       HeadNode = node1,

       TailNode = node3,

       HeadDecoratorShape = DecoratorShape.None,

       TailDecoratorShape = DecoratorShape.None,

       ConnectorType = ConnectorType.Orthogonal,

       LineColor = "black",

       LineWidth = 2,

       Label = "Line2"

     };

 

            model.Nodes = new NodesCollection()

            {

                node1,node2,node3

            };

            model.Connectors = new LinesCollection() { 

                line1,line2

            };

            model.Width = 900;

            model.Height = 500;

            model.DiagramMode = DiagramMode.SVG;

            ViewData["FlatDiagram"] = model;

            return View();

        }

 

 

Note: If you want to create the diagram in the Canvas mode, change the DiagramMode to Canvas. By default the diagram is rendered in the SVG mode.

 

3.   In the view, invoke the Diagram helper with the control ID which is same as the view data name.

 

View

 

<%{
      Html.Syncfusion().Diagram("FlatDiagram")

          .Render();

  }

%>

 

4.   Build and run the application.
