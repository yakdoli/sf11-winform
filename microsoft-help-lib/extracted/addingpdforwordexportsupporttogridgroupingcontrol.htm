Adding PDF or Word Export Support to GridGroupingControl

The Grid to PDF / Grid to Word export support can be implemented in the GridGroupingControl using the constructors as shown in the following sections:

For PDF Export

The constructor to be used here is GridPdfExport. This constructor can be used in both C# and VB code, as shown below:

[C#]

GridPdfExport pdf = new GridPdfExport(this.GridGroupingControl1, "PdfExport.pdf", ConverterOptionsExt.All);

 

pdf.ExportBorderSytles = true;

pdf.ExportNestedTable = true;

 

pdf.Export();

 

 

[VB]

 

Dim pdf As GridPdfExport

pdf = New GridPdfExport(Me.GridGroupingControl1, "PdfExport.pdf", ConverterOptionsExt.All)

 

pdf.ExportBorderSytles = true

pdf.ExportNestedTable = true;

 

pdf.Export()

 

 

 

For Word Export

The constructor to be used here is GridWordExport. This constructor can be used in both C# and VB code, as shown below:

 

[C#]

GridWordExport word = new GridWordExport(this.GridGroupingControl1, "WordDoc.docx", ConverterOptionsExt.All)

 

word.ExportBorderSytles = true;

word.ExportNestedTable = true;

 

word.Export();

 

[VB.NET]

 Dim word As GridWordExport = New GridWordExport(Me.GridGroupingControl1, "WordDoc.docx", ConverterOptionsExt.All)

 

word.ExportBorderSytles = True

word.ExportNestedTable = True

 

word.Export()
