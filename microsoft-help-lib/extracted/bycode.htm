By Code

 

Through Code

 

This section demonstrates how to sort the tables by different columns and how to clear sorting through code.

 

Enable Sorting

 

Sorting can be enabled by setting AllowSortColumns of TableOptions to True.

 

[C#]

 

this.GridGroupingControl1.TableOptions.AllowSortColumns = true;

 

[VB.NET]

 

Me.GridGroupingControl1.TableOptions.AllowSortColumns=True

 

Sort a Table by column

 

To sort a table by a column in the GridGroupingControl, add the column name to the SortedColumns collection in the TableDescriptor.

 

[C#]

 

// Group by column Col1.

this.GridGroupingControl1.TableDescriptor.SortedColumns.Add("Col1");    

 

[VB.NET]

 

' Group by column Col1.

Me.GridGroupingControl1.TableDescriptor.SortedColumns.Add("Col1")

 

You can also access Engine.TableDescriptor.SortedColumns which allows the user to sort the particular column in ascending or descending order. Follow the code snippet below.

 

[C#]

 

this.GridGroupingControl1.Engine.TableDescriptor.SortedColumns.Add("ColumnName", ListSortDirection.Ascending);

 

[VB.NET]

 

Me.GridGroupingControl1.Engine.TableDescriptor.SortedColumns.Add("ColumnName", ListSortDirection.Ascending)

 

Reset Sorted columns

 

The following code snippet resets the sorted columns.

 

[C#]

 

this.GridGroupingControl1.Engine.TableDescriptor.ResetSortedColumns();

 

[VB.NET]

 

Me.GridGroupingControl1.Engine.TableDescriptor.ResetSortedColumns()

 

Clear Sorted columns

 

You have also a option to clear the sorting behavior. i.e The columns will display the values as it had before sorting.

 

[C#]

 

this.GridGroupingControl1.Engine.TableDescriptor.SortedColumns.Clear();

 

[VB.NET]

 

Me.GridGroupingControl1.Engine.TableDescriptor.SortedColumns.Clear()

 

Avoid Sorting

 

The sorting behavior can be canceled by setting AllowSortColumns to False. Here is the code snippet.

 

[C#]

 

this.GridGroupingControl1.TableOptions.AllowSortColumns = false;

 

[VB.NET]

 

Me.GridGroupingControl1.TableOptions.AllowSortColumns=False
