Adding Rating in HTML5 to an MVC application

Rating control in HTML5 can be implemented in two ways:

·      Using Builder

·      Using Properties model

 

Using Builder

The following code snippets illustrate the implementation of the rating control using HTML5:

1.   In View, invoke the rating helper followed by the EnableHTML5, Shape and EditMode methods with the desired values as arguments.

 

[ASPX]

    <%=Html.Syncfusion().Rating("html5rating")

                .ClientSideMouseOver("OnMouseOver")

                 .ClientSideMouseOut("OnMouseOut")

                 .ClientSideClick("OnClick")

                 .ClientSideValueChange("OnValueChange")

                 .ClientSideOnLoad("OnLoad")

                 .ClientSideOnCustomShapeDrawing("onCustomShapeDrawing")

                 .EnableHTML5(true)

                 .AutoPostBack(false)

                 .RequestMapper("Html5Rating")

                 .CurrentValue(3)

                 .EditMode(true)

                 .MaximumValue(5)

                 .IncrementStep(1)

                 .Orientation(RatingOrientation.Horizontal)

                 .Precision(RatingPrecision.Full)

                 .Shape(RatingShape.Star)

                 .ShapeWidth(30)

                 .ShapeHeight(30)

    %>

 

[Razor]

 

@{Html.Syncfusion().Rating("html5rating") 

                .ClientSideMouseOver("OnMouseOver")

                 .ClientSideMouseOut("OnMouseOut")

                 .ClientSideClick("OnClick")

                 .ClientSideValueChange("OnValueChange")

                 .ClientSideOnLoad("OnLoad") 

                 .ClientSideOnCustomShapeDrawing("onCustomShapeDrawing") 

                 .EnableHTML5(true)

                 .AutoPostBack(false)

                 .RequestMapper("Html5Rating")

                 .CurrentValue(3)

                 .EditMode(true)

                 .MaximumValue(5)

                 .IncrementStep(1)

                 .Orientation(RatingOrientation.Horizontal)

                 .Precision(RatingPrecision.Full)

                 .Shape(RatingShape.Star)

                 .ShapeWidth(30)

                 .ShapeHeight(30)

                 .Render();

                 }

 

 

 

2.   Build and run the application.

Using Properties Model

The following code snippet illustrates the implementation of the HTML5 rating control using properties model.

1.   In the controller, create an instance of RatingModel.

2.   Define the EnableHTML5, Shape and CurrentValue properties and pass the instance through the view-specific data to the view.

 

[Controller]

            RatingModel ratingModel = new RatingModel()

            {

                EnableHTML5 = true,

                AutoPostBack = false,

                RequestMapper = "Html5Rating",

                CurrentValue = 3,

                EditMode = true,

                MaximumValue = 5,

                IncrementStep = 1,

                Orientation = RatingOrientation.Horizontal,

                Precision = RatingPrecision.Full,

                Shape = RatingShape.Star,

                ShapeWidth = 30,

                ShapeHeight = 30,

                ClientSideMouseOver = "OnMouseOver",

                ClientSideMouseOut = "OnMouseOut",

                ClientSideClick = "OnClick",

                ClientSideValueChange = "OnValueChange",

                ClientSideOnLoad = "OnLoad",

                ClientSideOnCustomShapeDrawing = "onCustomShapeDrawing",

            };

            ViewData["Html5Rating"] = ratingModel;

 

 

3.   In View, invoke the rating helper with the view data key as the control ID.

 

[ASPX]

<%=Html.Syncfusion().Rating("Html5Rating")

%>

 

[Razor]

 

@{Html.Syncfusion().Rating("Html5Rating") 

                 .Render();

                 }

 

 

4.   Build and run the application.
