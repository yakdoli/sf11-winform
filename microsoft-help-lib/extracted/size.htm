Size

 

This section discusses how the size of an appointment row can be customized as per the needs of the user.

 

Appointment Row Height and Width

 

The height and width of the appointment rows can be set using the properties given below.

 

 

Schedule Property

 

Description

ResolutionHeight

Gets / sets value (in pixels) that indicates the height of each time interval.

Resolution Width

Gets / sets value (in pixels) that indicates the width of each time interval.

 

Note: The ResolutionHeight property adjusts the height of the appointment rows according to the time interval, if set.

 

[ASPX]

 

<Appointments>

<Syncfusion:ScheduleWebAppointment UniqueID="1" ResolutionHeight="20" ResolutionWidth="20">

</Syncfusion:ScheduleWebAppointment>

</Appointments>

 

[C#]

 

Schedule1.ResolutionHeight = 20;

Schedule1.ResolutionWidth = 20;

 

[VB]

 

Private Schedule1.ResolutionHeight = 20

Private Schedule1.ResolutionWidth = 20
