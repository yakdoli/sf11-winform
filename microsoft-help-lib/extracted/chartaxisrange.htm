Chart Axis Range

 

Chart Axis Range is determined by using the IsAutoSetRange property of the axis. If this property is set to true, then the start value and the end value of the axis is automatically determined using the series value, otherwise the value given in the Range property will be the start value and the end value of the axis.

 

[XAML]

 

<syncfusion:Chart>

  <syncfusion:Chart Background="{StaticResource ChartBackground}">

                <syncfusion:ChartArea Background="WhiteSmoke">

                    <syncfusion:ChartArea.PrimaryAxis>

                        <syncfusion:ChartAxis Header="X-Axis"/>

                    </syncfusion:ChartArea.PrimaryAxis>

 

                    <syncfusion:ChartArea.SecondaryAxis>

                        <syncfusion:ChartAxis Header="Y-Axis" IsAutoSetRange="False" Range="0,25" Interval="5"/>

                    </syncfusion:ChartArea.SecondaryAxis>

 

                    <syncfusion:ChartSeries Data="1,14,2,8,3,9" Label="2008" Interior="{StaticResource Series1}"/>

                    <syncfusion:ChartSeries Data="1,20,2,14,3,8" Label="2009" Interior="{StaticResource Series2}"/>

 

                </syncfusion:ChartArea>

</syncfusion:Chart>

 

[C#]

 

ChartAxis axis = new ChartAxis();

axis.Orientation = Orientation.Vertical;

axis.Header = "Y-Axis";

axis.IsAutoSetRange = false;

axis.Range = new DoubleRange(0, 25);

axis.Interval = 5;

area.SecondaryAxis = axis;
