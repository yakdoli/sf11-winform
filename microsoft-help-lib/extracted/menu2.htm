Menu

Essential Tools Menu for Mobile MVC supports displaying a menu out of list items. The menu is based on parent-child hierarchy.

Key Features

The key features are:

·      Vertical and horizontal orientation support

·      In-built animations support

·      Four in-built skins support

·      Template support

·      Data binding support

·      Rich set of client side events and methods
