AJAX Support

 

ProgressBar control provides in-built AJAX support that allows to refresh the control using callback and also provides client events that can be triggered every time a callback is fired.

 

Property

Description

EnableCallbacks

Gets/sets the boolean value to refresh the control via callback. Default value is true. EnablePostbacks should then be set to false.

 

Property

Description

AfterCallbackResponseProcessedScript

Specifies the client side script to be executed after the callback request gets processed.

AfterCallbackScript

Specifies the client side script that will be executed after the  callback request is sent to the server.

BeforeCallbackResponseProcessedScript

Specifies the client side script to be executed before the callback request gets processed.

BeforeCallbackScript

Specifies the client side script to execute before the callback  request is sent to the server.

 

1.   While creating a progress bar on a button click (Refer Creating ProgressBar), define the client events that should be fired before and after callback.

 

[aspx]

 

<cc1:ProgressBar ID="ProgressBar1" runat="server" AutoFormat="Dark Blue" OnUpdateProgress="ProgressBar1_UpdateProgress" AfterCallbackResponseProcessedScript="afterscriptprocess(this)" AfterCallbackScript="afterscriptcall(this)" BeforeCallbackResponseProcessingScript="beforescriptprocess(this)" BeforeCallbackScript="beforescriptcall(this)" />

<br />

<br />

<textarea id="showlbl" cols="1" rows="1" style="background-color:Silver; height:200px; width:500px"></textarea>

 

2.   With the defined function names that are set to the client events, define the functions to perform the respective actions when executed. Here, the names of the various events, when the corresponding event is fired will be displayed in the textarea element.

 

[script]

 

function beforescriptcall()

{

    document.getElementById('showlbl').value+="BeforeCallbackScript is fired"+"\n";

}

function afterscriptcall()

{

    document.getElementById('showlbl').value+="AterCallbackScript is fired"+"\n";

}

function beforescript process()

{

    document.getElementById('showlbl').value+="BeforeCallbackResponseProcessingScript is fired"+"\n";

}

function afterscriptprocess()

{

    document.getElementById('showlbl').value+="AterCallbackResponseProcessingScript is fired"+"\n";

}
