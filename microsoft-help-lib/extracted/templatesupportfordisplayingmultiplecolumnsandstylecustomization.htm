Template support for displaying Multiple Columns and Style Customization

 

AutoComplete provides templates support that allows to create and display multiple columns of data. Templates also allows to customize the look and feel of the dropdown.

 

The various templates that are available with the autocomplete text box have been listed below.

 

Template

Description

AlternatingItemTemplate

Defines how alternate items should be displayed in the dropdown.

FooterTemplate

Defines the footer section.

HeaderTemplate   

Defines the head section.

ItemTemplate

Defines how items should be displayed in the dropdown.

TextTemplate

Defines the default text to be displayed in the control.

 

In the AutoCompleteTextBox control, templates support only the dropdown table format.

 

 

Figure 30: Multiple columns and alternating style using templates

 

1.   Add the autocomplete textbox control. In between the control tags, the templates must be added.

2.   Provide header to display any headings and to the item templates list the various columns that are listed in the data source to be displayed. To apply alternating backcolor or styles, apply the corresponding styles to one of the item templates.

 

[ASPX]

 

<style type="text/css">

    .CaptionClass

    {

        text-align:center;

        background-color:#d3e6fd;

        font-weight:bold;

    }

</style>

 

<HeaderTemplate>

    <table id="Actable" cellspacing="0" >

        <tr align="center">

            <caption  class="CaptionClass">CountryName</caption>

        </tr>      

</HeaderTemplate>

 

<AlternatingItemTemplate>

        <tr style="background-color:#e2edfb">

            <td align ="left" class="hover"><%# DataBinder.Eval(Container.DataItem, "Name")%></td>

            <td align="right" class="hover"><%# DataBinder.Eval(Container.DataItem, "CountryID")%> </td>

            <td align="right" class="hover"><%# DataBinder.Eval(Container.DataItem, "ID")%> </td>

        </tr>

</AlternatingItemTemplate>

 

<ItemTemplate>

        <tr>

            <td align ="left" class="hover"><%# DataBinder.Eval(Container.DataItem, "Name")%></td>

            <td align="right" class="hover"><%# DataBinder.Eval(Container.DataItem, "CountryID")%> </td>

            <td align="right" class="hover"><%# DataBinder.Eval(Container.DataItem, "ID")%> </td>

        </tr>

</ItemTemplate>

 

<FooterTemplate>

    </table>

</FooterTemplate>

 

Note: In the code for templates, the ID attribute for table must be specified as Actable. 

 

Setting Default Text

 

Initial text can be specified that should be displayed by default in the AutoCompleteTextBox by using the Text template.

 

[ASPX]

 

<Text>Select a state</Text>
