Export diagram in image format

Essential Diagram for WPF can be exported to the following File formats:

·      Exporting into Image File Format

o  Bitmap(.bmp)

o  JPEG

o  PNG

o  GIF

o  TIFF

o  WDP

·      Exporting into XPS Format

·      Export to Clipboard

The Diagram can be exported using following overloaded methods:

·      Stream

o  Stream

o  Stream with BitmapEncoder

o  Stream with Rect

o  Stream with Rect and BitmapEncoder

·      FIleName

o  FileName

o  FileName with BitmapEncoder

o  FileName with Rect

o  FileName with Rect and BitmapEncoder

·      XPS

o  Stream

o  Stream with Rect

o  FileName

o  FileName with Rect
