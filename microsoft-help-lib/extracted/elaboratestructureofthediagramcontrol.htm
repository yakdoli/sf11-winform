Elements and Features of the Control

The elements and features of the control are:

·      Node—Nodes are graphical objects that can be placed on the page; they are generally used to represent visual data to be placed on the page.

·      Connector—Connectors are objects that are used to create a link between two nodes

·      Symbol Palette—The SymbolPalette control displays node shapes and allows a user to drag and drop symbols onto diagrams.

·      Label—Label is a single line or multiline text that is displayed over the Node.
