Creating New Session or Server Connection

To create a new server connection:

1.   Click the Create New Session button on the OlapClient Toolbar as shown in the below screen shot:

 

Figure 40 OlapClientToolbar

 

8.   The Connection Option dialog opens:

 

Figure 41 Connection Option Dialog

 

9.   Do one of the following to provide the connection string:

·      Give the Server Name and the Database Name

·      Provide the connection string in the Connection String textbox

Note: If the server type is Non-Windows Authenticated (tightly coupled) then the ‘Credentials’ checkbox, available in the Server option has be checked  and the ‘User ID and Password’ details should be provided.

The end user can encrypt (either by using the default Encryption key or End User key) the given connection before passing over the Internet.

The following code snippet explains the Encryption techniques:

Default Encryption:

[C#]

private void OlapClientWindow_Loaded(object sender, RoutedEventArgs e)

  {

      InitializeConnection();

      _olapDataManager = new OlapDataManager();

      _olapDataManager.DataProvider = this._dataProvider;

      _olapDataManager.SetCurrentReport(CreateSimpleReport());

      _olapDataManager.ConnectionStringOptions.EncryptConnectionString = true;

      this.olapClient1.OlapDataManager = _olapDataManager;

  }

 

 

Encryption using End User key:

[C#]

private void OlapClientWindow_Loaded(object sender, RoutedEventArgs e)

  {

      InitializeConnection();

      _olapDataManager = new OlapDataManager();

      _olapDataManager.DataProvider = this._dataProvider;

      _olapDataManager.SetCurrentReport(CreateSimpleReport());

      _olapDataManager.ConnectionStringOptions.EncryptConnectionString = true;

      _olapDataManager.ConnectionStringOptions.EncryptionKey = "myKey4Enc";

      this.olapClient1.OlapDataManager = _olapDataManager;

  }

 

 

The server has to decrypt the connection string (using the default Encryption or End User key) sent by the client.

 

The following code snippet shows the decryption techniques at service (Server side) level:

[C#]

/// <summary>

/// Initializes a new instance of the <see cref="OlapManager"/> class.

/// </summary>

public OlapManager()

{

  string connectionString;

  int serviceHasConnectionString = OperationContext.Current.IncomingMessageHeaders.FindHeader(MsgHeaderName, NamespaceName);   

         

  if (serviceHasConnectionString != -1)

  {

    string conStrOnMsgHeader = OperationContext.Current.IncomingMessageHeaders.GetHeader<string>(MsgHeaderName, NamespaceName);

 

     connectionString = Syncfusion.OlapSilverlight.Common.Common.

Decrypt(conStrOnMsgHeader, DecryptKey);

  }

  else

  {

     connectionString = this.GetConnectionString();

  }

 

   _dataManager = new OlapDataProvider(connectionString);

 }
