Creating Magnifier control

 

Magnifier control is created programmatically using either XAML or C# code.

 

[XAML]

 

<syncfusion:Magnifier Name="magnifier1"/>

 

[C#]

 

// grid is the name of grid control

Magnifier magnifier1 = new Magnifier();

grid.Children.Add(magnifier1);

 

 

Figure 651: Magnifier Control

 

Note: For creating Magnifier using C# code, you must already have a panel in which you are going to add the control. Otherwise, the control cannot be displayed.
