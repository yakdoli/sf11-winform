Run Time

 

At run time, users can group the data by a column (or columns), by dragging the column header onto the GroupDrop area.

 

 

Figure 60: Dragging the Column Header

 

 

Figure 61: Column Header Dragged

 

 

To remove grouping, the header has to be dragged from the groupdrop area and dropped onto the column header row.

 

Multiple Grouping

 

You can add a number of columns to group the multiple columns by clicking on the Add button in the above collection editor.

 

Grouping by Code

 

[ASPX]

 

<GridGroupedColumns>

<sfwg:GridSortColumnDescriptor Name="Col1" />

</GridGroupedColumns>

 

[C#]

 

// group by column City

this.gridGroupingControl1.TableDescriptor.GroupedColumns.Add("City");

 

[VB.NET]

 

' group by column City

Me.GridGroupingControl1.TableDescriptor.GroupedColumns.Add("City")

 

Clearing Grouping by Code

 

To Clear all Grouping

 

[C#]

 

this.GridGroupingControl1.TableDescriptor.GroupedColumns.Clear();

 

[VB.NET]

 

Me.GridGroupingControl1.TableDescriptor.GroupedColumns.Clear()

 

To Remove a particular Grouping

 

[C#]

 

this.GridGroupingControl1.TableDescriptor.GroupedColumns.RemoveAt(0);

 

[VB.NET]

 

Me.GridGroupingControl1.TableDescriptor.GroupedColumns.RemoveAt(0)

 

Note: To get notified when Group settings are changed either by the user or programmatically, subscribe to the GridControl.TableDescriptor.GroupedColumn.Changed and / or Changing events.

 

Expanding / Collapsing Groups

 

To expand and collapse all groups / records, follow the code snippet given below.

 

[C#]

 

this.GridGroupingcontrol1.Table.ExpandAllRecords();

this.GridGroupingcontrol1.Table.CollapseAllRecords();

this.GridGroupingcontrol1.Table.ExpandAllGroups();

this.GridGroupingcontrol1.Table.CollapseAllGroups();

 

[VB.NET]

 

Me.GridGroupingcontrol1.Table.ExpandAllRecords()

Me.GridGroupingcontrol1.Table.CollapseAllRecords()

Me.GridGroupingcontrol1.Table.ExpandAllGroups()

Me.GridGroupingcontrol1.Table.CollapseAllGroups()

 

Changing Text of the Group Drop Area

 

The GroupDropAreaText property of the Grid can be used to set the text to be displayed in the GroupDrop Area, when no grouping is applied.

 

Header Grouping Indicator

 

1.   Set ShowHeaderGroupingIndicator property to true to make Header Grouping Indicator visible.

2.   Set the Header Grouping Indicator visible, by using the following code.

[ASPX]

 

<Syncfusion:GridGroupingControl EnableCallbacks="False" ID="GridGroupingControl1"

      runat="server" DataMember="DefaultView" BackColor="Transparent" DataSourceCachingMode="ViewState"

     AutoFormat="Office 2007 Blue" BorderCollapse="Separate" ShowHeaderGroupingIndicators="true"

      GroupDropAreaCssClass="GridOffice2007BlueGroupDropArea">

      <tableoptions showrowheader="False"></tableoptions>

     <tabledescriptor allowfilter="False" allownew="false" allowedit="false">

     </tabledescriptor>

     </Syncfusion:GridGroupingControl>

 

[CS]

 

this.GridGroupingControl1.ShowHeaderGroupingIndicators = true;

 

[VB.NET]

 

Me.GridGroupingControl1.ShowHeaderGroupingIndicators = true;

Show/Hide Filterbar Condition

This section illustrates how to show/hide the Filterbar condition button in the Filterbar.

1.   Filterbar condition button is shown by default.

Figure 63: Filterbar Condition Button Shown

 

2.   Set ShowFilterBarCondition property to false to hide Filterbar condition button.

 

The following code illustrates how to hide Filterbar Condition button.

Use any of this code to hide Filterbar Condition button.

[ASPX]

<TopLevelGroupOptions ShowFilterBar="true" ShowFilterBarCondition="false" />

 

 

[CS]

this.GridGroupingControl1.TopLevelGroupOptions.ShowFilterBarCondition =false;

 

 

[VB.NET]

Me.GridGroupingControl1.TopLevelGroupOptions.ShowFilterBarCondition = false;

 

When the code runs, the following output displays.

 

 

Figure 64: Filtercondition Button Hidden
