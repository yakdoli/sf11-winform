Client-Side Methods

The percent text box control supports a rich set of client-side methods to modify the control’s behavior.

 

Methods

 

Name

Parameters

Return type

Description

Reference Link

getValue

-

string

Returns the current value of the text box as a string.

-

setValue

Value – the value to be displayed in the text box.

NA

Sets the value of the text box with the specified value.

NA

 

The following steps explain how to use the client-side methods.

1.   In View, invoke the percent text box helper with the control ID as the first argument.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent") %>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent").ToString()))

 

 

2.   In JavaScript, use the methods demonstrated in the following code.

 

[Javascript]

 

<script type="text/javascript">

        function Value() {

            //Create an instance of the percent text box client-side object.

            var numericObj = $find("myPercent");

            //Code used to get the current value.

            var currentValue = numericObj.getValue();

            //Code used to set the value.

            numericObj.setValue(100);

        }   

       </script>

 

3.   Build and run the application.
