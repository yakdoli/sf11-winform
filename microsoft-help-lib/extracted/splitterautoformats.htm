Splitter AutoFormats

 

The Splitter control provides pre-defined set of styles that can be applied by a single click of a button. Right-click the control and selection the AutoFormat... option opens the following AutoFormat dialog box.

 

Figure 395: Auto Format for Splitter Control

 

 

Also chosen Auto Format will be applied to child SplitPane, SplitterBar, SlidingZone and SlidingPane controls also.

The Splitter control supports the following AutoFormats.

 

·      None (Default)

·      Office2003 Blue

·      Office2003 Olive

·      Office2003 Silver

·      Deep Sky Blue

·      Alice Blue

 

Splitters also support multiple skins defined in a single page. The following sample demonstrates this.

 

[aspx]

 

<cc1:Splitter ID="Splitter1" Layout="Vertical" runat="server" Height="250px" Width="250px"

    AutoFormat="Deep Sky Blue">

    <cc1:SplitPane ID="SplitterContainerPane" runat="server" Height="140px">

        <cc1:Splitter ID="InnerSplitter" runat="server" AutoFormat="Alice Blue">

            <cc1:SplitPane ID="LeftSplitPane" runat="server" Width="120px">

                <span>Left SplitPane</span>

            </cc1:SplitPane>

            <cc1:SplitterBar ID="SplitterBar2" runat="server" CollapseMode="both" />

            <cc1:SplitPane ID="RightSplitPane" runat="server">

                <span>Right SplitPane</span>

            </cc1:SplitPane>

        </cc1:Splitter>

    </cc1:SplitPane>

    <cc1:SplitterBar ID="SplitterBar1" runat="server" CollapseMode="both" />

    <cc1:SplitPane ID="BottomPane" runat="server" Height="110px">

        <span>Bottom SplitPane</span>

    </cc1:SplitPane>

</cc1:Splitter>
