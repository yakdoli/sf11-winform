Gallery

 

Gallery is a repository of categorized collection of objects in their thumbnail views with contents. It also includes built-in animation during layout of the child items. Each item inside the Gallery exhibits special features that are beneficial to the end-user while creating applications.

 

Features

 

·      Various built-in skins.

·      Built-in animation support.

·      Simple and detailed Visual modes.

·      Advanced selection schemes.

·      Supports different Gallery Skins.

·      Perform actions such as Add / Remove selected Item and Add / Remove selected group.

·      Add Caption and Description to individual gallery items.

·      Customize space between items and adjust width.
