Adding Date Picker to the MVC application

 

Refer to the Getting Started section to know the pre-requisites before stepping in to add a date picker control to the MVC application.

The following section explains the addition of a datepicket to an application.

1.   In View, invoke the date picker helper with control id as the first argument.

 

 

View[aspx]

 

<%=Html.Syncfusion().DatePicker("myDatePicker") %>

 

 

View[cshtml]

 

@{ Html.Syncfusion().DatePicker("myDatePicker").Render(); }

 

2.   Build and run the application.
