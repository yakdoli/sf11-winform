Distinct Value Grouping

You can group the items based on the distinct value of the item. For example you can group the list of songs based on the album or the singer.

To group the items based on the distinct value of the item, use the DistinctValueGroupProvider instance created for the GroupProvider. The PropertyValue is used to specify the field name to which the distinct value grouping has to be performed.

The following code illustrates how to group items based on distinct value of the item:

 

[XAML]

 

<syncfusion:JumpList x:Name="list">           

                <syncfusion:JumpList.GroupProvider>

                    <syncfusion:DistinctValueGroupProvider PropertyValue="Company"/>

                </syncfusion:JumpList.GroupProvider>

 

                <syncfusion:JumpList.GroupButtonStyle>

                    <Style TargetType="Button">

                        <Setter Property="Width" Value="400"/>

                        <Setter Property="Margin" Value="10"/>

                        <Setter Property="Padding" Value="0"/>

                    </Style>

                </syncfusion:JumpList.GroupButtonStyle>

 

                <syncfusion:JumpList.ItemTemplate>

                    <DataTemplate>

                        <StackPanel Margin="4">                

                  <TextBlock Grid.Row="0"  Grid.Column="1" Text="{Binding Title}"

                             FontSize="{StaticResource PhoneFontSizeMedium}"/>

                   <TextBlock  Grid.Row="1" Grid.Column="1" Text="{Binding Artist}"

                             FontSize="{StaticResource PhoneFontSizeMedium}"/>

                   <TextBlock  Grid.Row="2" Grid.Column="1" Text="{Binding Price}"

                             FontSize="{StaticResource PhoneFontSizeMedium}"/>

                    <TextBlock  Grid.Row="3"  Grid.Column="1" Text="{Binding Year}"

                             FontSize="{StaticResource PhoneFontSizeMedium}"/>

                        </StackPanel>

                    </DataTemplate>

                </syncfusion:JumpList.ItemTemplate>

            </syncfusion:JumpList>
