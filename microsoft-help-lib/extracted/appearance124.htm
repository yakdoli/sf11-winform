Appearance

Appearance of OlapPager can be customized using the CssClass property. The custom CssClass style should have the following CSS styles associated with it:

 

·      MovePrev – Defines styles for Move Previous button

·      MoveNext – Defines styles for Move Next button

·      MovePrevDisabled - Defines styles for Move Previous button’s Disabled State

·      MoveNextDisabled - Defines styles for Move Next button’s Disabled State

·      PagerPanel – Defines styles for Pager panel

·      PageBox – Defines styles for CurrentPage textbox

·      Text – Defines styles for spans used in Pager

 

The example for CssStyles for Pager is given in the following code snippet:

 

[CSS]

.PagerOffice2010Black

{

    cursor:default;

}

.PagerOffice2010Black div

{

    display:inline-block;

    margin-right:5px;

    padding:2px;

    border: 1px solid #4E4E4E;

}

.PagerOffice2010Black .MovePrev, .PagerOffice2010Black .MoveNext, .PagerOffice2010Black .MovePrevDisabled, .PagerOffice2010Black .MoveNextDisabled

{

    padding: 2px 10px;

    background-image: url('Images/black.png');

    background-repeat:no-repeat;

}

.PagerOffice2010Black .MovePrev

{

    background-position: 0 -229px;

}

.PagerOffice2010Black .MoveNext

{

    background-position: 0 -206px;

}

.PagerOffice2010Black .MovePrevDisabled

{

    background-position: 0 -44px;

    opacity:0.3;

}

.PagerOffice2010Black .MoveNextDisabled

{

    background-position: 0 -21px;

    opacity:0.3;

}

.PagerOffice2010Black .PageBox

{

    width:30px;

    font-family:Verdana;

    font-size:12px;

}

.PagerOffice2010Black .Text

{

    font-family:Verdana;

    font-size:12px;

    margin:0 5px;

}

Adding OlapPager to an Application

 

To enable paging in an application:

1.   Drag and Drop OlapChart to the page

2.   Bind the OlapDataManager to the chart

3.   Drag and Drop the OlapPager to the page

4.   Set the OlapControlID to Pager.

5.   Call the DataBind() of OlapChart method.

 

The following code snippets describe enabling paging.

 

[ASPX]

<syncfusion:OlapChart ID="OlapChart1" runat="server" IsAsyncRequestData="false" />

<syncfusion:Pager ID="pager1" runat="server" OlapControlID="OlapChart1" />

 

[C#]

var dataProvider = new AdomdDataProvider(connectionString);

var DataManager = new OlapDataManager(dataProvider);

DataManager.SetCurrentReport(CreateOlapReport());

this.OlapChart1.OlapDataManager = DataManager;

this.OlapChart1.DataBind();

 

[VB]

Dim dataProvider = New AdomdDataProvider(connectionString)

DataManager = New OlapDataManager(dataProvider)

DataManager.SetCurrentReport(CreateOlapReport())

Me.OlapChart1.OlapDataManager = DataManager

Me.OlapChart1.DataBind()
