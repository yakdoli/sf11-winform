Introduction to Essential Tools for ASP.NET MVC

Essential Tools contains a comprehensive set of lightweight, AJAX-enabled, stable and feature-rich professional user interface components that are built to suit the programming model of ASP.NET MVC framework. These controls will essentially benefit those users who want to build interactive applications such as filling in data entry forms, date selection using calendar, edit and compose HTML contents and so on. Important controls include Date Picker, Tree View, Rich Text Editor and other Editor controls.

Key Features

Some of the important features of Tools for MVC are listed below:

·      Rich set of editing and formatting tools in Rich Text Editor

·      Insert image support  in Rich Text Editor

·      Data persistence support over AJAXforms in Rich Text Editor

·      Resizable support for Rich Text Editor

·      Direct accessing  of contents  such as as HTML source in Rich text editor

·      Single and multiple expand mode support in TreeView

·      Case sensitive and cache support in Auto-complete text box

·      JSON mode support in Auto-complete text box

·      Context menu support in Menu

·      Menu separators support between menu items

·      Case sensitive and auto validation support in Captcha

·      Exact, half and full precision support in Rating

·      Column binding support in Tag Cloud

·      Custom styling support of every tag item in Tag Cloud

·      Customization support over pop-up panel dimensions in Generic drop-down

·      Range slider and multiple handles support in Slider

·      Mouse over and click event triggering support in Accordion and Tabs

·      Inline support in Date Picker

·      Custom Validation expression support in Client side and Server side validators

·      Watermark text support in editors namely Numeric text box and Percent text box

·      Rich set of client side events and methods in all the controls

·      Sixteen jQuery themes for jquery server controls namelyTabs, Accordion, Date Picker, Dialog and Slider
