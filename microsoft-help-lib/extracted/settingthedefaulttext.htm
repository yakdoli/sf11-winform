Setting the Default Text

 

Rich text editor supports setting the editor contents. The contents sets will be displayed within the content area on load.

 

Properties

Name

Description

Type of property

Value it accepts

Dependency

Text

Sets the content of the editor on load.

string

 

Any string

NA

 

Using Builder

The following steps explain how to set the editor contents using Builder.

1.   In View, call the rich text editor helper, followed by the Text method with desired content as argument.

View[ASPX]

<%=Html.Syncfusion().RichTextEditor("myRichtextEditor")

              .Text("This text will be displayed in the content area on load")%>

 

 

View[cshtml]

@{ Html.Syncfusion().RichTextEditor("myRichtextEditor")

 .Text("This text will be displayed in the content area on load").Render();}

 

 

2.   Build and run the application.

 

Using Properties Model

The following steps explain how to set the editor contents using Properties model.

1.   In the Controller, create an instance of RichTextEditorModel, define the Text property and pass the instance through view-specific data to the view as below.

 

[Controller]

public ActionResult Index()

        {

            RichTextEditorModel myModel = new RichTextEditorModel();

            myModel.Text = "This text will be displayed in the content area on load";

 

            //pass the model through view data to the view

            ViewData["myRichTextEditor"] = myModel;

            return View();

        }

 

 

2.   In View, call the rich text editor helper passing the view data key as control id.

 

View[ASPX]

<%=Html.Syncfusion().RichTextEditor("myRichtextEditor")%>

 

 

 

View[cshtml]

@{ Html.Syncfusion().RichTextEditor("myRichtextEditor").Render();}

 

 

3.   Build and run the application.
