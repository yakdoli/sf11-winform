Embedding Controls inside Groupbar

 

Groupbar control supports the use of templates to help embed any custom control as a child of the root groupbar item instance. Template can contain any server controls or html controls.

 

 

Figure 329: Syncfusion TreeView Embedded inside the GroupBar

 

1.   To the application, GroupBar, TreeView and ASP.NET Calendar controls should be added.

12.  Define the treeview and calendar controls inside the GroupBarTemplateControl (set an ID for the control) and Template tags.

13.  The html view (sample code snippet) of TreeView and Calendar controls embedded inside GroupBar.

 

<Templates>

 

   <cc1:GroupBarTemplateControl ID="Treeview">

      <Template>

        <div style="OVERFLOW: auto;">

<cc1:treeview id = "TreeView2" runat = "server" Width = "176px" ShowLines = "False" ClientSideOnNodeSelect = "OnTreeItemSelect(this)">

 

             <ItemLooks>

               <!-- Item Look definitions !-->

             </ItemLooks>

                                       

             <Items>

<cc1:TreeViewNode ImagePath = "mailbox.gif" Expanded = "True" ClientOnItemSelect = "OnTreeItemSelect(this)" EditNode = "False" Text = "MailBox" Look = "RootLookTree">

<cc1:TreeViewNode ImagePath = "deleted.gif" ClientOnItemSelect = "OnTreeItemSelect(this)" EditNode = "False" Text = "Deleted Items" Look = "ChildLookTree"></cc1:TreeViewNode>

.....

              </cc1:TreeViewNode>

                 .....

             </Items>

 

          </cc1:treeview>

        </div>

      </Template>

    </cc1:GroupBarTemplateControl>

 

    <cc1:GroupBarTemplateControl ID="Calendar">

      <Template>

<asp:Calendar ID = "Calendar1" Runat = "server" DayHeaderStyle-CssClass = "dayheader" OtherMonthDayStyle-CssClass = "othermonthday" SelectedDayStyle-CssClass = "selectedday" TodayDayStyle-Font-Bold = "True" TodayDayStyle-ForeColor="#ff3300" CssClass = "calendar" NextPrevStyle-CssClass = "nextprev" TitleStyle-CssClass = "month" TitleStyle-Font-Size = "11px">

</asp:Calendar>

      </Template>

    </cc1:GroupBarTemplateControl>

</Templates>

 

14.  Assign the id specified for the control in the GroupBarTemplateControl tag and set it to the TemplateID property of the respective groupbar item, inside which the control should be embedded.

 

<Items>

    <cc1:GroupBarItem ExpandImageURL = "top_mail.gif" Expanded = "True" Text = "Mail" Look = "RootLook" ControlSubPanelCSSClass = "">

<cc1:GroupBarItem TemplateID = "Treeview" Look = "ChildLook"></cc1:GroupBarItem>

    </cc1:GroupBarItem>

.....

    <cc1:GroupBarItem ExpandImageURL = "top_calendar.gif" Text = "Calendar" Look = "RootLook" ControlSubPanelCSSClass = "">

      <cc1:GroupBarItem ID = "calitem" TemplateID = "Calendar" ControlSubPanelCSSClass = ""></cc1:GroupBarItem>

    </cc1:GroupBarItem>

</Items>
