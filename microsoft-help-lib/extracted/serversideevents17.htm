Server-Side Events

The items in the gallery view support the server side click event.

The following code snippet explains this:

1.  Add a new Web Page in your project.

2.  Drag the GalleryView Control and add the following code in the HTML View.

[ASPX]

 

<syncfusion:GalleryView ID="GalleryView1" OnClick ="GalleryView1_Click" Height="116px" Width="532px" ItemsToShow="6" runat="server" DisplayMode="GalleryView">

 <Items>

  <syncfusion:GalleryViewItem  Name="Heading1" ImageUrl="Img/Heading1.png" />

  <syncfusion:GalleryViewItem  Name="Heading2" ImageUrl="Img/Heading2.png" />

  <syncfusion:GalleryViewItem  Name="Heading3" ImageUrl="Img/Heading3.png" />

  <syncfusion:GalleryViewItem  Name="Intense" ImageUrl="Img/Intense.png" />

  <syncfusion:GalleryViewItem  Name="IntenseRef" ImageUrl="Img/IntenseRef.png" />

  <syncfusion:GalleryViewItem  ImageUrl="Img/NoSpacing.png" Name="NoSpacing" />

  <syncfusion:GalleryViewItem  ImageUrl="Img/Title.png" Name="Title " />

 </Items>

   <ExtraItems>

     <syncfusion:GalleryViewExtraItem ImageUrl="Img/Save16.png" Text="Save Selection as new quick style" />

     <syncfusion:GalleryViewExtraItem ImageUrl="Img/ClearFormatting16.png" Text="Clear Formatting" />

   </ExtraItems>

</syncfusion:GalleryView>

 

3.   Add the following method in .cs file

[C#]

 

protected void GalleryView1_Click(object Sender, Syncfusion.Web.UI.WebControls.Shared.GalleryViewControl.GalleryClickEventArgs e)

    {

        if (e.SelectedItem != null)

        {

            Response.Write(e.SelectedItem.Text);

        }

        else

        {

            Response.Write(e.SelectedExtraItem.Text);

        }

    }

 

[VB]

 

Protected Sub GalleryView1_Click(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Shared.GalleryViewControl.GalleryClickEventArgs) Handles GalleryView1.Click

        If e.SelectedItem Is Nothing Then

            Response.Write(e.SelectedExtraItem.Text)

        Else

            Response.Write(e.SelectedExtraItem.Text)

        End If

 End Sub

 

4.   Build and run the application that the GalleryView1_Click method will be handling when you click on the items in the Gallery.

In the above sample SelectedItem gives the items value in the Gallery Window; while SelectedExtraItem gives the items value in GalleryExtraItems Window.
