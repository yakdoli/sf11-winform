Stacking Column 100 Chart

The Stacking Column 100 chart is similar to the Stacking Column chart. The only difference is that the total Y value is converted to a 100 percent proportional value and then the chart points are plotted.

The following code snippets illustrate how to create a Stacking Column 100 Chart.

 

[XAML]

 

<syncfusion:ChartSeries EnableEffects="True"  Type="StackingColumn100"    x:Name="Series1" Label="2008" Width="auto"   StrokeThickness="2" />

              

 <syncfusion:ChartSeries EnableEffects="True" Type="StackingColumn100"   x:Name="Series2" Label="2009" Width="auto"   StrokeThickness="2" />

 

 

 

[C#]

 

Chart1.Areas[0].Series[0].Type = ChartTypes. StackingColumn100;

Chart1.Areas[0].Series[1].Type = ChartTypes. StackingColumn100;
