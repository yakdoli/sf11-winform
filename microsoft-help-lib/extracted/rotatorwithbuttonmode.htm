Rotator with Button Mode
5.6.2.2.6.1 Introduction

The Rotator control with button mode allows users to browse through a set of items by clicking the buttons. The items can be moved in up or down and left or right directions by clicking the corresponding buttons.

5.6.2.2.6.2 Use Case Scenarios

 

The Rotator control with button mode allows users to scroll through the items by clicking buttons.

5.6.2.2.6.5 Getting Started

 

Feature Summary

The Rotator control with button mode is used to scroll items in a rotator through by clicking buttons.

 

Adding the control or framework to a Visual Studio.NET Project

A rotator with the button mode property enabled can be created in the following two ways:

 

Through Designer:

[ASPX]

 

<syncfusion:Rotator ID="Rotator1" runat="server" Width="600" CssClass="Rotator" RotationType="SmoothScroll" ScrollDirection="Down"

            Height="250" ButtonBackGround="RoyalBlue" SlidePause="3000" ScrollInterval="15" XmlContentFile="News.xml" ButtonMode="true" AutoStart="false"

            SmoothScrollSpeed="Medium">

            <SlideTemplate>

                <table height="85" cellspacing="0" cellpadding="4" border="0" onmouseover="this.className='NewsItemOver';"

                    onmouseout="this.className='NewsItem';" bgcolor="#edf0f6">

                    <tr>

                        <td>

                            <a href='<%# DataBinder.Eval(Container.DataItem, "Url") %>' target="_blank">

                                <img border="0" src='images/<%# DataBinder.Eval(Container.DataItem, "Image") %>'

                                    width="60" height="70" />

                            </a>

                        </td>

                        <td valign="top" align="left">

                            <span class="NewsTitle">

                                <%# DataBinder.Eval (Container.DataItem, "Title") %>

                            </span>

                            <br />

                            <span class="NewsText">

                                <%# DataBinder.Eval (Container.DataItem, "Text") %>

                            </span>

                            <img src="images/multiplescroller.gif" alt="" width="17" height="10" />

                        </td>

                    </tr>

                </table>

            </SlideTemplate>

        </syncfusion:Rotator>
