Dragging Mode of Node

Essential Diagram for MVC provides preview support while dragging a node in the diagram page. When you drag any node within the diagram page, a preview of the dragged node will be displayed.

Use Case Scenario

This feature displays a preview of the node you drag from diagram page, thus enables you to identify the node you are dragging from the diagram page.
