Deployment Requirements

DLL List

While deploying an application that references Syncfusion Essential Edit WPF assembly, the following dependencies must be included in the distribution.

 

·      Syncfusion.Core.dll

·      Syncfusion.Edit.Wpf.dll

·      Syncfusion.Shared.Wpf.dll

·      Syncfusion.GridCommon.Wpf.dll
