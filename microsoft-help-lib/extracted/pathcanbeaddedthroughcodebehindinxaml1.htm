Path can be added through Code Behind in XAML

When the parameters are provided in code and when you run the sample, the path will be displayed.

We can add the PathLabel in OnPoint and OnMiddlePoint.

OnPoint—The Pathlabel displayed in a Label Point mentioned.

OnMiddlePoint—The PathLabel displayed in a middle Point of the Path.

[XAML]

 

<syncfusion:MapControl.Layers>

                    <syncfusion:Layers>

                        <syncfusion:ShapeFileLayer IsDynamicCreatePath="True" Uri="Pathsupport.ShapeFiles.world.shp" x:Name="shapeLayer">

                            <syncfusion:ShapeFileLayer.MapPathCollection>

                                <syncfusion:MapPath PathColor="Red" LabelPoint="98,40" PathLabel="MapPAth" FontFamily="Times New Roman">

                                    <syncfusion:MapPath.PathPoints>

                                        <Point X="-68" Y="-24"/>

                                        <Point X="98" Y="40"/>

                                        <Point X="34" Y="62"/>

                                        <Point X="-101" Y="59"/>

                                    </syncfusion:MapPath.PathPoints>

                                </syncfusion:MapPath>

                            </syncfusion:ShapeFileLayer.MapPathCollection>

                        </syncfusion:ShapeFileLayer>

                    </syncfusion:Layers>

                </syncfusion:MapControl.Layers>
