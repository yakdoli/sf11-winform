GetAppointments

GetAppointments function is used to get the appointments from the schedule between the Starting and the Ending Date.

The following code will display the appointment subjects from Jan to Feb through an alert box in the schedule.

[ASPX]

 

       <syncfusion:Schedule ID="Scheduler1" runat="server" Height="50%" Width="100%"    

       ViewStrip="true" StartDate="1/4/2011" ViewMode="Vertical" ClientObjectID="Scheduler">

 <Resources>

       <Syncfusion:ScheduleWebResource Name="Mark"  UniqueID="1"/>

       </Resources>

       <Appointments>

       <syncfusion:ScheduleWebAppointment UniqueID="1" StartTime="1/4/2011 08:00:00"             

       EndTime="1/4/2011 09:00:00" Subject="Meeting" Owner="1">

       </syncfusion:ScheduleWebAppointment>

       </Appointments>

       </syncfusion:Schedule>

 

[JavaScript]

    <script type="text/javascript" language="javascript">

        function pageLoad()

         {

             var oScheduleobj = Scheduler;

             var oStartDate = new Date("Jan 3, 2011 07:00:00");

             var oEndDate = new Date("Jan 31, 2011 10:00:00");

             var oAppointments = oScheduleobj.GetAppointments(1, oStartDate,              

             oEndDate);

             for(var i=0; i<oAppointments.length; i++)

             alert(oAppointments[i].Subject);        

         }

    </script>
