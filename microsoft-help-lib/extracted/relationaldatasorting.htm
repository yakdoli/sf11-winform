Relational Data Sorting

The relational data that are displayed in OLAP controls allow the user to set and view the column and row header in any one of the following formats:

·      Ascending (the default value)

·      Descending

·      Unspecified

 

The following code snippet illustrates setting the sort type for relational data:

[C#]

this.olapGridControl1.OlapDataManager.RelationalDataSortOrder = SortType.UnSpecified;

 

[VB]

Me.olapGridControl1.OlapDataManager.RelationalDataSortOrder = SortType.UnSpecified
