Adding a Captcha to the MVC Application

 

Refer to the Getting Started section to know the pre-requisites before stepping in to add a captcha control to the MVC application.

Apart from the above mentioned pre-requisites, adding a captcha to an application requires registering the image handlers under httphandler and handler tags. These image handlers are different from the the MvcResource handler mentioned in the Getting Started section. These image handlers work together with the MvcResourceHandlers.

 

[Web.config]

<httpHandlers>

     

<add verb="GET,HEAD" path="MvcResourceHandler.axd" type="Syncfusion.Mvc.Shared.MvcResourceHandler, Syncfusion.Shared.Mvc, Version=x.x.x.x, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89" validate="false"/>

 

<add verb="*" path="syncfusion_generate.axd"  type="Syncfusion.Mvc.Tools.ImageHandler, Syncfusion.Shared.Mvc, Version=x.x.x.x, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89"  validate="false"/>

 

</httpHandlers>

 

<system.webServer>

    ----------

    ----------

    <handlers>

      <remove name="UrlRoutingHandler"/>

<add verb="GET,HEAD" name="MvcResourceHandler" path="MvcResourceHandler.axd" type="Syncfusion.Mvc.Shared.MvcResourceHandler, Syncfusion.Shared.Mvc, Version=x.x.x.x, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89"/>

 

<add verb="*" path="syncfusion_generate.axd" name="syncfusion_generate" type="Syncfusion.Mvc.Tools.ImageHandler, Syncfusion.Shared.Mvc, Version=x.x.x.x, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89" />

    </handlers>

 

</system.webServer>

 

The following steps explain the addion of a Captcha to an application.

1.   In View, create an input field with respect to which the captcha is to be validated and invoke the captcha helper with the control id as argument.

 

 

View[aspx]

 

<%=Html.Syncfusion().CaptchaControl("myCaptcha")%>

      <%=Html.Syncfusion().TextBox("myTextbox")%>

 

 

 

View[cshtml]

 

@{ Html.Syncfusion().CaptchaControl("myCaptcha").Render();}

      @{ Html.Syncfusion().TextBox("myTextbox").Render();}

 

 

2.   Build and run the application.
