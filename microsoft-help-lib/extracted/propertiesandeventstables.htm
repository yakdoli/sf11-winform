Dialog

This property contains all the dialog related properties

 

Syncfusion.Mvc.Tools.DialogModel

Dialog related values (depends on the sub-properties used)

Depends on EditMode—

 

If EditMode is set to True, the Dialog property is enabled.

·      Height—Specifies the height of the dialog.

·      Width—Specifies the Width of the dialog.

·      Resizable—Specifies whether the dialog is resizable.

·      Draggable—Specifies whether the dialog can be dragged or not.

·      MaxHeigh—Specifies the maximum height of the dialog box.

·      MaxWidth—Specifies the minimum width of the dialog box.

·      MinHeight—Specifies the minimum  height of the dialog box.

·      MinWidth—Specifies the minimum width of the dialog box.

·      Show—Specifies the animation type of the dialog box when it opens.

·      Hide—Specifies the animation type of the dialog box when it closes.

·      Position—Specifies the position of the dialog.
