Server-side Events

 

The server-side event of the ColorPicker control is illustrated below.

 

ColorClick

 

This event is triggered when a color in the color palette of the ColorPicker is selected.

 

Note: This event will trigger only when you set the Autopostback property to True.

 

[ASPX]

 

<Syncfusion:ColorPicker ID="ColorPicker1" runat="server" oncolorclick="ColorPicker1_ColorClick" />

 

[C#]

 

protected void col_ColorClick(object sender, ColorClickEventArgs e)

{

Textbox1.Text = e.SelectedColor.ToString();

Textbox2.Text = e.PreviousColor.ToString();

}

 

[VB]

 

Protected Sub col_ColorClick(ByVal sender As Object, ByVal e As ColorClickEventArgs)

Textbox1.Text = e.SelectedColor.ToString()

Textbox2.Text = e.PreviousColor.ToString()

End Sub
