How to disable the Clock from the DropDown Popup

Clock can be enabled or disabled by setting the IsWatchEnabled property. Here is a simple example to disable the Clock from the DropDown Popup:

 

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="230" Margin="10"

                         IsCalendarEnabled="True" IsWatchEnabled="False"

                         IsEmptyDateEnabled="True"/>

 

Figure 296: IsWatchEnabled set to false
