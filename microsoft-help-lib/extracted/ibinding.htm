I-Binding

 

In this sample, BindingList generic class (that implements IbindingList interface) is used as the data source for GGC as follows.

 

[ASPX]

 

<sfwg:GridGroupingControl ID="GridGroupingControl1" runat="server">

</sfwg:GridGroupingControl>

 

First, create Customer class with some properties: Name, Company, and so on. In future these properties will serve as fields for GGC. Then create an instance of BindingList class (that implements IBindingList interface) and add some Customer instances to it. Assign the instance of BindingList class as data source for GGC in Page_Load. GGC will step through public properties of Customer class and these properties will be represented as fields in GGC.

You can use any predefined or custom class that implements IBindingList, ITypedList or IList instead of BindingList class. The concept will be the same.

 

[C#]

 

private BindingList<Customer> bindingListOfCustomers;

 

      protected void Page_Load( object sender, EventArgs e )

      {

            bindingListOfCustomers = new BindingList<Customer>();

            bindingListOfCustomers.Add( new Customer(1, "Name1", "Company1", "Address1", "City1", "State1", "Zip1"));

            bindingListOfCustomers.Add( new Customer(2, "Name2", "Company2", "Address2", "City2", "State2", "Zip2"));

            GridGroupingControl1.DataSource = bindingListOfCustomers;

      }
