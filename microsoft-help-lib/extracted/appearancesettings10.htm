Appearance Settings

 

Users can modify the background appearance of the Items, Groups, FocusedItem, SelectedItems and SelectedGroup using the properties provided by the Gallery control.

 

The following sample code sets the background and mouse over background for group, background for gallery, and background and focused item background for item.

 

[XAML]

 

<!-- Adding Gallery -->

<syncfusion:Gallery Name="gallery" GroupBackground="Bisque" Background="BurlyWood" GroupMouseOverBackground="Bisque"

ItemBackground="Brown" FocusedItemBackground="SaddleBrown">

 

  <!-- Adding GalleryGroup -->

  <syncfusion:GalleryGroup Name="galleryGroup" Header="Photos">

 

    <!-- Adding GalleryItems -->

    <syncfusion:GalleryItem  Caption="HR" Description="HR Department">

      <Image Source="hr.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp5.jpg"/>

    </syncfusion:GalleryItem>

    <syncfusion:GalleryItem Caption="Employee" Description="Finance Department">

      <Image Source="emp2.jpg"/>

    </syncfusion:GalleryItem>

  </syncfusion:GalleryGroup>

</syncfusion:Gallery>

 

[C#]

 

//Setting background for gallery

gallery.Background = Brushes.BurlyWood;

 

//Setting background for group

gallery.GroupBackground = Brushes.Bisque;

 

//Setting mouse over background for group

gallery.GroupMouseOverBackground = Brushes.Bisque;

 

//Setting item background

gallery.ItemBackground = Brushes.Brown;

 

//Setting focused item background

gallery.FocusedItemBackground = Brushes.SaddleBrown;
