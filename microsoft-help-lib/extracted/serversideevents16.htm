Server-Side Events

 

The server side events can be triggered to execute a function on some user action. The various server side events are as follows.

 

Server-Side Event

Description

ItemCollapse

Specifies the function to trigger when a parent item is collapsed.

ItemCommand

Specifies the function to trigger, either when the selection of an item is canceled, or before navigating to the item's url .

ItemExpand

Specifies the function to trigger when a parent item is expanded.

ItemSelect

Specifies the function to trigger when an item is selected.

 

The following procedure shows how to process and raise the server side events.

15.  Add the following code snippets in the code view of your project.

 

[C#]

 

protected bool Groupbar1_ItemSelect(object sender, Syncfusion.Web.UI.WebControls.Tools.GroupBarCommandEventArgs e)

{

    Label1.Text = "Selected Group item - " + e.Item.Text;

    return true;

}

protected bool Groupbar1_ItemExpand(object sender, Syncfusion.Web.UI.WebControls.Tools.GroupBarCommandEventArgs e)

{

    Label1.Text = "Expanded Group item - " + e.Item.Text;

    return true;

}

protected bool Groupbar1_ItemCollapse(object sender, Syncfusion.Web.UI.WebControls.Tools.GroupBarCommandEventArgs e)

{

 

    Label1.Text = "Collapsed Group item - " + e.Item.Text;

    return true;

}

 

[VB]

 

Protected Function Groupbar1_ItemSelect(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.GroupBarCommandEventArgs) As Boolean

    Label1.Text = "Selected Group item - " & e.Item.Text

    Return True

End Function

 

Protected Function Groupbar1_ItemExpand(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.GroupBarCommandEventArgs) As Boolean

    Label1.Text = "Expanded Group item - " & e.Item.Text

    Return True

End Function

 

Protected Function Groupbar1_ItemCollapse(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.GroupBarCommandEventArgs) As Boolean

 

    Label1.Text = "Collapsed Group item - " & e.Item.Text

    Return True

End Function
