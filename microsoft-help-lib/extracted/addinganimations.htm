Adding animations


Menu supports in-built animations for the open and close actions.

Properties

Name

Description

Type of the property

Value it accepts

Dependency

ShowAnimation

Defines the animation to be added for the menu open action

enum

MenuModel.Animations.Blind,

MenuModel.Animations.Clip,

MenuModel.Animations.Drop,

MenuModel.Animations.Fold,

MenuModel.Animations.Scale,

MenuModel.Animations.Slide

NA

HideAnimation

Defines the animation to be added for the menu close action

ShowAnimationSpeed

Defines the animaton delay for the menu open action in milliseconds

int

0 to int.Max

NA

HideAnimationSpeed

Defines the animaton delay for the menu close action in milliseconds

int

0 to int.Max

NA

Using Properties Model

The following steps guide you in adding animations to the menu through the Properties model.

1.   In the Controller, create an instance of MenuModel. Define its ShowAnimation,ShowAnimationSpeed, HideAnimation, HideAnimationSpeed properties and pass the instance through view-specific data to View as given below:

 

[Controller]

public ActionResult Index()

        {

            MenuModel myModel = new MenuModel();

            myModel.ShowAnimation = MenuModel.Animations.Slide;

            myModel.HideAnimation = MenuModel.Animations.Slide;

            myModel.ShowAnimationSpeed = 100;

            myModel.HideAnimationSpeed = 100;

 

            ViewData["myMenuModel"] = myModel;

            return View();

        }

 

 

2.   In View, create ul-li hierarchy of menu items and invoke the menu helper with menu contents ID as the first argument and view data key as the second argument.
