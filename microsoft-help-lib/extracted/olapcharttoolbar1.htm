OLAP Chart Tool Bar

By using the menus in the OLAP Chart Tool Bar, the user can customise the appearance and style of the chart. And also the user can change the type of the chart.

Figure 64: OLAP Chart Tool Bar

The following is the list of options in the OLAP Chart Tool Bar.

Icon

Name

Description

Chart Appearance

Displays the Chart appearance dialog widow to change the chart appearance

Show Legend

Show/Hide the legend of the chart

Chart Colour Palette

Displays the list of colour palettes to change the current colour of the chart

Chart Types

Displays the list of chart types to change the current chart

Export Chart

Exports the current visual of the chart as Image

Print

Prints the current visual of the chart

Print mode

Used to fix the area of the chart to be printed

Export to word

Export the current visual of the chart to Word

Export to Pdf

Export the current visual of the chart to PDF
