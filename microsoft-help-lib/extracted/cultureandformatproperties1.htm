Culture and Format properties

MaskedTextBox provides globalization support through the Culture property. The CurrencySymbol, DateSeparator, DecimalSeparator, TimeSeparator, and NumberGroupSeparator are based on the Culture property.

XAML

 

<syncfusion:MaskedTextBox x:Name="maskedTextBox" Height="25" Width="150" Culture="en-US"

                          Mask="0,000.00"/>

 

C#

 

MaskedTextBox maskedTextBox = new MaskedTextBox();

maskedTextBox.Height = 25;

maskedTextBox.Width = 150;

maskedTextBox.Culture = new CultureInfo("en-US");

maskedTextBox.Mask = "0,000.00";

Figure 680: Culture property set to bs-Latn

 

As you have seen in these samples whenever you change the Culture property the Value is formatted based on the Culture.

MaskedTextBox supports direct properties such as the CurrencySymbol, DateSeparator, DecimalSeparator, TimeSeparator, and NumberGroupSeparator.

XAML

 

<syncfusion:MaskedTextBox x:Name="maskedTextBox" Height="25" Width="150"

                          Mask="00/00/0000 00:00" DateSeparator="|" TimeSeparator="*"/>

 

C#

 

MaskedTextBox maskedTextBox = new MaskedTextBox();

maskedTextBox.Height = 25;

maskedTextBox.Width = 150;

maskedTextBox.Mask = "00/00/0000 00:00";

maskedTextBox.DateSeparator = "|";

maskedTextBox.TimeSeparator = "*";
