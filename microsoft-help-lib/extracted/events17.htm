5.1.11.3.3.1        Client-side Events

To set the ButtonAdv control as client side button, give the client side function name to the OnClientClick property. The code-snippets are given as follows:

 

[ASPX]

 

syncfusion:ButtonAdv ID="Button1" OnClientClick ="InvokeClick" ImageUrl="Img/Save16.png" runat="server" CustomClass="buttonback"

Text="Save As" DisplayType="ImageBeforeText"></syncfusion:ButtonAdv>

 

[JavaScript]

 

<script type ="text/javascript" >

        function InvokeClick(value) {

            alert("You Clicked " + value + " Button");

        }   

</script>

 

The value is the text of the ButtonAdv Control. For Image only button, you can set the value in the Name property, the code snippet is given below:

 

[ASPX]

 

<syncfusion:ButtonAdv ID="Button1" OnClientClick ="InvokeClick" ImageUrl="Img/Save16.png" runat="server" CustomClass="buttonback"

Name ="Save As" DisplayType="ImageOnly"></syncfusion:ButtonAdv>

5.1.11.3.3.2        Server-Side Events

To set the ButtonAdv Control as server-side button, give the server-side function to the OnClick event.

Follow these steps to give the event to the function (and go through the code to understand how this works)-

1.   Add a new Web Page in your project.

2.   Drag the ButtonAdv Control and add the following code in the HTML View.

[ASPX]

 

<syncfusion:ButtonAdv ID="ButtonAdvance"  OnClick ="ButtonAdvance_Click" ImageUrl="Img/Save16.png" runat="server" CustomClass="buttonback"

Text ="Save As" DisplayType="ImageOnly">

 

</syncfusion:ButtonAdv>

 

3.   Add the following method in .cs file

 

[C#]

protected void ButtonAdvance_Click(object sender,Syncfusion.Web.UI.WebControls.Shared.ButtonAdvControl.ButtonAdvClickEventArgs e)

{

   if (e.SelectedItem != null)

        {

            Response.Write(e.SelectedItem.Text);

        }

        else

        {

            Response.Write(e.SelectedText);

        }

}

 

 

[VB]

Protected Sub ButtonAdvance_Click(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Shared.ButtonAdvControl.ButtonAdvClickEventArgs) Handles ButtonAdvance.Click

 

If e.SelectedItem Is Nothing Then

   Response.Write(e.SelectedText)

Else

    Response.Write(e.SelectedItem.Text)

End If

End Sub

 

 

4.   Build and run the application. The ButtonAdvance_Click method will be handling when you click on the button.

In the above sample the values for button sub-menu items are given by SelectedItem, and  those of buttons that don’t have sub-menu items are given by SelectedText .
