Client-side method

There is only one client-side method that can be implemented for the Rating control:

Name of the method

Parameters of the method

Return type

Descriptions

Reset

NA

NA

Resets the rating value to zero.

 

You can use the client-side method using the following code:

 

ASPX Code

 

[ASPX]

<syncfusion:Rating ID="Rating1" runat="server" ClientObjectId="ratingObj" />

 

 

[JavaScript]

function updateData() {

            //code used to reset the rating

            ratingObj.Reset();

        }
