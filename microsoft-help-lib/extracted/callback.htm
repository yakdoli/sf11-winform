Customizing the Appearance of Callback Status

 

This section will walk you through the properties which can be used to customize the appearance of the callback status in a Schedule control.

 

The properties involved are as follows.

 

Schedule Property

Description

WaitingPopupText

Specifies the text to be displayed on callback.

DisabledBackgroundColor

Specifies the color of disabled background element.

WaitingPopupCSSClass

Specifies the css class name, which will be applied to the Waiting Pop-up.

 

[ASPX]

 

<syncfusion:Schedule ID="Schedule1" runat="server" WaitingPopupText="Waiting..." DisabledBackgroundColor="LavenderBlush">

</syncfusion:Schedule>

 

[C#]

 

Schedule1.WaitingPopupText = "Waiting...";

Schedule1.DisabledBackgroundColor = System.Drawing.Color.LavenderBlush;

 

[VB]

 

Schedule1.WaitingPopupText = "Waiting..."

Schedule1.DisabledBackgroundColor = System.Drawing.Color.LavenderBlush

Rotating images and text can be displayed to intimate the callback status. There are different types of pre-defined rotating images and you can choose one by making use of the WaitingPopupAutoFormat property. This property is of type "string".

 

 

 

Schedule Property

 

Description

WaitingPopupAutoFormat

Specifies the pre-defined set of waiting images.

 

The Auto Format types in the Waiting Pop-up are given below.

 

Figure 38

 

 You can assign the Auto Format name programmatically as follows.

 

[ASPX]

 

<syncfusion:Schedule ID="Schedule1" runat="server" WaitingPopupAutoFormat="Arrow">

</syncfusion:Schedule>

 

[C#]

 

Schedule1.WaitingPopupAutoFormat = "Arrow";

 

[VB]

 

Schedule1.WaitingPopupAutoFormat = "Arrow"

 

Canceling Callback

 

This section discusses how callbacks can be canceled by the user.

 

In any case, if a callback is not returned, and if you want to cancel that callback, the TimeSpan property can be used to display the cancel button after the specified time (in milliseconds).

 

Schedule Property

Description

TimeSpan

Specifies time, in milliseconds, after which the cancel button will be shown in the Waiting Pop-up.

 

[ASPX]

 

<syncfusion:Schedule ID="Schedule1" runat="server" TimeSpan="1">

</syncfusion:Schedule>

 

[C#]

 

Schedule1.TimeSpan = 1;

 

[VB]

 

Schedule1.TimeSpan = 1
