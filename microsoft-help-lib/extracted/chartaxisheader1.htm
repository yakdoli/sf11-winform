Chart Axis Header

 

Essential Chart for Windows Phone provides support for Chart Axis Titles with the help of the Header property. This property can hold the other elements. We can assign any other Windows Phone element to this Header property to display the data in the Chart area.

 

[XAML]

 

<syncfusion:Chart Background="LightBlue">

            <syncfusion:ChartArea FontWeight="Bold" GridBackground="White">

                <syncfusion:ChartArea.PrimaryAxis>

                    <syncfusion:ChartAxis ShowGridLines="False">

                        <syncfusion:ChartAxis.Header>

                            <TextBlock Text="X-Axis" Margin="0,5" FontWeight="Bold" FontSize="15" Foreground="Blue"/>

                        </syncfusion:ChartAxis.Header>

                    </syncfusion:ChartAxis>

                </syncfusion:ChartArea.PrimaryAxis>

 

                <syncfusion:ChartArea.SecondaryAxis>

                    <syncfusion:ChartAxis>

                        <syncfusion:ChartAxis.Header>

                            <TextBlock Text="Y-Axis" Margin="0,5" FontWeight="Bold" FontSize="15" Foreground="Blue"/>

                        </syncfusion:ChartAxis.Header>

                    </syncfusion:ChartAxis>

                </syncfusion:ChartArea.SecondaryAxis>

 

                <syncfusion:ChartSeries Data="1,12,2,18,3,13,4,7" Interior="{StaticResource Series1}"/>

            </syncfusion:ChartArea>

        </syncfusion:Chart>
