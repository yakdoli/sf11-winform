Server-Side Events

 

The server-side events can be triggered to execute a function on some user action. The various server-side events are listed below.

 

Server-Side Event

Description

TextChanged

Specifies the function to be executed when the text in the input area of the MultiColumnDropDownCombo changes. This event is handled only when the AutoPostBackOnTextChanged property is set to True.

SelectedIndexChanged

Specifies the function to be executed when a new item is selected from the dropdown. This event is handled only when the AutoPostBackOnSelectedIndexChanged property is set to True.

SortCommand

Specifies the client-side function to call to sort the grid data.

 

The following procedure shows how to process and handle the server-side events.

 

1.   Add the following code snippet in the html view of your project.

 

[ASPX]

 

<cc1:MultiSelectionDropDown ID="MultiSelectionDropDown1" runat="server" CheckBoxListRepeatColumns="2"  DataSourceID="XmlDataSource1" DataTextField="Title" DataValueField="Title" Width="376px" ClientSideOnBeforePopupShow="OnBeforePopup(this)" ClientSideOnItemCheckChanged="OnItemChecked(this)" ClientSideOnPopupShown="OnPopup(this)" ClientSideOnTextChanged="OnTextChange(this)" AutoFormat="Office2007 Blue">

<CheckBoxListStyle BackColor="#DAE5F5" Font-Names="Verdana" Font-Size="12px" ForeColor="#000033" />

</cc1:MultiSelectionDropDown>

 

2.   Add the following code snippets in the code view of your project.

 

[C#]

 

protected void MultiColumnDropDownCombo1_SelectedIndexChanged(object sender, Syncfusion.Web.UI.WebControls.Shared.MultiColumnDropDownComboEventArgs e)

{

this.Label1.Text = e.MultiColumnDropDownCombo.SelectedIndex.ToString();

}

 

protected void MultiColumnDropDownCombo1_TextChanged(object sender, Syncfusion.Web.UI.WebControls.Shared.GenericDropDownTextChangeEventArg e)

}

3.   Build and run the application.

 

On changing the text and selecting a new item in the MultiColumnDropDownCombo control, the corresponding server-side events are handled.

Note: Refer the Sorting the DropDown Data topic, to know about the SortCommand event.

 

5.1.6.3.1.1 Sorting the dropdown data

 

Sorting can be performed on the data in the dropdown combo. Sorting functionality has to be specified by using the SortCommand event. To execute the sorting function, the AllowSorting property has to be set.

 

[C#]

 

private bool IsSortAccelerate

{

    get

    {

        bool bAcc = (null == ViewState["SortAccelerate"]) ?

            true : (bool)ViewState["SortAccelerate"];

        return bAcc;

    }

    set

    {

        ViewState["SortAccelerate"] = value;

    }

}

 

private string SortExpression

{

    get

    {

        string sSortExpression = (null == ViewState["SortExpression"]) ?

            "" : (string)ViewState["SortExpression"];

        return sSortExpression;

    }

    set

    {

        ViewState["SortExpression"] = value;

    }

}

protected void MultiColumnDropDownCombo1_SortCommand(object source, DataGridSortCommandEventArgs e)

{

    if (this.SortExpression == e.SortExpression)

    {

        this.IsSortAccelerate = !this.IsSortAccelerate;

    }

    else

    {

        this.SortExpression = e.SortExpression;

    }

    AccessDataSource2.SelectCommand= "SELECT [BookName], [AuthorName] FROM [Books1] ORDER BY" +

        e.SortExpression + (this.IsSortAccelerate ? "Asc" : "Desc");

    MultiColumnDropDownCombo1.DataSource = AccessDataSource2;

    MultiColumnDropDownCombo1.DataBind();

}

 

[VB]

 

Private Property IsSortAccelerate() As Boolean

       Get

              Dim bAcc As Boolean = IIf((Nothing Is ViewState("SortAccelerate")), True, CBool(ViewState("SortAccelerate")))

              Return bAcc

       End Get

       Set

              ViewState("SortAccelerate") = Value

       End Set

End Property

 

Private Property SortExpression() As String

       Get

              Dim sSortExpression As String = IIf((Nothing Is ViewState("SortExpression")), "", CStr(ViewState("SortExpression")))

              Return sSortExpression

       End Get

       Set

              ViewState("SortExpression") = Value

       End Set

End Property

Protected Sub MultiColumnDropDownCombo1_SortCommand(ByVal source As Object, ByVal e As DataGridSortCommandEventArgs)

       If Me.SortExpression = e.SortExpression Then

              Me.IsSortAccelerate = Not Me.IsSortAccelerate

       Else

              Me.SortExpression = e.SortExpression

       End If

       AccessDataSource2.SelectCommand= "SELECT [BookName], [AuthorName] FROM [Books1] ORDER BY" & e.SortExpression + (IIf(Me.IsSortAccelerate, "Asc", "Desc"))

       MultiColumnDropDownCombo1.DataSource = AccessDataSource2

       MultiColumnDropDownCombo1.DataBind()

End Sub
