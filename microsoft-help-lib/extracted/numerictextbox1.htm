Numeric Text Box

The numeric text box control in Essential Tools for MVC allows you to display only numeric values within a text box.

 

Key Features

·      Customizable range support.

·      Double value support.

·      Watermarking support.

·      A rich set of client-side events and methods.

·      Fourteen built-in skins.
