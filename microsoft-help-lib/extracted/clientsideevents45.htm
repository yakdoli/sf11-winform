The tree-view control supports client-side event handling.

            //args:

        }

Using Properties Model

The following steps explain how to handle client-side events raised by the tree view through the properties model.

1.   In the controller, create an instance of TreeViewModel.

2.   Define the ClientSideOnLoded, ClientSideOnNodeClick, ClientSideOnNodeExpand, ClientSieOnNodeCollapse, and ClientSideInlineEditValidation properties and pass the instance through the view-specific data to the view.

 

[Controller]

public ActionResult Index()

        {

            TreeViewModel myModel = new TreeViewModel();

            myModel.ClientSideOnLoaded="OnLoaded";

            myModel.ClientSideOnNodeClick="OnNodeClick";

            myModel.ClientSideOnNodeExpand="OnExpand";

            myModel.ClientSideOnNodeCollapse="OnCollapse";

            myModel.ClientSideInlineEditValidation = "OnEdit";

 

            //pass the model through view data to the view

            ViewData["myTreeView"] = myModel;

            return View();

        }

 

 

3.   In View, create a ul-li hierarchy of tree-view nodes and invoke the tree-view helper by passing the view data key as the first argument and the tree-view content ID as the second argument.
