Chart Types

 

Essential Chart for Windows Phone supports 36 chart types for business needs. All chart types should have minimum one X and Y value. Some chart types require more than one Y value, based on their behavior. You can also switch from one chart type to another by using the Type property of ChartSeries class. Initially, only 28 chart types were supported and they did not include the Radar, Polar, Bubble, BoxAndWhisker, Tornado, StackingColumn100, StackingBar100 and RotatedSpline charts. Now, new chart types have been added to Windows Phone Chart control. They are:

·      Radar

·      Polar

·      Bubble

·      BoxAndWhisker

·      Tornado

·      StackingColumn100

·      StackingBar100

·      RotatedSpline charts

 

You can have better visualization of data with the new chart types that have been added to Windows Phone.

Initializing Multiple Y Values in a Chart

 

Multiple Y values can be initialized in the Chart either by using the Data or DataSource property of ChartSeries class. The following code example illustrates how to initialize multiple Y values in the Chart.

 

Initializing Series By Using Data Property

 

[XAML]

 

// Syntax 1

<syncfusion:ChartSeries Type="Bubble" Interior="Blue">

    <syncfusion:ChartPoint X="1" Y="30" Values="30,50"/>

    <syncfusion:ChartPoint X="2" Y="80" Values="80,100"/>

    <syncfusion:ChartPoint X="3" Y="75" Values="75,150"/>

    <syncfusion:ChartPoint X="4" Y="55" Values="55,90"/>

    <syncfusion:ChartPoint X="5" Y="80" Values="80,70"/>

    <syncfusion:ChartPoint X="6" Y="60" Values="60,90"/>

</syncfusion:ChartSeries>

 

// Syntax 2

<syncfusion:ChartSeries Type="Bubble" Data="1,{60,40},2,{40,20},3,{90,10},4,{100,50},5,{40,50},6,{50,40}" />

 

[C#]

 

Chart chart = new Chart();

ChartArea area = new ChartArea();

ChartSeries series = new ChartSeries();

 

// Initialize Chart Points.

ChartPointsCollection points = new ChartPointsCollection();

points.Add(new ChartPoint(1, new double[] { 30, 50 }));

points.Add(new ChartPoint(2, new double[] { 80, 100 }));

points.Add(new ChartPoint(3, new double[] { 75, 150 }));

points.Add(new ChartPoint(4, new double[] { 55, 90 }));

points.Add(new ChartPoint(5, new double[] { 80, 70 }));

points.Add(new ChartPoint(6, new double[] { 60, 90 }));

 

series.Data = points;

area.Series.Add(series);

chart.Areas.Add(area);

[C#]

 

// Initialize the Chart, Chart Area and Chart Series.

Chart chart = new Chart();

ChartArea area = new ChartArea();

 

// Initialize Series.

ChartSeries series = new ChartSeries();

series.Type = ChartTypes.BoxAndWhisker;

 

// Binding the Data Source value.

series.DataSource = this.Resources["data1"] as StockData;

series.BindingPathX = "StockDate";

series.BindingPathsY = new List<string>() { "MaxStockPrice”, “MinStockPrice”, “OpenPrice”, “ClosePrice”, “PurchasePrice" };

area.Series.Add(series);

chart.Areas.Add(area);

    public class DateConverter : TypeConverter

    {

        private const string split = "/";

 

        public override bool CanConvertFrom(ITypeDescriptorContext context, Type sourceType)

        {

            return (sourceType == typeof(string)) || base.CanConvertFrom(context, sourceType);

        }

 

        public override object ConvertFrom(ITypeDescriptorContext context, CultureInfo culture, object value)

        {

            string str = value as string;

            if (str != null)

            {

                string[] valuestr = Regex.Split(str, split);

                int[] datevalue = new int[valuestr.Length];

                int month = Convert.ToInt32(valuestr[0], CultureInfo.InvariantCulture);

                int day = Convert.ToInt32(valuestr[1], CultureInfo.InvariantCulture);

                int year = Convert.ToInt32(valuestr[2], CultureInfo.InvariantCulture);

                return new DateTime(year, month, day);

            }

            return null;

        }

    }
