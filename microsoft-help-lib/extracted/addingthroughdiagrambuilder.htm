Adding through DiagramBuilder

A node can also be added into the diagram through Builder. The following code describes the method in which it can be done.

1.   Create an application.

2.   Add the following code into the view page.

 

View

 

<% Node node1 = new Node()

   {

       Name = "Node1",

       Label = "Node1",

       LabelHorizontalAlignment = Horizontal.Center,

       LabelVerticalAlignment = Vertical.Middle,

       OffsetX = 225,

       OffsetY = 100,

       Shape = Shapes.Ellipse,

       Height = 50.00,

       Width = 50.00,

       BackgroundColor = "orange",

       BorderColor = "black",

       BorderWidth = 1,

       LabelFontColor = "black",

       LabelFontSize = 12,

       LabelFontFamily="Times New Roman

   };

 

%>

<%{

  Html.Syncfusion().Diagram("FlatDiagram")

          .Nodes(nodes => nodes.Add(node1))

          .Width(Unit.Pixel(1100))

          .Height(Unit.Pixel(500))

           .DiagramMode(DiagramMode.SVG)

          .Render();

  }

%>

Note: If you want to create the diagram in the Canvas mode. Change the DiagramMode to Canvas. By default the diagram is rendered in the SVG mode.

 

 

3.   Run the application. The node will appear in the working area as shown below
