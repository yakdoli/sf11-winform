Hide a Chart

 

On setting the display mode option to GridOnly, the chart hides.

[C#]

this.OlapClient1.DisplayMode = DisplayMode.GridOnly;

this.OlapClient1.DataBind();

 

[VB]

Me.OlapClient1.DisplayMode = DisplayMode.GridOnly

Me.OlapClient1.DataBind()
