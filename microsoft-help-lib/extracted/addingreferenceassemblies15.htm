Adding Reference Assemblies

The steps to add reference assemblies are as follows:

1.   On the Solution Explorer, right-click the References folder, and then click Add Reference. The Add Reference dialog box appears:

Figure 39: Add Reference option displayed on right-clicking the References folder

 

Note: In the Add Reference dialog box the .NET tab is highlighted by default. The assemblies for the MVC application are listed below.

Figure 40: Add Reference dialog box

2.   Select the following assemblies:

 

·      Syncfusion.Core, Syncfusion.Chart.Mvc

·      Syncfusion.Linq.Base

·      Syncfusion.Shared.Mvc

·      Syncfusion.Chart.Base

·      SyncfusionShared.Base Syncfusion.DocIO.Mvc

 

3.   Click OK.

The selected assemblies are added under References.

 

Figure 41: Selected assemblies displayed under the References folder
