Adding Numeric textbox to the Mobile MVC application

In the Getting Started section, we discussed how to create a Mobile MVC application and how to add Tools package to an application. This section guides you to add Numeric textbox control to an application.

To add the Numeric textbox control to an application:

 

1.   In View, invoke the Numeric textbox helper with the numeric ID as the first argument.

 

[ASPX]

  <% {                               

    Html.MobSyncfusion().NumericTextbox("WebsiteNumeric").WaterMarkText("Enter value").Render();

       }%>

 [Razor]

    @{            Html.MobSyncfusion().NumericTextbox("WebsiteNumeric").WaterMarkText("Enter value").Render();

       }

 

2.   Run the application.
