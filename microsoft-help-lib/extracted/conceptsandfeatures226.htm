4.1.7.1.2.1 Enable Calendar Zooming Navigation Mode

The schedule CalendarNavigationMode property’s default value is Default. If we changed the property value to Windows7 then the calendar can navigate to the month, year, and 10-year views when clicking on the header.

4.1.7.1.2.2 Schedule Calendar Navigation Properties

The steps to enable the Essential Schedule calendar navigation mode with code are as follows:

[ASPX]

 

<syncfusion:Schedule ID="schedule1" runat="server" CalendarPosition="Right" CalendarNavigationMode="Windows7"  Height="400px" Width="700px" AutoFormat="Vista"> </syncfusion:Schedule>

 

[C#]

 

schedule1.CalendarNavigationMode = Syncfusion.Web.UI.WebControls.ScheduleControl.CalendarNavigationMode.Windows7;

 

[VB]

 

schedule1.CalendarNavigationMode = Syncfusion.Web.UI.WebControls.ScheduleControl.CalendarNavigationMode.Windows7
