DomainUpDownExt Events

This section describes the events of DomainUpDownExt control.

 

DomainUpDownExt Events

Description

ThemeChanged

This event is handled when ThemesEnabled property is changed.

SpinOrientationChanged

This event is handled when orientation of spin button is changed.

BorderSidesChanged

This event is handled when BorderSides property is changed.

BorderColorChanged

This event is handled when BorderColor is changed.

Border3DStyleChanged

This event is handled when Border3DStyle is changed.
