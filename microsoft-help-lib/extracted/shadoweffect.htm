Shadow Effect

 

Menu allows you to render the structure with shadow effects, in addition to style settings. Shadow effects can be set for the entire menu structure to enhance the look and feel of the menu.

 

Menu Property

Description

ShadowColor

Specifies the color to use for dropdown menu shadow.

ShadowDirection

Specifies the direction of shadow offset, in degrees.

ShadowStrength

Specifies distance in pixels to which the shadow filter effect extends.

 

The shadow effect can be applied using the ShadowStrength, ShadowDirection and ShadowColor properties.

 

 

Figure 225: SubMenu with Shadow effect

 

Sample code for setting shadow effect using the above said properties.

 

<cc1:Menu id = "Menu1" runat = "server" style = "POSITION: absolute" CustomCSS = "css/menuStyle.css" ShadowColor = "255, 186, 109"

ShadowStrength = "10" ShadowDirection = "140">

  <Items>

    <cc1:MenuItem Text="Products" Look="lookroot">

      <cc1:MenuItem Text="Essential Tools" Look="lookcommon">

        <cc1:MenuItem Text="Editors Package" Look="lookcommon"> </cc1:MenuItem>

      </cc1:MenuItem>

      <cc1:MenuItem Text="Essential Grid" Look="lookcommon"> </cc1:MenuItem>

      <cc1:MenuItem Text="Essential Chart" Look="lookcommon"> </cc1:MenuItem>

      <cc1:MenuItem Text="Essential Edit" Look="lookcommon"> </cc1:MenuItem>

      <cc1:MenuItem Text="Essential Diagram" Look="lookcommon"> </cc1:MenuItem>

    </cc1:MenuItem>

  </Items>

 

  <ItemLooks>

    <!--Add the required item looks!-->

  </ItemLooks>

</cc1:Menu>
