Declaring ButtonAdv

To include the ButtonAdv control in an application, the following Assembly should be reffered:

·      Assembly: Syncfusion.Shared.Phone

 

The following Namespace should be reffered in the application page:

·      Namespace: Syncfusion.Phone.Tools.Controls

4.4.1.2.1    Setting Label

The Label property represents the Text content of the ButtonAdv control.

The following code illustrates the declaration of ButtonAdv control using XAML:

[XAML]

 

<sync:ButtonAdv Label="ButtonAdv"/>

 

The ButtonAdv control can be created using C# as follows:

[C#]

 

ButtonAdv button = new ButtonAdv()

button.Label = "ButtonAdv";

4.4.1.2.2    Setting Size Mode

The Size Mode of the ButtonAdv control can be easily changed using the SizeMode property. The SizeMode property contains following values:

·      Small

·      Normal

·      Large

 

The following code sets SizeMode to “Small”:

 

[XAML]

 

<sync:ButtonAdv SizeMode="Small" Label="ButtonAdv"/>

 

[C#]

 

ButtonAdv button = new ButtonAdv()

button.Label = "ButtonAdv";

button.SizeMode = SizeMode.Small;

 

The following code sets SizeMode to “Normal”:

[XAML]

 

<sync:ButtonAdv SizeMode="Normal" Label="Hello World"/>

 

[C#]

 

ButtonAdv button = new ButtonAdv()

button.Label = "ButtonAdv";

button.SizeMode = SizeMode.Normal;

 

The following sets SizeMode to “Large”:

 

[XAML]

 

<sync:ButtonAdv SizeMode="Large" Label="ButtonAdv"/>

 

[C#]

 

ButtonAdv button = new ButtonAdv()

button.Label = "ButtonAdv";

button.SizeMode = SizeMode.Large;

4.4.1.2.3    Setting Image

The Image displayed in the control can be set to any of the following properties:

·      SmallIcon –When the SizeMode is Normal or Small

·      LargeIcon –When the SizeMode is Large

 

The SmallIcon property can be set as follows when “SizeMode” is “Small”:

 

[XAML]

 

<sync:ButtonAdv SizeMode="Small" Label="Chart" SmallIcon="chart.png"/>

 

[C#]

 

ButtonAdv button = new ButtonAdv()

button.Label = "Chart";

button.SizeMode = SizeMode.Small;

button.SmallIcon = new BitmapImage(new Uri("chart.png"));

 

The SmallIcon property can be set as follows when “SizeMode” is “Normal”:

[XAML]

 

<sync:ButtonAdv SizeMode="Normal" SmallIcon="chart.png" Label="Chart"/>

 

[C#]

 

ButtonAdv button = new ButtonAdv()

button.Label = "Chart";

button.SizeMode = SizeMode.Normal;

button.SmallIcon = new BitmapImage(new Uri("chart.png"));

 

The LargeIcon property can be set as follows:

[XAML]

 

<sync:ButtonAdv SizeMode="Large" LargeIcon="chart.png" Label="Chart"/>

 

[C#]

 

ButtonAdv button = new ButtonAdv()

button.Label = "Chart";

button.SizeMode = SizeMode.Large;

button.SmallIcon = new BitmapImage(new Uri("chart.png"));
