Embedding Controls inside Snap

 

The Snap control works seamlessly with any control that is integrated with the snap element.

 

Figure 383: Integrating controls into Snap control

 

The Snap control also supports the data binding of the child controls. To embed a control inside Snap, include the control's code snippet between the ContentTemplate tags. Here the Rotator control is embedded within the Snap element.

The code snippet given below illustrates inserting the Rotator control within the Snap element and also the data binding of the Rotator control with xml file.

 

<cc1:Snap ID="Snap1" runat="server" DockingContainers = "LeftColumn,RightColumn" CollapseDuration = "200" ExpandDuration = "200" DraggingStyle = "GhostCopy" DockingStyle = "TransparentRectangle" MustBeDocked = "True" IsCollapsed = "false" Width = "410" Height = "70">

   <ContentTemplate>

      <cc2:Rotator ID = "Rotator1" runat = "server" Width = "400" CssClass = "Rotator" RotationType = "SmoothScroll" Height = "250" SlidePause = "3000" ScrollInterval = "15" XmlContentFile = "News.xml" SmoothScrollSpeed = "Medium">

         <slidetemplate>

            <table height = "85" width = "400" cellspacing = "0" cellpadding = "4" border = "0" onmouseover = "this.className='NewsItemOver';" onmouseout = "this.className='NewsItem';" bgColor = "#edf0f6">

               <tr>

               <td><a href='<%# DataBinder.Eval(Container.DataItem, "Url") %>' target=_blank> <img border=0 src='images/<%# DataBinder.Eval(Container.DataItem, "Image") %>' width="60" height="70" />

               </a></td>

               <td valign="top" align="left">

               <span class="NewsTitle"><%# DataBinder.Eval(Container.DataItem, "Title") %></span>

               <br />

               <span class="NewsText"><%# DataBinder.Eval(Container.DataItem, "Text") %></span>

               <img src="images/multiplescroller.gif" alt="" width="17" height="10" />

               </td>

               </tr>

            </table>

         </slidetemplate>

      </cc2:Rotator>

   </ContentTemplate>

  

   <HeaderTemplate>

      <div style="CURSOR: move;">

         <table cellSpacing="0" cellPadding="0" height="25px" width="408px" border="0">

            <td class="SnapHeader">&nbsp;Grab here to undock the rotator

            </td>

         </table>

      </div>

   </HeaderTemplate>

</cc1:Snap>
