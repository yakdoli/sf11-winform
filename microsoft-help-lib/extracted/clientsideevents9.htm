Client-Side Events

 

 

To raise and process client side events when the node is selected, renamed, expanded or check state changed, follow the steps given below.

 

1.   The TreeView control and a span tag with id 'eventDisplay' are added to the Web project.

57.  In HTML view add the following content.

 

<script language="javascript" type="text/javascript">

  function nodeSelected(node)

  {

    document.getElementById('eventDisplay').innerHTML="Selected '"+node.Text+"'";

  }

  function nodeRenamed(node)

  {

    document.getElementById('eventDisplay').innerHTML="Renamed '"+node.OldText+"' to '"+node.Text+"'";

  }

  function nodeMoved(node)

  {

    document.getElementById('eventDisplay').innerHTML="Moving '"+node.Text+"'";

  }

  function nodeDropped(node)

  {

    document.getElementById('eventDisplay').innerHTML="Dropped '" + node.SourceNode.Text + "under'" + node.TargetNode.Text;

  }

  function nodeExpanded(node)

  {

    document.getElementById('eventDisplay').innerHTML="Expanded '"+node.Text+"'";

  }

  function nodeCollapsed(node)

  {

    document.getElementById('eventDisplay').innerHTML="Collapsed '"+node.Text+"'";

  }

  function nodeChecked(node)

  {

    if(node.Checked)

    {

      document.getElementById('eventDisplay').innerHTML="Checked '"+node.Text+"'";

    }

    else

    {

      document.getElementById('eventDisplay').innerHTML="UnChecked '"+node.Text+"'";

    }

  }

</script>

Code Analysis

 

ClientSideOnNodeSelect

 

In the above example, the ClientSideOnNodeSelect property is set to the 'nodeSelected' client-side javascript function. This will get executed whenever a node is selected and passes the selected node as a parameter to the NodeSelected event.

 

If Selectable property of the node is set to False, ClientSideOnNodeSelect event won't get triggered.

 

ClientSideOnNodeRename

 

In the above example, ClientSideOnNodeRename property is set to the 'nodeRenamed' client-side javascript function. This will get executed whenever a node is renamed and passes the renamed node as parameters to the NodeRenamed event. Make sure that the EditNode property is set to True, to allow  node to be edited. You can get the nodes old text using the renamed node which is passed as a parameter to the NodeRenamed event.

 

ClientSideOnNodeMove

 

In the above example, ClientSideOnNodeMove property is set to the 'nodeMoved' client-side javascript function. This will get executed whenever a node is dropped and passes the dropped node as parameter to the NodeMoved event. Make sure that the DragAndDropEnabled property is set to True, to allow nodes to be moved.

 

ClientSideOnNodeDrop

 

In the above example, ClientSideOnNodeDrop property is set to the 'nodeDropped' client-side javascript function. This will get executed whenever a node is dropped and passes the dropped node as parameters to the NodeDropped event. Make sure that the DragAndDropEnabled property is set to True, to allow node to be dropped.

 

node.SourceNode.Text and node.TartgetNode.Text can be used to obtain the source and the target nodes of the dropped node.

 

ClientSideOnNodeExpand

 

In the above example, the ClientSideOnNodeExpand property is set to the 'nodeExpanded' client-side javascript function. This will get executed whenever a node gets expanded and passes the expanded node as a parameter to the NodeExpanded event.

 

ClientSideOnNodeCollapse

 

In the above example, the ClientSideOnNodeCollapse property is set to the 'nodeCollapsed' client-side javascript function. This will get executed whenever a node gets collapsed and passes the collapsed node as a parameter to the NodeCollapsed event.

 

ClientSideOnNodeCheckChanged

 

In the above example, ClientSideOnNodeCheckChanged property is set to the 'nodeChecked' client-side javascript function. This will get executed whenever a node in the checkbox is checked / unchecked. Here Checked attribute gives the status of the checkbox, whether it is checked / unchecked.

5.3.1.3.2.2 ClientSideOnContextMenu Event

 

 

ClientSideOnContextMenu is fired on right-clicking the node. Parameter of this event is ClientEventData.

Following sample demonstrates how to override default browser context menu for TreeView node.

 

[ASPX]

 

<cc1:TreeView ID="TreeView1" runat="server" EditNode="False" Width="192px" Height="288px"

    ClientSideOnContextMenu="NodeOnContextMenu(this)">

    <Items>

        <cc1:TreeViewNode Text="Calendar">

        </cc1:TreeViewNode>

        <cc1:TreeViewNode Text="Contacts">

        </cc1:TreeViewNode>

        <cc1:TreeViewNode Text="Inbox">

        </cc1:TreeViewNode>

        <cc1:TreeViewNode Text="Node with browser's context menu">

        </cc1:TreeViewNode>

    </Items>

</cc1:TreeView>

<cc1:Menu ID="MenuCalendar" ClientObjectId="_sfMenuCalendar"  runat="server" ContextMenu="Custom" Layout="Vertical" ClientSideOnItemSelect="OnMenuItemSelect( this )">

    <Items>

        <cc1:MenuItem Text="Menu Calendar">                  

        </cc1:MenuItem>               

    </Items>

</cc1:Menu>

<cc1:Menu ID="MenuContacts" ClientObjectId="_sfMenuContacts" runat="server" ContextMenu="Custom" Layout="Vertical" ClientSideOnItemSelect="OnMenuItemSelect( this )">

    <Items>

        <cc1:MenuItem Text="Menu Contacts">

        </cc1:MenuItem>               

    </Items>

</cc1:Menu>

<cc1:Menu ID="MenuInbox" ClientObjectId="_sfMenuInbox" runat="server" ContextMenu="Custom" Layout="Vertical" ClientSideOnItemSelect="OnMenuItemSelect( this )">

    <Items>

        <cc1:MenuItem Text="Menu Inbox">

        </cc1:MenuItem>

    </Items>

</cc1:Menu>

 

[JavaScript]

 

function NodeOnContextMenu( oNodeEventData )

{

       var bShowMenu = false;

       switch( oNodeEventData.Text )

       {

              case 'Calendar':

              _sfMenuCalendar.ShowContextMenu( null, null, oNodeEventData.Event, oNodeEventData );

              break;

 

              case 'Contacts':

              _sfMenuContacts.ShowContextMenu( null, null, oNodeEventData.Event, oNodeEventData );

              break;

 

              case 'Inbox':

              _sfMenuInbox.ShowContextMenu( null, null, oNodeEventData.Event, oNodeEventData );

              break;

 

              default:            

                  //In other case return true to show default browser's context menu.

                  bShowMenu = true;

              break;

       }

      

       //Return false to cancel showing default browser's default context menu.

       return bShowMenu;

}

 

function OnMenuItemSelect( oMenuItemData )

{

       var oContextDataNode = oMenuItemData.ParentMenu.ContextData;

       var feedback = '\"' + oMenuItemData.Text + '\" command was issued on the \"' + oContextDataNode.Text + '\"';

       alert( feedback );

       return false;

}

5.3.1.3.2.4 ClientSideOnNodeCheckChange Event

 

ClientSideOnNodeCheckChange event is fired on node check change. Parameter of this event is ClientSideData object.

 

Properties

 

·      Checked: indicates whether the node is checked or not

This is client-side property of Tree node object.

 

Methods

 

The following are the methods of the TreeView client side object.

 

·      Check / UnCheck: checks / unchecks the node

 

These are methods of Tree node client side object.

 

·      SetAutoCheckNodes(bool) / GetAutoCheckNodes: sets / gets value indicating whether the child nodes are automatically checked or unchecked on parent node check change

 

[ASPX]

 

<cc1:TreeView ID="TreeView1" ClientSideOnNodeCheckChanged="NodeOnCheckChange(this)" runat="server">

5.3.1.3.2.5 ClientSideOnNodeDragStart Event

 

ClientSideOnNodeDragStart event is fired on node start drag. Parameter of this event is ClientSideData object.

 

Make sure that the DragDropEnabled property is set to True, to allow nodes to be moved. This event can be canceled by simply returning false from the event handler. For more details see example below.

<asp:CheckBox ID="checkAllowDrag" Checked="true" runat="server" Text="Allow node dragging" />

<cc1:TreeView ID="TreeView1" ClientSideOnNodeDragStart="NodeOnDragStart(this)" DragAndDropEnabled="true" runat="server">

    <Items>

        <cc1:TreeViewNode Expanded="True" Text="Root Node1">

            <cc1:TreeViewNode Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode Text="Child Node2">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode>

        <cc1:TreeViewNode Expanded="True" Text="Root Node2">

            <cc1:TreeViewNode Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode Text="Child Node2">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode>

    </Items>

</cc1:TreeView>

function NodeOnDragStart( EventData )

{

    var bRes = document.getElementById( "checkAllowDrag" ).checked;

    return bRes;

}

 

5.3.1.3.2.6 ClientSideOnNodeDrop event

 

ClientSideOnNodeDrop event is fired on node drop. Parameter of this event contains the following properties.

 

·      SourceNode: dropping client side Treeview node object

·      TargetNode: target client side Treeview node object for dropping item

·      Event: browser event object

 

Make sure that the DragDropEnabled property is set to True to allow nodes to be moved. DroppingAccrossTreesEnabled is set True to allow nodes to be dropped from another Treeview, DropSiblingEnabled property indicates whether to allow dropping to create siblings (drop between nodes). This event can be canceled by simply returning False from the event handler and node dropping will be canceled.

 

This example demonstrates how allow drag and drop nodes only across TreeViews.

 

[ASPX]

 

<cc1:TreeView ID="TreeView1" ClientSideOnNodeDrop="NodeOnDrop(this)" runat="server"        DragAndDropEnabled="True" DraggingAcrossTreesEnabled="True" DropSiblingEnabled="True">

    <Items>

       ...

    </Items>

</cc1:TreeView>

 

<cc1:TreeView ID="TreeView2" ClientSideOnNodeDrop="NodeOnDrop(this)" runat="server"        DragAndDropEnabled="True" DraggingAcrossTreesEnabled="True" DropSiblingEnabled="True">

    <Items>

       ...

    </Items>

</cc1:TreeView>

 

[javascript]

 

function NodeOnDrop( EventData )

{

    var bRes = (EventData.SourceNode.TreeViewElement.id != EventData.TargetNode.TreeViewElement.id );

    return bRes;

}

 

5.3.1.3.2.7 ClientSideOnNodeMove event

 

ClientSideOnNodeMove event is fired on node is moved. Make sure that the DragDropEnabled property is set to True to allow nodes to be moved and DraggingAccrossTreesEnabled is set True to allow nodes to be dragged to another Treeview. Parameter of this event is ClientSideData object.

 

5.3.1.3.2.8 ClientSideNodeRename event

 

ClientSideNodeRename event is fired on node rename. Parameter of this event is ClientEventData object. Also this event data has OldText property which is used to get the text of the node before editing. This event can be canceled by simply returning False from the event handler and node renaming will be canceled.

 

[ASPX]

 

<cc1:TreeView ID="TreeView1" EditNode="true" ClientSideOnNodeRename="NodeOnRename(this)" runat="server">

    <Items>

        <cc1:TreeViewNode Expanded="True" Text="Root Node1">

            <cc1:TreeViewNode Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode Text="Child Node2">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode>

        <cc1:TreeViewNode Expanded="True" Text="Root Node2">

            <cc1:TreeViewNode Text="Child Node1">

            </cc1:TreeViewNode>

            <cc1:TreeViewNode Text="Child Node2">

            </cc1:TreeViewNode>

        </cc1:TreeViewNode

    </Items>

</cc1:TreeView>

 

[JavaScript]

 

function NodeOnRename( oNodeEventData )

{

    var sText = "Do you want rename " + oNodeEventData.OldText + " to " + oNodeEventData.Text;

    var bRes = confirm( sText );

    //Return false to cancel node renaming.

    return bRes;

}
