NumericUpDown

 

The NumericUpDown control is a text box with a pair of arrow buttons that increase / decrease the value given in a text box. It supports double values. The range of values can be specified.

 

Figure 26: NumericUpDown Control

 

Feature Summary

 

·      AllowEdit- specifies whether the control is editable or not.

·      Interval - specifies the step value for the control when the up / down buttons are clicked.

·      MaxValue and MinValue - specifies the range of values for the control.

·      TextAlignment - specifies the alignment of the content.

·      FlowDirection - specifies the flow direction for the control.

·      NegativeForeground - specifies the foreground color for the input value when the value is less than zero.
