Expand/Collapse Settings

 

Expand Settings

 

The content template of a snap element can be collapsed or expanded on clicking html or any element, for which the element's id must be set to the ExpandCollapseElementIDs.

 

Property

Description

ExpandCollapseElementIDs

A comma-delimited list of object ids allowed to expand/collapse for Snap.

 

The id of the element, which on clicking the content template must be collapsed or expanded, should be set to the ExpandCollapseElementIDs property.

Here, the id of the div element of the header template is set, such that the content template is collapsed or expanded, while clicking anywhere on the snap header.

 

[aspx]

 

<cc1:Snap ID="Snap2" runat="server" IsCollapsed="true" ExpandCollapseElementIDs="header" ExpandTransition="WipeUp" ExpandDuration="10" ExpandType="Constant" CollapseTransition="Pixelate" CollapseDuration="10" CollapseType="Accelerate">

    <ContentTemplate>

        .....

    </ContentTemplate>

    <HeaderTemplate>

        <div style="cursor: move" id="header">

            <table cellspacing="0" cellpadding="0" width="100%" border="0" >

                .....

            </table>

        </div>

    </HeaderTemplate>

<cc1:Snap>

 

[C#]

 

this.Snap1.ExpandCollapseElementIDs = "header";

this.Snap1.IsCollapsed = true;

 

[VB]

 

Private Me.Snap1.ExpandCollapseElementIDs = "header"

Private Me.Snap1.IsCollapsed = True

 

Collapse Settings

 

A snap element's content template can be hidden by default, i.e., collapsed by setting the IsCollapsed property to True.

 

Property

Description

IsCollapsed

When set to true, the Snap control will collapse on page load.
