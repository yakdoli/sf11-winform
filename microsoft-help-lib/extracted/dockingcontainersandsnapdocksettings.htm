Docking Containers and Snap Dock settings

 

Parent docking containers

 

The controls onto which the snap elements can be allowed to dock, could be set using the DockingContainers property. Any number of controls can be listed as Docking container just by separating the control name with comma. This allows the snap element to be docked only to those controls.

 

         Property       

Description

DockingContainers

Client side objects used as containers to dock Snap elements.

 

The DockingContainer is set to the client side html object id's de-limited using comma that defines the container for the snap elements.

 

Programmatically the property can be set as follows.

 

[C#]

 

Snap1.DockingContainers = "RightColumn,LeftColumn";

 

[VB]

 

Private Snap1.DockingContainers = "RightColumn,LeftColumn"

 

The Docking containers are created and the snap instances can be docked into the container or floated as follows.

 

<cc1:snap id="Snap2" runat="server" MustBeDocked = "True" ExpandCollapseElementIDs = "imgExpSnap1, imgCollSnap1" DockingContainers = "LeftColumn, RightColumn"> <cc1:snap>

 

The Code snippet for the Left and Right Containers is given below.

 

<%--LEFT DOCKING CONTAINER--%>

   <div id="LeftColumn" style="WIDTH: 100%; HEIGHT: 500px">

      <cc1:snap id  = "Snap1" runat = "server" DockingContainers = "LeftColumn, RightColumn" MustBeDocked = "True" ExpandCollapseElementIDs = "imgExpSnap1, imgCollSnap1 ">

      ....<%--template definitions--%>

      </cc1:snap>

   </div>

 

<%--RIGHT DOCKING CONTAINTER--%>

   <div id="RightColumn" style="WIDTH: 100%; HEIGHT: 500px">

      <cc1:snap id = "Snap2" runat = "server" ExpandCollapseElementIDs = "imgSnap3" MustBeDocked = "False" DockingContainers = "LeftColumn,RightColumn" >

      .....<%--template definitions--%>

      </cc1:snap>

   </div>

 

Element Docking and Floating settings

 

The snap elements can be floated anywhere on the browser window or it can be docked inside the parent containers. The MustBeDocked property should be set to True to dock the snap instances only inside the containers. Else they can be set to False to make the instances float.

 

         Property       

Description

MustBeDocked

Gets/sets the boolean value whether the snap elements should be docked or made to float.

 

Programmatically the property can be set as follows.

 

[C#]

 

Snap1.MustBeDocked = true;

 

[VB]

 

Private Snap1.MustBeDocked = True
