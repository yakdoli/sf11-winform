Client Side Methods

 

Rich text editor supports rich set of client side methods to control its behavior.

Methods

 

Name

Parameters

Return type

Description

Refernce Link

Disable_ToolbarItem

 

toolName –  name of the tool to be disabled. Possible values are {"JustifyLeft",JustifyRight", "JustifyCenter","JustifyFull", "Bold", "Italic","Underline", "StrikeThrough", "Cut","Copy","Paste", "OrderedList","UnorderedList", "ClearFormat", "Undo" , "Redo", "Indent", "Outdent", "Hyperlink","Unlink","ClearAll", "Smiley", "InsertImage"}

-

Disables the specified tool

-

Enable_ToolbarItem

 

toolName –  name of the tool to be enabled

-

Enables the specified tool

-

Remove_ToolbarItem

toolbarItemName –  name of the toolbar item to be removed

-

Removes the specified toolbar item.

-

Hide

-

-

Hides the rich text editor

-

 

The following steps explain how to use the client side method.

1.   In View, call the rich text editor helper with control id as first argument.

View[ASPX]

<%=Html.Syncfusion().RichTextEditor("myRichtextEditor")%>

 

 

View[cshtml]

@{ Html.Syncfusion().RichTextEditor("myRichtextEditor").Render();}

 

 

2.   In the Javascript, define the methods as below.

 

[Javascript]

 

<script type="text/javascript">

        function DisableItem() {

            //creating client side object for the editor

            var rteObj = $find("myRichtextEditor");

            //code to disable a tool

            rteObj.Disable_ToolbarItem("Bold");

            rteObj.Disable_ToolbarItem("Smiley");

        }

        function EnableItem() {

            //creating client side object for the editor

            var rteObj = $find("myRichtextEditor");

            //code to disable a tool

            rteObj.Enable_ToolbarItem("Bold");

            rteObj.Enable_ToolbarItem("Smiley");

        } function RemoveItem() {

            //creating client side object for the editor

            var rteObj = $find("myRichtextEditor");

            //code to remove a toolbar item

            rteObj.Remove_ToolbarItem("Bold");

            rteObj.Remove_ToolbarItem("Smiley");

        }

 

        function Show() {

            $find("myRichtextEditor").Show();

        }

        function Hide() {

            $find("myRichtextEditor").Hide();

        }

       </script>

 

 

3.   Build and run the applicaton.
