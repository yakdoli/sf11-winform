Using Properties Model

The following steps explain the handling of client side events of the Accordion using the Properties Model.

1.   In the Controller, create an instance of the MobAccordionModel, set the client side events and pass the instance through the view specific data to View as given below:

[Controller ]

public ActionResult Accordion()

        {

            MobAccordionModel model = newMobAccordionModel();

            ------

            model.OnAccordionLoad="OnAccordionLoad";

            model.OnAccordionSelect="OnAccordionSelect";

            model.OnAccordionEnable="OnAccordionEnable";

            model.OnAccordionDisable="OnAccordionDisable";

            -------

            ViewData["AccordionModel"] = model;

            return View();

        }
