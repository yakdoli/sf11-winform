Adding animations to the Dialog

The Dialog supports a number of in-built animations.

Properties

Name

Description

Type of property

Value it accepts

Dependency

Show

Sets the animation for the dialog open action

enum

DialogAnimations.bounce, DialogAnimations.blind, DialogAnimations.clip, DialogAnimations.drop, DialogAnimations.explode, DialogAnimations.fold, DialogAnimations.highlight, DialogAnimations.puff, DialogAnimations.pulsate, DialogAnimations.shake, DialogAnimations.slide

NA

Hide

Sets the animation for the dialog close action

enum

NA

 

Using Builder

The following steps explain the addition of animations to the Dialog using Builder.

1.   In View, create the contents of the Dialog and invoke the Dialog Helper with the control ID as the first argument followed by the Show and Hide methods with the desired animations as arguments.

 

View[aspx]

 

<div id="myDialog" title="Syncfusion Dialog" style="visibility: hidden">

This is the Syncfusion Dialog control with the 'x' icon. The dialog    window can be moved, resized and closed.

       </div>

       <%=Html.Syncfusion().Dialog("myDialog")

              .Show(DialogAnimations.bounce)

.Hide(DialogAnimations.bounce)%>

 

 

 

View[cshtml]

 

<div id="myDialog" title="Syncfusion Dialog" style="visibility: hidden">

This is the Syncfusion Dialog control with the 'x' icon. The dialog    window can be moved, resized and closed.

       </div>

       @{ Html.Syncfusion().Dialog("myDialog")

              .Show(DialogAnimations.bounce)

.Hide(DialogAnimations.bounce).Render();}

 

 

 

2.   Build and run the application.

 

Using Properties Model

The following steps explain the addition of animations to the Dialog using the Properties model.

1.   In the Controller, create an instance of DialogModel, define the Show and Hide and pass the instance through view specific data to View as given below.

 

 

 

[Controller]

 

public ActionResult Index()

        {

            //create an instance of DialogModel

            DialogModel myModel = new DialogModel();

            myModel.Show = DialogAnimations.bounce;

            myModel.Hide = DialogAnimations.bounce;

 

            //pass the instance through view data to the view

            ViewData["myDialog"] = myModel;

            return View();

        }

 

 

2.   In View, create the dialog contents and invoke the dialog helper with the View Data key as the first argument.

 

View[ASPX]

 

<div id="myDialog" title="Syncfusion Dialog" style="visibility: hidden">

This is the Syncfusion Dialog control with the 'x' icon. The dialog    window can be moved, resized and closed.

       </div>

<%=Html.Syncfusion().Dialog("myDialog")%>

 

 

View[cshtml]

 

<div id="myDialog" title="Syncfusion Dialog" style="visibility: hidden">

This is the Syncfusion Dialog control with the 'x' icon. The dialog    window can be moved, resized and closed.

       </div>

@{ Html.Syncfusion().Dialog("myDialog").Render();}

 

 

3.   Build and run the application.

The applied animations can be seen effective on the dialog open and close actions.
