Using Properties Model

The following steps explain how to set the ScrollType:

1.   In the controller, create an instance of MobScrollPanelModel.

2.   Define the scrolltype properties and pass the instance through the view-specific data to the view.

 

 [Controller]

 

        publicActionResult ScrollPanel()

        {

            MobScrollPanelModel myModel = newMobScrollPanelModel();

            myModel.Height = 300;

            myModel.Width = 500;

            myModel.ScrollBarWidth = 7;

            myModel.TargetId = "scrollContent";

            myModel.ScrollType = ScrollType.Both;

            //Passing the instance through the view data to the view.

            ViewData["myScrollPanel"] = myModel;

 

            return View();

        }

4.   In View, invoke the ScrollPanel helper with the view data key as the control ID.

 

 

 [ASPX]

 

<% = Html.MobSyncfusion().ScrollPanel("myScrollPanel") %>

 

 

[Razor]

@{ Html.MobSyncfusion().ScrollPanel("myScrollPanel") .Render();}
