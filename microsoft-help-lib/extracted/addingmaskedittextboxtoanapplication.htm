Adding MaskEditTextBox to an Application

Steps to create the MaskEditTextBox by using Visual Studio in C# are as follows:

1.  Open Visual Studio. On the File menu click New > Project. This opens the New Project dialog box.

Fig 142: New Project Creation

2.   Select Windows Phone Application in the New Project dialog window and type the name of the project in the name field. Click OK.

Fig 143: Select Windows Phone Application

3.   Add the following reference with the sample project.

·      Syncfusion.Shared.Phone.dll

Fig 144: Solution Explorer

 

4.   Add MaskEditTextBox to your application.

 

[C#]

 

MaskEditTextBox maskedittextbox1 = new MaskEditTextBox();

maskedittextbox1.Height = 75;

maskedittextbox1.Mask = "00/00/0000";

 

[XAML:]

 

<syncfusion:MaskEditTextBox Height="75" Mask="00/00/0000" x:Name="maskedittxt1"/>
