Client-Side Methods

The following section details the client-side methods supported by the Ribbon control.

 

Properties

 

Method

Description

Parameters

Return Type

ShowContextTab(name)

Shows the contextual tab for the selected items in the page.

Name of the contextual tab.

NA

ShowTab(name)

Shows the ribbon tab.

Name of the ribbon tab.

NA

HideContext(name)

Hides the contextual tab for the selected items in the page.

Name of the contextual tab.

NA

HideTab(name)

Hides the ribbon tab.

Name of the ribbon tab.

NA

4.   In JavaScript, use the following methods.

 

[JavaScript]

 <script type="text/javascript">

          function showContextTab()

          {  

              //code used to show the context tab        

              $("#ribbon1").sfRibbon("ShowContextTab", 1);

 

              //code used to show the tab

 

              $("#ribbon1").sfRibbon("ShowTab", 1, 1);

 

          }

 

          function hideContextTab()

          {

 

              //code used to hide the context tab

 

              $("#ribbon1").sfRibbon("HideContextTab", 1);

 

              //code used to show the tab

 

              $("#ribbon1").sfRibbon("ShowTab", 0, 0);

         

          }

 

       </script>
