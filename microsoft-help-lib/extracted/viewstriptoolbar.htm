ViewStrip Toolbar

 

ViewStrip toolbar provides options to view the today's date, full work week, week days, and print and delete appointments. It can be displayed by setting the ViewStrip property to True. This property is set to False, by default.

The customization options provided by the toolbar are given below.

 

·      Today: displays the current date of the system

·      WorkWeek: displays all the work week dates excluding "Saturdays" and "Sundays", and when you click on the navigation buttons on the date header, it will display the next set of work week dates

·      Week: displays all the days in the week including "Saturdays" and "Sundays"

·      Month: displays all the months in the year excluding "Sundays"

·      Delete Appointment: click on any appointment to select it, and then click the "Delete" button in the ViewStrip toolbar to delete the appointment

·      Print: prints the Schedule control

 

[ASPX]

 

<cc1:Schedule ID="Schedule1" ViewStrip="true" runat="server">

</syncfusion:Schedule >

 

[C#]

 

this.Schedule1.ViewStrip = true;

 

[VB]

 

Me.Schedule1.ViewStrip = True

Programmatically show / hide the items on the ViewStrip by using the below given properties.

 

Schedule Property

Description

ShowPrintStripItem

Specifies whether to show the viewstrip toolbar. Default value is False.

ShowTodayStripItem

Specifies whether to show the viewstrip toolbar. Default value is False.

ShowWeekStripItem

Specifies whether to show the viewstrip toolbar. Default value is False.

ShowWorkWeekStripItem

Specifies whether to show the viewstrip toolbar. Default value is False.

ShowDayStripItem

Specifies whether to show the viewstrip toolbar. Default value is False.

 

[ASPX]

 

<syncfusion:Schedule ViewStrip="true"  ID="Scheduler1" Height="400px" Width="500px" runat="server" ShowPrintStripItem="false" showtodaystripitem="false" showdaystripitem="false" showweekstripitem="false" showworkweekstripitem="false"showmonthstripitem="false" showdeletestripitem="false" ScheduleType="day" StartDate="04/21/2007" AutoFormat="Office2007Blue">

</syncfusion:Schedule >

 

[C#]

 

this.Schedule1.ViewStrip = true;

 

this.Schedule1.ShowPrintStripItem = false;

this.Schedule1.ShowTodayStripItem = false;

this.Schedule1.ShowWeekStripItem = false;

this.Schedule1.ShowWorkWeekStripItem = false;

this.Schedule1.ShowDayStripItem = false;

 

[VB]

 

Me.Schedule1.ViewStrip = True

 

Me.Schedule1.ShowMonthStripItem = False

Me.Schedule1.ShowPrintStripItem = False

Me.Schedule1.ShowTodayStripItem = False

Me.Schedule1.ShowWeekStripItem = False
