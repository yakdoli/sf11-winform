When will the MaskCompleted property be set

 

MaskCompleted is set to true if all the required and optional inputs have been entered; otherwise, the false.MaskCompletedChanged event occurs when the MaskCompleted property is changed.

 

XAML

 

<syncfusion:MaskedTextBox Name="maskedTextBox1" Height="25" Width="150" Mask="000-0000" PromptChar="_" LostFocus="maskedTextBox1_LostFocus"/>

 

In the LostFocus you can check the MaskCompleted property to show error messages.

 

C#

 

private void maskedTextBox1_LostFocus(object sender, RoutedEventArgs e)

        {

            if (maskedTextBox1.MaskCompleted)

            {

                MessageBox.Show("Validation succeeded");

            }

            else

            {

                MessageBox.Show("Validation Failed");

            }

        }
