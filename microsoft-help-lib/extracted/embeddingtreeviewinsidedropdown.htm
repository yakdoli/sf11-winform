Embedding TreeView inside DropDown

 

Any control can be flexibly integrated inside the dropdown container. The following code snippet illustrates how to add a TreeView control inside the DropDown portion of the GenericDropDown control.

 

 

Figure 100: TreeView embedded inside GenericDropDown

 

1.   Open a Web application, and drag the GenericDropDown control onto the Web Page.

2.   Drag the TreeView control onto the drop-down area of the control.

3.   The html view of the Web application will look as follows.

 

<cc1:GenericDropDown ID="GenericDropDown1" runat="server" ClientObjectID="Mygeneric" Width="316px" Height="37px" Text="-SELECT-" TextBoxCssClass="textcss" PopupCssClass="popupcss" TextBoxHoverCssClass="textcss" ContainerTableCssClass="" ContainerHoverCSSClass="" ButtonCssClass="" ButtonHoverCssClass="">

 

<cc1:TreeView ID="TreeView1" runat="server" CssClass="" CustomCSS="css/TreeStyle.css" DragAndDropEnabled="True" EditNode="False"  NodeEditCssClass="NodeEdit " ExpandSinglePath="True" Height="211px" Width="313px" ClientSideOnNodeExpand="OnExpand(this)">

          

  <Items>

    <cc1:TreeViewNode ImageHoverPath="general.gif" ImagePath="general.gif" Look="common" Text="ASP.NET">

      <cc1:TreeViewNode Look="common" Text="UI Products">

        <cc1:TreeViewNode ClientOnItemSelect="Onselect(this)" ImageHoverPath="grid.gif" ImagePath="grid.gif" Look="common" Text="Essential Grid">

        </cc1:TreeViewNode>

        <cc1:TreeViewNode ClientOnItemSelect="Onselect(this)" ImageHoverPath="tools.gif" ImagePath="tools.gif" Look="common" Text="Essential Tools">

        </cc1:TreeViewNode>

        .....

        <cc1:TreeViewNode ClientOnItemSelect="Onselect(this)" ImageHoverPath="edit.gif" ImagePath="edit.gif" Look="common" Text="Essential Edit">

        </cc1:TreeViewNode>

        <cc1:TreeViewNode ClientOnItemSelect="Onselect(this)" ImagePath="htmlui.gif" Look="common" Text="Essential HTMLUI">

        </cc1:TreeViewNode>

        </cc1:TreeViewNode>

 

        <cc1:TreeViewNode Look="common" Text="Back Office Products">

        .....

        </cc1:TreeViewNode>

      </cc1:TreeViewNode>

    </cc1:TreeViewNode>

 

    <cc1:TreeViewNode ImageHoverPath="general.gif" ImagePath="general.gif" Look="common" Text="Windows Forms">

      <cc1:TreeViewNode Look="common" Text="UI Products">

        .....

      </cc1:TreeViewNode>

    </cc1:TreeViewNode>

  </Items>

 

  <ItemLooks>

    <cc1:TreeViewItemLook ID="common" LeftImageHeight="18px" LeftImageWidth="18px" TextPaddingBottom="2px" TextPaddingTop="2px">

      <%--(Item look definitions)--%>

    </cc1:TreeViewItemLook>

  </ItemLooks>

 

</cc1:TreeView>                

</cc1:GenericDropDown>

 

4.   Add the required nodes to the TreeView.

5.   To display the selected text on the list area of the control, include the following javascript function.

 

function Onselect(Odata)

{                

  Mygeneric.SetText(Odata.ValuePath);

  Mygeneric.HidePopup();         

}

  

function OnExpand(Odata)

{

  Mygeneric.SetText(Odata.ValuePath);        

}
