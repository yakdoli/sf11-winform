Sorting

Sorting is defined as the process of arranging items/records in some ordered sequence. Essential Grid supports arranging table data in ascending () or descending () order based on the column header that is clicked. The order switches between ascending and descending when you click a column header for sorting.

Use Case Scenarios

Sorting is used to sort records either by ascending and descending order or by data that can be retrieved easily.

 

Enabling Sorting in MultiColumnDropDown

MultiColumnDropDown supports two modes of sorting:

·      Server mode

·      JSON mode
