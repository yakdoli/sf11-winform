Icon of BalloonTip

 

You can display the following five different icons in the NotifyIcon control.

 

·      Custom

·      Info

·      Error

·      None

·      Warning

 

The following code snippet is used to set this property.

 

[XAML]

 

<!-- BalloonTipIcon="Warning" -->

<syncfusion:NotifyIcon Name="notifyIcon" BalloonTipText="Custom Notify Icon is Available"  BalloonTipTitle="Default NotifyIcon" BalloonTipIcon="Warning" ShowBalloonTipTime="1000" HideBalloonTipTime="1000"/>

 

[C#]

 

//BalloonTipIcon="Warning"

notifyIcon.BalloonTipIcon = BalloonTipIcon.Warning;
