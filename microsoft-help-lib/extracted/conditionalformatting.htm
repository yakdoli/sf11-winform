Conditional Formatting

 

This is mainly used to format according to the criteria specified when AutoFormat is applied.

 

[CSS]

 

<style type="text/css">

    .MyClass

    {

        color: red !important;

    }

</style>

 

Note: CSS attribute, which has to override predefined AutoFormat parameter, should use "!important.

 

[ASPX]

 

<sfwg:GridGroupingControl ID="GridGroupingControl2" runat="server"

AutoFormat="Black" CssClass="GridBlack" GroupDropAreaCssClass="GridBlackGroupDropArea">

<Appearance>

<RecordPreviewCell CssClass="GridBlackRecordPreview" />

<ColumnHeaderCell CssClass="GridBlackColumnHeaders" />

<TopLeftHeaderCell CssClass="GridBlackTopLeftHeaderCell" />

<RowHeaderCell CssClass="GridBlackRowHeaders" />

<AnyRecordFieldCell CssClass="GridBlackAnyRecord" />

<AlternateRecordFieldCell CssClass="GridBlackAlternateRecord" />

<GroupIndentCell CssClass="GridBlackGroupIndentCell" />

<GroupCaptionCell CssClass="GridBlackGroupCaption" />

<GroupCaptionPlusMinusCell CssClass="GridBlackPlusMinus" />

<AnySummaryCell CssClass="GridBlackAnySummary" />

</Appearance>

</sfwg:GridGroupingControl>

 

[C#]

 

GridConditionalFormatDescriptor gcfd1 = new GridConditionalFormatDescriptor();

gcfd1.Name = "Criteria1";

gcfd1.Expression = "[id]>3";

gcfd1.Appearance.AnyRecordFieldCell.CssClass = "Class " + this.GridGroupingControl1.Appearance.AnyRecordFieldCell.CssClass;

GridGroupingControl1.TableDescriptor.ConditionalFormats.Add(gcfd1);
