Template

Menu supports templates so you can host content inside the menu items.

Properties

 

Name

Description

Type of the property

Value it accepts

Dependency

Template

To define contents for the menu items

Server-side

 

Action Builder

 

NA

The following steps allow you using client side methods.

1.   In View, invoke the menu helper with menu ID as the first argument, and then define the menu items with template content.

 

[ASPX]

        <%{

              Html.MobSyncfusion().Menu("menuTemplate")

                  .AutoFormat(MobSkins.DarkNight)

                  .ShowAnimation(MobAnimations.Slide)

                  .Orientation(MenuOrientation.Vertical)

                  .Items(items =>

                  {

 

                      items.Add().Template(

          (Item) =>

          {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-IE"></span>

              <spanclass="menu-text">Internet Explorer </span></a>

        <%});

                      items.Add().Template(

          (Item) =>

          {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-Safari"></span>

              <spanclass="menu-text">Safari </span></a>

        <%});

                      items.Add().Template(

          (Item) =>

          {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-TheWorld">

          </span><spanclass="menu-text">The World </span></a>

        <%});

                      items.Add().Template(

          (Item) =>

          {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-chrome"></span>

              <spanclass="menu-text">Google Chrome </span></a>

        <%});

                      items.Add().Template(

          (Item) =>

          {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-firefox"></span>

                  <spanclass="menu-text">Mozilla Firefox </span></a>

        <%});

                          items.Add().Template(

              (Item) =>

              {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-maxthon"></span>

          <spanclass="menu-text">Maxthon </span></a>

        <%});

                  items.Add().Template(

      (Item) =>

      {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-netscape">

    </span><spanclass="menu-text">Netscape</span></a>

                items.Add().Template(

    (Item) =>

    {%><aclass="sf-menuitem-anchor"href=""><spanclass="tm-menuicon sprite-opera"></span>
