Adding Percent textbox to MVC application

Refer to the Getting Started section to know the pre-requisites before stepping in to add a numierc textbox control to MVC application.

1.   In View, invoke the percent textbox helper with control id as first argument.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent") %>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent").ToString()))

 

 

2.   Build and run the application.

Using Builder

The following steps explain how to set the range of the percent text box through the builder.

1.   In View, invoke the percent text box helper followed by the MinValue, MaxValue, and IncrementStep methods with the desired values as arguments.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent")

.MinValue(50)

.MaxValue(200)

.IncrementStep(10)%>

 

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent")

.MinValue(50)

.MaxValue(200)

.IncrementStep(10).ToString()))

 

 

2.   Build and run the application.

 

Using Properties Model

 

The following steps explain how to set the range of the percent text box through the properties model.

1.   In the controller, create an instance of PercentTextBoxModel.

2.   Define the MinValue, MaxValue, and IncrementStep properties and pass the instance through the view-specific data to the view.

 

[Controller]

 

public ActionResult Index()

        {

            //Creating instance of PercentTextBoxModel

            PercentTextBoxModel myModel = new PercentTextBoxModel();

            myModel.MinValue = 50;

            myModel.MaxValue = 200;

            myModel.IncrementStep = 10;

 

            //pass the instance through view data to the view

            ViewData["myPercent"] = myModel;

            return View();

        }

 

 

3.   In View, invoke the percent text box helper with the view data key as the control ID.

 

View[ASPX]

 

<%=Html.Syncfusion().PercentTextBox("myPercent") %>

 

 

View[cshtml]

 

@(new HtmlString(Html.Syncfusion().PercentTextBox("myPercent").ToString()))

 

 

4.   Build and run the application.
