Show or Hide Disabled Item

Jump buttons will be enabled or disabled based on the item’s availability.  You can show or hide the disabled buttons as needed. To hide the disabled buttons set the IsHideDisabledGroupButtons property to true. By default this is set to false.

The following code illustrates how to show the disabled buttons:

 

[XAML]

<syncfusion:JumpList Name="jumplist" Width="468"  IsHideDisabledGroupButtons="False">

               <syncfusion:JumpList.GroupProvider>

                    <syncfusion:FirstLetterGroupProvider />

                </syncfusion:JumpList.GroupProvider>

            </syncfusion:JumpList>

 

 

 

[C#]

jumplist.IsHideDisabledGroupButtons = false;

 

 

 

Figure 57: Disabled buttons are visible.

 

The following code illustrates how to hide the disabled buttons:

 

[XAML]

 

<syncfusion:JumpList Name="jumplist"  Width="468"  IsHideDisabledGroupButtons="True">

               <syncfusion:JumpList.GroupProvider>

                    <syncfusion:FirstLetterGroupProvider />

                </syncfusion:JumpList.GroupProvider>

            </syncfusion:JumpList>

 

 

[C#]

jumplist.IsHideDisabledGroupButtons = true;

 

Figure 58: Disables buttons are hidden
