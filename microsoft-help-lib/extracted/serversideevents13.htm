Server-Side Events

 

The server side events can be triggered on selecting a tab element (Click event).

 

1.   Add a new Web Page to your project.

110.   Drag the TabStrip control and a label called 'lblActionPerformed' onto your Web Page.

111.   In HTML view add the following content.

 

<cc1:TabStrip id="TabStrip1" runat="server" ImageBaseURL="images" CustomCSS="css/TabDesign.css">

  <Looks>

    <cc1:TabStripItemLook ID="TabLook">

     <!-- ItemLooks definition !-->

    </cc1:TabStripItemLook>

  </Looks>

 

  <Items>

    <cc1:TabStripItem ID="Products" Text="Products" Look="TabLook">

      <cc1:TabStripItem ID="essentialtools" Text="Essential Tools" Look="TabLook">

        <cc1:TabStripItem ID="menuspkg" Text="Menus Package" Look="TabLook"></cc1:TabStripItem>

        <cc1:TabStripItem ID="editorspkg" Text="Editors Package" Look="TabLook"></cc1:TabStripItem>

      </cc1:TabStripItem>

     

     <!-- Tab structure definition !-->

 

      <cc1:TabStripItem ID="orderonline" Text="Order Online" Look="TabLook"></cc1:TabStripItem>

      <cc1:TabStripItem ID="brochures" Text="Brochures" Look="TabLook"></cc1:TabStripItem>

    </cc1:TabStripItem>

  </Items>

</cc1:TabStrip>

 

112.   Add the following event handlers in the PageLoad event.

 

[C#]

 

this.TabStrip1.TabSelected += new Syncfusion.Web.UI.WebControls.Tools.Tabstrip.TabStrip.TabStripSelectEventHandler(this.TabStrip1_TabSelected);

 

[VB]

 

AddHandler Private TabStrip1.TabSelected, AddressOf TabStrip1_TabSelected

 

113.   Add the following code in the code behind file.

 

TabSelected

 

[C#]

 

privatevoidTabStrip1_Click(object sender, Syncfusion.Web.UI.WebControls.Tools.TabStripCommandEventArgs e)

{                       

  lblActionPerformed.Text = "Item Click ";

  lblSelectedItem.Text = e.StripItem.Text;

}

 

[VB]

 

Private Function TabStrip1_Click(ByVal sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.TabStripCommandEventArgs) As privatevoid

  lblActionPerformed.Text = "Item Click "

  lblSelectedItem.Text = e.StripItem.Text

End Function

 

To trigger the TabSelected event, set the AutoPostBack property to true. This property posts back the page when the selection changes and triggers the TabClicked event. The TabClicked event includes TabStripCommandEventArgs object which contains a reference to the selected tab. Using this object you can access all the properties of the selected tab. In the above example, we are assigning e.StripItem.Text value to lblActionPerformed label.
