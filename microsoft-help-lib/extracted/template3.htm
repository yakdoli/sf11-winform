Template

The toolbar control supports templates that you can use to host content inside the toolbar item.

Properties

 

Name

Description

Type of the property

Value it accepts

Dependency

Template

To define contents for the Toolbar items

Server-side

 

Action Builder

 

NA

The following steps guide you in using the template feature:

1.   In View, invoke the Toolbar helper with Toolbar ID as the first argument, and then define the Toolbar items with template content.

 

[ASPX]

<% {

  Html.MobSyncfusion().Toolbar("toolbarTemplate")

  .Items(items =>

  {

 

   items.Add().Template((Item) =>

   {%>

< a class ="sf-toolbaritem-anchor" href =""> < span class ="tm-toolbaricon sprite-book"></ span >Book </a>

   <%});

  

   items.Add().Template((Item) =>

   {%>

< a class ="sf-toolbaritem-anchor" href =""> < span class ="tm-toolbaricon sprite-emotion"></ span >Skype </a>

   <%});

 

   items.Add().Template((Item) =>

   {%>

< a class ="sf-toolbaritem-anchor" href =""> < span class ="tm-toolbaricon sprite-facebook"></ span >Facebook </a>

   <%});

  

   items.Add().Template((Item) =>

   {%><aclass="sf-toolbaritem-anchor"href=""><spanclass="tm-toolbaricon sprite-game">

                </span>Games </a>

   <%});

 

   })

   .Render(); }%>

 

[Razor]

 

@{

   Html.MobSyncfusion().Toolbar("toolbarTemplate")

   .Items(items =>

   {

 

    items.Add().Template(@<aclass="sf-toolbaritem-anchor"href=""><spanclass="tm-toolbaricon sprite-book">

                </span>Book </a>);

 

    items.Add().Template(@<aclass="sf-toolbaritem-anchor"href=""><spanclass="tm-toolbaricon sprite-emotion">

                </span>Skype </a>);

 

    items.Add().Template(@<aclass="sf-toolbaritem-anchor"href=""><spanclass="tm-toolbaricon sprite-facebook">

                </span>Facebook </a>);

 

    items.Add().Template(@<aclass="sf-toolbaritem-anchor"href=""><spanclass="tm-toolbaricon sprite-game">

                </span>Games </a>);

 

    })

    .Render(); }

 

2.   Build and run the application.
