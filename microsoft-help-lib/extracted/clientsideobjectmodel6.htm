Refresh

For .NET Framework version 2.0 only. Sends callback to server without page refreshing and triggers CallbackRefresh server side Menu event. To perform callback the EnableCallbacks property must be set to true .

ShowContextMenu

x, y, event, value

bool

Shows a context menu returning true if successful. False is returned  on a non-context menu. The parameters are,

 

x - Represents the x coordinate of the menu.

y - Represents the y coordinate of the menu.

event - Indicates the event handled to show the context menu.

Value - An optional parameter used to set the Menu's ContextData property.

The following code example demonstrates how use Menu as context menu only for some html elements.

 

[C#]

 

<cc1:Menu ID="Menu1" ClientObjectId="_sfContextMenu" runat="server" Layout="Vertical"

    AutoFormat="Windows Classic" ContextMenu="Custom" ClientSideOnItemSelect="OnMenuItemClick(this)">

    <Items>

        <cc1:MenuItem Text="Item1"></cc1:MenuItem>

        <cc1:MenuItem Text="Item2">

            <cc1:MenuItem Text="Child Item1"></cc1:MenuItem>

        </cc1:MenuItem>

        <cc1:MenuItem Text="Item3"></cc1:MenuItem>

        <cc1:MenuItem Text="Item4"></cc1:MenuItem>

        <cc1:MenuItem Text="Item5"></cc1:MenuItem>

    </Items>

</cc1:Menu>

[JavaScript]

 

function ShowContextMenu( sColorName, event )

{

    _sfContextMenu.ShowContextMenu( null, null, event, sColorName );           

}

 

function OnMenuItemClick( MenuItemEventData )

{

    var sMessage = "You have clicked on context menu '" + MenuItemEventData.Text + "' ";

    sMessage += "for " + _sfContextMenu.ContextData + " div element";

    alert( sMessage );

    //return false to cancel postback

    return false;

}
