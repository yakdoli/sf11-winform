Adding DomainUpDown to the Application

 

To create a Windows Phone application and deploy Essential Tools for Windows Phone, refer to section 3 Getting Started. This section covers how to add DomainUpDown control to this application.

 

The DomainUpDown control can be added to the application by using either XAML or procedural code. The following code snippet can be used to add the DomainUpDown control to the application.

 

[XAML]

 

<syncfusion: DomainUpDown x:Name="DomainUpDown1" />

 

[C#]

 

DomainUpDown domainUpDown1 = new DomainUpDown();

domainUpDown1.Name = "DomainUpDown1";
