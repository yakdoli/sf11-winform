Client Side Methods

 

Menu supports a rich set of client side methods to control its behaviour.

 

Methods

 

Name

Parameters

Return type

Description

DisableMenuItem

itemToDisable – DOM element to be disabled

-

Disables the specified menu item

DisableMenuItembyID

itemID – ID of the item to disable

-

Disables the menu item with specified ID attribute

EnableMenuItem

itemToEnable - DOM element to be enabled

-

Enables the specified menu item

EnableMenuItembyID

itemID  - ID of the item to enable

-

Enables the menu item with the specified ID attribute

Disable

-

-

Disables all the menu items.

Enable

-

-

Enables all the menu items.

 

The following steps guide you in using client side methods.

2.   In Javascript, use the methods to enable and disable an item as follows.

 

[Javascript]

 

<script type="text/javascript">

        function DisableItem() {

            //Code to disable an item passing the id as parameter

            $find("myMenu").DisableMenuItembyID("Products");

            //Code to disable an item passing the DOM element as parameter

            $find("myMenu").DisableMenuItem($("#myMenu li:first"));

            //Code to disable all the menu items

            $find("myMenu").Disable();

        }

        function EnableItem() {

            //Code to enable an item passing the id as parameter

            $find("myMenu").EnableMenuItembyID("Products");

            //Code to enable an item passing the DOM element as parameter

            $find("myMenu").EnableMenuItem($("#myMenu li:first"));

            //Code to enable all the menu items

            $find("myMenu").Disable();

        }

       

 </script>
