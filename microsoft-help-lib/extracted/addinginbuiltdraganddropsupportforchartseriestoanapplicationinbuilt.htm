Adding Inbuilt Drag and Drop Support for Chart Series to an Application Inbuilt

 

Drag and Drop Support can be added to an Application using the following code snippet:

[C#]

 

Chart1.Areas[0].AllowSegmentDragDrop = true;

 

 

[xaml]

        <sync:Chart x:Name="Chart1">

            <sync:ChartArea AllowSegmentDragDrop="True">               

                <sync:ChartSeries x:Name="series1" Type="Bubble"/>                             

            </sync:ChartArea>

        </sync:Chart>
