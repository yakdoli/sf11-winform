To create the control through designer

 

1.   Create a new ASP.NET Web application. For details, see Creating ASP.NET Web Application.

6.   Drag the Captcha control onto the Web Form of your application.

 

 

Figure 138: Captcha control dragged onto the Web Form

 

[ASPX]

 

<syncfusion:Captcha ID="Captcha1" runat="server" Height="50" Width="150" />

 

7.   Add the following httpHandlers to the Web.Config file, to generate an image on the fly. When the dlls are referred from the GAC, the version must be specified.

 

[Web.Config]

 

<httpHandlers>

<add path="Captcha.axd" verb="*" type="Syncfusion.Web.UI.WebControls.Tools.CaptchaControl.ImageCaptchaHandler,Syncfusion.Tools.Web, Version=X.X.X.X, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89" />

</httpHandlers>

 

8.   Check if the code in the image matches the code you have entered by using the IsValid method of the Captcha control.

 

[C#]

 

protected void Validate_Click(object sender, EventArgs e)

{

if (Captcha1.IsValid(TextBox1.Text))

{

this.msgLabel.Text = "Message Sent Successfully!";

}

else

{

this.msgLabel.Text = "Invalid Anti-spam number!";

Captcha1.RenderNewChallenge();

}

}

 

[VB]

 

Protected Sub Validate_Click(ByVal sender As Object, ByVal e As EventArgs)

If Captcha1.IsValid(TextBox1.Text) Then

Me.msgLabel.Text = "Message Sent Successfully!"

Else

Me.msgLabel.Text = "Invalid Anti-spam number!"

Captcha1.RenderNewChallenge()

End If

End Sub
