Setting Watermark

 

You can set the Watermark for the MaskedTextBox by using the WatermarkText property. To enable Watermark, you have to set the WatermarkTextIsVisible property to true.

 

Note: WatermarkText is visible only when the Value is null or empty.

 

XAML

 

<syncfusion:MaskedTextBox x:Name="maskedTextBox" Height="25" Width="100"

                          WatermarkText="Type Here" WatermarkTextIsVisible="True"/>

 

C#

 

MaskedTextBox maskedTextBox = new MaskedTextBox();

maskedTextBox.Height = 25;

maskedTextBox.Width = 150;

maskedTextBox.WatermarkText = "Type Here";

maskedTextBox.WatermarkTextIsVisible = true;
