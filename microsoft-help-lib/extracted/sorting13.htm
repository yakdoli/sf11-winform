Sorting

Sorting is defined as the process of arranging items/records in some ordered sequence. Essential Grid supports arranging table data in ascending () or descending () order based on the column header that is clicked. The order switches between ascending and descending each time you click a column header for sorting. We can add the sorted columns initially using SortedColumns in TableDescriptor.

Multi-sorting is enabled by setting the AllowMultiSorting property to True. It can also be performed by holding CTRL and clicking the respective column headers.

The Ajax Grid exposes the following properties to enable and control the sorting feature.

Server Mode

In server mode, sorting will be done by enabling the property AllowSortColumns and setting the AllowMultiSorting and AllowSort properties as per requirement.

 

 

[ASPX]

<Syncfusion:GridGroupingControl ID="GridGroupingControl1" runat="server" AjaxAutoformat="Midnight" EnableCallbacks="false" ShowGroupDropArea="false"  EnableAjaxMode="true" DataSourceCachingMode="ViewState" AllowMultiSorting="false"  EnableAjaxPaging="true" >

<TableOptions AllowSortColumns="true" />

<TableDescriptor >

<Columns>

<Syncfusion:GridColumnDescriptor AllowSort="true" MappingName="Product ID" > </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort=" false" MappingName="Product Name" > </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort="true" MappingName="Quantity Per Unit" > </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort="true" MappingName="Unit Price"> </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort=" false" MappingName="Units In Stock" > </Syncfusion:GridColumnDescriptor>

</Columns>

<GridSortedColumns>

<Syncfusion:GridSortColumnDescriptor Name="Product ID" SortDirection="Descending"/>

</GridSortedColumns>

</TableDescriptor>

</Syncfusion:GridGroupingControl>

 

 

[C#]

// AllowSortColumns to enable Sorting feature

this.GridGroupingControl1.TableOptions.AllowSortColumns = true;

// AllowMultiSorting to enable/disable MultiSorting in grid

this.GridGroupingControl1.AllowMultiSorting = true;

// AllowSort to enable/disable Sorting in particular column

this.GridGroupingControl1.TableDescriptor.Columns.FindByMappingName("Product ID").AllowSort = true;

this.GridGroupingControl1.TableDescriptor.Columns.FindByMappingName("Product Name").AllowSort = false;

this.GridGroupingControl1.TableDescriptor.Columns.FindByMappingName("Quantity Per Unit").AllowSort = true;

this.GridGroupingControl1.TableDescriptor.Columns.FindByMappingName("Unit Price").AllowSort = true;

this.GridGroupingControl1.TableDescriptor.Columns.FindByMappingName("Units In Stock").AllowSort = false;

//Adding Sorted Columns

SortColumnDescriptor sortcolumn = new SortColumnDescriptor("Product ID", ListSortDirection.Descending);

this.GridGroupingControl1.TableDescriptor.SortedColumns.Add(sortcolumn);

JSON Mode

JSON mode uses ASP.NET AJAX 4.0 client templates for displaying the grid. The paging operation in JSON mode should be handled by the user. To enable the JSON mode, set the AjaxActionMode property to Json. To enable the sorting functionality, set the AllowSortColumns property to true. Use the AllowMultiSorting property to enable multicolumn sorting in the AJAX grid. Use the AllowSort property to enable sorting for individual columns.  We need to specify the action for handling the paging action, and this can be done using JsonActionMapper.

[ASPX]

<Syncfusion:GridGroupingControl ID="GridGroupingControl1" runat="server" AjaxAutoformat="Midnight" EnableCallbacks="false" ShowGroupDropArea="false"  EnableAjaxMode="true" AllowMultiSorting="false"  EnableAjaxPaging="true"  AjaxActionMode="Json" JsonActionMapper="Sort" >

<TableOptions AllowSortColumns="true" />

<TableDescriptor >

<Columns>

<Syncfusion:GridColumnDescriptor AllowSort="true" MappingName="Product ID" > </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort=" false" MappingName="Product Name" > </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort="true" MappingName="Quantity Per Unit" > </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort="true" MappingName="Unit Price"> </Syncfusion:GridColumnDescriptor>

<Syncfusion:GridColumnDescriptor AllowSort=" false" MappingName="Units In Stock" > </Syncfusion:GridColumnDescriptor>

</Columns>         

<GridSortedColumns>

<Syncfusion:GridSortColumnDescriptor Name="Product ID" SortDirection="Descending"/>

</GridSortedColumns>

</TableDescriptor>

</Syncfusion:GridGroupingControl>

 //Json Action

[WebMethod()]

public static IEnumerable Sort(object GridJsonArgs)

{        //To allow ASP.NET to use SQL Compact Server 3.5

AppDomain.CurrentDomain.SetData("SQLServerCompactEditionUnderWebHosting", true);

string ConnectionString = @"Data Source=|DataDirectory|\Northwind.sdf";

Northwind NorthwindDB = new Northwind(ConnectionString);

var ProductsData = from p in NorthwindDB.Products

select new

{

ProductID = p.ProductID,

ProductName = p.ProductName,

QuantityPerUnit = p.QuantityPerUnit,

UnitPrice = p.UnitPrice,

UnitsInStock = p.UnitsInStock,

};

GridJSONAction obj = new GridJSONAction();

IEnumerable data = obj.GridActionResult(GridJsonArgs, ProductsData);

return data;

}

Public Shared Function Sort(ByVal GridJsonArgs As Object) As IEnumerable

'To allow ASP.NET to use SQL Compact Server 3.5

Dim ConnectionString As String = "Data Source=|DataDirectory|\Northwind.sdf"

Dim NorthwindDB As New Northwind(ConnectionString)

Dim ProductsData = From prod In NorthwindDB.Products

Select prod.ProductID, prod.ProductName, prod.QuantityPerUnit, prod.UnitPrice, prod.UnitsInStock

Dim obj As New GridJSONAction()

Dim data As IEnumerable = obj.GridActionResult(GridJsonArgs, ProductsData)

Return data
