Client-Side Events

           

jQueryUITabs control consists of the following client-side events.

 

 

Client-Side Event

 

Description

OnAdd

Triggers when a tab has been added.

OnEnable

Triggers when a tab get enabled.

OnDisable

Triggers when a tab get disabled.

OnLoad

Triggers when the remote content of a tab has been loaded.

OnRemove

Triggers when a tab has been removed.

OnSelect

Triggers on clicking a tab.

OnShow

Triggers when a tab is shown.

 

[ASPX]

 

<Syncfusion:jQueryUITab ID="JQueryUITab1" runat="server" OnAdd="add()" OnRemove="remove()" OnEnable="enable()" OnDisable="disable()", OnLoad="load()"; OnSelect="select()" OnShow="show()">

<Syncfusion:jQueryUITabItem Text="Header1">This the content for the Header1.</Syncfusion:jQueryUITabItem>

<Syncfusion:jQueryUITabItem Text="Header2">This the content for the Header2.</Syncfusion:jQueryUITabItem>

<Syncfusion:jQueryUITabItem Text="Header3">This the content for the Header3.</Syncfusion:jQueryUITabItem>

</Syncfusion:jQueryUITab>

<asp:TextBox ID="TextBox1" runat="Server"/>
