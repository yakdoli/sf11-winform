Server-Side Events

 

Event

Description

Arguments

OnMenuItemClick

The event will be triggered when you click on the application sub menu items. 

The selected items will be passed as arguments.

OnHelpButtonClick

The event will be triggered when you click on the help button

NA

 

To raise and process the server-side events:

1.   Add a new Web Page in your project.

2.   Drag the Ribbon Control and a label with Id as ‘lblActionPerformed’. Then add it to your web page along with the required items in the .aspx page.

 

[ASPX]

 

<syncfusion:ribbon id="Ribbon1" OnMenuItemClick ="Ribbon1_MenuItemClick" AutoFormat="office2010blue" runat="server"  ApplicationMenuColor ="#F9A403" ApplicationMenuType="ApplicationMenu" ApplicationMenuText ="File" ExpanderClientClick ="expandclick" width="600px">

 <ApplicationMenu>

     <MenuItem>

         <Item>

        <syncfusion:ApplicationMenuItem Text="Save" ImageUrl="Img/Save16.png">                      

         </syncfusion:ApplicationMenuItem>

         <syncfusion:ApplicationMenuItem Text="Save As" ImageUrl="Img/saveas16.gif">                      

         </syncfusion:ApplicationMenuItem>

        </Item>

      </MenuItem>

 </ApplicationMenu>

</ syncfusion:ribbon>

 

[C#]

 

protected void Ribbon1_MenuItemClick(object Sender, Syncfusion.Web.UI.WebControls.Tools.RibbonControl.MenuItemClickEventArgs e)

    {

        this. lblActionPerformed.Text = e.SelectedItem.Text;

    }

 

[VB]

 

Protected Sub Ribbon1_MenuItemClick(ByVal Sender As Object, ByVal e As Syncfusion.Web.UI.WebControls.Tools.RibbonControl.MenuItemClickEventArgs)

        Me.lblActionPerformed.Text = e.SelectedItem.Text

End Sub

 

In the code, MenuItemClick gets triggered when you select the submenus in the application button. Build and run the application, then click on the submenus in the application button. On doing so, the selected items text will be displayed on the label - lblActionPerformed.
