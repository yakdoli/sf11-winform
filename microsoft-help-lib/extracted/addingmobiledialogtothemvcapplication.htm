Adding Mobile Dialog to the MVC application

Refer to the Getting Started section to know the pre-requisites before stepping in to add a Mobile dialog control to the MVC application.

 

Using Builder

The following steps explain the addition of a dialog to an application using Builder.

1.   In View, invoke the dialog helper with the Control ID as the first argument followed by the Template method with the dialog contents as argument.

 

[ASPX]

 

    <% {

           Html.MobSyncfusion().Dialog("myDialog")

                 

                  .Template(() =>

                  {%><p>

        This is the Syncfusion Dialog control with the 'x' icon. The dialog window can be

        moved, resized and closed.</p>

 

    <%}).Render();

       }%>

 

 

[Razor]

 

   @{ Html.MobSyncfusion().Dialog("myDialog")

        .Template(

 

    @<p>

        This is the Syncfusion Dialog control with the 'x' icon. The dialog window can be

        moved, resized and closed.</p>

        ).Render();

}

 

 

2.   Build and run the application in emulator.

 

Using Properties Model

The following steps explain the addition of a dialog to an application using the Properties model:

1.   In the Controller, create an instance of the MobDialogModel, define the properties and pass the instance through View Specific Data to View as given below:

 

[Controller]

 

        publicActionResult Dialog()

        {

            //create an instance of MobDialogModel

            MobDialogModel model = newMobDialogModel()

            {

                AutoFormat=MobSkins.DarkNight

            };

            ViewData["myDialog"] = model;

            return View();

        }

 

 

2.   In View, create the dialog contents and invoke the dialog helper with the View Data key as the first argument.

 

[ASPX]

 

    <%{

           Html.MobSyncfusion().Dialog("myDialog")

               .Template(() =>

               {%> <p>

        Essential Tools Mobile Dialog for MVC supports display of a dialog window within                your web page. The dialog widget lets us display a message, supplementary content (like images or text) and interactive content (like forms).</p>

    <%})

       .Render();

       }%>

 

 

[Razor]

 

    @{

        Html.MobSyncfusion().Dialog("myDialog")

            .Template <p>

        Essential Tools Mobile Dialog for MVC supports display of a dialog window within your web page. The dialog widget lets us display a message, supplementary content (like images or text) and interactive content (like forms).</p>

    )

.Render();}

 

3.   Build and run the application in emulator.
