Using Builder

The following steps explain how you can enable the filtering feature using the EnableFiltering method:

1.   In View, invoke the Listbox Helper with the control ID as the first argument followed by the EnableFiltering()with the desired value as an argument.

 

[ASPX]

 

    <% Html.MobSyncfusion().ListBox("lbCore")

          .EnableFiltering(true)

           .Items(items =>

           {

               items.Add()

                   .Text("Windows 7");

               items.Add()

                   .Text("Linux");

               items.Add()

                   .Text("Ubuntu");

               items.Add()

                   .Text("Solaris");

               items.Add()

                   .Text("Android");

               items.Add()

                   .Text("Eclipse");

               items.Add()

                   .Text("Unix");

           })

     .Render();

    %>

 

 

[Razor]

 

    @{

        Html.MobSyncfusion().ListBox("lbCore")

          .EnableFiltering(true)

           .Items(items =>

           {

               items.Add()

                   .Text("Windows 7");

               items.Add()

                   .Text("Linux");

               items.Add()

                   .Text("Ubuntu");

               items.Add()

                   .Text("Solaris");

               items.Add()

                   .Text("Android");

               items.Add()

                   .Text("Eclipse");

               items.Add()

                   .Text("Unix");

           })

.Render();

    }

 

 

 

2.   Build and run the application.
