Generic Collection

 

This section demonstrates the implementation of a Generic Collection and how you can bind it to a GridGroupingControl.

A generic collection is one that can handle any Type in a generic and type-safe manner. By creating a generic collection, you can get the immediate benefit of type-safety without having to derive from a base collection type and implement type-specific members.

This can be achieved by accessing the BindingList class. This class is new in the .NET Framework version 2.0 and provides a generic collection that supports data binding.

The following example code demonstrates binding to a BindingList component containing a EmpClass object.

 

[C#]

 

BindingList<T> b1 = new BindingList<T>(); // where ‘T’ is a place holder that will accept the type of the custom collection class.

 

[VB]

 

Private b1 As BindingList(Of T) = New BindingList(Of T)() ' where ‘T’ is a place holder that will accept the type of the custom collection class.

 

The code below can be used to create a binding list.

 

1.   Include the required namespace.

 

[C#]

 

using System.ComponentModel;

 

[VB]

 

Imports System.ComponentModel

 

2.   Declare and create a new BindingList with the Employee class object.

 

[C#]

 

private BindingList<EmpClass> bl;

bl = new BindingList<EmpClass>();

 

[VB]

 

Private bl As BindingList(Of EmpClass)

Private bl = New BindingList(Of EmpClass)()

 

3.   Create an Employee class object containing 'ID' and 'Name' as members.

 

[C#]

 

public class Employeeclass

{

int Eid;

string Ename;

public Employeeclass(int E_id, string E_name)

{

this.Eid = E_id;

this.Ename = E_name;

}

 

public int ID

{

get { return Eid; }

set {  Eid= value; }

}

 

public string Name

{

get { return Ename; }

set { Ename = value; }

}

}

 

[VB]

 

Public Class Employeeclass

        Private Eid As Integer

        Private Ename As String

        Public Sub New(ByVal E_id As Integer, ByVal E_name As String)

            Me.Eid = E_id

            Me.Ename = E_name

        End Sub

 

        Public Property ID() As Integer

            Get

                Return Eid

            End Get

            Set(ByVal value As Integer)

                Eid = Value

            End Set

        End Property

 

        Public Property Name() As String

            Get

                Return Ename

            End Get

            Set(ByVal value As String)

                Ename = Value

            End Set

        End Property

 

End Class

 

4.   Add EmpClass objects to the BindingList.

 

[C#]

 

bl.Add(new EmpClass(10101, "Charlotte"));

bl.Add(new EmpClass(20102, "Shelley"));

bl.Add(new EmpClass(30103, "Regina"));

bl.Add(new EmpClass(40104, "Yoshi"));

bl.Add(new EmpClass(50105, "Mayumi"));

bl.Add(new EmpClass(60106, "Ian"));

 

[VB]

 

bl.Add(New EmpClass(10101, "Charlotte"))

bl.Add(New EmpClass(20102, "Shelley"))

bl.Add(New EmpClass(30103, "Regina"))

bl.Add(New EmpClass(40104, "Yoshi"))

bl.Add(New EmpClass(50105, "Mayumi"))

bl.Add(New EmpClass(60106, "Ian"))

 

5.   Bind the created BindingList with the Employee class object to the GridGroupingControl, in Page_Init.

 

[C#]

 

this.GridGroupingControl1.DataSource = b1;

 

[VB]

 

Me.GridGroupingControl1.DataSource = b1
