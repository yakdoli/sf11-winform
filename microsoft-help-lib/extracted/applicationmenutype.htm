Application Menu Type

The type of application menu can be chosen from the options of the ApplicationMenuType property. The options provided for the menu types are as follows.

 

Property

Description

ApplicationMenuType

Specifies the type of the application sub menu. Default value is None. The options Included are as follows:

·      None

·      ApplicationMenu

·      BackStagePage

 

5.5.3.3.1.1 ApplicationMenu

To render the ribbon with application menu, set the ApplicationType property to ApplicationMenu.

 

[ASPX]

<syncfusion:ribbon id="Ribbon1" AutoFormat="office2010blue" runat="server" ApplicationMenuColor ="#F9A403" ApplicationMenuType="ApplicationMenu" ApplicationMenuText ="File" ExpanderClientClick ="expandclick" width="600px">

 <ApplicationMenu>

     <MenuItem>

         <Item>

        <syncfusion:ApplicationMenuItem Text="Save" ImageUrl="Img/Save16.png">                      

         </syncfusion:ApplicationMenuItem>

         <syncfusion:ApplicationMenuItem Text="Save As" ImageUrl="Img/saveas16.gif">                      

         </syncfusion:ApplicationMenuItem>

        </Item>

      </MenuItem>

 </ApplicationMenu>

</ syncfusion:ribbon>

 

[C#]

 

Ribbon1.ApplicationMenuType = Syncfusion.Web.UI.WebControls.Tools.RibbonControl.AppMenuType.ApplicationMenu;

 

[VB]

 

Ribbon1.ApplicationMenuType = Syncfusion.Web.UI.WebControls.Tools.RibbonControl.AppMenuType.ApplicationMenu

 

Build and run the application, then click on the application button. The following output will be generated.

5.5.3.3.1.2 BackStagePage

The Backstage page has a feature to add UserControl to the submenu items. The left side of the page contains menu items and the right side contains UserControl.

To render the ribbon with the backstage page, set the ApplicationMenuType property to BackStagePage as shown in the following code snippet.

 

[ASPX]

<syncfusion:Ribbon ID="Ribbon1" AutoFormat="office2010blue"  runat="server" ApplicationMenuColor="#F9A403" ApplicationMenuType="BackstagePage"

        ApplicationMenuText="File"  ExpanderClientClick ="expandclick" Width="635px">

        <ApplicationMenu>

            <BackStagePage>

            <ApplicationPage>

                        <syncfusion:BackStagePage Text="Info" UserControl="../Backstage/info.ascx" />

                        <syncfusion:BackStagePage Text="Recent" UserControl="../Backstage/recent.ascx" />

                        <syncfusion:BackStagePage Text="New" UserControl="../Backstage/new.ascx" />                      

            </ApplicationPage>

            </BackStagePage>

        </ApplicationMenu>

</ syncfusion:ribbon>

 

[C#]

 

Ribbon1.ApplicationMenuType = Syncfusion.Web.UI.WebControls.Tools.RibbonControl.AppMenuType.BackstagePage;

 

[VB]

 

Ribbon1.ApplicationMenuType = Syncfusion.Web.UI.WebControls.Tools.RibbonControl.AppMenuType. BackstagePage

 

Build and run the application, then click on the application button, and the following output will be generated.

Figure 320: BackStagePage
