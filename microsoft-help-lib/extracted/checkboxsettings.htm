CheckBox Settings

 

The following properties can be used for customizing the checkbox.

 

Property

Description

CheckBoxListRepeatColumns

Specifies the number of columns used to lay out the items.

CheckBoxListCellPadding

Specifies the padding between each item.

CheckBoxListRepeatDirection

Specifies the direction in which items are laid out.

CheckBoxListCellSpacing

Specifies the spacing between each item.
