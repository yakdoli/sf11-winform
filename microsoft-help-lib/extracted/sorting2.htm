Sorting

Sorting is defined as the process of arranging items/records in some ordered sequence. Essential Grid supports arranging table data in ascending () or descending () order based on the column header that is clicked. The order switches between ascending and descending each time you click a column header for sorting.

 

Multi-sorting is enabled by setting the AllowMultiSorting property to True. It can also be performed by holding CTRL and clicking the respective column headers.

The Grid control has the following properties and methods to enable sorting.
