Frame Type of Magnifier

 

You can change the shape of the Magnifier frame by using the FrameType property. Magnifier control supports the following types of frames.

 

·      Circle

·      Rectangle

·      RoundedRectangle

 

[XAML]

 

<syncfusion:Magnifier Name="magnifier1" FrameBackground="Bisque" FrameType="Circle" />

 

[C#]

 

// Setting FrameType as  Circle

magnifier1.FrameType = FrameType.Circle;
