Through designer

The Gallery View control can be customized using DisplayMode and ItemsToShow property,

Procedure to customize Gallery View control through designer

 

1.  Create a new ASP.NET Web application. For details, refer to Creating ASP.NET Web Application

2.   Drag the GalleryView Control onto the webform in the new web application.

3.   Give the necessary details in the .aspx page-HTML view. A sample code snippet is given below.

4.      

[ASPX]

 

<syncfusion:GalleryView ID="Gallery" Height="96px" Width="370px" ItemsToShow="4" runat="server" DisplayMode="GalleryView">

 <Items>

  <syncfusion:GalleryViewItem Name="Heading1" ImageUrl="Img/Heading1.png" />

  <syncfusion:GalleryViewItem Name="Heading2" ImageUrl="Img/Heading2.png" />

  <syncfusion:GalleryViewItem Name="Heading3" ImageUrl="Img/Heading3.png" />

  <syncfusion:GalleryViewItem Name="Intense" ImageUrl="Img/Intense.png" />

  <syncfusion:GalleryViewItem Name="IntenseRef" ImageUrl="Img/IntenseRef.png" />

  <syncfusion:GalleryViewItem ImageUrl="Img/NoSpacing.png" Name="NoSpacing" />

  <syncfusion:GalleryViewItem ImageUrl="Img/Title.png" Name="Title " />

</Items>

  <ExtraItems>

<syncfusion:GalleryViewExtraItem Text="Save Selection as new quick style" />

     <syncfusion:GalleryViewExtraItem Text="Clear Formatting" />

     <syncfusion:GalleryViewExtraItem Text="Apply Styles" />

</ExtraItems>

</syncfusion:GalleryView>

 

 

5.   Build and run the application. The result that is displayed should look like this-
