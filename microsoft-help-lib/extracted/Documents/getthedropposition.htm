Get the Drop Position

 

The MouseEventArgs property in DragDropEventArgs contains the GetPosition() function. It will give the position of the mouse on dropping the object.

 

[C#]             

void DragAndDropManager_Drop(object sender, DragDropEventArgs args)

 {           

  Image img = args.PayLoad as Image;

  Point mousepoint = args.MouseEventArgs.GetPosition(sender as UIElement);

  if(img != null)

    {

       Canvas.SetLeft(img, mousepoint.X);

       Canvas.SetTop(img, mousepoint.Y);

      }

  }
