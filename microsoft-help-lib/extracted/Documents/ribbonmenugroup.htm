Ribbon Menu Group

Ribbon Menu Group enables the user to group the menu items categorically. It is highly customizable and can be resizable.

Declaring Ribbon Menu Group

Namespace: Syncfusion.Windows.Tools.Controls

Assembly: Syncfusion.Ribbon.Silverlight

XAML

 

<syncfusion:RibbonMenuGroup IconBarEnabled="False" IsMoreItemsIconTrayEnabled="True" IsResizable="True" ScrollBarVisibility="Visible">

           <syncfusion:RibbonMenuItem Header="----------------------" Margin="-18,0,0,0"/>

           <syncfusion:RibbonMenuItem Header="----------------------" Margin="-18,0,0,0" FontWeight="ExtraLight"/>

           <syncfusion:RibbonMenuItem Header="----------------------" Margin="-18,0,0,0" FontWeight="Thin"/>

           <syncfusion:RibbonMenuItem Header="----------------------" Margin="-18,0,0,0"/>

           <syncfusion:RibbonMenuItem Header="----------------------" Margin="-18,0,0,0" />

            <syncfusion:RibbonMenuGroup.MoreItems>

                 <syncfusion:RibbonMenuItem Header="More Underlines..."/>

                 <syncfusion:RibbonMenuItem Header="Underline Color">

                      <syncfusion:RibbonMenuItem.Icon>

                            <Image Source="FontColor16.png"/>

                      </syncfusion:RibbonMenuItem.Icon>

                 </syncfusion:RibbonMenuItem>

           </syncfusion:RibbonMenuGroup.MoreItems>

</syncfusion:RibbonMenuGroup>
