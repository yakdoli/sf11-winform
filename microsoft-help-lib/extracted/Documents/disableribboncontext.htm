Disable Ribbon Context menu

The Ribbon control is shipped with built-in context menu. The following code helps to disable the entire Ribbon Context Menu from the control.

C#

 

public MainPage()

{

     InitializeComponent();

     myRibbon.OnRibbonContextMenuOpened += new RoutedEventHandler(myRibbon_OnRibbonContextMenuOpened);

}

 

 

void myRibbon_OnRibbonContextMenuOpened(object sender, RoutedEventArgs e)

{

     ContextMenuAdv adv = sender as ContextMenuAdv;

     adv.Visibility = System.Windows.Visibility.Collapsed;

}
