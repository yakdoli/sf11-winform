Switch between Skins at Run-time

Themes can be dynamically switched.

 Example 1

 

The below  code snippet explains how to switch between the skins at run-time by using ComboBox SelectionChanged event.

 

[XAML]

<Grid Name="grid">       

        <Grid.ColumnDefinitions>

            <ColumnDefinition Width="*"/>

            <ColumnDefinition Width="*"/>

        </Grid.ColumnDefinitions>

        <ComboBox Name="themecombobox" Grid.Column="0" SelectionChanged="ComboBox_SelectionChanged" Width="150" Height="30">

            <ComboBoxItem> Blend </ComboBoxItem>

            <ComboBoxItem> Office2007Blue </ComboBoxItem>

        </ComboBox>

        <syncfusion:BrushEdit Name="brushedit" ></syncfusion:BrushEdit>       

</Grid>

 

 

On ComboBox SelectionChanged event, particular VisualStyle should be set to the control.

 

[C#]

 

Private void ComboBox_SelectionChanged(object sender, SelectionChangedEventArgs e)

        {

            if (themecombobox.SelectedIndex == 0)

            {

                SkinStorage.SetVisualStyle(brushedit, "Office2007Blue");

            }

            Else if (themecombobox.SelectedIndex == 1)

            {

                SkinStorage.SetVisualStyle(brushedit, "Blend");

            }

        }
