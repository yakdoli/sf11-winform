Drag and Drop Support

You can rearrange the TreeViewAdv using built-in drag and drop capability. To enable Drag and Drop, you have to set the DragEnabled Property to true. You can alos customize the color of the drag line using the DragLineColor property.

The following is the example for Drag and Drop.

[XAML]
