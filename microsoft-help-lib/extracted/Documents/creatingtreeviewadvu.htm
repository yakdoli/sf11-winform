Creating TreeViewAdv using C#

To create a TreeViewAdv using C#:

1.   Open Visual Studio.

2.   On the File menu click New -> Project. This opens the New Project Dialog box.

 

Figure 729: New Project Dialog box

 

3.   On the Project Dialog window, select Silverlight Application and in the name field type the name of the project and then click OK.

 

Figure 730: New Project

 

4.   Navigate to solution Explorer.

5.   Right-click References folder and click Add Reference.

6.   Add the Syncfusion.Tools.Silverlight assembly to the project References folder.

         

Figure 731:  Add Reference

 

7.   Add Syncfusion.Tools.Silverlight reference in XAML and C# code as follows.

 

[XAML]

 

xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Tools.Controls; assembly=Syncfusion.Tools.Silverlight"

 

 

[C#]

 

using Syncfusion.Windows.Tools.Controls;

 

8.   Click and open C# file and add TreeViewAdv to the application.

 

[C#]

 

TreeViewAdv treeview = new TreeViewAdv();

TreeViewItemAdv head = new TreeViewItemAdv() { Header = "Syncfusion" };

TreeViewItemAdv subhead1 = new TreeViewItemAdv() { Header = "UserInterface Edition" };

TreeViewItemAdv item1 = new TreeViewItemAdv() { Header = "ASP.NET" };

TreeViewItemAdv item2 = new TreeViewItemAdv() { Header = "ASP.NET MVC" };

TreeViewItemAdv item3 = new TreeViewItemAdv() { Header = "Windows Forms" };

TreeViewItemAdv item4 = new TreeViewItemAdv() { Header = "WPF" };

TreeViewItemAdv item5 = new TreeViewItemAdv() { Header = "Silverlight" };

subhead1.Items.Add(item1);

subhead1.Items.Add(item2);

subhead1.Items.Add(item3);

subhead1.Items.Add(item4);

subhead1.Items.Add(item5);

TreeViewItemAdv subhead2 = new TreeViewItemAdv() { Header = "Reporting Edition" };

TreeViewItemAdv subhead3 = new TreeViewItemAdv() { Header = "BI Edition" };

head.Items.Add(subhead1);

head.Items.Add(subhead2);

head.Items.Add(subhead3);

treeview.Items.Add(head);

this.LayoutRoot.Children.Add(treeview);
