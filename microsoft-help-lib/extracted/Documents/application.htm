Application

 

Color Picker is used for selecting color to be applied as background or foreground. The Color Return is of type Brush.

 

Event-Based

 

The selected color can be applied to the background or foreground of any property through ColorChanged event of Color Picker.

 

ColorChanged Event

 

Whenever a color is being selected from color picker, the color is set as SelectedColor of the control and ColorChanged event is triggered.

 

The following code snippet illustrates binding.

 

[XAML]

 

<Syncfusion:ColorPickerPalette ColorChanged="ColorPickerPaletteColorChanged"   

x:Name="ColorPicker"/>

<TextBox Text="Hello World"   x:Name="TxtBox" ></TextBox>

<Border   x:Name="border"  ></Border>

 

[C#]

 

private void ColorPickerPaletteColorChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)

{

            TxtBox.Foreground = ColorPicker.SelectedColor;

            border.Background=ColorPicker.SelectedColor;

}

 

Binding

 

Apart from Event-Handler, binding also can be used to retrieve the color selected in ColorPicker.

 

The following code snippet illustrates binding.

 

[XAML]

 

<Syncfusion:ColorPickerPalette  x:Name="ColorPicker"  />

 

<TextBox  Text="Hello World" x:Name="TxtBox" Foreground="{Binding

ElementName=ColorPicker,Path=SelectedColor,Mode=OneWay}" ></TextBox>

<Border  Text="Border"  Background="{Binding

ElementName=ColorPicker,Path=SelectedColor,Mode=OneWay}" ></Border>
