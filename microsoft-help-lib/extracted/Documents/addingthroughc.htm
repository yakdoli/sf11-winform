Adding through C#

The following code example illustrates how to add the TileViewControl to an Application through C#.

 

[C#]

            TileViewControl Tile = new TileViewControl();

            Tile.Width = 500;

            Tile.Height = 400;

            for (int i = 1; i <= 4; i++)

            {

                TileViewItem item1 = new TileViewItem();

                item1.Name = "item" + i;

                item1.Header = "Item " + i;

                item1.Content = "Content " + i;

                Tile.Items.Add(item1);

            }

            this.LayoutRoot.Children.Add(Tile);
