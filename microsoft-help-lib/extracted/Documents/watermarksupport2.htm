Watermark Support

Watermark is the dummy content displayed in the integer textbox when the value is null. The watermarkText support behavior could be enabled by setting the WatermarkTextIsVisible property to true.

[XAML]

 

<syncfusion:IntegerTextBox x:Name="integerTextBox" Width="150" Height="25"

                           WatermarkText="Type Here" WatermarkTextIsVisible="True"

WatermarkOpacity="0.5" UseNullOption="True"/>

 

 

Figure 155: WatermarkTextisVisible

Watermark Text automatically collapses when the control is in focus. When the control loses its focus Watermark Text come to visible state if Value is null and WatermarkTextIsVisible is true.
