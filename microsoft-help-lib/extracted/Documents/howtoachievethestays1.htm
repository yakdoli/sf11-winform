How to achieve the “StaysOpenOnClick” behavior in the DropDownButtonAdv

The DropDown can remain open when you cancel the DropDownClosing event.

C#

 

public MainPage()

{

     InitializeComponent();

     button.DropDownClosing += new CancelEventHandler(button_DropDownClosing);

}

 

void button_DropDownClosing(object sender, System.ComponentModel.CancelEventArgs e)

{

     e.Cancel = true;

     //DropDown will not close.

}
