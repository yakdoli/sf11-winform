Using WatermarkTemplate

You can customize the Visual appearance of WatermarkText using WatermarkTemplate property.

XAML

<syncfusion:CurrencyTextBox x:Name="currencyTextBox" Width="150" Height="25"

                            WatermarkText="Type Here" CornerRadius="3"

                            WatermarkTextIsVisible="True" WatermarkOpacity="0.5"

                            UseNullOption="True">

    <syncfusion:CurrencyTextBox.WatermarkTemplate>

        <DataTemplate>

            <Border Background="LightGray">

                <TextBlock Text="{Binding}" VerticalAlignment="Center" Margin="5,0,0,0"/>

            </Border>

        </DataTemplate>

    </syncfusion:CurrencyTextBox.WatermarkTemplate>

</syncfusion:CurrencyTextBox>
