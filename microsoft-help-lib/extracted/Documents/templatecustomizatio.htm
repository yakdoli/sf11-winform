Template customization with Expression Blend

The Ribbon control template can be easily customizable using the Expression Blend. Right click the Ribbon control and select the option ‘Edit a Copy…” in the Edit template.

 

 

Figure 652: Edit Style Window

The following window will appear:

 

 

Figure 653: Add Style name Window

XAML

 

<syncfusion:Ribbon Title="Document 1 - Microsoft Word" x:Name="myRibbon" Margin="0,22,0,0" VerticalAlignment="Top" Style="{StaticResource RibbonStyle1}" ApplicationMenuStyle="{StaticResource ApplicationMenuStyle1}">

   <syncfusion:Ribbon.ApplicationMenu>

        <syncfusion:ApplicationMenu Icon="app.png"/>           

   </syncfusion:Ribbon.ApplicationMenu>

   <syncfusion:RibbonTab Header="Ribbon Tab">

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

   </syncfusion:RibbonTab>

</syncfusion:Ribbon>

 

 

All resources will be displayed in the Resources pane. User can easily customize the resources and a custom style or theme can be applied to the Ribbon control as shown below:
