Ribbon Tabs Group

 

The Context Tab Groups are used to group Ribbon tabs in the application for easy navigation. Each Context Tab Group can be displayed with a unique color, label, and so on, to differentiate between other Context Tab Groups in the Ribbon.

Declaring RibbonTabsGroup

 

Namespace: Syncfusion.Windows.Tools.Controls

Assembly: Syncfusion.Ribbon.Silverlight

The following code example illustrates the creation of a Context Tab Group.

XAML

 

<syncfusion:RibbonTabsGroup Color="Yellow" Caption="Picture Tools" Name="tabgroup">

     <syncfusion:RibbonTab Name="formattab" Caption="Format">

          <syncfusion:RibbonBar Header="Adjust">

              <syncfusion:RibbonButton SizeMode="Large" Label="Remove Background" IsMultiLine="True" LargeIcon="removebackground.png"/>

              <syncfusion:RibbonButton SizeMode="Large" Label="Corrections" IsMultiLine="True" LargeIcon="corrections.png"/>

              <syncfusion:RibbonButton SizeMode="Large" Label="Color" IsMultiLine="True" LargeIcon="color.png"/>

              <syncfusion:RibbonButton SizeMode="Normal" Label="Artistic Effects" SmallIcon="resize.png"/>

              <syncfusion:RibbonButton SizeMode="Normal" Label="Compress Pictures" SmallIcon="resize.png"/>

              <syncfusion:RibbonButton SizeMode="Normal" Label="Change Pictures" SmallIcon="resize.png"/>

           </syncfusion:RibbonBar>

      </syncfusion:RibbonTab>

      <syncfusion:RibbonTab Caption="Reset Picture"/>

</syncfusion:RibbonTabsGroup>
