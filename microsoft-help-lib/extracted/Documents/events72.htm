Events

The Window Control exposes the following events.

More:

Opening – The event occurs before the instance opens.

Opened – The event occurs after the instance opens.

Closing – The event occurs before the instance closes.

Closed – The event occurs after the instance closes.

OnWindowStateChanged-The event occurs when the Window state changes.

ContextMenuOpened – The event occurs when the Context Menu opens.

ContextMenuClosed – The event occurs when the Contex Menu closes.
