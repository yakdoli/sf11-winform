Apply Skin for Ribbon Control

Add the following dll’s to apply corresponding theme for Hierarchy Navigator control. SkinManager class is used to apply different visual styles for a control, which is available in Syncfusion.Theming.Silverlight project.

·      Syncfusion.Theming.Silverlight.dll

·      Syncfusion.Theming.Office2007Blue.dll

·      Syncfusion.Theming.Office2007Black.dll

·      Syncfusion.Theming.Office2007Silver.dll

 

1.   Create Ribbon instance either in xaml or code behind as below.

 

XAML

 

<syncfusion:Ribbon x:Name="myRibbon"/>

 

[Or]

 

C#

 

Ribbon myRibbon = new Ribbon();

 

 

2.   Apply Visual Style as shown below in Code behind, by calling the static method in SkinManager class in Syncfusion.Theming.Silverlight. The example is provided here for Office2007Blue. You can refer See also link to see more details on Skins.

 

Office2007Blue

C#

 

SkinManager.SetVisualStyle(myRibbon, Syncfusion.Windows.Controls.Theming.VisualStyle.Office2007Blue);
