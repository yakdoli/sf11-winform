Button Text and Icon Customization

 

The button text and icon of alert windows and prompt windows can be customized:

• ShowAlert (CustomWindowProperties)—Shows the customized Alert Window.

• ShowPrompt (CustomWindowProperties)—Shows the customized Prompt Window.
