Show Window Control

 

The Window Control can be shown using two Methods namely Show() and ShowDialog().

·      Show() – Shows the Window normally and

·      ShowDialog() – Shows the Window as a Modal Dialog

 

C#

WindowControl window = new WindowControl();

window.Title = "Window Demo";

window.Show();

 

Figure 1086: A typical Window Control

C#

WindowControl window = new WindowControl();

window.Title = "Window Demo";

window.OverlayBrush = new SolidColorBrush(Colors.Gray);

window.ShowDialog();
