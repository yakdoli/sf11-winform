Dock Ability

 

Indicates where you can dock a window inside another window.  It is flagged enumeration. By default, DockAbility will be set as DockAbility.All so that all the drag indicators appears for all windows.  It contains the following values:

 

Position

Description

Left

Left drag indicator will appear.

Right

Right drag indicator will appear.

Tabbed

Center drag indicator will appear.

Top

Top drag indicator will appear.

Bottom

Bottom drag indicator will appear.

None

No drag indicator will appear.

 

Following code illustrates the DockAbility property:

 

[XAML]

 

<UserControl x:Class=”Sample.MainPage”

    xmlns=”http://schemas.microsoft.com/winfx/2006/xaml/presentation”

    xmlns:x=”http://schemas.microsoft.com/winfx/2006/xaml”

    xmlns:d=”http://schemas.microsoft.com/expression/blend/2008” xmlns:mc=”http://schemas.openxmlformats.org/markup-compatibility/2006” xmlns:syncfusion=”clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.DockingManager.Silverlight”

             xmlns:system=”clr-namespace:System.Windows.Controls;assembly=System.Windows.Controls”

    mc:Ignorable=”d” d:DesignWidth=”640” d:DesignHeight=”480”>

    <Grid x:Name=”LayoutRoot”>

        <syncfusion:DockingManager Name=”dockingManager”>

            <!—DockAbility of Solution Explorer window is set to Left, Right, Top and Bottomà

            <system:TreeView syncfusion:DockingManager.Header=”Solution Explorer” syncfusion:DockingManager.SideInDockedMode=”Right” syncfusion:DockingManager.DockAbility=”Left,Right,Top,Bottom” syncfusion:DockingManager.DockState=”Dock” syncfusion:DockingManager.WindowName=”solutionexplorer” syncfusion:DockingManager.DesiredWidthInDockedMode=”150”>

                </system:TreeView>

           <!—DockAbility is set to Allà

            <ListBox syncfusion:DockingManager.DockState=”Dock” syncfusion:DockingManager.Header=”Properties” syncfusion:DockingManager.DockAbility=”All” syncfusion:DockingManager.SideInDockedMode=”Top” syncfusion:DockingManager.DesiredHeightInDockedMode=”200”/>

            <!—DockAbility of Help window is set to Tabbedà

            <ContentControl syncfusion:DockingManager.DockState=”Dock” syncfusion:DockingManager.Header=”Help” syncfusion:DockingManager.DockAbility=”Tabbed” syncfusion:DockingManager.SideInDockedMode=”Left”  syncfusion:DockingManager.WindowName=”help”/>

            <!—DockAbility of Find window is set to Bottom, Leftà

            <ContentControl syncfusion:DockingManager.DockState=”Dock” syncfusion:DockingManager.Header=”Find” syncfusion:DockingManager.DockAbility=”Bottom,Left” syncfusion:DockingManager.SideInDockedMode=”Right”  syncfusion:DockingManager.WindowName=”find”/>

        </syncfusion:DockingManager>

    </Grid>

</UserControl>

 

 

 

[C#]

 

DockingManager.SetDockAbility(this.treeView, DockAbility.Left | DockAbility.Right | DockAbility.Top | DockAbility.Bottom);

 

In the image, center drag indicator does not appear in the Solution Explorer window since its DockAbility is set only for Left, Right, Top and Bottom.

OuterDockAbility:

Controls the visibility of the outer drag providers. It is a flagged enumeration. By default, OuterDockAbility will be set as OuterDockAbility.All so that all the outer drag indicators appear.  It contains the following tabulated values:

Position

Description

Left

Left drag indicator will appear.

Right

Right drag indicator will appear.

Top

Top drag indicator will appear.

Bottom

Bottom drag indicator will appear.

None

No drag indicator will appear.

 

Following code illustrates the OuterDockAbility,

 

[XAML]

 

<UserControl x:Class="Sample.MainPage"

    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"

    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"

    xmlns:d="http://schemas.microsoft.com/expression/blend/2008" xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006" xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.DockingManager.Silverlight"

             xmlns:system="clr-namespace:System.Windows.Controls;assembly=System.Windows.Controls"

    mc:Ignorable="d" d:DesignWidth="640" d:DesignHeight="480">

    <Grid x:Name="LayoutRoot">

        <!—OuterDockAbility is set to Left and Right-->

        <syncfusion:DockingManager Name="dockingManager" OuterDockAbility="Left,Right">

            <system:TreeView syncfusion:DockingManager.Header="Solution Explorer" syncfusion:DockingManager.SideInDockedMode="Right" syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.WindowName="solutionexplorer" syncfusion:DockingManager.DesiredWidthInDockedMode="150">

                </system:TreeView>

            <!-- Find Results is docked at bottom-->

            <ContentControl syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.Header="Find Results" syncfusion:DockingManager.SideInDockedMode="Bottom"  syncfusion:DockingManager.WindowName="findresults"/>

            <ListBox syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.Header="Properties" syncfusion:DockingManager.SideInDockedMode="Top" syncfusion:DockingManager.DesiredHeightInDockedMode="200"/>

            <!-- Help window is docked to left-->

            <ContentControl syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.Header="Help" syncfusion:DockingManager.SideInDockedMode="Left"  syncfusion:DockingManager.WindowName="help"/>

            <!-- Find window is docked to right-->

            <ContentControl syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.Header="Find" syncfusion:DockingManager.SideInDockedMode="Right"  syncfusion:DockingManager.WindowName="find"/>

        </syncfusion:DockingManager>

    </Grid>

</UserControl>

 

 

 

[C#]

 

this.dockingManager.OuterDockAbility = OuterDockAbility.Left | OuterDockAbility.Right;

 

In the below image, only left and right outer drag indicators are displayed since OuterDockAbility is set only for Left and Right.
