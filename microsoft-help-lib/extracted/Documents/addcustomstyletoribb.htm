Add Custom Style to Ribbon Control

The Ribbon control template can be easily customizable using Expression Blend. Right-click the Ribbon control and select the option “Edit a Copy…” in Edit Template.

 

 

Figure 689: Edit Style Window

The following window will appear:

 

 

Figure 690: Add Style Name for Ribbon

XAML

 

<syncfusion:Ribbon Title="Document 1 - Microsoft Word" x:Name="myRibbon" Margin="0,22,0,0" VerticalAlignment="Top" Style="{StaticResource RibbonStyle1}" ApplicationMenuStyle="{StaticResource ApplicationMenuStyle1}">

   <syncfusion:Ribbon.ApplicationMenu>

        <syncfusion:ApplicationMenu ApplicationButtonImage="app.png"/>           

   </syncfusion:Ribbon.ApplicationMenu>

   <syncfusion:RibbonTab Caption="Ribbon Tab">

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

        <syncfusion:RibbonBar/>

   </syncfusion:RibbonTab>

</syncfusion:Ribbon>

 

All resources will be displayed in the Resources pane. The user can easily customize the resources and a custom style or theme can be applied to the Ribbon control as follows:
