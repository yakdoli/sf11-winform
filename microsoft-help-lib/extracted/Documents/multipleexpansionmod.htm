Multiple Expansion Mode

 

When the VisualMode property is set to MultipleExpansion, the GroupBar is displayed in a tree view structure. You can expand or collapse any number of groupbar items. The Expand and Collapse behavior is as seen in the TreeView.

 

The following code example illustrates how to set the VisualMode property to MultipleExpansion.

 

[XAML]

 

<syncfusion:GroupBar x:Name="groupbar" Width="250" VisualMode="MultipleExpansion" Height="450" Orientation="Vertical" >

    <syncfusion:GroupBarItem x:Name="groupbaritem" IsExpanded="True" Background="White" HeaderText="Groupbar" >

    </syncfusion:GroupBarItem>

</syncfusion:GroupBar>

 

[C#]

 

GroupBar groupbar = new GroupBar();

groupbar.VisualMode = VisualMode.MultipleExpansion;

GroupBarItem groupbaritem = new GroupBarItem();

groupbaritem.HeaderText = "Groupbaritem";

Grid grid = new Grid();

TextBlock tb = new TextBlock();

tb.Text = "Content";

grid.Children.Add(tb);

groupbaritem.Content = grid;

groupbar.Items.Add(groupbaritem);

LayoutRoot.Children.Add(groupbar);
