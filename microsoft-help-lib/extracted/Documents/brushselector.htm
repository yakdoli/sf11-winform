BrushSelector

 

The BrushSelector control is a User Interface (UI) control similar to the ColorPicker control used in the graphics software. The BrushSelector is used to preview and test color values. It allows alteration of a color by different types of values like HSV and RGB values.

 

Note: The major difference between a ColorPicker and BrushSelector is that it returns a brush value which can be a Solid or Gradient.

 

The BrushSelector control comprises another sub-control named BrushEdit with similar properties. For details, refer the structure of BrushSelector. The following sections will also discuss the BrushEdit control alongside BrushSelector.

 

Feature Summary

 

Following are the common features for BrushSelector and BrushEdit controls.

 

·      Support to select the ColorSelection mode of the control by using the VisualizationStyle property. It can be RGB or HSV mode.

·      Support to choose the mode of the selected brush by using BrushMode property. It can be either SolidColorBrush or a GradientBrush.

·      Support to specify the border color of the selected gradient item in the GradientBar by using SelectedBackground property.

·      Support to specify the selected brush for the control by using SelectedBrush property.

·      Enable and disables the switching between Solid and Gradient Brush by using the EnableSolidToGradientBrush event.
