Setting Value

You must use Value property to set value to MaskedTextBox.

Note: Do not use Text Property to set value for MaskedTextBox. Use only Value property.

XAML

<syncfusion:MaskedTextBox x:Name="maskedTextBox" Height="25" Width="150"

                          Mask="00/00/0000" Value="07/02/2010"/>

 

C#

maskedTextBox.Value = "07/02/2010";
