Setting Tab Panel background

            The user may customize the TabPanel by setting the background color. You can set TabPanel Background through Xaml and Code behind.

[Xaml]

<syncfusion:TabControlAdv Name="MyTabCtrl" Height="250" Width="300" TabPanelBackground="DarkGoldenrod">

[C#]

this.MyTabCtrl.TabPanelBackground = new SolidColorBrush(Colors.Orange);
