Switching Brush Modes

 

This feature enables you to switch between brush modes at run time. If this feature is disabled, then the brush mode set in the code becomes static, and hence you cannot change the mode at run time.

 

This feature can be enabled by using the EnableGradientToSolidSwitch property.

 

[XAML]

 

<!-- Adding BrushEdit -->

<syncfusion:BrushEdit Margin="20" EnableGradientToSolidSwitch="true" Name="brushedit"/>

 

[C#]

 

// Creating an instance of the BrushSelector control.

BrushEdit brushedit = new BrushEdit();

 

// Setting brush mode as Gradient.

brushedit.EnableGradientToSolidSwitch = true;

 

Note: The preceding feature also applies to the BrushSelector control.
