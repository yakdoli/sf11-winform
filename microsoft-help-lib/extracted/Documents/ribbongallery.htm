Ribbon Gallery

The Ribbon control provides support to add the Gallery control to the Ribbon control. Ribbon Gallery control displays items in a neat manner and also enables you to classify the items as groups for easy navigation.

Declaring Ribbon Gallery

The following code example illustrates the adding of a Gallery control to the ribbon instance.

XAML

 

<syncfusion:RibbonGallery>

    <syncfusion:RibbonGalleryItem>

         <syncfusion:RibbonGalleryItem.Content>

              <Image Source="Images/Apex.png"/>

         </syncfusion:RibbonGalleryItem.Content>

    </syncfusion:RibbonGalleryItem>

</syncfusion:RibbonGallery>

 

C#

 

RibbonGallery gallery = new RibbonGallery();

RibbonGalleryItem galleryItem = new RibbonGalleryItem();

galleryItem.Content = new Image() { Source = new BitmapImage(new Uri("Apex.png")) };
