Binding XML Data

You can bind XML data with TreeViewAdv. To bind XML to TreeViewAdv, you need to convert the XML to a collection of objects and then bind the collection using ItemsSource property.

XML data used in this example are:

Create a separate class that represents the node in XML document. Here a class is created with the name Category that represents the XML data.

[C#]

   

public class Category

        {

            public string Name { get; set; }

            public string Area { get; set; }

            public string Population { get; set; }

            public List<Category> SubCategories { get; set; }

        }

 

Convert XML data to collection and then bind the collection to ItemsSource property of TreeViewAdv. Here the code is to convert XML to collection.

[C#]

 

   public partial class MainPage : UserControl

    {

        public MainPage()

        {

            InitializeComponent();

            LoadData();

        }

 

        private void LoadData()

        {

            List<Category> categories = new List<Category>();

            XDocument categoriesXML = XDocument.Load("Categories.xml");

            categories = this.GetCategories(categoriesXML.Element("categories"));

            this.treeview1.ItemsSource = categories;

        }

 

        private List<Category> GetCategories(XElement element)

        {

            return (from category in element.Elements("category")

                    select new Category()

                    {

                        Name = category.Attribute("name").Value,

                        Area = category.Attribute("area").Value,

                        Population = category.Attribute("population").Value,

                        SubCategories = this.GetCategories(category)

                    }).ToList();

        }

    }

 

 

The following is the code for TreeViewAdv. Since data is hierarchical, you need to declare Hierarchical Data Template.

[XAML]

 

<syncfusion:TreeViewAdv x:Name="treeview1" BorderBrush="Black" BorderThickness="2">

            <syncfusion:TreeViewAdv.ItemTemplate>

                <common:HierarchicalDataTemplate ItemsSource="{Binding SubCategories}">

                    <Border>

                        <Grid>

                            <Grid.ColumnDefinitions>

                                <ColumnDefinition Width="*"/>

                                <ColumnDefinition Width="*"/>

                                <ColumnDefinition Width="*"/>

                            </Grid.ColumnDefinitions>

                            <TextBlock Margin="10,0,0,0" Text="{Binding Name}" Grid.Column="0"/>

                            <TextBlock Margin="30,0,0,0" Text="{Binding Area}" Grid.Column="1"/>

                            <TextBlock Margin="30,0,0,0" Text="{Binding Population}" Grid.Column="2"/>

                        </Grid>

                    </Border>

                </common:HierarchicalDataTemplate>

            </syncfusion:TreeViewAdv.ItemTemplate>

        </syncfusion:TreeViewAdv>
