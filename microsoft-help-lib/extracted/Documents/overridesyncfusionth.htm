Override Syncfusion Themes

All Syncfusion styles can be overridden by a common Naming Convention. A unique key is given to each and every style, so that you can override the styles using the BasedOn property.

Naming Convention of the key

VisualStyle-ControlName-Style

Example:  BlendButtonAdvStyle

 

The following steps explain how to override Syncfusion themes.

 

4.   Add the corresponding ResourceDictionary in the sample.

[XAML]                                            

 

<ResourceDictionary>

            <ResourceDictionary.MergedDictionaries>

                <ResourceDictionary Source="/Syncfusion.Theming.Blend;component/ButtonAdv.xaml"></ResourceDictionary>

            </ResourceDictionary.MergedDictionaries>

</ResourceDictionary>

 

 

5.   Define the new style using the BasedOn property.

 

The following code snippet overrides the Syncfusion style for the ButtonAdv control.

[XAML]

<Grid x:Name="LayoutRoot" Background="White">

        <Grid.Resources>

            <Style TargetType="syncfusion:ButtonAdv" BasedOn="{StaticResource BlendButtonAdvStyle}">

                <Setter Property="Foreground" Value="Red"/>

            </Style>

        </Grid.Resources>

 

        <syncfusion:ButtonAdv Height="30" Width="150" Content="ButtonAdv"/>

</Grid>

 

 

The derived style should be defined with the BasedOn attribute in root level resources.
