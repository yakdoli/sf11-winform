Mouse Support

            TabControlAdv control has Mouse Support for high usage with easy customization.

TabItemOpen Modes

            The users can select any one of the following modes as TabItemOpenMode. OnMouseClick is the default mode for this property.

OnMouseClick

            In this selection, the tab item content will open when clicked on the tab item.      

[Xaml]

<syncfusion:TabControlAdv Name="MyTabCtrl" Height="250" Width="300" TabItemOpenMode="OnMouseClick"  >

 

 

[C#]

this.MyTabCtrl.TabItemOpenMode = TabItemOpenMode.OnMouseClick;

 

 

OMouseOver

            In this selection, the tab item content will open during mouse move over on the tab item.

[Xaml]

<syncfusion:TabControlAdv Name="MyTabCtrl" Height="250" Width="300" TabItemOpenMode="OnMouseOver"  >

 

 

[C#]

this.MyTabCtrl.TabItemOpenMode = TabItemOpenMode.OnMouseOver;

 

 

TabItemOpen Mode

            You can select the following modes for TabItemOpenMode.

·      OnMouseClick

·      OnMouseOver  

 

OnMouseClick is the default mode for this property. By this feature you can use TabControlAdv by mouse support.

OnMouseClick

         

The tab item content opens when you click on the tab item in this OnMouseClick selection.

[XAML]

<syncfusion:TabControlAdv Name="MyTabCtrl" Height="250" Width="300" TabItemOpenMode="OnMouseClick"  >

 

 

[C#]

this.MyTabCtrl.TabItemOpenMode = TabItemOpenMode.OnMouseClick;

 

 

OnMouseOver          

            In this type of selection, the tab item content will open when mouse moves on the tab item.

[Xaml]

<syncfusion:TabControlAdv Name="MyTabCtrl" Height="250" Width="300" TabItemOpenMode="OnMouseOver"  >

 

 

[C#]

this.MyTabCtrl.TabItemOpenMode = TabItemOpenMode.OnMouseOver;
