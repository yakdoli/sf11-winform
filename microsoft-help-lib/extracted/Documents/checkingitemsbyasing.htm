Checking Items by a Single Mouse-click

CheckedListBox control provides support to check items by a single mouse-click. The user can enable or disable this feature by using the CheckOnClick property. The default value for this property is set to false.

 

Use Case Scenarios

This feature allows users to select an item (check the CheckBox / Radio Button) by clicking anywhere on the item.

 

Adding Checking Items to an Application by a Single Mouse-click

The following code example describes the addition of Checking Items (a single mouse-click feature) to the application using XAML.

 

[XAML]

 

<sync:CheckedListBox Mode="Checked" x:Name="CKBox" CheckOnClick="True"

            Height="200" Width="150"Background="LightGray"

            BorderBrush="DarkGray" BorderThickness="2">

      <sync:CheckedListBoxItem Content=" Argentina"

                      LeftImageSource="Images/argentina.jpg" />

      <sync:CheckedListBoxItem Content=" Brazil"

                      LeftImageSource="Images/brazil.jpg" />

      <sync:CheckedListBoxItem Content=" Canada"

                      LeftImageSource="Images/canada.jpg" />

      <sync:CheckedListBoxItem Content=" England"

                      LeftImageSource="Images/England.png" />

      <sync:CheckedListBoxItem Content=" Germany"

                      LeftImageSource="Images/Germany.png" />          

</sync:CheckedListBox>
