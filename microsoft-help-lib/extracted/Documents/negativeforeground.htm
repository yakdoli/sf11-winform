Negative Foreground

The Foreground of the DoubleTextBox can be customized based on the Value property. When Negative value assigned to Value property automatically the NegativeForeground value gets assigned to Foreground property.

Note:

The NegativeForeground in DoubleTextBox can be enabled by setting ApplyNegativeForeground property to true.

 

XAML

<syncfusion:DoubleTextBox x:Name="doubleTextBox" Width="150" Height="25" Value="-123"

                           ApplyNegativeForeground="True" NegativeForeground="Red"/>
