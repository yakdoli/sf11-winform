Enable Drag and Drop when using Data Binding for ListBoxItems

 

The Style is used to set the AllowDrag and AllowDrop for each ListBoxItem when Data Binding is used to fill the ListBoxItems. The following sample explains this:

 

[XAML]

 

<ListBox  sync:DragAndDropManager.AllowDrop="True" ItemsSource="{Binding Path=MyProperty}" Margin="50 20" Height="300" BorderBrush="Black" BorderThickness="2">

 <ListBox.ItemContainerStyle>

  <Style TargetType="ListBoxItem">

   <Setter Property="sync:DragAndDropManager.AllowDrag" Value="True"/>

   <Setter Property="sync:DragAndDropManager.AllowDrop" Value="True"/>                                   

  </Style>

  </ListBox.ItemContainerStyle>

  <ListBox.ItemTemplate>

    <DataTemplate >

     <Grid>

      <Border Background="Transparent">

     <StackPanel Orientation="Horizontal">                                   

       <Image Source="{Binding Icon}" Width="50" Height="50" Margin="10"/>

       <TextBlock Text="{Binding Name}" Margin="10" VerticalAlign         

                 ment="Center"/>

     </StackPanel>

     </Border>

    </Grid>

   </DataTemplate>

 </ListBox.ItemTemplate>

</ListBox>
