Canceling the progress bar

The progress bar can be canceled in two ways:

1.   By calling the CancelProgressBar method in HierarchyNavigator.

 

C#

 

HierarchyNavigator hierarchyNavigator = new HierarchyNavigator();

hierarchyNavigator.CancelProgressBar();

 

2.   Or by passing an argument in the method to cancel the progress bar for a specified time span (below, a time span of 1000 ms has been specified).

 

 

C#

 

HierarchyNavigator hierarchyNavigator = new HierarchyNavigator();

hierarchyNavigator.OnCancelProgressBar(new TimeSpan(0, 0, 0, 0, 1000));
