Feature Summary

 

The DragAndDropManager provides the following distinct features:

 

·      Interoperability between different elements

·      Rich set of events

·      Custom Drag Icon

·      Custom Drop Description

·      Custom Drag Threshold

·      Drag Arrow

·      Drag Arrow Customization

·      Auto Scrolling

·      Keyboard interaction

·      Return animation for the dragged object on cancelling the drag operation
