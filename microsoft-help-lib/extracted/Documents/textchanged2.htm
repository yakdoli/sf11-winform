TextChanged

 

TextChanged – The event occurs when the value property of the MaskedTextBox is changed.

XAML

<syncfusion:MaskedTextBox x:Name="maskedTextBox"

                          TextChanged="maskedTextBox_TextChanged"/>

 

C#

MaskedTextBox maskedTextBox = new MaskedTextBox();

maskedTextBox.TextChanged += new TextChangedEventHandler(maskedTextBox_TextChanged);

You can handle the TextChanged event as follows.

C#

private void maskedTextBox_TextChanged(object sender, TextChangedEventArgs e)

        {

            //Insert code to do some operations when Text of MaskedTextBox changes.

        }
