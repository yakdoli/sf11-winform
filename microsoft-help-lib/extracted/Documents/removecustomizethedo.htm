Remove/customize the Docking menu

 

Docking Menu can be removed by setting the following property to False:

 

[C#]

 

this.dockingManager.ShowMenuButton = false;

 

DockingManager supports addition of custom menu items. This can be achieved by attaching CustomContextMenuItems property to the Docking Manager child which enables inclusion of additional item (i.e. Syncfusion.Silverlight.Shared.ContextMenuItemAdv) to the Menu. It is a collection of ContextMenuItemAdv presented in Syncfusion.Silverlight.Shared assembly.

The following code illustrates this:

 

[XAML]

 

<TextBox x:Name="textBox" syncfusion:DockingManager.Header="Text" syncfusion:DockingManager.SideInDockedMode="Top" syncfusion:DockingManager.FloatingWindowRect="100,100,100,100" syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.WindowName="text">

                <syncfusion:DockingManager.CustomContextMenuItems>

                    <syncfusion:CustomContextMenuItemCollection>

                        <shared:ContextMenuItemAdv Header="CustomItem"/>

                    </syncfusion:CustomContextMenuItemCollection>

                </syncfusion:DockingManager.CustomContextMenuItems>

            </TextBox>

 

[C#]

 

CustomContextMenuItemCollection collection = new CustomContextMenuItemCollection();

            ContextMenuItemAdv item = new ContextMenuItemAdv();

            item.Header = "CustomItem";

            collection.Add(item);

            DockingManager.SetCustomContextMenuItems(this.textBox, collection);
