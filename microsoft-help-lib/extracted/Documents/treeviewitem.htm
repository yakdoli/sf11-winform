TreeViewItem

TreeViewItemAdv is a HeaderedItemsControl that contains multiple items and a header. To expand or collapse a TreeViewItemAdv, use the IsExpanded property.

SelectedItem (Object): Gets or sets the selected item in TreeViewAdv.

SelectedNode (TreeViewItemAdv): Gets or sets the Tree Node that is currently selected in TreeViewAdv.

SelectedItems (List<Object>): Gets or sets the Tree Nodes that are currently selected in TreeViewAdv.

SelectedNodes (List<TreeViewItemAdv>): Gets or sets the selected items in TreeViewAdv.

            Here are the step by step instructions for adding items to TreeViewAdv in XAML.

1.   Create an empty TreeViewAdv without any items.

 

[XAML]

 

<syncfusion:TreeViewAdv x:Name="treeview" FullRowSelect="True" HorizontalAlignment="Center" VerticalAlignment="Center" Height="400" Width="300">

 

2.   Now the user can add TreeViewItemAdv to TreeViewAdv as shown in the following code.

 

[XAML]

 

<syncfusion:TreeViewAdv x:Name="treeview" FullRowSelect="True" HorizontalAlignment="Center" VerticalAlignment="Center" Height="400" Width="300">

            <syncfusion:TreeViewItemAdv Header="Syncfusion">

                <syncfusion:TreeViewItemAdv Header="UserInterface Edition">

                              <syncfusion:TreeViewItemAdv Header="ASP.NET"/>

                              <syncfusion:TreeViewItemAdv Header="ASP.NET MVC"/>

                              <syncfusion:TreeViewItemAdv Header="Windows Forms"/>

                              <syncfusion:TreeViewItemAdv Header="WPF"/>

                              <syncfusion:TreeViewItemAdv Header="Silverlight"/>

                        </syncfusion:TreeViewItemAdv>

                        <syncfusion:TreeViewItemAdv Header="BI Edition"/>

                        <syncfusion:TreeViewItemAdv Header="Reporting Edition"/>

            </syncfusion:TreeViewItemAdv>

</syncfusion:TreeViewAdv>

 

You can add or remove TreeViewItemAdv in code behind also.

[C#]

 

TreeViewItemAdv head = new TreeViewItemAdv() { Header = "Syncfusion" };

            TreeViewItemAdv subhead1 = new TreeViewItemAdv() { Header = "UserInterface Edition" };

            TreeViewItemAdv item1 = new TreeViewItemAdv() { Header = "ASP.NET" };

            TreeViewItemAdv item2 = new TreeViewItemAdv() { Header = "ASP.NET MVC" };

            TreeViewItemAdv item3 = new TreeViewItemAdv() { Header = "Windows Forms" };

            TreeViewItemAdv item4 = new TreeViewItemAdv() { Header = "WPF" };

            TreeViewItemAdv item5 = new TreeViewItemAdv() { Header = "Silverlight" };

            subhead1.Items.Add(item1);

            subhead1.Items.Add(item2);

            subhead1.Items.Add(item3);

            subhead1.Items.Add(item4);

            subhead1.Items.Add(item5);

            TreeViewItemAdv subhead2 = new TreeViewItemAdv() { Header = "Reporting Edition" };

            TreeViewItemAdv subhead3 = new TreeViewItemAdv() { Header = "BI Edition" };

            head.Items.Add(subhead1);

            head.Items.Add(subhead2);

            head.Items.Add(subhead3);

            treeview.Items.Add(head);
