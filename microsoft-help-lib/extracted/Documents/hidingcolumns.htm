Hiding Columns

 

It is possible hide the columns, using the ColumnsToHide property. By default, seven columns will be visible for displaying information about the files being uploaded. This property is of type Array ColumnNames: here ColumnNames is an enumeration which consists of the following details.

 

·      ColumnNames.FileSize

·      ColumnNames.FileName

·      ColumnNames.Progress

·      ColumnNames.Remove

·      ColumnNames.Cancel

·      ColumnNames.Status

·      ColumnNames.SizeUploaded.

 

The following code snippet illustrates its usage.

 

[C#]

 

FileUploadControl fileupload = FileUploadControl();

ColumnNames[] columnnames = { ColumnNames.FileSize, ColumnNames.FileName, ColumnNames.Progress, ColumnNames.Remove };

fileupload.ColumnsToHide = columnnames;
