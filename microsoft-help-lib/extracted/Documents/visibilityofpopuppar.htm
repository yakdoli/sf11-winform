Visibility of Popup Parts

·      Calendar Button visibility can be enabled by setting IsCalendarEnabled property to True.

·      None Button visibility can be enabled by setting IsEmptyDateEnabled property to True.

 

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="200" IsCalendarEnabled="False" IsEmptyDateEnabled="False"

                         EnableClassicStyle="True"

                         DateTime="07/05/2010" Pattern="LongDate"/>

 

 

Figure 439: IsCalendarEnabled set to False

 

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="230" Margin="10"

                         IsCalendarEnabled="True"                         IsEmptyDateEnabled="True"/>

 

 

Figure 440: EnableClassicStyle set to False

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="200" IsCalendarEnabled="True" IsEmptyDateEnabled="True"

                         EnableClassicStyle="True"

                         DateTime="07/05/2010" Pattern="LongDate"/>

 

Figure 441: EnableClassicStyle set to True

 

 

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="200" IsCalendarEnabled="True" IsEmptyDateEnabled="False"

                         EnableClassicStyle="False"

                         DateTime="07/05/2010" Pattern="LongDate"/>

 

 

Figure 442: IsEmptyDateEnabled set to False

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="200" IsCalendarEnabled="True" IsEmptyDateEnabled="False"

                         EnableClassicStyle="True"

                         DateTime="07/05/2010" Pattern="LongDate"/>

 

 

Figure 443: IsEmptyDateEnabled set to True

 

Working with DropDown Popup

By clicking None Button you can set Null Value to DateTime property of DateTimeEdit control. You can use Calendar for changing the Date and Time of the DateTimeEdit control.
