Zoom Options

Following options are available for Zooming: 

·      Zooming Operation

o  ZoomIn

o  ZoomOut

·      ZoomReset

·      ZoomTo

 

 

Zoom Operations

 

Zoom operation can be performed in two methods. They are:

 

·      Using ZoomPan window

·      Using Command

 

Using ZoomPan Window

You can perform zooming operation by resizing the ZoomPan Window.

 

Using Command

You can perform zooming operation using command.

Following code illustrates how to perform ZoomIn Command: 

 

[XAML]

 

<Button Content="ZoomIn" Command="{Binding ElementName=overview, Path=ZoomIn}"/>

 

Following code illustrates how to perform ZoomOut Command: 

 

[XAML]

 

<RepeatButton Content="ZoomOut" Command="{Binding ElementName=overview, Path=ZoomOut}"/>

 

 

 

 

ZoomReset

Following code illustrates how to reset the Zooming operation performed:

 

[XAML]

<RepeatButton Content="Reset" Command="{Binding ElementName=overview, Path=ZoomReset}"/>

 

 

ZoomTo

 

You can zoom to a specific value in two methods. They are:

·      Using Commands

·      Using Property

 

Using Commands

 

To execute ZoomTo command you have to send an object that implements IZoomParameter as command parameter.

 

The following code illustrates how to zoom to a specific value:

 

[C#]

 

class ZoomParamenter : IZoomParameter

    {

        public double ZoomTo { get; set; }

 

        public double ZoomFactor { get; set; }

    }

 

 

 

 

[XAML]

 

 

<Button Content="ZoomTo" Command="{Binding ElementName=overview, Path=ZoomTo}">

    <Button.CommandParameter>

        <local:ZoomParamenter ZoomTo="4"/>

    </Button.CommandParameter>

</Button>

 

 

Using Property

 

You can zoom to a specific value by binging scale property to a double value.

 

[XAML]

 

<Slider Minimum="{Binding ElementName=overview, Path=MinimumZoom, Mode=TwoWay}"

    Maximum="{Binding ElementName=overview, Path=MaximumZoom, Mode=TwoWay}"

    Value="{Binding ElementName=overview, Path=Scale, Mode=TwoWay}"/>
