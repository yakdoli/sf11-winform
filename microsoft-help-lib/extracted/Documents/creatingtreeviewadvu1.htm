Creating TreeViewAdv using XAML

To create TreeViewAdv using VisualStudio in XAML:     

1.   Create a new Silverlight application in Visual Studio.

2.   In Visual Studio Toolbox, click syncfusion Silverlight Toolbox tab and select TreeViewAdv.

Figure 733: Visual Studio Toolbox

 

3.   Drag and Drop the TreeViewAdv to the Design View, to add TreeViewAdv to the application.

 

 

Figure 734: New Silverlight application in Visual Studio

 

4.   Now you can customize the properties of TreeViewAdv in the Properties Window.

 

[XAML]

 

<syncfusion:TreeViewAdv FullRowSelect="True" HorizontalAlignment="Center" VerticalAlignment="Center" Height="250" Width="300" Foreground="#FF8E8989">

    <syncfusion:TreeViewItemAdv Header="Syncfusion">

        <syncfusion:TreeViewItemAdv Header="UserInterface Edition">

            <syncfusion:TreeViewItemAdv Header="ASP.NET"/>

            <syncfusion:TreeViewItemAdv Header="ASP.NET MVC"/>

            <syncfusion:TreeViewItemAdv Header="Windows Forms"/>

            <syncfusion:TreeViewItemAdv Header="WPF"/>

            <syncfusion:TreeViewItemAdv Header="Silverlight"/>

        </syncfusion:TreeViewItemAdv>

        <syncfusion:TreeViewItemAdv Header="BI Edition"/>

        <syncfusion:TreeViewItemAdv Header="Reporting Edition"/>

    </syncfusion:TreeViewItemAdv>

</syncfusion:TreeViewAdv>
