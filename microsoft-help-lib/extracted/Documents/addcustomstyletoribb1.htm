Add custom style to Ribbon Tab

The template for each Ribbon tab can be edited using the property RibbonTab.TabButtonStyle. The Target type of the Style should be TabButton. Here is the sample code explaining this:

XAML

 

<sync:RibbonTab Caption="Tab Item 2" IsChecked="False">

   <sync:RibbonTab.TabButtonStyle>

       <Style TargetType="sync:TabButton">

           <Setter Property="Foreground" Value="White"/>

           <Setter Property="Background" Value="Red"/>

           <Setter Property="Template">

              <Setter.Value>

                <ControlTemplate TargetType="sync:TabButton">

                   <Border Height="50"  Background="{TemplateBinding Background}" CornerRadius="15 15 0 0">

                       <Grid>

                          <TextBlock Text="{TemplateBinding Caption}" x:Name="PART_Caption" Margin="0 3" Foreground="{TemplateBinding Foreground}" VerticalAlignment="Top"/>

                       </Grid>

                   </Border>

              </ControlTemplate>

             </Setter.Value>

          </Setter>

       </Style>

    </sync:RibbonTab.TabButtonStyle>

</sync:RibbonTab>
