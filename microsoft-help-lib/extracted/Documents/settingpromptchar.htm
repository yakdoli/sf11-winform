Setting Prompt Char

Mask position will be represented by PromptChar property. You can set Prompt Char using PromptChar property.

XAML

<syncfusion:MaskedTextBox Name="maskedTextBox1" Height="25" Width="150"

                          Mask="00/00/0000" PromptChar="_"/>

 

C#

maskedTextBox1.PromptChar = "_";
