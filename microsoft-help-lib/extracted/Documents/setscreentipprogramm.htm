Set Screen Tip programmatically

The following step is used to set tooltip in code behind:

C#

 

RibbonButton button = new RibbonButton();

button.SetValue(Ribbon.ScreenTipProperty, new ScreenTip() { Description = "Hello World", Content = "This is a Screen Tip!" });

 

Figure 698: ScreenTip

XAML

 

<syncfusion:RibbonSplitButton Name="_Paste" Command="{Binding Paste}" SmallIcon="Paste16.png" Label="Paste" SizeMode="Large" IsMultiLine="True" LargeIcon="Paste32.png">

      <syncfusion:Ribbon.ScreenTip>

         <syncfusion:ScreenTip Content="Paste the contents of the clipboard." ImageSource="Paste32.png"

Description="Paste" HelpImage="Help16.png"  HelpText="Press F1 for Help">

        </syncfusion:ScreenTip>

    </syncfusion:Ribbon.ScreenTip>

</syncfusion:RibbonSplitButton>
