Blendability support

 

The FileUpload control can be easily edited in Blend. The user can edit the template of the FileUpload control to give a customized look and feel for the control using Expression Blend. This can be started by simply creating an application in Blend.

Use Case Scenarios

This feature will be useful to improve the look and feel of the FileUpload control.

Adding the Blendability Support to an Application

1.   To create an application in Blend: Open Blend.

2.   On the File Menu, click New Project. This opens the New Project dialog box.

 

Figure 385: Blend – New Project

 

3.   In the Project types panel, select Silverlight Application and then click OK.

4.   Add the following reference with the sample project:

·      Syncfusion.Tools.Silverlight.dll

Figure 386: Blend - New Project Dialog

 

5.   On the Window menu, select Assets. This opens the Assets Library dialog box.

6.   In the Search box, type FileUploadControl. This displays the search results.

7.   Drag the FileUpload control to Design view.

 

Figure 387: Blend - Design View

8.   Create the FileUpload control.

9.   Select the FileUpload control and go to Object -> Edit Style -> Edit a Copy, to edit the template of the FileUpload control.

 

Figure 388: Blend - Edit Template

 

Another way to edit the template:

1.   In Object and Timeline window, right click the FileUpload control and choose the Edit Template option as shown in the following screenshot.

 

Figure 389: Blend - Edit Template

 

This will open a dialog (as shown in the following screenshot) where you can give the style a name and define exactly where you like to store it.

Figure 390: Blend - Create Style

 

What is produced with the help of these steps is XAML, which is placed within the application. This XAML represents the default style for the FileUpload control.

 

[XAML]

 

<Syncfusion:FileUploadControl x:Name="fileupload" Grid.Row="0" EnableThumbnail="True"  Margin="50"
                IsMultiSelect="True" Style="{StaticResource FileUploadControlStyle1}"/>

 

 

 

All template items can now be found in the Objects and Timeline window.

 

Figure 391: Objects and Timelines window

 

Now the user can edit each part in the template. As commands are used for each operation in the FileUpload control, the user can change the inner DataGrid also. In the following example, DataGrid is replaced with the ListBox and the template is edited to get a customized look and feel.

 

[XAML]

 

    <UserControl.Resources>
        <Style x:Key="FileUploadControlStyle1" TargetType="Syncfusion:FileUploadControl">
 
            <Setter Property="Background">
                <Setter.Value>
                    <LinearGradientBrush EndPoint="0.5,1" StartPoint="0.5,0">
                        <GradientStop Color="#FFF3F4DC" Offset="0"/>
                        <GradientStop Color="#FFF7F7E1" Offset="0.725"/>
                        <GradientStop Color="#FFF8F8E2" Offset="1"/>
                    </LinearGradientBrush>
                </Setter.Value>
            </Setter>
            <Setter Property="BorderBrush" Value="Gray"/>
            <Setter Property="BorderThickness" Value="2"/>
            <Setter Property="CornerRadius" Value="1"/>
            <Setter Property="Header" Value="Select Files"/>
            <Setter Property="HeaderContentTemplate" Value="{StaticResource FileUploadHeaderContentTemplate}"/>
            <Setter Property="Template">
                <Setter.Value>
                    <ControlTemplate TargetType="Syncfusion:FileUploadControl">
 
                        <Border x:Name="MainBorder" Background="{TemplateBinding Background}" BorderThickness="{TemplateBinding BorderThickness}" 
                            BorderBrush="{TemplateBinding BorderBrush}" CornerRadius="{TemplateBinding CornerRadius}"
                            HorizontalAlignment="Stretch" VerticalAlignment="Stretch">
                            <Grid x:Name="PART_Root">
 
                                <Grid>
                                    <Grid.RowDefinitions>
                                        <RowDefinition Height="Auto"/>
                                        <RowDefinition Height="*"/>
                                        <RowDefinition Height="Auto"/>
                                    </Grid.RowDefinitions>
 
                                    <ListBox x:Name="PART_ListBox" Margin="5" SelectionMode="Single" ItemContainerStyle="{StaticResource ListBoxItemStyle1}" Grid.Row="1"
                                         ItemsSource="{Binding UploadFileCollection,RelativeSource={RelativeSource TemplatedParent}}">
                                        <ListBox.ItemTemplate>
                                            <DataTemplate>
                                                <Grid Margin="3">
                                                    <ProgressBar Maximum="100" Minimum="0"  Value="{Binding PercentageUploaded}" Foreground="Red" Grid.ColumnSpan="2" BorderThickness="0" Style="{StaticResource ProgressBarStyle1}"/>
                                                    <Grid Margin="5" VerticalAlignment="Center">
                                                        <Grid.ColumnDefinitions>
                                                            <ColumnDefinition Width="*"/>
                                                            <ColumnDefinition Width="Auto"/>
                                                        </Grid.ColumnDefinitions>
 
                                                        <TextBlock Text="{Binding Path=FileName}" HorizontalAlignment="Left"/>
                                                        <TextBlock Text="{Binding Path=FileSize}" HorizontalAlignment="Right"/>
 
                                                        <Button Content="r" FontFamily="Webdings" HorizontalAlignment="Right" Visibility="Visible"
                                                            Grid.Column="1" VerticalAlignment="Center" Margin="3" Cursor="Hand"
                                                            Command="{Binding CancelUploadCommand}">
                                                            <Button.Template>
                                                                <ControlTemplate TargetType="Button">
                                                                    <Grid>
                                                                        <ContentPresenter/>
                                                                    </Grid>
                                                                </ControlTemplate>
                                                            </Button.Template>
                                                        </Button>
                                                    </Grid>
                                                </Grid>
                                            </DataTemplate>
                                        </ListBox.ItemTemplate>
                                    </ListBox>
 
                                    <Grid Grid.Row="2" HorizontalAlignment="Left" Margin="5">
 
                                        <Grid.ColumnDefinitions>
                                            <ColumnDefinition Width="*"/>
                                            <ColumnDefinition Width="100"/>
                                            <ColumnDefinition Width="100"/>
                                            <ColumnDefinition Width="100"/>
                                        </Grid.ColumnDefinitions>
 
                                        <Grid Grid.Row="0" Grid.Column="0" Margin="0,10,0,0" x:Name="DetailsGrid" 
                                    Visibility="{Binding RelativeSource={RelativeSource TemplatedParent},Path=EnableDetails,Converter={StaticResource BooleanToVisibilityConverter}}" >
                                            <Grid.ColumnDefinitions >
                                                <ColumnDefinition Width="60"></ColumnDefinition>
                                                <ColumnDefinition Width="*"></ColumnDefinition>
                                            </Grid.ColumnDefinitions>
 
                                            <TextBlock x:Name="TxtDetails" Text="Details" Foreground="Gray"  FontSize="14" FontWeight="Bold" Grid.Column="0" Margin="5,0,0,0"></TextBlock>
                                            <StackPanel Grid.Column="1"  Margin="15,2,0,0">
                                                <StackPanel Orientation="Horizontal" >
                                                    <TextBlock  x:Name="TxtTotalFilesHeading" Foreground="Gray" Text="Total Files Uploaded   : " />
                                                    <TextBlock  x:Name="TxtTotalFiles"  Foreground="Gray" Text="0"/>
                                                </StackPanel>
                                                <Grid>
                                                    <StackPanel Orientation="Horizontal" >
                                                        <TextBlock x:Name="TxtTotalBytesHeading" Foreground="Gray" Text="Total Bytes Uploaded : " />
                                                        <TextBlock x:Name="TxtTotalBytes"  Foreground="Gray" Text="0"/>
                                                    </StackPanel>
                                                </Grid>
                                            </StackPanel>
                                        </Grid>
 
 
                                        <Button Style="{StaticResource FileUploadButtonStyle}" Width="90" Content="Upload" Command="{Binding RelativeSource={RelativeSource TemplatedParent},Path=UploadCommand}"
                                            Height="25" x:Name="Button_Upload" Grid.Column="2"/>
 
                                        <Button Style="{StaticResource FileUploadButtonStyle}" Width="90" Content="Add more files" Command="{Binding RelativeSource={RelativeSource TemplatedParent},Path=BrowseCommand}"
                                            Height="25" x:Name="Button_Addmorefiles" Grid.Column="3"/>
                                    </Grid>
 
                                </Grid>
 
                            </Grid>
                        </Border>
                    </ControlTemplate>
                </Setter.Value>
            </Setter>
        </Style>
    </UserControl.Resources>
 
    <Grid HorizontalAlignment="Stretch" VerticalAlignment="Stretch" Margin="10">
        <Syncfusion:FileUploadControl x:Name="fileupload" Grid.Row="0" EnableThumbnail="True"  Margin="50" Style="{StaticResource FileUploadControlStyle1}"
                                      IsMultiSelect="True">
        </Syncfusion:FileUploadControl>
    </Grid>
