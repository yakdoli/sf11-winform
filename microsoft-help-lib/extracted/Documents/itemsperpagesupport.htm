ItemsPerPage Support

Using ItemsPerPage property, you can get or set the number of items to be displayed in the Carousel control.

 

Using ItemsPerPage in an Application

In the below sample, ItemsPerPage is set as 4. Hence while running the sample; only 4 items will be displayed in the path.

 

[XAML]

           

<syncfusion:Carousel x:Name="carousel" Height="400" Width="450" ItemsPerPage="4">
    <syncfusion:Carousel.ItemTemplate>
        <DataTemplate>
            <ContentControl Content="{Binding}"/>
        </DataTemplate>
    </syncfusion:Carousel.ItemTemplate>
</syncfusion:Carousel>

 

 

[C#]

           

carousel.ItemsSource = new ObservableCollection<string>() { "Item1", "Item2", "Item3", "Item4", "Item5", "Item6", "Item7", "Item8", "Item9" };
