Use MaskedTextBox as IntegerTextBox

 

You can use MaskedTextBox as IntegerTextBox using Mask property. “0” is the Masking element that represents the Digit. You can customize the number digits using Mask property.

XAML

<syncfusion:MaskedTextBox x:Name="maskedTextBox" Width="200" Height="25" Mask="0000"

                          PromptChar="0"/>

 

Figure 206: “0” is the Masking element that represents the Digit

This will allow the value between 0 to 9999.
