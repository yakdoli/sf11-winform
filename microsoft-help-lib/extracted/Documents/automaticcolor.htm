Automatic Color

 

Automatic color is the default color which is set as the selected color of the Color Picker control when SelectedColor property is not set. Black is the default automatic. Any required color can be set as the default automatic color.

 

The following is the code snippet illustrates how to set an automatic color:

 

[XAML]

 

<Syncfusion:ColorPickerPalette AutomaticColor="Blue"  x:Name="ColorPicker">

</Syncfusion:ColorPickerPalette>

 

[C#]

 

ColorPickerPalette colorPicker = new ColorPickerPalette();

colorPicker.AutomaticColor = new SolidColorBrush(Colors.Blue);
