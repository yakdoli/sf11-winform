Adding through XAML

The following code example illustrates how to add the TileViewControl to an Application through XAML.

 

[XAML]

 

  <syncfusion:TileViewControl Width="500" Height="400">

            <syncfusion:TileViewItem Header="Item1" Content="Content 1"/>

            <syncfusion:TileViewItem Header="Item2" Content="Content 2"/>

            <syncfusion:TileViewItem Header="Item3" Content="Content 3"/>

            <syncfusion:TileViewItem Header="Item4" Content="Content 4"/>           

   </syncfusion:TileViewControl>
