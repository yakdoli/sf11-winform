Zero Color

 

The Foreground of the IntegerTextBox can be customized based on the Value property. When ‘Zero’ is assigned as a value to Value property, then automatically the ZeroColor is set to Foreground property.

Note: The ZeroColor in integer textbox could be enabled by setting ApplyZeroColor property to true.

[XAML]

 

<syncfusion:IntegerTextBox x:Name="integerTextBox" Width="150" Height="25" Value="0"

                           ApplyZeroColor="True" ZeroColor="Magenta"/>
