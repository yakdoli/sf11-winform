Adding DragAndDropManager to an Application

 

The Namespace that is required for using DragAndDropManager is provided in the following code snippet:

 

[XAML]

 

xmlns:Syncfusion="clr-namespace:Syncfusion.Windows.Shared.Controls;

                  assembly=Syncfusion.Shared.Silverlight"

 

[C#]

 

using Syncfusion.Windows.Shared.Controls;

 

Every object that will be dragged must have the AllowDrag property set to True. This is an attached property and in XAML it can be set in the following way:

 

 

[XAML]

 

<ListBox Syncfusion:DragAndDropManager.AllowDrag="True" x:Name="listBox1">

 

In code-behind the AllowDrag property can be set as:

 

[C#]

 

DragAndDropManager.SetAllowDrag(listBox1, true);

 

Similarly, the AllowDrop property should be set to True for all the objects that will be the drop targets of the drag and drop operation. In XAML it can be set in the following way:

 

[XAML]

 

<ListBox Syncfusion:DragAndDropManager.AllowDrop="True" x:Name="listBox2">

 

In code behind, the AllowDrop property can set as:

 

[C#]

 

DragAndDropManager.SetAllowDrop(listBox2, true);

 

After setting the AllowDrag and AllowDrop property for the elements, as seen above, the elements will receive all the DragAndDropManager events.

 

The DragStarted event is the first event that will be fired when dragging an object. This event can be subscribed as follows:

 

[C#]

 

DragAndDropManager.DragStarted +=

                   new DragDropEventHandler(DragAndDropManager_DragStarted);

 

This will create the following hollow event handler:

 

[C#]

 

void DragAndDropManager_DragStarted(object sender, DragDropEventArgs args)

  {

    throw new NotImplementedException();

    /* delete the above statement and to do necessary steps to start

      dragging the object */

  }

 

Usually, in this DragStarted event handler, the PayLoad is set to the object that needs to be dragged. The PayLoad is the property of the object of DragAndDropEventArgs. Also, the DragIcon is set to an image that denotes the dragged object.

 

The next event that will be fired after the DragStarted event is Drag. This will be raised continuously along with the MouseMove event during the drag process.  This event can be subscribed as follows:

 

[C#]

 

DragAndDropManager.Drag += new DragDropEventHandler(DragAndDropManager_Drag);

 

This will create the following hollow event handler:

 

[C#]

 

void DragAndDropManager_Drag(object sender, DragDropEventArgs args)

  {

    throw new NotImplementedException();

    /* delete the above statement and to do necessary steps on dragging

       the object */

  }

 

Perform the necessary operations during the dragging process using the above event handler.

 

When the dragged object enters the boundary of the target element (the DragAndDropManaer.AllowDrop property of that element is True) the DropEnter event gets fired for that element. This event can be subscribed as follows:

 

[C#]

 

DragAndDropManager.DropEnter += new                             

                  DragDropEventHandler(DragAndDropManager_DropEnter);

 

This will create the following hollow event handler:

 

[C#]

void DragAndDropManager_DropEnter(object sender, DragDropEventArgs args)

 {

     throw new NotImplementedException();

     /* delete the above statement and to do necessary steps that needed when

       dragged object entered into boundary of target element */

 }

 

For example, the DropEnter event handler is used to set the DropDescription that describes how the object is handled by the target element. The DropDescription is the property of the object of DragAndDropEventArgs.

 

The Drop event gets fired when the dragged object is dropped into the boundary of the target element. This event can be subscribed as follows:

 

[C#]

 

DragAndDropManager.Drop += new DragDropEventHandler(DragAndDropManager_Drop);

 

This will create the following hollow event handler:

 

[C#]

void DragAndDropManager_Drop(object sender, DragDropEventArgs args)

  {

    throw new NotImplementedException();

    /* delete the above statement and to do necessary steps that needed when

       drop the object into the boundary of target element */

  }

 

The necessary steps for managing the drag and drop of an object is implemented in the event handler.
For example, the dragged object is removed from the source element and added into the target element using this event handler.

 

When the dragged object leaves the boundary of the target element without getting dropped then the DropLeave event gets fired for that element. This event can be subscribed as follows:

 

 

[C#]

DragAndDropManager.DropLeave += new

                         DragDropEventHandler(DragAndDropManager_DropLeave);

 

This will create the following hollow event handler:

 

[C#]

void DragAndDropManager_DropLeave(object sender, DragDropEventArgs args)

 {

    throw new NotImplementedException();

    /* delete the above statement and to do necessary steps that needed when

       dragged object leaved from boundary of target element without drop */

 }

 

The necessary steps that need to be executed when the dragged object leaves the target element boundary are included in the following event hander.

 

The QueryContinueDrag event gets raised when any key in the keyboard is pressed during dragging process. The pressed key is stored in the DragKey property of the object DragDropEventArgs. This event can be subscribed as follows:

 

[C#] 

DragAndDropManager.QueryContinueDrag += new

                  DragDropEventHandler(DragAndDropManager_QueryContinueDrag);

 

This will create the following hollow event handler:

 

[C#]

void DragAndDropManager_QueryContinueDrag(object sender,DragDropEventArgs 

args)

   {

     throw new NotImplementedException();

     /* delete the above statement and to do necessary steps that needed when

        any key in keyboard is pressed */

   }

 

Usually, the DragMode can be changed with this event handler. For example, the DragMode is set to DragMode.Copy when Ctrl (Control) is pressed. The QueryContinueDrag is the most suitable handler for changing the DragMode.

 

The DropCancelled event gets fired when dropping an object into the target element gets cancelled.

This event can be subscribed as follows:

 

[C#]

DragAndDropManager.DropCancelled += new

                   DragDropEventHandler(DragAndDropManager_DropCancelled);

 

This will create the following hollow event handler:

 

[C#]

void DragAndDropManager_DropCancelled(object sender, DragDropEventArgs args)

  {

   throw new NotImplementedException();

   /* delete the above statement and to do necessary steps when the

       drop operation cancelled */

  }

 

The following ListBoxDragAndDrop example describes the implementation of simple drag and drop between two ListBox controls.

 

1.   Open Visual Studio. 

 

2.   Create a new Silverlight Application project and name it ListBoxDragAndDrop.

 

3.   ListBoxItem is the type of ObjcetModel.  The instance of ObjectModel is used as PayLoad for drag and drop operation.  So create the ObjectModel class as follows.

 

 

[C#]

 public class ObjectModel

    {

        public ObjectModel()

        {

            SubCollection = new ObservableCollection<ObjectModel>();

        }

 

        public string Name { get; set; }

        public ImageSource Icon { get; set; }

        public ObservableCollection<ObjectModel> SubCollection { get; set; }

 

     }

 

 

4.   Now create a source ListBox in the Silverlight page by using XAML as given in the following code snippet:

 

[XAML]

<ListBox  Syncfusion:DragAndDropManager.AllowDrop="True"

           ItemsSource="{Binding Path=MyProperty}" Name="Source">

 <ListBox.ItemContainerStyle>

  <Style TargetType="ListBoxItem">

   <Setter Property="Syncfusion:DragAndDropManager.AllowDrag"     

           Value="True"/>

   </Style>

 </ListBox.ItemContainerStyle>

 <ListBox.ItemTemplate>

   <DataTemplate>

     <Grid>

       <Border Background="Transparent"  MouseMove="Border_MouseMove"

               MouseLeave="Border_MouseLeave">

        <StackPanel Orientation="Horizontal">   

         <Image Source="{Binding Icon}" Width="50" Height="50"

                 Margin="10"/>

          <TextBlock Text="{Binding Name}" Margin="10"

                     VerticalAlignment="Center"/>

        </StackPanel>

       </Border>

      </Grid>

     </DataTemplate>

   </ListBox.ItemTemplate>

 </ListBox>

 

 

 

The list box items for the ListBox control are provided with Data Binding. So, Style is used to set the AllowDrag and AllowDrop properties for each list box items.

 

5.   Create the target ListBox similar to the creation of the source ListBox. This is shown in the following code snippet.

 

[XAML]

<ListBox  Syncfusion:DragAndDropManager.AllowDrop="True"

           ItemsSource="{Binding Path=MyProperty}" Name="Target">

 <ListBox.ItemContainerStyle>

  <Style TargetType="ListBoxItem">

   <Setter Property="Syncfusion:DragAndDropManager.AllowDrag"     

           Value="True"/>

  </Style>

 </ListBox.ItemContainerStyle>

 <ListBox.ItemTemplate>

   <DataTemplate>

     <Grid>

      <Border Background="Transparent">

       <StackPanel Orientation="Horizontal">   

         <Image Source="{Binding Icon}" Width="50" Height="50"

                Margin="10"/>

           <TextBlock Text="{Binding Name}" Margin="10"

                      VerticalAlignment="Center"/>

        </StackPanel>

       </Border>

      </Grid>

    </DataTemplate>

 </ListBox.ItemTemplate>

</ListBox>

 

The binding sources for the ListBox controls are given in the corresponding code behind file.

 

6.   In the  code behind file, subscribe the DragAndDropManager events as given in the following code snippet

 

[C#]

public MainPage()

 {

  InitializeComponent();

 DragAndDropManager.DragStarted += new

          DragDropEventHandler(DragAndDropManager_DragStarted);

 DragAndDropManager.Drop += new  

          DragDropEventHandler(DragAndDropManager_Drop);

 DragAndDropManager.Drag += new

           DragDropEventHandler(DragAndDropManager_Drag);

 DragAndDropManager.DropLeave += new

            DragDropEventHandler(DragAndDropManager_DropLeave);

   }

 

 

7.   Now, create the objects of ObjectModel class and add those objects into the corresponding collection for ListBoxItem data source.

 

[C#]

//create the ObjectModel instances for ListBoxItem as follows

void MainPage_Loaded(object sender, RoutedEventArgs e)

{

 MyProperty = new ObservableCollection<ObjectModel>();

 MyProperty1 = new ObservableCollection<ObjectModel>();

 ObjectModel item1 = new ObjectModel() { Name = "Recent Places",                    

       Icon = new BitmapImage(new                                   

        Uri("/ListBoxDragAndDrop;component/Images/recentplaces.png", 

              UriKind.RelativeOrAbsolute)) };

 ObjectModel item2 = new ObjectModel() { Name = "Calendar",

         Icon = new BitmapImage(new

         Uri("/ListBoxDragAndDrop;component/Images/calendar.png", 

             UriKind.RelativeOrAbsolute)) };

 MyProperty.Add(item1);

 MyProperty1.Add(item2);

}

 

Similarly, create all the list box items for the source and target ListBox controls.

 

8.   The PayLoad of the DragDropEventArgs needs to be set in DragStarted event handler. This is shown in the following code snippet.

 

[C#]

 // DragStarted event implementation

void DragAndDropManager_DragStarted(object sender, DragDropEventArgs args)

{

 if (sender is ListBoxItem)

  {

    ObjectModel obj = ((FrameworkElement)sender).DataContext as

                        ObjectModel;

    args.PayLoad = obj;

    args.DragIcon = new Image() { Source = obj.Icon };

   }

}

 

 

9.   In the Drop event handler, the dragged item is removed from the source ListBox control and added to the target ListBox control. This is shown in the following code snippet:

 

[C#]

// Drop event implementation

void DragAndDropManager_Drop(object sender, DragDropEventArgs args)

{

 ObservableCollection<ObjectModel> sourceCollection = null;

 ObservableCollection<ObjectModel> targetCollection = null;

 if (args.PayLoad is ObjectModel)

  {

    source = args.DragSource as ListBox;

    if (source != null)

     {

      sourceCollection = source.ItemsSource as

                        ObservableCollection<ObjectModel>;

     }

  if (args.DropTarget is ListBox)

   {

    destination = args.DropTarget as ListBox;

    if(destination != null)

      targetCollection = destination.ItemsSource as

                         ObservableCollection<ObjectModel>;

    }

    if (args.PayLoad != null && targetCollection != null &&

        sourceCollection != null)

     {

       sourceCollection.Remove(args.PayLoad as ObjectModel);

        targetCollection.Add(args.PayLoad as ObjectModel);

        }

     }

 }

 

10.  Now, run the sample and perform the drag and drop operation between the ListBox controls.
