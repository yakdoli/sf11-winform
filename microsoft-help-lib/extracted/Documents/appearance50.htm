Appearance

The appearance of the MenuAdv control can be changed by using the VisualStyle property. The following styles are supported by the MenuAdv control:

·      Windows7

·      Blend

·      Office2007Blue

·      Office2007Black

·      Office2007Silver

·      Office2010Blue

·      Office2010Black

·      Office2010Silver

·      Vs2010

·      Metro

 

Different visual styles can applied to the control, as shown in the following code snippet.

 

[XAML]

<shared:MenuAdv Height="25" Width="200"

shared:SkinManager.SetVisualStyle="Office2007Blue"/>

 

[C#]

SkinManager.SetVisualStyle(this,

Syncfusion.Windows.Controls.Theming.VisualStyle.Office2007Blue);
