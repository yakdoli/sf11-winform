Watermark Support

Watermark is the dummy content displayed in the DateTimeEdit control when the DateTime property is set to Null. You can set the content of Watermark using NoneDateText property.

XAML

<syncfusion:DateTimeEdit x:Name="dateTimeEdit" Height="25" Width="230" Margin="10"

                            NullValue="{x:Null}" IsEmptyDateEnabled="True"

                            NoneDateText="No date is selected"/>
