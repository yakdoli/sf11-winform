Animation Type

Window Control is shipped with the following built-in Animation types:

·      Fade

·      None

·      Horizontal Swivel

·      Vertical Swivel

·      Rotate

·      Zoom

XAML

<sync:WindowControl x:Name="windowControl"  x:Class="Samples.ExplorerDemo"

    Title="Window Demo" Icon="app.png"

    xmlns:sync="clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.Shared.Silverlight" Height="300" Width="300" AnimationType="Fade">

     <Image Source="WindowBG.jpg" Stretch="UniformToFill"/>

</sync:WindowControl>
