Prevent resizing of docking windows

 

Resizing of docking windows can be controlled in two ways:

·      Using CanResize property

·      Using FreezeLayout property

 

CanResize

By default, this property will be set to True. This allows the user to resize a window. If it is set to false, window cannot be resized. This property is used to control the resizing of a particular control.

[XAML]

 

<TextBox x:Name="textBox" syncfusion:DockingManager.Header="Text" syncfusion:DockingManager.SideInDockedMode="Top" syncfusion:DockingManager.CanResize="False" syncfusion:DockingManager.DockState="AutoHidden" syncfusion:DockingManager.WindowName="text" />

 

 

[C#]

 

DockingManager.SetCanResize(this.textBox, false);

 

FreezeLayout

When this property is set to false, we will not be able to resize any docked window. By default this will be set to True.

 

[XAML]

 

<syncfusion:DockingManager Name="dockingManager" FreezeLayout="False">

            <!--Text window is Autohidden at top-->

            <TextBox syncfusion:DockingManager.Header="Text" syncfusion:DockingManager.SideInDockedMode="Top" syncfusion:DockingManager.CanResize="False" syncfusion:DockingManager.DockState="AutoHidden" syncfusion:DockingManager.WindowName="text" />

        </syncfusion:DockingManager>

 

 

[C#]

 

this.dockingManager.FreezeLayout = false;
