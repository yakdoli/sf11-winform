Previous Month Days Foreground Color

 

You can set the foreground color for the dates that belong to the previous month by using the PreviousMonthDaysForeground property.

 

Note: This property takes effect only when you enable the ShowPreviousMonthDates property.

 

The following code example illustrates how to set this property.

 

[XAML]

 

<Syncfusion:CalendarControl x:Name=”calendarcontrol” PreviousMonthDaysForeground="DarkSlateBlue" />

 

[C#]

 

CalendarControl calendarcontrol = new CalendarControl();

calendarcontrol.PreviousMonthDaysForeground = new SolidColorBrush(Colors.DarkSlateBlue);
