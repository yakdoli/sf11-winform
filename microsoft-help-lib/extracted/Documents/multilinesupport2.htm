Multi Line Support

The Label displayed in the button can be shown in a single line or in two lines when the property IsMultiLine is set to true. The default value is true.

XAML

 

<sync:DropDownButtonAdv SizeMode="Large" IsMultiLine="False"/>

 

Figure 1075: DropDownButtonAdv control without a MultiLine

Note: This property is only applicable for Large Size Mode Buttons.
