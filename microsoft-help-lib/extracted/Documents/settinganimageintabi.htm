Setting an Image in Tab Item Header

            In this control, the Tab item header allows you to add an image with header content. We can set the image of the Tab header through xaml and code behind. When creating TabItem in xaml, refer the following code for adding image with the header.

 [Xaml]

 <syncfusion:TabControlAdv Name="MyTabCtrl"  Height="300" Width="400">
            <syncfusion:TabItemAdv Header="TabItem1" Image="/TabControl;component/Images/chart.png"  />
            <syncfusion:TabItemAdv Header="TabItem2" Image="/TabControl;component/Images/gauge.png"/>
            <syncfusion:TabItemAdv Header="TabItem3" Image="/TabControl;component/Images/grid.png" />            
        </syncfusion:TabControlAdv>
