1.1.1.1.1.1.3      Add Image to Application Menu Button

 

Images can be added to the Application Button by setting the ApplicationImage property as shown in the following code snippet:

XAML

 

<syncfusion:ApplicationMenu ApplicationButtonImage="app.png"/>

 

C#

 

ApplicationMenu applicationmenu = new ApplicationMenu() { ApplicationButtonImage

= new BitmapImage(new Uri("app.png")) };

 

Figure 518: Application Menu with Icon

1.1.1.1.1.1.4      Adding Items to the Application Menu

 

The Application Menu can be populated with Ribbon Items. Here is a code snippet which explains the adding of items into a Ribbon Application Menu.

XAML

 

<syncfusion:ApplicationMenu>

     <syncfusion:ApplicationMenu.ItemsPane>

         <syncfusion:RibbonItemsControl>

              <syncfusion:SimpleMenuButton Icon="New32.png" Label="New"/>

               <syncfusion:SimpleMenuButton Icon="Save32.png" Label="Save"/>

               <syncfusion:SimpleMenuButton Icon="Open32.png" Label="Open"/>

         </syncfusion:RibbonItemsControl>

     </syncfusion:ApplicationMenu.ItemsPane>

</syncfusion:ApplicationMenu>

 

C#

 

SimpleMenuButton itemNew = new SimpleMenuButton () { Label = "New" };

SimpleMenuButton itemOpen = new SimpleMenuButton () { Label = "Open" };

SimpleMenuButton itemSave = new SimpleMenuButton () { Label = "Save" };

SimpleMenu appMenu = new ApplicationMenu();

appMenu.ItemsPane = new RibbonItemsControl();

appMenu.ItemsPane.Items.Add(itemNew);

appMenu.ItemsPane.Items.Add(itemOpen);

appMenu.ItemsPane.Items.Add(itemSave);

myRibbon.ApplicationMenu = appMenu;

1.1.1.1.1.1.5      Adding Split Item to the Application Menu

 

Ribbon Split Items can also be added to the Application Menu. This is demonstrated in the following code snippet:

XAML

 

<syncfusion:ApplicationMenu.ItemsPane>

    <syncfusion:RibbonItemsControl>

         <syncfusion:SimpleMenuButton Icon="New32.png" Label="New"/>

         <syncfusion:SplitMenuButton Header="Save As" Icon="Save32.png">

             <syncfusion:RibbonMenuGroup  IconBarEnabled="False">

                 <syncfusion:SimpleMenuButton Label="Save as PNG" Icon="Save32.png"/>

                 <syncfusion:SimpleMenuButton Label="Save as BMP" Icon="Save32.png"/>

             </syncfusion:RibbonMenuGroup>

         </syncfusion:SplitMenuButton>

         <syncfusion:SimpleMenuButton Icon="Save32.png" Label="Save"/>

        <syncfusion:SimpleMenuButton Icon="Open32.png" Label="Open"/>

   </syncfusion:RibbonItemsControl>

</syncfusion:ApplicationMenu.ItemsPane>

1.1.1.1.1.1.6      Adding Menu Items to the Application Menu

 

Menu Items are items that are displayed on the right side pane of the Application Menu. Menu Items should be added in the Menu Items Pane property of the Application Menu. The following code snippet explains the implementation:

XAML

 

<syncfusion:ApplicationMenu.MenuItemsPane>

    <syncfusion:RibbonItemsControl Margin="10">

          <TextBlock Text="Menu Items Pane….." Margin="5"/>

          <syncfusion:RibbonSeparator Height="1" BorderThickness="1" BorderBrush="Gray" Width="200"/>

           <TextBlock Text="1. RibbonSilverlightControl.docx"/>

           <TextBlock Text="2. SyncfusionSupport.docx"/>

           <TextBlock Text="3. Syncfusion_Controls.docx"/>

           <TextBlock Text="4. RibbonWPF.docx"/>

           <TextBlock Text="5. Profile.docx"/>

     </syncfusion:RibbonItemsControl>

</syncfusion:ApplicationMenu.MenuItemsPane>

 

Figure 521: Application Menu with Menu Items

 

1.1.1.1.1.1.7      Adding System Items to the Application Menu

 

System Items are items that are added to the bottom pane of the Application Menu. System Items can be added through System Items Pane property of the Application Menu. The following code snippet explains the implementation:

XAML

 

<syncfusion:ApplicationMenu.SystemItemsPane>

     <syncfusion:RibbonItemsControl>

       <syncfusion:RibbonButton Label="Edit Options" SmallIcon="options.png" HorizontalAlignment="Right" VerticalAlignment="Center" Margin="3" BorderThickness="1" Background="#FFD2E3FA" BorderBrush="#FF5B81B3"/>

     </syncfusion:RibbonItemsControl>

</syncfusion:ApplicationMenu.SystemItemsPane>
