Skin Manager

Introduction to Skin

The Skin Manager Framework provides a convenient way to give the appealing appearance to the Silverlight controls as well as the Syncfusion controls.

Feature Summary

 

·      10 Built-In skins support for the Syncfusion controls as well as the Microsoft controls.

·      Applying Custom color for the WPF controls by setting the Single property.

·      Customizing the brushes used in Built-In-Skins.

·      Styles can be applied for dynamically added controls as well as the derived controls.

·      Overridden and Non-Overridden styles can be dynamically switched.

·      Applying and overriding styles can be done at the application level.
