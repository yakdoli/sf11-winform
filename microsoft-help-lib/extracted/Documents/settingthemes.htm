Setting Themes

 

List of predefined themes which the user can select and is applied to theme colors collection.

 

Following are the list of themes supported:

 

2.   Office Theme (Default)

 

 

3.   Gray Scale

 

 

4.   Apex

 

 

5.   Aspect

 

 

6.   Civic

 

 

7.   Equity

 

 

8.   Flow

 

 

9.   Foundary

 

 

10.  Median

 

 

11.  Metro

 

 

The following code snippet illustrates setting of themes:

 

[XAML]

 

<Syncfusion:ColorPickerPalette  Themes="Equity"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Apex"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Aspect"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Civic"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Flow"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Foundary"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Grayscale"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Median"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

<Syncfusion:ColorPickerPalette  Themes="Metro"  x:Name="ColorPicker"

< /Syncfusion:ColorPickerPalette>

 

[C#]

 

ColorPickerPalette colorPicker = new ColorPickerPalette();

colorPicker.Themes = Theme.Equity;

colorPicker.Themes = Theme.Apex;   

colorPicker.Themes = Theme.Aspect;             

colorPicker.Themes = Theme.Civic;

colorPicker.Themes = Theme.Flow;

colorPicker.Themes = Theme.Foundary;

colorPicker.Themes = Theme.Grayscale;

colorPicker.Themes = Theme.Median;

colorPicker.Themes = Theme.Metro;
