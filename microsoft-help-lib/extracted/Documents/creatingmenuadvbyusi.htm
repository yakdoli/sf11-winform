Creating MenuAdv by Using C#

Open Visual Studio.

 On the File menu, select New, and then select Project. The New Project dialog box is displayed.

 

 

Figure 914:  Creating a New Silverlight Project

 

In the New Project dialog window, select Silverlight Application, in the Name field, type the name of the project, and then click OK.

 

Figure 915: Creating a New Silverlight Application

 

In the Solution Explorer, right-click the References folder, and click Add Reference.

Add the Syncfusion.Shared.Silverlight assembly to the project References folder.

         

Figure 916: Adding Reference to the Project

 

Add the Syncfusion.Shared.Silverlight reference in XAML and C#,  as shown in the following code snippets.

 

[XAML]

xmlns:syncfusion="clr-namespace:

Syncfusion.Windows.Shared;assembly=Syncfusion.Shared.Silverlight"

 

 

 

 

 

 

[C#]

using Syncfusion.Windows.Shared;

 

 

 

Click and open C# file and add MenuAdv to application.

 

[C#]

MenuAdv menu = new MenuAdv();

LayoutRoot.Children.Add(menu);

 

MenuItemAdv file = new MenuItemAdv();

file.Header = "File";

 

MenuItemAdv edit = new MenuItemAdv();

edit.Header = "Edit";

 

MenuItemAdv newfile = new MenuItemAdv();

newfile.Header = "New";

BitmapImage img1 = new BitmapImage(new Uri

(@"/MenuControlDemo;component/Images/NewIcon.jpg",UriKind.Relative));

Image newImg = new Image();

newImg.Source = img1;

newfile.Icon = newImg;

file.Items.Add(newfile);

 

MenuItemAdv copyfile = new MenuItemAdv();

copyfile.Header = "Copy";

BitmapImage img2 = new BitmapImage(new Uri

(@"/MenuControlDemo;component/Images/CopyIcon.jpg",UriKind.Relative));

Image copyImg = new Image();

copyImg.Source = img2;

copyfile.Icon = copyImg;

file.Items.Add(copyfile);

 

MenuItemAdv cutfile = new MenuItemAdv();

cutfile.Header = "Cut";

BitmapImage img3 = new BitmapImage(new Uri

(@"/MenuControlDemo;component/Images/CutIcon.jpg", UriKind.Relative));

Image cutImg = new Image();

cutImg.Source = img3;

cutfile.Icon = cutImg;

file.Items.Add(cutfile);

 

menu.Items.Add(file);

menu.Items.Add(edit);
