Alert Window Customization

 

The alert window button text and icon can be customized using the ShowAlert(CustomWindowProperties) method.

 Use Case Scenarios

Formerly in the alert window we could use only the predefined button values and predefined dialog icons. Now, you can give the desired text value for the button, the desired icon for the window, and you can also set the template for the window.

Adding Alert Customization to an Application

The CustomWindowProperties class has the properties that support the alert window. Users can set the necessary properties and assign the CustomWidowProperties class instance to the ShowAlert() method.

 

[C#]

CustomWindowProperties properties = new CustomWindowProperties() { Message = "Hello Word!", Title ="Message", ImageSource = new BitmapImage(new Uri(imagePath, UriKind.RelativeOrAbsolute)), ClosedEventHandler = OnClosed, Animation = AnimationType.Zoom, WindowStartupLocation = Syncfusion.Windows.Tools.Controls.WindowStartupLocation.CenterScreen, TitleBarVisibility = System.Windows.Visibility.Visible};

 

properties.ButtonTexts[0] = “Button1”;

properties.ButtonTexts[1] = “Button2”;

properties.ButtonTexts[2] = “Button3”;

 

WindowControl.ShowAlert(properties);

 

 

We can provide a template for the alert window.

[C#]

CustomWindowProperties window;

System.Windows.ResourceDictionary resource = new System.Windows.ResourceDictionary();

DataTemplate template = this.Resources["template1"] as DataTemplate;

window = new CustomWindowProperties() { ContentTemplate = template};

WindowControl.ShowAlert(window);

 

The template instance can be closed by calling the method

window.Close();
