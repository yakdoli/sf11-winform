Prevent a particular window from maximizing

 

We can prevent a particular window from maximizing by setting MaximizeButtonVisible property to False or we can cancel the Maximzing event. This event will be raised when a particular window is maximizing.  The below given example checks whether the window containing TreeView is Maximizing. If so, the event will be cancelled.

 

[C#]

 

this.dockingManager.Maximizing += new MaximizingEventHandler(dockingManager_Maximizing);

 

 

void dockingManager_Maximizing(object sender, MaximizingEventArgs args)

        {

            if (args.UIElement == this.treeView)

            {

                args.Cancel = true;

            }

        }
