Customize the DragArrow

The DragArrowTemplate property in DragAndDropManager, is used to customize the DragArrow.

The following code snippet shows the customization of the DragArrow:

 

14.  Create the ControlTemplate for DragArrow in XAML as follows:

 

[XAML]

<ControlTemplate x:Key="dragArrowTemplate">

 <Grid>

  <Grid Margin="30,0,30,0">

    <Grid.ColumnDefinitions>

      <ColumnDefinition Width="*" />

      <ColumnDefinition Width="50" />

    </Grid.ColumnDefinitions>

    <Grid.RowDefinitions>

       <RowDefinition Height="*" />

       <RowDefinition Height="*" />

       <RowDefinition Height="*" />

       <RowDefinition Height="*" />

       <RowDefinition Height="*" />

    </Grid.RowDefinitions>

 

 <Canvas x:Name="Arrow50" Grid.Column="1" Grid.RowSpan="4">

  <Path x:Name="Path_18" Width="49.4867" Height="36.0052"  Stretch="Fill"

   Fill="#FF000000" Margin="0 -4 0 0"

   Data="{StaticResource customPathData}"/>

 </Canvas>

  <Border Grid.Row="1" Grid.RowSpan="5" Margin="0,0,-1,0" BorderBrush="Black"

            BorderThickness="0,1,1,1" >

  <Border.Background>

  <LinearGradientBrush EndPoint="0.5,1" MappingMode="RelativeToBoundingBox"

                       StartPoint="0.5,0">

   <GradientStop Color="LightYellow" Offset="1"/>

   <GradientStop Color="Orange"/>

    </LinearGradientBrush>

   </Border.Background>

  </Border>

  </Grid>

 </Grid>

</ControlTemplate>

 

Then the control template is assigned to the DragArrow in XAML as follows:

 

[XAML]

<ListBox  sync:DragAndDropManager.AllowDrop="True" sync:DragAndDropManager.DragArrowTemplate="{StaticResource dragArrowTemplate}">

</ListBox>

 

 

In code behind, the control template is assigned to DragArrow as follows:

 

 

[C#]             

void DragAndDropManager_DragStarted(object sender, DragDropEventArgs args)

   {

   ControlTemplate dragArrowTemplate = this.Resources["dragArrowTemplate"] as

                                      ControlTemplate;

   DragAndDropManager.SetDragArrowTemplate(this, dragArrowTemplate);

   }
