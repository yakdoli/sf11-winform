Ribbon Buttons
RibbonButton

 

The RibbonButton control is a basic button control, which is used to design complex forms and applications. Also the control is shipped with the Commanding Support, which provides compatibility in MVVM design pattern.

1.1.1.1.1.1.27     Concepts and Features

1.1.1.1.1.1.27.1  Command Binding

 

The RibbonButton control supports Commanding. The Command and Command Parameter properties enable the user to execute any action on clicking the instance.

 

XAML

 

<sync:RibbonButton SizeMode="Normal" Command="{Binding CustomCommand}" CommandParameter="CUSTOM"/>

 

 

1.1.1.1.1.1.27.2  Checkable Support

 

The RibbonButton Controls can also be used as Checkboxes, if IsCheckable property is set to true.

XAML

 

<sync:RibbonButton SizeMode="Normal" IsCheckable="True" IsChecked="True"/>

 

 

C#

 

RibbonButton button = new RibbonButton()

button.Label = "Hello World";

button.SizeMode = SizeMode.Large;

button.SmallIcon = new BitmapImage(new Uri("employee.png"));

button.IsCheckable = true;

button.IsChecked = true;

 

 

 

Figure 544: Checkable RibbonButton Control

1.1.1.1.1.1.34     How To:

1.1.1.1.1.1.34.1  disable the DropDown Popup?

 

The DropDown can be disabled by cancelling the event DropDownOpening. It is described with the help of a code snippet:

C#

 

public MainPage()

{

    InitializeComponent();

    button.DropDownOpening += new CancelEventHandler(button_DropDownOpening);

}

 

void button_DropDownOpening(object sender, System.ComponentModel.CancelEventArgs e)

{

    e.Cancel = true;

    //DropDown will not open.

}

 

1.1.1.1.1.1.34.2  Achieve StaysOpenOnClick behavior in RibbonDropDownButton?

 

The DropDown can stay open, when we cancel the DropDownClosing event.

C#

 

public MainPage()

{

     InitializeComponent();

     button.DropDownClosing += new CancelEventHandler(button_DropDownClosing);

}

 

void button_DropDownClosing(object sender, System.ComponentModel.CancelEventArgs e)

{

     e.Cancel = true;

     //DropDown will not close.

}

RibbonSplitButton button = new RibbonplitButton();

RibbonMenuItem menuItem2 = new RibbonMenuItem();

RibbonMenuItem menuItem3 = new RibbonMenuItem();
