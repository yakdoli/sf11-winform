Binding Support

Data binding is the process of establishing connection between application UI and business logic. Data binding can be unidirectional (source -> target or target <- source), or bidirectional (source <-> target). User can bind the data to DoubleTextBox through Value property.

 

The following example shows a simple binding between value of DoubleTextBox and another DoubleTextBox value that reflects the typed value:

 

XAML

<StackPanel>

    <syncfusion:DoubleTextBox x:Name="doubleTextBox1" Width="150" Margin="10"/>

    <syncfusion:DoubleTextBox x:Name="doubleTextBox2" Width="150" Margin="10"

                Value="{Binding ElementName=doubleTextBox1,Path=Value,Mode=TwoWay}"/>

</StackPanel>

The Data Context property inherits its value to child elements. So you can set the Data Context on a superior layout container and its value is inherited to all child elements. This is very useful if you want to build a form that is bound to multiple properties of the same data object. If you don't explicitly define a source of a binding, it takes the data context by default.

 

XAML

<StackPanel DataContext="{StaticResource myCustomer}">

    <TextBox Text="{Binding FirstName}"/>

    <TextBox Text ="{Binding LastName}"/>

    <syncfusion:DoubleTextBox Value="{Binding Phone}"/>

    <syncfusion:DoubleTextBox Value="{Binding Income}"/>

</StackPanel>

 

If you want to bind other than double types, you must use Value Converter. The following example shows a simple binding between the value of DoubleTextBox and Textbox text that reflects the typed value:

 

XAML

<StackPanel>

    <StackPanel.Resources>

        <c:StringToDoubleConverter x:Key="stringToDoubleConverter"/>

    </StackPanel.Resources>

   

    <syncfusion:DoubleTextBox x:Name="doubleTextBox" Width="150" Margin="10"/>

    <TextBox x:Name="textBox" Width="150" Margin="10" Text="{Binding

             ElementName=doubleTextBox,Path=Value,Mode=TwoWay,

             Converter={StaticResource stringToDoubleConverter}}"/>   

</StackPanel>
