Adding Overview Control to an Application

 

Follow the below steps to add the Overview Control.

 

1.   Host the content within the OverviewContentHolder instead of ScrollViewer as given in the following code:

 

[XAML]

<ScrollViewer Name="SourceAncestor">

            <syncfusion:OverviewContentHolder>

               <!—The content should be placed here -->

            </syncfusion:OverviewContentHolder>

        </ScrollViewer>

 

 

 

2.   Create an instance of Overview and set the OverviewSourceAncestor property   to OverviewContentHolder or one of its visual parent as given in the following code:

 

[XAML]

 

<syncfusion:Overview OverviewSourceAncestor="{Binding ElementName=SourceAncestor}"/>
