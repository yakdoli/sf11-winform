Drop Direction

The DropDown Direction can be changed by using the property DropDirection. The Enum takes the following values. The default value is BottomLeft.

·      Left

·      Right

·      BottomLeft

·      BottomRight

·      TopLeft

·      TopRight

 

 

XAML

 

<sync:DropDownButtonAdv  DropDirection="BottomLeft"/>

XAML

 

<sync:DropDownButtonAdv  DropDirection="BottomRight"/>

<sync:DropDownButtonAdv  DropDirection="Right"/>
