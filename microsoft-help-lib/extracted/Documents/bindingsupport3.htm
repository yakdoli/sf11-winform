Binding Support

Data binding is the process of establishing connection between application UI and business logic. Data binding can be unidirectional (source to target), or bidirectional (source to target and target to source). You can bind the data to PercentTextBox through Value property.

 

The following example shows a simple binding between the PercentValue of PercentTextBox and another PercentTextBox PercentValue that reflects the typed value:

 

[XAML]

 

<StackPanel>

    <syncfusion:PercentTextBox x:Name="percentTextBox1" Width="150" Margin="10"/>

    <syncfusion:PercentTextBox x:Name="percentTextBox2" Width="150" Margin="10" 

                     PercentValue="{Binding ElementName=percentTextBox1,

                     Path=PercentValue,Mode=TwoWay}"/>

</StackPanel>

The Data Context property inherits its value to child elements. So you can set the Data Context on a superior layout container and its value is inherited to all child elements. This is very useful if you want to build a form that is bound to multiple properties of the same data object. If you don't explicitly define a source of a binding, it takes the data context by default.

 

[XAML]

 

<StackPanel DataContext="{StaticResource myCustomer}">

    <TextBox Text="{Binding FirstName}"/>

    <TextBox Text ="{Binding LastName}"/>

    <syncfusion:PercentTextBox PercentValue="{Binding Phone}"/>

    <syncfusion:PercentTextBox PercentValue="{Binding Income}"/>

</StackPanel>

 

 

                If you want to bind other than double types, you must use Value Converter. The following example shows a simple binding between the PercentValue of PercentTextBox and Textbox text that reflects the typed value:

[XAML]

 

<StackPanel>

    <StackPanel.Resources>

        <c:StringToDoubleConverter x:Key="stringToDoubleConverter"/>

    </StackPanel.Resources>

    <syncfusion:PercentTextBox x:Name="percentTextBox" Width="150" Margin="10"/>

    <TextBox x:Name="textBox" Width="150" Margin="10" Text="{Binding

        ElementName= percentTextBox,Path=PercentValue,Mode=TwoWay,

        Converter={StaticResource stringToDoubleConverter}}"/>

</StackPanel>
