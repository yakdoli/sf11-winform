Data Binding

The CheckedListBox control provides a rich DataBinding support that allows users to fill the CheckedListBox items using Collections.

 

Use Case Scenarios

This Feature will be useful when you want to bind the data from the collections or from the database by setting the ItemsSource property of the CheckeddListBox as Collections or DataSet.Not applicable.

 

Adding Data Binding Feature to an Application

The following code example explains the addition of the Data Binding feature to the application.

 

[XAML]

<sync:CheckedListBox Mode="RadioGroup" x:Name="CKBox" 

       ItemsSource="{Binding ElementName=CHKLSTBOX, Path=MyProperty}"

       Height="200" Width="150" Background="LightGray"

       BorderBrush="DarkGray" BorderThickness="2">

       <sync:CheckedListBox.ItemTemplate>      

           <DataTemplate>

               <StackPanel>

                    <TextBlock Text="{Binding Name}"/>

               </StackPanel>                   

           </DataTemplate>

       </sync:CheckedListBox.ItemTemplate>           

</sync:CheckedListBox>

 

[C#]

 

     public ObservableCollection<BusinessObject> MyProperty

     {

            get;

            set;

     }

 

     MyProperty = new ObservableCollection<BusinessObject>();

     MyProperty.Add(new BusinessObject() { Name = "Argentina" });

     MyProperty.Add(new BusinessObject() { Name = "Brazil" });

     MyProperty.Add(new BusinessObject() { Name = "Germany" });

     MyProperty.Add(new BusinessObject() { Name = "England" });

     MyProperty.Add(new BusinessObject() { Name = "France" });

 

    public class BusinessObject

    {

        public BusinessObject()

        { }

        public string Name

        {

            get;

            set;

        }

    }
