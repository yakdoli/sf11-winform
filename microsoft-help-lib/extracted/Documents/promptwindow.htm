Prompt Window

The Prompt allows the user to get input from the end user. The Prompt Window can be shown by calling a static method ShowPrompt(). The method will take the following arguments:

·      Message

·      Title

·      Prompt Text

·      DialogIcon

·      DialogButton

·      ClosedEventHandler

·      AnimationType

C#

WindowControl.ShowPrompt("Enter the text:", "Prompt");

 

Figure 1091: Prompt

C#

WindowControl.ShowPrompt("Enter the text:", "Prompt", "Input", DialogIcon.Question, DialogButton.OKCancel, null, AnimationType.Fade);

 

Figure 1092: Input

C#

WindowControl.ShowPrompt("Enter the text:", "Prompt", "Input", DialogIcon.Question, DialogButton.OKCancel, new ClosedEventHandler(OnClosed), AnimationType.Fade);
