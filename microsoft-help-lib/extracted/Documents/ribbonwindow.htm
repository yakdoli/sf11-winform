1.1.1.1.1.1.62     RibbonWindow Position

The position of the RibbonWindow can be controlled by the user by setting the property. WindowStartUpLocation. The Enum takes the following values:

·      CenterScreen – RibbonWindow will appear at the center of the screen.

·      Manual - The location of the window can be controlled by Top and Left properties.

The property can be set as follows:

1.1.1.1.1.1.62.1  Center Screen

XAML

 

<syncfusion:RibbonWindow x:Name="windowControl"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        x:Class="RibbonSample.RibbonWindowControl"
    WindowStartupLocation="CenterScreen"
    xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.Ribbon.Silverlight"

Height="465" Width="800">
   <syncfusion:Ribbon HorizontalAlignment="Left" IsInRibbonWindow="True">
      <syncfusion:RibbonTab Caption="Home">
            <syncfusion:RibbonBar Header="Clipboard">
            <syncfusion:RibbonSplitButton SizeMode="Small" />
        </syncfusion:RibbonBar>
      </syncfusion:RibbonTab>
      </syncfusion:Ribbon>
</syncfusion:RibbonWindow>

 

C#

 

RibbonWindowControl window = new RibbonWindowControl() { Height = 465, Width = 800 };
window.WindowStartupLocation = Syncfusion.Windows.Tools.Controls.WindowStartupLocation.CenterScreen;
var ribbon = new Ribbon();
window.Content = ribbon;
var ribbontab = new RibbonTab() { Caption ="Home" };
ribbon.Items.Add(ribbontab);
var ribbonbar = new RibbonBar() { Header = "Clipboard" };
ribbontab.Items.Add(ribbonbar);
ribbonbar.Items.Add(new RibbonSplitButton() { SizeMode = SizeMode.Small });
window.Show();

 

 

Figure 617: RibbonWindow appears in the Center of the Screen

1.1.1.1.1.1.62.2  Manual

<syncfusion:RibbonWindow x:Name="windowControl"

var ribbonbar = new RibbonBar() { Header = "Clipboard" };
ribbontab.Items.Add(ribbonbar);
ribbonbar.Items.Add(new RibbonSplitButton() { SizeMode = SizeMode.Small });
window.Show();

1.1.1.1.1.1.64     Resize Mode

The Resizing capability of the RibbonWindow Control can be controlled using the ResizeMode property. The Enumeration takes the following values:

·      CanResize

·      NoResize

·      CanResizeWithGrip

·      CanMinimize

·      CanMaximize

1.1.1.1.1.1.64.1  CanResize

This is the default Resize Mode of the RibbonWindow Control. Setting this value enables the user to resize the RibbonWindow Control in all aspects.

XAML

 

<syncfusion:RibbonWindow x:Name="windowControl"
   xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
   xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
   x:Class="RibbonSample.RibbonWindowControl" ResizeMode="CanMinimize"

   xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.Ribbon.Silverlight" 

   Height="450" Width="800">
 </syncfusion:RibbonWindow>

 

C#

 

RibbonWindowControl window = new RibbonWindowControl() { Height = 350, Width = 400 };
window.ResizeMode = ResizeMode.CanResize;

 

 

Figure 620: Resizable RibbonWindow Control

Setting this value disables the Resizing behavior of RibbonWindow Control.

   xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"

   xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.Ribbon.Silverlight"

 </syncfusion:RibbonWindow>

1.1.1.1.1.1.65     Window State

The state of the windows can be controlled by the property WindowState. The Enum takes the following values:

·      Normal

·      Minimized and

·      Maximized

1.1.1.1.1.1.65.1  Normal

This is the default state of the RibbonWindow.

XAML

 

<sync:RibbonWindow x:Name="RibbonWindowControl"  

    x:Class="Syncfusion.RibbonWindowControl"

    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"  

    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"

    Title="Ribbon Window Demo"

    WindowStartupLocation="CenterScreen" ResizeMode="CanMaximize"

    xmlns:sync="clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.Ribbon.Silverlight" Height="465" Width="800" WindowState="Normal">

</sync:RibbonWindow>

 

C#

 

RibbonWindowControl window = new RibbonWindowControl();

window.Title = "Ribbon Window Demo";

window.WindowStartupLocation = Syncfusion.Windows.Tools.Controls.WindowStartupLocation.CenterScreen;

window.ResizeMode = ResizeMode.CanMaximize;

window.WindowState = Syncfusion.Windows.Tools.Controls.WindowState.Normal;

 

 

Figure 624: A normal RibbonWindow Control
