Creating MenuAdv by Using XAML

To create MenuAdv by using VisualStudio in XAML:

1.   In Visual Studio, create a new Silverlight application.

3.   In the Visual Studio Toolbox, click the Syncfusion Silverlight Toolbox tab, and then select MenuAdv.

 

 

Figure 918: Select MenuAdv from Toolbox

 

To add MenuAdv to the application, drag MenuAdv to design View.

In the Properties window, customize the properties of MenuAdv.

[XAML]

 

<shared:MenuAdv x:Name="Menu">

                <shared:MenuItemAdv Header="File">

                    <shared:MenuItemAdv Header="New">

                        <shared:MenuItemAdv.Icon>

                            <Image Source="/MenuControlDemo;component/Images/NewIcon.jpg"/>

                        </shared:MenuItemAdv.Icon>

                    </shared:MenuItemAdv>

                    <shared:MenuItemAdv Header="Copy">

                        <shared:MenuItemAdv.Icon>

                            <Image Source="/MenuControlDemo;component/Images/CopyIcon.jpg"/>

                        </shared:MenuItemAdv.Icon>

                    </shared:MenuItemAdv>

                    <shared:MenuItemAdv Header="Cut">

                        <shared:MenuItemAdv.Icon>

                            <Image Source="/MenuControlDemo;component/Images/CutIcon.jpg"/>

                        </shared:MenuItemAdv.Icon>

                    </shared:MenuItemAdv>

                </shared:MenuItemAdv>

                <shared:MenuItemAdv Header="Edit"/>

</shared:MenuAdv>
