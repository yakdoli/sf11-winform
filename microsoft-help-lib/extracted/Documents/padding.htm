Padding

 

The Padding property specifies the padding values for the control. This property is of type Thickness, which accepts four values, specifying the padding value for Left, Top, Right and Bottom. The following code snippet illustrates this.

 

[XAML]

 

<Syncfusion:TaskBar Margin="10" GroupOrientation="Horizontal"  x:Name="taskbar1" BorderThickness="5" FlowDirection="LeftToRight" HorizontalAlignment="Center" VerticalAlignment="Center">

<Syncfusion:TaskBarItem  x:Name="item1" HeaderHeight="35" Padding = "10,10,10,10" Header="System Tasks">

<Syncfusion:TaskBarItem.Content>

<StackPanel Margin="10">

<TextBlock Text="View System Information" Foreground="Black" Margin="9,5,0,5" FontWeight="Normal" FontFamily="Segoe UI"/>

<TextBlock Text="Add or Remove Programs" Foreground="Black" Margin="5,5,0,5" FontWeight="Normal" FontFamily="Segoe UI"/>

</StackPanel>

</Syncfusion:TaskBarItem.Content>

</Syncfusion:TaskBarItem>

<Syncfusion:TaskBar>

TaskBar taskBar = new TaskBar();
