Background Color

 

You can set the background color for the CalendarControl by using the Background property. The following code example illustrates how to set this property.

 

[XAML]

 

<Syncfusion:CalendarControl x:Name=”calendarcontrol” Background="RoyalBlue" />

 

[C#]

 

CalendarControl calendarcontrol = new CalendarControl();

calendarcontrol.Background = new SolidColorBrush(Colors.RoyalBlue);
