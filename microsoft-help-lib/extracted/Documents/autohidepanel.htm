Autohide Panel

 

DockingManager provides Autohide facility to the docked control. When the Autohide button or Awl button is clicked, the docked control will be hidden.It will be placed along the side (where the control is docked before auto hiding) of the container control on which it was placed. When mouse is moved over it, the auto hidden control will be displayed. The control will restore its appearance when the auto hidden button is clicked again.

A window can be made Autohidden through XAML, c# code or by Mouse. If we set DockState property to Autohidden, window will be autohidden.

 

 A window can also be autohidden by selecting AutoHide from menu button options as shown in the below figure,

 

Figure 88: Docking Menu Containing Auto Hide Option

 

Following is a sample code that illustrates how Autohidden window can be created.

 

[XAML]

 

<UserControl x:Class="Sample.MainPage"

    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"

    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"

    xmlns:d="http://schemas.microsoft.com/expression/blend/2008" xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006" xmlns:syncfusion="clr-namespace:Syncfusion.Windows.Tools.Controls;assembly=Syncfusion.DockingManager.Silverlight"

             xmlns:system="clr-namespace:System.Windows.Controls;assembly=System.Windows.Controls"

    mc:Ignorable="d" d:DesignWidth="640" d:DesignHeight="480">

    <Grid x:Name="LayoutRoot">

        <syncfusion:DockingManager Name="dockingManager">

            <system:TreeView syncfusion:DockingManager.Header="Solution Explorer" syncfusion:DockingManager.SideInDockedMode="Right" syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.WindowName="solutionexplorer" syncfusion:DockingManager.DesiredWidthInDockedMode="150">

                </system:TreeView>

            <!--Text window is Autohidden at top-->

            <TextBox syncfusion:DockingManager.Header="Text" syncfusion:DockingManager.SideInDockedMode="Top" syncfusion:DockingManager.DockState="AutoHidden" syncfusion:DockingManager.WindowName="text" />

            <!-- Find Results is Autohidden at bottom-->

            <ContentControl syncfusion:DockingManager.DockState="AutoHidden" syncfusion:DockingManager.Header="Find Results" syncfusion:DockingManager.SideInDockedMode="Bottom"  syncfusion:DockingManager.WindowName="findresults"/>

            <ListBox syncfusion:DockingManager.DockState="Dock" syncfusion:DockingManager.Header="Properties" syncfusion:DockingManager.SideInDockedMode="Top" syncfusion:DockingManager.DesiredHeightInDockedMode="200"/>

            <!-- Help window is Autohidden at Left-->

            <ContentControl syncfusion:DockingManager.DockState="AutoHidden" syncfusion:DockingManager.Header="Help" syncfusion:DockingManager.SideInDockedMode="Left"  syncfusion:DockingManager.WindowName="help"/>

            <!-- Find window is Autohidden at Right-->

            <ContentControl syncfusion:DockingManager.DockState="AutoHidden" syncfusion:DockingManager.Header="Find" syncfusion:DockingManager.SideInDockedMode="Right"  syncfusion:DockingManager.WindowName="find"/>

        </syncfusion:DockingManager>

    </Grid>

</UserControl>
