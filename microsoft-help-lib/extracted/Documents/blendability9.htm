Blendability

The Button Controls can be easily edited by using Expression Blend. The steps to edit the Button Controls by using Expression Blend are as follows:

·      Open the Sample in Expression Blend. Right-click the Button Control and select the Edit Template option, as shown below.

Figure 1006: Editing the style by using Expression Blend

 

·      A window will appear as shown below. Click OK, to create a new style for the Button Control.

Figure 1007: Style Resource window

·      All the resources will be displayed on the resources pane in the right side of the design area. These resources can be edited to create a new style.
