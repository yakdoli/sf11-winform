Background Color

 

You can set the background color for the selected CheckBoxList Item by using the SelectedItemBackground property. Also you can set the background color of the CheckedListBox Item over which the mouse pointer rests by using the MouseOverBackground property.

 

The following code example illustrates how to set these properties.

 

[XAML]

 

<syncfusion:CheckedListBox Name="checklistbox" SelectedItemBackground="Violet" MouseOverBackground="SteelBlue" Height="350" Width="200" >

    <syncfusion:CheckedListBoxItem Content="Mexico" LeftImageSource="mexico.jpg" />

    <syncfusion:CheckedListBoxItem Content="Canada" LeftImageSource="canada.jpg"/>

</syncfusion:CheckedListBox>

 

[C#]

 

CheckedListBox checkedlistbox = new CheckedListBox();

CheckedListBoxItem checkeditem = new CheckedListBoxItem();

checkeditem.Content = "Silverlight";

 

checklistbox.Items.Add(checkeditem);

checklistbox.SelectedItemBackground = new SolidColorBrush(Colors.Blue);

checklistbox.MouseOverBackground = new SolidColorBrush(Colors.Gray);

grid.Children.Add(checkedlistbox);
