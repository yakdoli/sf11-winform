Negative Foreground

The foreground of the IntegerTextBox can be customized based on the Value property. When a negative value is assigned to the Value property, the NegativeForeground value is assigned to Foreground property.

Note: The NegativeForeground in integer textbox could be enabled by setting ApplyNegativeForeground property to true.

 

[XAML]

 

<syncfusion:IntegerTextBox x:Name="integerTextBox" Width="150" Height="25" Value="-123"

                           ApplyNegativeForeground="True" NegativeForeground="Red"/>
