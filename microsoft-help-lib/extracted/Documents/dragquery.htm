DragQuery

This vent is triggered when Draged over nodes.

TreeViewAdvDragEventArgs

 

·      You can cancel Dragging using the Handled property of TreeViewAdvDragEventArgs.

·      Source property in TreeViewAdvDragEventArgs represents the list of TreeViewItemAdvs selected.

·      SourceParentTreeViewItem property in TreeViewAdvDragEventArgs represents the parent TreeViewItems of the selected TreeViewItem’s.

·      The Target property in TreeViewAdvDragEventArgs represents the current mouse over item.

·      TargetParentTreeViewItem in TreeViewAdvDragEventArgs represents the parent tree view item of Target.

·     

[XAML]

<syncfusion:TreeViewAdv x:Name="treeview" FullRowSelect="True" BorderBrush="Black"  BorderThickness="1"

                Height="400" Width="300" DraggingEnabled="True" DragQuery="treeview_DragQuery">

    </syncfusion:TreeViewItemAdv>
