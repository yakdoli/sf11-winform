Blendability

You can Customize ContextMenu in Blend. Add ContextMenuAdv to the design view without setting the ContextMenuAdvService attached property. Now you can see ContextMenuAdv in Object and Timelines Tap in the design view.

 

Figure 893: Object and Timeline

Figure 894: Design View

 

1.   Right-click the ContextMenuItemAdv and click the Edit Template option.

Figure 895: Object and Timeline

2.   On the window, provide the Style name and click OK.

Figure 896: Create Style Resource

 

 

Now you can customize each part in the ContextMenuItemAdv Template.

In the following example, the Mouse Over effects for ContextMenuItemAdv are changed.

[XAML]

 

<Rectangle x:Name="Bg" Opacity="0" RadiusY="2" RadiusX="2" Stroke="#FFBCD6F6" StrokeThickness="1">

    <Rectangle.Fill>

        <LinearGradientBrush EndPoint="0.5,1" StartPoint="0.5,0">

            <GradientStop Color="#FFC6EC90" Offset="0"/>

            <GradientStop Color="#FFE6EDF6" Offset="0.807"/>

            <GradientStop Color="#FFC1E391" Offset="0.993"/>

            <GradientStop Color="#FFEDF1F6" Offset="0.247"/>

        </LinearGradientBrush>

    </Rectangle.Fill>

</Rectangle>

 

[XAML]

 

        <VisualStateGroup x:Name="FocusStates">

            <VisualState x:Name="Unfocused"/>

            <VisualState x:Name="Focused">

                <Storyboard>

                    <DoubleAnimation Duration="0" To="1" Storyboard.TargetProperty="Opacity" Storyboard.TargetName="Bg"/>

                    <ColorAnimation Duration="0" To="#40FFFFFF" Storyboard.TargetProperty="(Shape.Stroke).(SolidColorBrush.Color)" Storyboard.TargetName="InnerBorder"/>

                </Storyboard>

            </VisualState>

        </VisualStateGroup>

 

Now, add the ContextMenuAdv inside the ContextMenuAdvService attached property.

[XAML]

 

<shared:ContextMenuAdvService.ContextMenuAdv>

     

</shared:ContextMenuAdvService.ContextMenuAdv>
