TaskBar

 

 TaskBar control allows to create collapsible panels that can be used to host a collection of command items or snippets of information pertaining to the current context.

 

 

Figure 393: TaskBar Control

 

Feature Summary

 

·      FlowDirection: specifies the flow direction of the control

·      IsHeaderShown: specifies whether the header part of the control is visible or not

·      IsExpanded: specifies whether content part of the control is expanded or not

·      HeaderHeight: specifies the height for the header part of the control

·      Padding: specifies the padding values for the control

·      Arrow Style: specifies the style for the arrows displayed in the header part of the control

·      SkinManager: specifies the visual style for the control
