Zero Color

The Foreground of the CurrencyTextBox can be customized based on the Value property. When Zero is assigned as value to Value property, then automatically the ZeroColor sets to Foreground property.

 

Note: The ZeroColor in CurrencyTextBox could be enabled by setting ApplyZeroColor property to true.

 

 

XAML

<syncfusion:CurrencyTextBox x:Name="currencyTextBox" Height="25" Width="150"

                            CornerRadius="2" Value="0" ZeroColor="Magenta"

                            ApplyZeroColor="True"/>
