Prevent the drop of an object into/on an unsupported element manually at runtime

 

You can prevent the drop of an object into an unsupported element by setting the drag operation status to “Impossible”. This is explained in the following code snippet:

 

[C#]

void DragAndDropManager_DropEnter(object sender, DragDropEventArgs args)

   {

    if (sender is Panel)

     {

     if (args.PayLoad is Directory)

      {

         args.Status = Status.Impossible;

      }

     }

  }
