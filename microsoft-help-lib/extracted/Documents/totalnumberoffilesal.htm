Total Number of Files Allowed

 

1.   Create a new folder in Web project (for eg: UploadedFiles).

2.   Add the HttpHandler file (for eg: FileUploadUrlspecifier.ashx).

 

Following are the codes should be added into the ProcessRequest() of this handler file.

 

[C#]

 

string uploadfilepath = httpcontext.Server.MapPath("~/UploadedFiles");

HttpHandlerHelperClass fileUpload = new HttpHandlerHelperClass();

fileUpload.HandleRequest(httpcontext, uploadfilepath);

 

Note: Here UploadedFiles is the folder where all the uploaded files are saved.
