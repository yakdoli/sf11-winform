Header Properties

 

This section provides information on the following topics:

 

Background Color

 

You can set the background color for the header of the GroupBar by using the HeaderBackground property. The following code example illustrates how to set this property.

 

[XAML]

 

<syncfusion:GroupBar x:Name="groupbar" Width="250" VisualMode="StackMode" Height="450" Orientation="Vertical" >

<syncfusion:GroupBarItem x:Name="groupbaritem"  HeaderBackground="White" HeaderText="Groupbaritem" >              

<Grid>

<TextBlock Text="TextBlock" />

</Grid>

</ syncfusion:GroupBarItem>

</syncfusion:GroupBar>

 

[C#]

 

GroupBar groupbar = new GroupBar();

groupbar.Width = 200;

groupbar.Height = 200;

groupbar.VisualMode = VisualMode.StackMode;

groupbar.Orientation = Orientation.Vertical;

GroupBarItem groupbaritem = new GroupBarItem();

groupbaritem.HeaderText = "Groupbaritem";

groupbaritem.HeaderBackground = new SolidColorBrush(Colors.Black);

Grid grid = new Grid();

TextBlock tb = new TextBlock();

tb.Text = "Content";

grid.Children.Add(tb);

groupbaritem.Content = grid;

groupbar.Items.Add(groupbaritem);

LayoutRoot.Children.Add(groupbar);

Text Horizontal Alignment

 

You can set the horizontal alignment for the header text of the GroupBar control by using the TextHorizontalAlignment property. It includes the following options.

 

·      Left

·      Right

·      Center

·      Stretch

 

The following code example illustrates how to set this property.

 

[XAML]

 

<syncfusion:GroupBar x:Name="groupbar" VisualMode="StackMode" Height="450" Orientation="Vertical"  >

    <syncfusion:GroupBarItem x:Name="groupbaritem" HeaderText="Groupbar item" TextHorizontalAlignment="Left">

       <Grid>

          <TextBlock Text="TextBlock" />

       </Grid>

</syncfusion:GroupBarItem>

</syncfusion:GroupBar>

 

[C#]

 

GroupBar groupbar = new GroupBar();

groupbar.Width = 200;

groupbar.Height = 200;

groupbar.VisualMode = VisualMode.StackMode;

groupbar.Orientation = Orientation.Vertical;

GroupBarItem groupbaritem = new GroupBarItem();

groupbaritem.HeaderText = "Groupbaritem";

Grid grid = new Grid();

TextBlock tb = new TextBlock();

tb.Text = "Content";

grid.Children.Add(tb);

groupbaritem.Content = grid;

groupbaritem.TextHorizontalAlignment = HorizontalAlignment.Right;

groupbar.Items.Add(groupbaritem);

LayoutRoot.Children.Add(groupbar);
