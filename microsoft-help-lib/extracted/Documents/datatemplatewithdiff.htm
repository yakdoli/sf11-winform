DataTemplate with Different DataTypes

This feature allows you to bind different data type to the data template and apply visual appearance to the data type object.

 

Use Case Scenarios

This feature can be used when you want to bind data from different object to the data template.

 

Adding DataTemplate with Different DataTypes to an Application

The following code example illustrates how to add the DataTemplate with Different DataTypes feature to the Application through XAML.

 

[XAML]

 

<syncfusion:TileViewControl x:Name="TileView1"

         ItemsSource="{Binding TileViewItemData, ElementName=Tile}"

         HeaderTemplate="{Binding Source={StaticResource header}}">

<syncfusion:TileViewControl.ItemTemplate>

     <DataTemplate>

          <local:DataTemplateSelector Content="{Binding}">

              <local:DataTemplateSelector.Resources>

                <DataTemplate x:Key="Data">

                  <StackPanel Orientation="Vertical">

                    <StackPanel Orientation="Horizontal">

                      <TextBlock Text="Name :" FontFamily="Trebuchet MS"

                                 Foreground="Brown" FontSize="14"/>

                      <TextBlock Text="{Binding Name}" Foreground="Brown"

                                 FontFamily="Trebuchet MS" FontSize="14"/>

                    </StackPanel>

                    <StackPanel Orientation="Horizontal">

                      <TextBlock Text="Age :" FontFamily="Trebuchet MS"

                                 Foreground="Brown" FontSize="14"/>

                      <TextBlock Text="{Binding Age}" Foreground="Brown"

                                 FontFamily="Trebuchet MS" FontSize="14"/>

                    </StackPanel>

                    <StackPanel Orientation="Horizontal">

                      <TextBlock Text="Dept :" FontFamily="Trebuchet MS"

                                 Foreground="Brown" FontSize="14"/>

                      <TextBlock Text="{Binding Dept}" Foreground="Brown"

                                 FontFamily="Trebuchet MS" FontSize="14"/>

                    </StackPanel>

                  </StackPanel>

                 </DataTemplate>

                 <DataTemplate x:Key="Details">

                   <StackPanel Orientation="Vertical">

                     <StackPanel Orientation="Horizontal">

                       <TextBlock Text="Name :" FontFamily="Trebuchet MS"

                                  Foreground="Blue" FontSize="14"/>

                       <TextBlock Text="{Binding Name}" Foreground="Blue"

                                  FontFamily="Trebuchet MS" FontSize="14"/>

                     </StackPanel>

                     <StackPanel Orientation="Horizontal">

                       <TextBlock Text="Department :" Foreground="Blue"

                                  FontFamily="Trebuchet MS" FontSize="14"/>

                       <TextBlock Text="{Binding Dept}" Foreground="Blue"

                                  FontFamily="Trebuchet MS" FontSize="14"/>

                     </StackPanel>

                     <StackPanel Orientation="Horizontal">

                       <TextBlock Text="Designation :" Foreground="Blue"

                                  FontFamily="Trebuchet MS" FontSize="14"/>

                       <TextBlock Text="{Binding Desig}" Foreground="Blue"

                                  FontSize="14" FontFamily="Trebuchet MS"/>

                     </StackPanel>

                     <StackPanel Orientation="Horizontal">

                       <TextBlock Text="Experience :" Foreground="Blue"

                                  FontFamily="Trebuchet MS" FontSize="14"/>

                       <TextBlock Text="{Binding Exp}" Foreground="Blue"

                                  FontFamily="Trebuchet MS" FontSize="14"/>

                     </StackPanel>

                   </StackPanel>

                 </DataTemplate>

              </local:DataTemplateSelector.Resources>

          </local:DataTemplateSelector>

      </DataTemplate>

</syncfusion:TileViewControl.ItemTemplate>

</syncfusion:TileViewControl>
