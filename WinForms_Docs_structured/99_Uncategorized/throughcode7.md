[] 

To create the control programmatically:

[] 

1.   Add the following namespaces to the code behind the file.

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                   |
|                                                                                                                                                                                    |

| [using][ Syncfusion.Web.UI;]                                  |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                     |
|                                                                                                                                                                                      |

|                                                                                                                                                                                      |

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

10.  Instantiate the Captcha control, and add it to the page to display it.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                     |
|                                                                                                                                                                                                                      |

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

11.  Add the following httpHandlers to the Web.Config file, to generate image on the fly. When the dlls are referred from the GAC, the version must be specified.

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[Web.Config\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [\<][httpHandlers][\>]                                                                                                                                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [\<][add][ [path][=\"Captcha.axd\"] [verb][=\"\*\"] [type][=\"Syncfusion.Web.UI.WebControls.Tools.CaptchaControl.ImageCaptchaHandler,Syncfusion.Tools.Web, Version=X.X.X.X, Culture=neutral, PublicKeyToken=3d67ed1f87d44c89\"] [/\>]] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [\</][httpHandlers][\>]                                                                                                                                                                                                                                                                                                                                                   |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 


[{border="0"}]Note: You might have to change the version number in the tags to whatever version you are linking to.


[]
