### TreeView {#treeview style="tab-stops: 0pt"}

[] 

TreeView control provides a highly customizable object model for rendering hierarchical tree structure that lets you create a wide range of look-and-feel and behavior for the control. Some powerful features includes, ability to nest any ASP.NET control, comprehensive client side object models, keyboard control, node editing and load on demand using AJAX.

The TreeView control has a wide variety of features that enhances the creation of rich web interface with hierarchical tree structures. The core features of the control are as follows.

[] 

[·      ]**Nesting Content**: ability to nest custom ASP.NET content

[·      ]**Client side object model**: effectively integrated client side object models enables feature rich application development

[·      ]**Keyboard support**: ability to navigate using the keyboard

[·      ]You can navigate through the nodes and also expand / collapse the nodes.

[·      ]**Node Editing**: provides support to edit the node text just by clicking a selected node

[·      ]**Check-box support**: enables you to easily add a checkbox to each node

[·      ]**Css Customization**: enables you to customize fonts, colors and other style information for individual node

[·      ]Each node can have separate css class for hover, select and default.

[·      ]**Transition Effect**: provides support to set transition and visual effects to treeview.

[·      ]**Multiple instances on a single page**: allows the use of multiple treeviews per page, reusing a single code library for faster development and speed on the client

[·      ]**Load-on-demand**: enables to create tree nodes dynamically on demand and load the tree structure with Ajax enabled callback support

[·      ]**Drag-and-drop**: supports drag-and-drop functionality

[·      ]You could drag and drop the nodes inside the control or between 2 or more TreeView controls.

[·      ]**Context Menu**: context menu can be added for every treeview node or for the entire control

[·      ]Also, custom styles can be applied effectively.
