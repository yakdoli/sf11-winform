#### Custom Template for Restore Button {#custom-template-for-restore-button style="tab-stops: 0pt"}

ChromelessWindow enables you to write your own template for the []{#DDE_LINK2}**Restore** button in the TitleBar. **RestoreButtonTemplate** property is used to apply the template for the Restore button.

 

To set the RestoreButtonTemplate property, use the below code

|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| [\<][shared][:][ChromelessWindow][ x][:][Class][=\"TestChromeless.Window1\"] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| [xmlns][=\"http://schemas.microsoft.com/winfx/2006/xaml/presentation\"]                                                                                                                                                                                                                                                                                                                                                                                                                 |
