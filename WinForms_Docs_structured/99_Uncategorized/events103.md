#### Events {#events style="tab-stops: 0pt"}

 


  Events                                   Description                                                                                                              Reference
  ---------------------------------------- ------------------------------------------------------------------------------------------------------------------------ ------------------------------------------------------------------------------------------------------------------------------------------------
  ActiveWindowChanged                      This event is raised whenever the ActiveWindow property has changed.                                                     []{.UGHyperlink}
  AutoHideAnimationStarts                  This event is raised whenever AutoHide animation is triggered.                                                           []{.UGHyperlink}
  AutoHideAnimationStops                   This Event is raised after the AutoHideAnimationStarts event.                                                            []{.UGHyperlink}
  CloseAllTabs                             This event is raised whenever CloseAll Document tab menu is clicked.                                                     []{.UGHyperlink}
  CloseButtonClick                         This Event is raised whenever CloseButton of Document child has been clicked.                                            []{.UGHyperlink}
  CloseOtherTabs                           This Event is raised whenever CloseAllButThis menu item is clicked from context menu of Document tab childs.             []{.UGHyperlink}
  ContainerModeChanged                     This Event is raised whenever ContainerMode is changed.                                                                  []{.UGHyperlink}
  ContextMenuItemClick                     This Event is raised whenever Context Menu Item which is available when right click on child headers has been clicked.   []{.UGHyperlink}
  DockStateChanged                         This event is raised whenever State Attached Property has been changed.                                                  []{.UGHyperlink}
  ShowTabItemContextMenuChanged            This event is raised whenever ShowTabItemContextMenu property has been changed.                                          []{.UGHyperlink}
  ShowTabListContextMenuChanged            This event is raised whenever ShowTabListContextMenu property has been changed.                                          []{.UGHyperlink}
  SidePanelBorderThicknessChanged          This event is raised whenever SidePanelBorderThickness property has been changed.                                        []{.UGHyperlink}
  SplitterBackgroundChanged                This event is raised whenever SplitterBackground property has been changed.                                              []{.UGHyperlink}
  SwitchModeChanged                        This event is raised whenever SwitchMode property has been changed.                                                      []{.UGHyperlink}
  TabItemBorderThicknessChanged            This event is raised whenever TabItemBorderThickness property has been changed.                                          []{.UGHyperlink}
  TabItemsBorderThicknessSelectedChanged   This event is raised whenever TabItemsBorderThicknessSelected property has been changed.                                 []{.UGHyperlink}
  TabPanelBorderThicknessChanged           This event is raised whenever TabPanelBorderThicknessChanged has been changed.                                           []{.UGHyperlink}
  TargetNameInDockedModeChanged            This event is raised when TargetNameInDockedMode attached property has been changed.                                     []{.UGHyperlink}
  TargetNameInFloatModeChanged             This event is raised when TargetNameInFloatMode attached property has been changed.                                      []{.UGHyperlink}
