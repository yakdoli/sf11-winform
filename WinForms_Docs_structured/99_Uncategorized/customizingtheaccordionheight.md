#### Customizing the Accordion Height {#customizing-the-accordion-height style="tab-stops: 0pt"}

 

The height of the accordion can be customized either with respect to the accordion contents or to the parent element.

 

Properties

 

+-------------+------------------------------------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------+---------------------------------------+
| Name        | Description                                                                                                                        | Type of the property                                                                           | Value it accepts                                                                                     | Dependecy                             |
+-------------+------------------------------------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------+---------------------------------------+
| AutoHeight  | If set, the highest content part is used as height reference for all other parts. Provides more consistent animations.             | [[bool]]{.UGHyperlink} | [[true/false]]{.UGHyperlink} | Gets overridden with FillSpace        |
|             |                                                                                                                                    |                                                                                                |                                                                                                      |                                       |
|             |                                                                                                                                    |                                                                                                |                                                                                                      |                                       |
+-------------+------------------------------------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------+---------------------------------------+
| ClearStyle  | If set, it clears the height and overflow styles after finishing animations. This enables accordions to work with dynamic content. | [[bool]]{.UGHyperlink} | [[true/false]]{.UGHyperlink} | Do not work together with AutoHeight. |
|             |                                                                                                                                    |                                                                                                |                                                                                                      |                                       |
|             |                                                                                                                                    | [[]]{.UGHyperlink}     | [[]]{.UGHyperlink}           |                                       |
+-------------+------------------------------------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------+---------------------------------------+
| FillSpace   | If set, the accordion completely fills the height of the parent element and overrides autoheight.                                  | [[bool]]{.UGHyperlink} | [[true/false]]{.UGHyperlink} | NA                                    |
|             |                                                                                                                                    |                                                                                                |                                                                                                      |                                       |
|             |                                                                                                                                    | [[]]{.UGHyperlink}     | [[]]{.UGHyperlink}           |                                       |
+-------------+------------------------------------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------+---------------------------------------+

Using Properties Model

The following steps explain the setting of the the height of the Accordion content through the Properties model.

1.   In the Controller, create an instance of AccordionModel, set the **FillSpace** property and pass the instance through **view specific data** to **View** as given below.**

*[[]]{.underline}* 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[Controller\]]**                                                                                                                    |
|                                                                                                                                                                             |
| **[]**                                                                                                                                  |
|                                                                                                                                                                             |
| [public][ [ActionResult] Index()]                              |
|                                                                                                                                                                             |
| [        {]                                                                                                                             |
|                                                                                                                                                                             |
| [            [//Creating new instance of Accordion Model]]                                                        |
|                                                                                                                                                                             |
| [            [AccordionModel] myModel = [new] [AccordionModel]();] |
|                                                                                                                                                                             |
| []                                                                                                                                      |
|                                                                                                                                                                             |
| [            [//Setting the properties]]                                                                          |
|                                                                                                                                                                             |
| [            myModel.TargetControlId = [\"AccordionContents\"];]                                                |
|                                                                                                                                                                             |
| [            myModel.AutoFormat = [Skins].Monochrome;                       ]                                   |
|                                                                                                                                                                             |
| [            myModel.FillSpace = [true];]                                                                          |
|                                                                                                                                                                             |
| []                                                                                                                                      |
|                                                                                                                                                                             |
| [            [//Passing the model through View Data]]                                                             |
|                                                                                                                                                                             |
| [            ViewData\[[\"myAccordion\"]\] = myModel;]                                                          |

| [            [return] View();]                                                                                     |
|                                                                                                                                                                             |
| [        }]                                                                                                                             |
