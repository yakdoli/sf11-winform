##### Using Properties Model {#using-properties-model style="tab-stops: 0pt"}

The following steps guide in handling the addition of custom shapes in the diagram page using the properties model.

1.   In the **controller**, create an object for the **DiagramPropertiesModel** class. Assign this model class to **view data**.
