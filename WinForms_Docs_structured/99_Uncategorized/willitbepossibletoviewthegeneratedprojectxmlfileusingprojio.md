## Will it be possible to view the generated project \[.xml file\] using ProjIO? {#will-it-be-possible-to-view-the-generated-project-.xml-file-using-projio style="tab-stops: 0pt"}

No. ProjIO does not have a Graphical User Interface to view the generated project files. MS Project is required to view the project files generated by using ProjIO.
