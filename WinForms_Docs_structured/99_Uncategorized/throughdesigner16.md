##### Through Designer {#through-designer style="tab-stops: 0pt"}

1.   **To create ribbon control Through Designer:** Create a new ASP.NET Web application. For details, see [[Creating ASP.NET Web Application]](http://help.syncfusion.com/ug_91/User%20Interface/ASP.NET/Tools/Documents/42creatingaspnetwebapplication.htm)

2.   Drag the Ribbon Control onto the webform in the new web application.

3.   Give the necessary details in the .aspx page HTML view, as shown in the following code snippet.
