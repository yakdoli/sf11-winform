## Layers {#layers style="tab-stops: 0pt"}

 

Layers are sets of Objects. Map Control's content will be one of these objects. This section will describes how to add the Layers and how to set the content of the Map Control.

 

 

{border="0"}

Figure 12: ShapeFileLayer
