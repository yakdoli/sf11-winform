## Column Based Sizing {#column-based-sizing style="tab-stops: 0pt"}

**[]** 

**Column Based sizing** enables you to set width of visible columns based on available width.

 Developers can use this feature when column sizing is required for columns based on available width, cell content.

Feature can be used when **GridDataControl**  **VisibleColumns** are set individually with specific widths.

[] 

Applying Width Value[  ]

Columns are sized based on values you set.

Allowed width values are:

[·      ]SizeToCells

[·      ]SizeToHeader

[·      ]Auto

[·      ]\*

[] 


{border="0"}Note: You can also provide numeric values for \*.

\* can be preceded by any double value.


[]
