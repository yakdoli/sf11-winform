##### Rotator type {#rotator-type style="tab-stops: 0pt"}

The Rotator control supports various types of scrolling that are given by the following properties:

 

**Properties**

 

+-------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+------------------+------------------------------------------------------------------+-------------+
| Name        | Description                                                                                                                                                                                                                                                       | Type of property | Value it accepts                                                 | Dependency  |
+-------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+------------------+------------------------------------------------------------------+-------------+
| RotatorType | [This property allows you to choose the type of rotation you would like to see enabled in the rotator.\                                                                                                                                                           | RotationType\    | [·      ]RotationType.Random        | NA          |
|             | There are 4 different types of rotator types, based on the type of rotation-]                                                                                                                                                               | enum             |                                                                  |             |
|             |                                                                                                                                                                                                                                                                   |                  | [·      ]RotationType.ContentScroll |             |
|             | [·      ]**[Random rotator type]**[: this type of rotator allows you to view random item on the list, with a scroll interval between visible items.]                       |                  |                                                                  |             |
|             |                                                                                                                                                                                                                                                                   |                  | [·      ]RotationType.SlideShow     |             |
|             | [·      ]**[Content Scroll rotator type]**[: this type of rotator allows you to view the items on the list continuously, without any scroll interval, in the given order.] |                  |                                                                  |             |
|             |                                                                                                                                                                                                                                                                   |                  | [·      ]RotationType.SmoothScroll  |             |
|             | [·      ]**[Smooth Scroll rotator type]**[: this type of rotator allows you to view the items smoothly, with the given scroll interval.]                                   |                  |                                                                  |             |
|             |                                                                                                                                                                                                                                                                   |                  |                                                                  |             |
|             | [·      ]**[SlideShow rotator type]**[: this rotator type allows you to view the items in the list, with a fade-in, fade-out transition effect. ]                          |                  |                                                                  |             |
|             |                                                                                                                                                                                                                                                                   |                  | Default value is  RotationType.SmoothScroll                      |             |
+-------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+------------------+------------------------------------------------------------------+-------------+

 

You can set the Rotator Control's scrolling type in two different ways-

**[Using Builder]**

The following steps guide you in configuring the orientation through Builder.

1.   In **View**, create ul-li hierarchy of rotator items and invoke the rotator helper with the rotator Contents ID as the first argument and enable the **RotatorType** method with the desired option as argument.
