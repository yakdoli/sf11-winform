### Legend {#legend style="tab-stops: 0pt"}

\
The various properties of the chart legend such as visibility, position and alignment can be changed easily using this wizard. It has two tabs.

[] 

[·      ]**Legend -** In this window, the user can customize the legend\'s visibility, set its position and alignment using Position and Alignment combo boxes provided.

[] 

{border="0"}

**[]** 

Figure 33: Chart Wizard with Legend Customization Settings

[] 

[·      ]**Border Style -** Here the user can set custom borders to the legend. The visibility of the border, border color, it\'s Dash style as well as the Border Width can be set easily by selecting the appropriate options.

[]
