### Pow {#pow style="tab-stops: 0pt"}

The **Pow** function returns the result of a number raised to a power.

 

**Syntax:**

**POW(number, power)** 

 

**where,**

[·      ]**number** is the base number. It can be any real number.

[·      ]**power** is the exponent to which, the base number is raised.
