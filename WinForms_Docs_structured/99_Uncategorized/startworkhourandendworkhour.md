### Start Work Hour and End Work Hour {#start-work-hour-and-end-work-hour style="tab-stops: 0pt"}

[·      ]This is used to indicate the Start and End working hours of the day. The differentiation between the working hours and the normal hours is based on the different background Colors.

[·      ]The **StartWorkHour** property is used to set the start work hour for the Schedule control. The Default value for this property is set to 8. Similarly, the **EndWorkHour** property is used to set the end work hour for the Schedule control. The Default value for this property is set to 17 (or 5 PM).
