##### Through Designer {#through-designer style="tab-stops: 0pt"}

[] 

The following steps illustrate how to create the jQueryUIDatePicker control through designer.

[] 

1.   Drag the jQueryUIDatePicker control from the toolbox onto the form and add the following code in the aspx page.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[ASPX\]]**                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| []                                                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| [\<][Syncfusion][:][jQueryUIDatePicker][ [ID][=\"JQueryUIDatePicker1\"] [runat][=\"server\"/\>]] |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

{border="0"}

***[]*** 

Figure 463: jQueryUIDatePicker control dragged onto the Web Form

[] 

2.   Build and run the application to view the jQueryUIDatePicker control.

[] 


{border="0"}Note: jQueryUIDatePicker requires script manager to be added onto the page.
