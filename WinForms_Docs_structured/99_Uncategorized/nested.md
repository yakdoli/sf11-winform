### Nested {#nested style="tab-stops: 0pt"}

[] 

Nested Relation Hierarchy is mainly used to link two or more tables with their field of Relation, for example, the ID will be common for the Order table and the Shipping table.

[] 

[·      ]The Nested Relations is given in code, using the GridRelationDescriptor.

[·      ]Hierarchical display can be implemented by defining multiple Grid levels.

[·      ]Click on the top-left \"+/-\" column to expand the hierarchical records.

[·      ]**QueryShowRelationDisplayFields** event is raised for each foreign key relation and lets you control at runtime, if the related fields of the Child table should be added to the FieldDescriptor collection.

[]
