### Adding Codes to the Web.config File {#adding-codes-to-the-web.config-file style="tab-stops: 0pt"}

The steps to add codes to the Web.config file are as follows:[]

1.   On the Solution Explorer, double-click the **Web.config** file (There will be two web.config files. Refer the one in the root folder.). The Web.config page appears.

 

{border="0"}

Figure 28: Web.config page

[] 

2.   Add the following assemblies in the Web.config page under the \<compilation\> tag:

 

[·      ]Syncfusion.Core

[·      ]Syncfusion.Mobile.Chart.Mvc

[·      ]Syncfusion.Linq.Base

[·      ]Syncfusion.Mobile.Shared.Mvc[]
