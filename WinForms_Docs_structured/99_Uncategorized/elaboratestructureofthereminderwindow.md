Elements and Features of the Reminder Window

The elements and features of the Reminder window are:

[·      ]**Dismiss All**: This button is used to dismiss the reminder from all displayed appointments.

[·      ]**Dismiss**: This button is used to dismiss reminder from a particular selected appointment.

[·      ]**Open Item**: This button is used to update/view the appointment details.

[·      ]**Snooze**: This button is used to update the reminder value to remind again.
