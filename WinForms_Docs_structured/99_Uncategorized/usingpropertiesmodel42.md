##### Using Properties Model {#using-properties-model style="tab-stops: 0pt"}

The following steps enable three different date picker modes using the properties model.

1.  [In the **controller**, create an instance of the **MobDatePickerModel** and define the properties. ]

a.  [Simple Mode]

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[Controller]**                                                                                                                                                     |

| [public] [ [ActionResult] DatePicker()]                                                     |

|                                                                                                                                                                                                          |
| [       MobDatePickerModel] [ model = [new][MobDatePickerModel]();] |
|                                                                                                                                                                                                          |
| [       \-\-\-\-\-\-\--]                                                                                                                                             |
|                                                                                                                                                                                                          |
| [       model.Mode = [Mode].Simple;]                                                                                                         |
|                                                                                                                                                                                                          |
| [       \-\-\-\-\-\-\--]                                                                                                                                             |
|                                                                                                                                                                                                          |
| [       ViewData\[[\"DatePicker \"]\] = model; ]                                                                                             |
