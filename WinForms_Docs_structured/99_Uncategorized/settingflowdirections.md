#### Setting flow directions {#setting-flow-directions style="tab-stops: 0pt"}

[] 

The flow direction for the TreeViewAdv is set through the **FlowDirection** property. The options provided are as follows.

[] 

[·      ]Left-to-Right

[·      ]Right-to-Left
