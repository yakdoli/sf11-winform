### COUNTBLANK {#countblank style="tab-stops: 0pt"}

 

Counts empty cells in a specified range of cells.

 

**Syntax**

 

COUNTBLANK(range)

 

where:

**range** is the range from which you want to count the blank cells.

 

**Remarks**

 

[·      ]Cells with formulas that return \"\" (empty text) are also counted. Cells with zero values are not counted.[]{#p99}
