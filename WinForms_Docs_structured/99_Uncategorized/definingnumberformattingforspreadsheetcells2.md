#### Defining number formatting for Spreadsheet Cells {#defining-number-formatting-for-spreadsheet-cells style="tab-stops: 0pt"}

You can define the number formatting using the *NumberFormattingCammand*. Number formatting will be applied to the Spreadsheet cells based on the command parameter. The following code illustrates this:
