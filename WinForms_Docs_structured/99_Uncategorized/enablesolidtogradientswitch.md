##### Enable Solid To Gradient Switch {#enable-solid-to-gradient-switch style="tab-stops: 0pt"}

This property specifies whether switching between Solid and Gradient BrushMode and vice-versa is enabled at runtime or not.

 

The following code snippets illustrate this:
