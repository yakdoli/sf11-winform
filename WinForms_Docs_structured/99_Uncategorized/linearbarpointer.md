##### Linear Bar Pointer {#linear-bar-pointer style="tab-stops: 0pt"}

The Linear Bar Pointer is used to represent the values over the scale, which is integrated on the linear scale and its value variation look like a thermometer. The following are few important properties of Linear Bar Pointers.

**[]** 

Table 19: Property Table


  ----------------- -----------------------------------------------------------------
  Property          Description
  BackgroundBrush   To set the Background brush for the pointer.
  BorderBrush       To set the Border brush for the pointer.
  BorderWidth       To set the Border width of the pointer cap. Default value is 0.
  PointerWidth      To set width of the pointer. Default value is 0.
  Value             To set the value of the pointer. Default value is 0.
  BarStyle          To specify the bar pointer style. Default value is Rectangle.
  ----------------- -----------------------------------------------------------------
