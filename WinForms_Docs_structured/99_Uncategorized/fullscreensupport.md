## Full Screen Support {#full-screen-support style="tab-stops: 0pt"}

Full screen view will collapse the entire sub components except the data visualizing control (Chart and Grid) and expand the data visualizing control to the full size of the OLAP Client.

You can switch to and from full screen and normal screen by clicking the full screen button in the right top corner data visualizing controls tab.

Use case Scenarios

When users want to view all the records in a single screen without scrolling much, the full screen mode will be helpful.
