#### Defining the dimensions {#defining-the-dimensions style="tab-stops: 0pt"}

Generic drop-down supports customizing the dimensions.

**[]** 

**[Properties]**

+------------------+---------------------------------------------------------------------+--------------------------------------------------------------------------------------------------+-------------------------------------------+-------------+
| Name             | Description                                                         | Type of the property                                                                             | Value it accepts                          | Dependency  |
+------------------+---------------------------------------------------------------------+--------------------------------------------------------------------------------------------------+-------------------------------------------+-------------+
| Width            | Sets the width of the generic drop-down text box in pixels.         | [[struct]]{.UGHyperlink} | Members of [Unit] | NA          |
+------------------+---------------------------------------------------------------------+--------------------------------------------------------------------------------------------------+-------------------------------------------+-------------+
| PopupPanelHeight | Sets the height of the pop-up panel holding the contents in pixels. | [[struct]]{.UGHyperlink} | Members of [Unit] | NA          |
|                  |                                                                     |                                                                                                  |                                           |             |
|                  |                                                                     |                                                                                                  |                                           |             |
+------------------+---------------------------------------------------------------------+--------------------------------------------------------------------------------------------------+-------------------------------------------+-------------+
| PopupPanelWidth  | Sets the width of the pop-up panel holding the contents in pixels.  | [[struct]]{.UGHyperlink} | Members of [Unit] | NA          |
|                  |                                                                     |                                                                                                  |                                           |             |
|                  |                                                                     |                                                                                                  |                                           |             |
+------------------+---------------------------------------------------------------------+--------------------------------------------------------------------------------------------------+-------------------------------------------+-------------+

Using Properties Model

The following steps explain the setting of the dimensions for the generic drop-down using the Properties model.

1.   In the **Controller**, create and instance of **GenericDropDownModel**, set the **Width, PopupPanelHeight** and **PopupPanelWidth** properties and pass the instance through view specific data to the view as given below.**

**[]** 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **\[Controller\]**                                                                                                                                                                                   |
|                                                                                                                                                                                                      |
|                                                                                                                                                                                                      |
|                                                                                                                                                                                                      |
| [public][ [ActionResult] Index()]                             |
|                                                                                                                                                                                                      |
| [        {]                                                                                                                                         |
|                                                                                                                                                                                                      |
| [            [GenericDropDownModel] myModel = [new] [GenericDropDownModel]();] |
|                                                                                                                                                                                                      |
| [            myModel.AutoFormat = [Skins].Monochrome;]                                                                      |
|                                                                                                                                                                                                      |
| **[            myModel.TargetContentId = [\"drop-down-contents\"];]**                                                       |
|                                                                                                                                                                                                      |
| **[            myModel.Width = 300;]**                                                                                                              |
|                                                                                                                                                                                                      |
| **[            myModel.PopupPanelWidth = 300;]**                                                                                                    |
|                                                                                                                                                                                                      |
| **[            myModel.PopupPanelHeight = 410;]**[]                                                |
|                                                                                                                                                                                                      |
| []                                                                                                                                                  |
|                                                                                                                                                                                                      |

| [        }]                                                                                                                                         |
