### SIGN {#sign style="tab-stops: 0pt"}

 

Determines the sign of a number. Returns 1 if the number is positive, zero (0) if the number is 0 and -1 if the number is negative.

 

**Syntax**

 

**SIGN(number)**

 

where:

**number** is any real number.
