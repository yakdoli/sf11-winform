### Reminder Icon Customization {#reminder-icon-customization style="tab-stops: 0pt"}

1.   Add a Reminder Appointment.

2.   Customize the Reminder Icon and its content block (i.e div block) using the properties as shown in the below code.

 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| [\[ASPX\]]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [        [\<][Appointments][\>]]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [            [\<][syncfusion][:][ScheduleWebAppointment] [Reminder][=\"true\"] [ReminderCssClass][=\"remcss\"] [ReminderIconUrl][=\"Images/Alerts.png\"] [LocationValue][=\"First Floor\"] [EndTime][=\"05/30/2011 11:00:00\"] [StartTime][=\"05/30/2011 09:35:31\"] [Subject][=\"Meeting\"] [/\>]] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [            [\<][syncfusion][:][ScheduleWebAppointment] [Reminder][=\"true\"] [ReminderCssClass][=\"green\"] [ReminderIconUrl][=\"Images/alert.png\"] [EndTime][=\"05/30/2011 14:35:31\"] [StartTime][=\"05/30/2011 13:35:31\"] [Subject][=\"Testing\"] [UniqueID][=\"1\"] [/\>]]                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [        [\</][Appointments][\>]]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+--------------------------------------------------------------------------------------------------------------------------+
| []                                                                      |
|                                                                                                                          |
| [\[C#\]]                                                                |
|                                                                                                                          |
| [  Appoint.Reminder = [true];]                                  |
|                                                                                                                          |
| [        Appoint.ReminderIconUrl = [\"Images/Alerts.png\"];] |

|                                                                                                                          |
