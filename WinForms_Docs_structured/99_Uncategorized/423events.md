##### 4.2.3 Events {#events style="tab-stops: 0pt"}

The events in the RadioButton and RadioButtonFor controls are listed and described in the following table.

  -------------------------------------------------------------------------------------------------- ---------------------------------------- -----------------------------------------------------------------------------------------------------------------------
  **[Event]** []   **[Parameters]**   **[Description]**
  [OnTouchStart]                                                               inst,args[]      This event rises immediately when the touch start event is triggered in the Button control.[]
  [OnTouchStop]                                                                inst,args[]      This event rises immediately when the touch end event is triggered in the Button control.[]
  -------------------------------------------------------------------------------------------------- ---------------------------------------- -----------------------------------------------------------------------------------------------------------------------
