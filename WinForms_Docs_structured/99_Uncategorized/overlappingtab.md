##### Overlapping Tab {#overlapping-tab style="tab-stops: 0pt"}

[] 

The tabstrip elements can be made to achieve the overlapping edge effect as follows.

[] 

{border="0"}

**[]** 

Figure 296: TabStrip with overlapping edge effect

[] 

1.   Drag the control onto the Web Page of the project.

107.   The following properties contain the default image names and the separators for the above shown images. Set the images to the following default image names. Else it could be given custom names in which case the image names has to be replaced accordingly for the corresponding properties.
