### WaitingPopup {#waitingpopup style="tab-stops: 0pt"}

 

WaitingPopup control displays the visual element that indicates the loading/processing state of any process.

Some of the salient features of WaitingPopup are given below.

[·      ]Orientation: WaitingPopup control can be positioned relative to either an element or the screen

The control can be positioned in accordance to the X and Y co-ordinates.

[·      ]Client side actions: client-side functions can be effectively utilized to control the behavior and actions on client side

[·      ]WaitingPopup control can be hosted in Safari browser too.

 

Creating WaitingPopup

 

[·      ]Drag the control onto the application.

[·      ]Set ClientObjectID property.

[·      ]Call ShowPopup or HidePopup client-side methods through the ClientObjectID to show / hide the control.
