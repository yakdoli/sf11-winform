### Skins Supported {#skins-supported style="tab-stops: 0pt"}

[·      ]Office2007Black

[·      ]Office2007Silver

How to Apply the Skin

You can apply the skin for the Range Slider control in code behind using the below code snippet.

For more details refer, to [[SkinManager]](http://help.syncfusion.com/ug_84/User%20Interface/WPF/Tools/default.htm?turl=builtinskins1.htm) .

[] 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                |
| [RangeSliderControl][ RangeSlider = [new] [RangeSliderControl]();]                                                                        |
|                                                                                                                                                                                                                                                                                |
| [RangeSlider.Name = [\"rangeSlider\"];]                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                |
| [SkinStorage][.SetVisualStyle([rangeSlider], ][\"Office2007Blue\"][);] |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

 You can apply the skin in XAML using the code snippet shown below.

 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**[]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| [ ][\<][Syncfusion][:][RangeSliderControl][ x][:][Name][=\"rangeSlider\" ][Range][=\"10,50\" ][TickFrequency][=\"10\" ][Syncfusion][:][SkinStorage.VisualStyle][=\"Office2007Blue\"/\>][] |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
