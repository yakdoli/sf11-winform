## Namespace Changes       {#namespace-changes style="tab-stops: 0pt"}

[] 

In order to maintain consistent namespace and enable code sharing between our WPF and Silverlight Gauge control, namespace for Silverlight Gauge has been modified similar to WPF. Following namespace changes are done to Gauge Silverlight.

 


  ------------------------------- ---------------------------
  Old Namespace                   New Namespace
  Syncfusion.Silverlight.Gauge    Syncfusion.Windows.Gauge
  Syncfusion.Silverlight.Shared   Syncfusion.Windows.Shared
  ------------------------------- ---------------------------
