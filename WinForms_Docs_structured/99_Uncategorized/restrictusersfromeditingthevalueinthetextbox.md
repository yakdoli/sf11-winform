#### Restrict users from editing the value in the text box {#restrict-users-from-editing-the-value-in-the-text-box style="tab-stops: 0pt"}

You can restrict users from editing the value in the text box by setting the AllowEdit property to false, as shown in the following code snippets.

 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [\<][syncfusion][:][UpDown][ Name][=\"upDown\"][ AllowEdit][=\"false\"\>] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [            ][]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [        ][\</][ syncfusion][:][UpDown][\>]                                                                                                                                                            |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                               |
|                                                                                                                                                                                                                |
| [UpDown][ upDown = [new] [UpDown]();] |
|                                                                                                                                                                                                                |
| [upDown.AllowEdit = [false];][]                                                    |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
