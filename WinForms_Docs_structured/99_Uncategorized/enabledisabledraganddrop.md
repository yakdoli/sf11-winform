##### Enable / Disable Drag and Drop {#enable-disable-drag-and-drop style="tab-stops: 0pt"}

[·      ]Appointments added to Essential Schedule can be dragged and dropped in all types of views.

[·      ]To disable appointment drag-and-drop, set the **AllowDragAndDrop** property to **false**. The **AllowDragAndDrop** property is set to **true** by default.

**[]** 

To add the **AllowDragAndDrop** property to the schedule control, use the appropriate code, given below.

 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| [\<][schedule][:][Schedule][ x][:][Name][=\"schedule\"][ AllowDragAndDrop][=\"False\"/\>] |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| [Schedule][ schedule = [new] [Schedule]();]                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| [schedule.AllowDragAndDrop = [true];]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

Once dragging and dropping is enabled, an appointment can be dragged and dropped in all types of views[.]
