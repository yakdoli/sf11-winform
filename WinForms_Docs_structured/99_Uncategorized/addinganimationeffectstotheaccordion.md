#### Adding Animation Effects to the Accordion {#adding-animation-effects-to-the-accordion style="tab-stops: 0pt"}

Accordion supports built-in animation effects for the expand and collapse actions.[ ]

Property

+-------------+------------------------------------------------------------------------------------+----------------------+----------------------------------------------------+-------------+
| Name        | Description                                                                        | Type of the property | Value it accepts                                   | Dependency  |
+=============+====================================================================================+======================+====================================================+=============+
| Animate     | Used to define the animation effect for the  accordion expand and collapse actions | enum                 | [Effects].jswing,\         | NA          |
|             |                                                                                    |                      | [Effects.]bounceslide,\    |             |
|             |                                                                                    |                      | [Effects].slide,\          |             |
|             |                                                                                    |                      | [Effects.]easeOutQuad,\    |             |
|             |                                                                                    |                      | [Effects] .easeOutBounce,\ |             |
|             |                                                                                    |                      | [Effects] .easeOutCubic,\  |             |
|             |                                                                                    |                      | [Effects] .easeOutQuart,\  |             |
|             |                                                                                    |                      | [Effects] .easeOutQuint,\  |             |
|             |                                                                                    |                      | [Effects] .easeOutSine,\   |             |
|             |                                                                                    |                      | [Effects] .easeOutExpo,\   |             |
|             |                                                                                    |                      | [Effects] .easeOutCirc     |             |
+-------------+------------------------------------------------------------------------------------+----------------------+----------------------------------------------------+-------------+

Using Properties Model

The following steps explain the addition of animation to the Accordion using Builder.

1.   In **Controller**, create an instance of *AccordionModel*, define the *Animate* property and pass the instance through view specific data to **View** as given below.

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[Controller\]]**                                                                                                                                |
|                                                                                                                                                                                         |
| [public][ [ActionResult] Index()]                                          |
|                                                                                                                                                                                         |
| [        {]                                                                                                                                         |
|                                                                                                                                                                                         |
| [            [//Creating new instance of Accordion Model]]                                                                    |
|                                                                                                                                                                                         |
| [            [AccordionModel] myModel = [new] [AccordionModel]();            ] |
|                                                                                                                                                                                         |
| [            myModel.TargetControlId = [\"AccordionContents\"];]                                                            |
|                                                                                                                                                                                         |
| [            myModel.Animate = [Effects].jswing;]                                                                           |
|                                                                                                                                                                                         |
| []                                                                                                                                                  |
|                                                                                                                                                                                         |
| [            [//Passing the model through View Data]]                                                                         |
|                                                                                                                                                                                         |
| [            ViewData\[[\"myAccordion\"]\] = myModel;]                                                                      |
|                                                                                                                                                                                         |
| [            [return] View();]                                                                                                 |
|                                                                                                                                                                                         |
| [        }]                                                                                                                                         |
|                                                                                                                                                                                         |
| []                                                                                                                              |
