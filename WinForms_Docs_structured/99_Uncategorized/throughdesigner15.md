Traversing through the Pages using Client-side Methods

**[]** 

1.   You can traverse through the pages using client side methods like **GoFirst**, **GoNext**, **GoPrevious**, **GoLast** or using **SetIndex** method by appending the \'\_sf\' to the Multipage id as follows. Also the client side methods can be accessed with the instance of the MultiPage control.

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| [\<][input][ ][type][=\"button\"][ ][onclick][=\"\_sfMultiPage1.GoFirst()\"][ ][value][=\"First\"][ ][\>]       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| [\<][input][ ][type][=\"button\"][ ][onclick][=\"\_sfMultiPage1.GoPrevious()\"][ ][value][=\"Previous\"][ ][\>] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| [\<][input][ ][type][=\"button\"][ ][onclick][=\"\_sfMultiPage1.GoNext()\"][ ][value][=\"Next\"][ ][\>]         |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| [\<][input][ ][type][=\"button\"][ ][onclick][=\"\_sfMultiPage1.GoLast()\"][ ][value][=\"Last\"][ ][\>]         |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

118.   Build and run the application.
