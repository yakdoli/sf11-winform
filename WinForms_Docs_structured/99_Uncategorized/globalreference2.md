**\[Visual Studio Install Directory\]\\Common7\\IDE\\ItemTemplates\\\[CSharp \| VisualBasic\]\\Web\\MVC2\\CodeTemplates\\**


{border="0"}Note: If we place the templates here, templates are visible in any MVC application.
