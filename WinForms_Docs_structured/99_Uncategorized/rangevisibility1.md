#### Range Visibility {#range-visibility style="tab-stops: 0pt"}

[] 

The **RangeVisibility**[ ]property specifies the visibility of the selected range. The default value is set to true. When set to false, the slider displays only one thumb and the property value is used to indicate the position of the thumb.

 

The following code snippet illustrates this:
