#### On Report Selection Change {#on-report-selection-change style="tab-stops: 0pt"}

 

When we make a report selection change, all the controls will get populated with the data mentioned in that report.

 

[·      ]The Cube Dimension Browser will get populated with the cube mentioned in that report.

[·      ]The Axis Element Builder will get loaded with the appropriate element mentioned in that report for each axis.

[·      ]The Chart and Grid will reflect the output of the selected report.
