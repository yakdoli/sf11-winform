##### Through Designer {#through-designer style="tab-stops: 0pt"}

[] 

The following steps illustrate how to create the jQueryUISlider control through designer.

[] 

1.   Drag the jQueryUISlider control from the toolbox onto the form and add the following code in the aspx page.

[]

| **[\[ASPX\]]**                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                          |

|                                                                                                                                                                                                                                                                                                                                                                                                                          |
| [\<][Syncfusion][:][jQueryUISlider][ [ID][=\"JQueryUISlider1\"] [runat][=\"server\"/\>]] |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]

[] 

2.   Build and run the application to view the jQueryUISlider control.
