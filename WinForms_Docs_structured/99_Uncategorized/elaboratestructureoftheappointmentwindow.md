Elements and Features of the Appointment Window

The elements and features of the Appointment window are:

[·      ]Save and Close: To save/update the appointment details.

[·      ]Delete: To delete the appointment details.

[·      ]Recurrence: To create/remove recurrence for appointment.

[·      ]Priority: To set an important level for the appointment.

[·      ]Reminder: To set a reminder for the appointment, select the reminder value.

[·      ]Time zone: To allow time zone dropdown in the Appointment window, select this option.
