## How to apply Conditional formatting? {#how-to-apply-conditional-formatting style="tab-stops: 0pt"}

**Conditional** Formatting for **OlapGrid** WPF allows you to select cells and set conditions for formatting them.  The formatting is applied only when the conditions are met. It can be achieved by overriding the default template of Grid cells.
