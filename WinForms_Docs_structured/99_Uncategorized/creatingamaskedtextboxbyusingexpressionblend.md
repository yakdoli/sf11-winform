##### Creating a MaskedTextBox by using Expression Blend {#creating-a-maskedtextbox-by-using-expression-blend style="tab-stops: 0pt"}

 

The steps to create a MaskedTextBox in the application by using Expression Blend are as follows:

1.   Open Expression Blend.

2.   On the File menu, select **New Project**. This opens the New Project dialog box.

[] 

[] 

{border="0"}

 

Figure 672: Expression Blend -- Open New Project

[][] 

3.   In the Project types panel, select **WPF Application** and then click **OK**.

{border="0"}

 

Figure 673: New Project panel[]

[] 

4.   Add the following reference with the sample project:

[·      ]Syncfusion.Shared.WPF.dll

5.   On the Window menu, select **Assets**. This opens the Assets Library dialog box.

6.   In the Search box, type **MaskedTextBox**. This displays the search results.

[] 

{border="0"}

 

Figure 674: Assets

 

7.   Drag the **MaskedTextBox** control to Design View, to edit the properties of the MaskedTextBox in the Properties window.

[] 

[] 

{border="0"}

 

Figure 675: Expression Blend -- Design View
