##### Enabling Captcha Refresh {#enabling-captcha-refresh style="tab-stops: 0pt"}

[The Captcha refresh feature provides the ability to refresh the Captcha image. You can refresh the Captcha image by using the **EnableRefreshImage** property. It updates the Captcha with a new image on every post. ]

 

5.4.3.6.1.1 Use Case Scenarios

[Captcha ][r][efresh is used to enable users to regenerate][ C][aptcha images in ][the ][case][ of][ ][a Captcha image][ being ][too difficult to read.]

Properties

  ---------------------------------------------------------------------- -------------------------------------------------------------------------------- ------------------------------------- --------------------------------
  **Property**                                                           **Description**                                                                  **Type**                              **Data Type**
  [EnableRefreshImage][]   [Enables or disables EnableRefreshImage in the Captcha.]   [Server side]   [bool]
  RequestMapper                                                          [Gets or sets the name for the post action function.]      [Server side]   [String]

Adding Captcha Refresh to an Application

The Captcha refresh feature can be customized in two ways, namely:

[·      ]CaptchaBuilder

[·      ]CaptchaModel

**Using Properties Model**

The following steps explain enabling the Captcha image refresh feature using the properties model.

1.   In the **controller**, create an instance of **CaptchaModel**, define the **EnableRefreshImage** and **RequestMapper** properties, and pass the instance through **view specific data** to the **view** as shown below.
