#### Watermark Support {#watermark-support style="tab-stops: 0pt"}

 

Watermark is the dummy content displayed in the MaskedTextBox when the Value string is empty. The WatermarkText support behavior can be enabled by setting the WatermarkTextIsVisible property to true.

Figure 687: MaskedTextBox with WatermarkText

 

WatermarkText automatically collapses when the control is in focus. When the control loses its focus the WatermarkText comes to the visible state if the Value is null and the **WatermarkTextIsVisible** is true.
