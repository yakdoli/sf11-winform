##### Adding Through XAML {#adding-through-xaml style="tab-stops: 0pt"}

To add ComboBoxAdv using XAML, first include the following namespace in the XAML.

 

 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                                                                                                                    |
| [      ][xmlns][:][syncfusion][=\"http://schemas.syncfusion.com/wpf\"][] |
|                                                                                                                                                                                                                                                                                                                                                    |
| []                                                                                                                                                                                                                                                                                                             |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
