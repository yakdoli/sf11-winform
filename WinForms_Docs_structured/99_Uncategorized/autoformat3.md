### AutoFormat {#autoformat style="tab-stops: 0pt"}

The OlapGrid control supports the following AutoFormat styles.

[·      ]Default

[·      ]Office2010Blue

[·      ]Office2010Black

[·      ]Office2010Silver

[·      ]Office2007Blue

[·      ]Office2007Olive

[·      ]Office2007Black

[·      ]Office2007Silver

[·      ]Custom

 

AutoFormat styles can be set by using the following code.

 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                          |
| [this][.OlapGrid1.AutoFormat ][= ][Autoformat][.Office2010Blue;][] |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                                                                                                                                                      |
|                                                                                                                                                                                                                                                                                                                                                                       |
| [Me][.OlapGrid1.AutoFormat ][= ][Autoformat][.Office2010Blue][] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
