## FontListComboBox {#fontlistcombobox style="tab-stops: 0pt"}

A FontListComboBox is used to display a combo box with a choice list of system fonts or a custom list of fonts.

 

Features

[] 

[·      ]This control enables the user to add font items to the FontListComboBox without a single piece of code.

[·      ]Easy to select fonts from the combo box.

[·      ]Enables to add custom source to the FontListComboBox collection.

[·      ]Supports adding groups like recently used fonts, all fonts and so on.

[·      ]Displays the font item in its own style.
