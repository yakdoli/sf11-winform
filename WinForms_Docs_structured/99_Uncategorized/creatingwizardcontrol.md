### Creating Wizard Control {#creating-wizard-control style="tab-stops: 0pt"}

[] 

Wizard control is created programmatically by using either XAML or C# code. The following lines of code can be used to create the Wizard control.

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| []                                                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| [\<][syncfusion][:][WizardControl][ Name][=\"wizardControl\"/\>] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                              |
|                                                                                                                                             |
| []                                                                        |
|                                                                                                                                             |
| [// \"grid\" is the name of grid panel]                                   |
|                                                                                                                                             |
| [WizardControl wizardControl = [new] WizardControl();            ] |
|                                                                                                                                             |
| [grid.Children.Add(wizardControl); ]                                                    |
+---------------------------------------------------------------------------------------------------------------------------------------------+

[] 


{border="0"}Note: For creating Wizard control using C# code, you must already have a panel in which you are going to add the control. Otherwise, the control cannot be displayed.
