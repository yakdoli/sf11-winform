#### ValueChanged {#valuechanged style="tab-stops: 0pt"}

 

ValueChanged -- The event occurs when the Value property of the DoubleTextBox is changed.

| **XAML**                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

|                                                                                                                                                                                                                           |
