#### Set the Visibility of the CloseButton {#set-the-visibility-of-the-closebutton style="tab-stops: 0pt"}

You can set the visibility of the CloseButton by using the **CloseButtonVisibility** property through C# as below. 

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                |
|                                                                                                                                                                 |
| [      [TileViewItem] item1 = [new] [TileViewItem]();] |
|                                                                                                                                                                 |
| [      item1.CloseButtonVisibility = System.Windows.[Visibility].Visible;]                          |
|                                                                                                                                                                 |
| [          ]                                                                                                                |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------+
