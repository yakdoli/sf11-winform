#### How to set the cursor  to  GridGroupingControl instead of the default one[?] {#how-to-set-the-cursor-to-gridgroupingcontrol-instead-of-the-default-one style="tab-stops: 0pt"}

You need to handle the TableControlCellCursor event of GridGroupingControl and set the required cursor to the e.Inner.Cursor property.
