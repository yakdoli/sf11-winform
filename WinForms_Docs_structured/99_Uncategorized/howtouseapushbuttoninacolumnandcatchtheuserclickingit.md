### How to Use a PushButton in a Column and Catch the User Clicking It {#how-to-use-a-pushbutton-in-a-column-and-catch-the-user-clicking-it style="tab-stops: 0pt"}

[] 

Introduction

[] 

Set the [CellType]{.UGHyperlink} property in the column style to \"PushButton\" and handle the grids CellButtonClicked event. Use the Description property of the column style to specify the text that is displayed on the button. To access a column\'s style, use either the [GridDataBoundGrid]{.UGHyperlink}[.][GridBoundColumns]{.UGHyperlink} or [GridDataBoundGrid.Binder.InternalColumn]{.UGHyperlink} depending upon whether you have explicitly added the GridBoundColumns or not.

[]
