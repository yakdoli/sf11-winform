#### Enable the ClickHeaderToMaximize {#enable-the-clickheadertomaximize style="tab-stops: 0pt"}

You can enable the ClickHeaderToMaximize feature by using the **ClickHeaderToMaximize** property through C# as below. []{.UGHyperlink}

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                      |
|                                                                                                                                                                       |
| [      [TileViewControl] item1 = [new] [TileViewControl]();] |
|                                                                                                                                                                       |
| [      item1.ClickHeaderToMaximize = true;]                                                                                       |
|                                                                                                                                                                       |
| [          ]                                                                                                                      |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------+
