## How to set the tooltip for the GroupDropArea {#how-to-set-the-tooltip-for-the-groupdroparea style="tab-stops: 0pt"}

[] 

 You can make use of the **GroupDropAreaTextTooltip** property of the grid to specify the tooltip for the GroupDropArea.

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                      |
|                                                                                                                                                                                                                     |
| []                                                                                                                                                                 |
|                                                                                                                                                                                                                     |
| [this][.GridGroupingControl1.GroupDropAreaTextTooltip = [\"Drag-and-drop the column headers here\"]; ] |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB.NET\]]**                                                                                                                                                            |
|                                                                                                                                                                                                                 |
| []                                                                                                                                                                          |
|                                                                                                                                                                                                                 |
| [Me][.GridGroupingControl1.GroupDropAreaTextTooltip = [\"Drag-and-drop the column headers here\"]] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
