### ContextMenu {#contextmenu style="tab-stops: 0pt"}

[Essential Chart for ASP.NET MVC supports the Context Menu. The Context Menu contains the following options]{.BodyText1Char}[:]

 

[·      ]Save the chart

[·      ]Print the chart

[·      ]Change the legend position

[·      ]Enable chart 3D effect

[·      ]Change the chart type

[  ]
