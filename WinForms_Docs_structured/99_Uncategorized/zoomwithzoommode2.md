#### Zoom with Zoom Mode {#zoom-with-zoom-mode style="tab-stops: 0pt"}

 

There are two ZoomModes available in the Map Control. They are:

 

[·      ]SingleClick

[·      ]DoubleClick

 

Select Zoom mode as SingleClick and click on the Map. Ten Map will be get ZoomedIn.

Select Zoom mode as DoubleClick and click twice on the Map. Ten Map will be get ZoomedIn.
