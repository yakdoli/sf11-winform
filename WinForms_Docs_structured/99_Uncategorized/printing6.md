## Printing {#printing style="LINE-HEIGHT: 115%; tab-stops: 0pt"}

Essential Diagram for ASP.NET MVC is capable of printing a copy of the diagram page. Users can print diagrams both in color as well as in black and white using a **Print** dialog box.[]

 

Use Case Scenarios

This feature enables the user to print a diagram page both in color and in black and white.
