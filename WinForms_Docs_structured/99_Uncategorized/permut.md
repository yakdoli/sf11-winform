### Permut {#permut style="tab-stops: 0pt"}

The **Permut** function returns the number of permutations of n items taken at k time.

 

**Syntax:**

**Permut(n, k)**

 

**where,**

[·      ]**n** is the number of items.

[·      ]**k** is the time taken.
