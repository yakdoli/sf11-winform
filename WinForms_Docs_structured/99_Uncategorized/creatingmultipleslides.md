##### Creating Multiple Slides {#creating-multiple-slides style="tab-stops: 0pt"}

[] 

This tutorial shows how to display multiple slides in a Rotator using XML file. 

[] 

[·      ]Multiple slides can be displayed in vertical as well as in horizontal direction.

[·      ]This can be done by simply setting the height / width of Rotator control as multiple times to that of the corresponding slide\'s height / width (This is just to make sure that the required number of slides are displayed in a single frame). The controls height depends upon the height / width of individual slides you are using inside Rotator.

[·      ]The **RotationType** must be set to either ContentScroll or SmoothScroll, to display multiple slides.

[·      ]Horizontally, multiple slides can be displayed by setting **ScrollDirection** to Left or Right.

[·      ]Vertically, multiple slides can be displayed by setting **ScrollDirection** to Up or Down.

[]
