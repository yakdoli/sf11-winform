## Does DocIO require MS Word to be installed on the report generation machine / server? {#does-docio-require-ms-word-to-be-installed-on-the-report-generation-machine-server style="tab-stops: 0pt"}

 

No. Essential DocIO is a 100% Native .NET library that does not depend on MS Word.
