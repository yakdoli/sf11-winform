### Creating FontListComboBox control {#creating-fontlistcombobox-control style="tab-stops: 0pt"}

 

You can add FontListComboBox to both Windows WPF and XBAP applications by using the XAML or C# code. Use the following code to add a FontListComboBox control to a WPF application.

 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                   |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| []                                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| [\<][syncfusion][:][FontListComboBox][ Name][=\"FontListComboBox1\"/\>] |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                           |
|                                                                                                                                                                                                                                          |
| **[]**                                                                                                                                                                 |
|                                                                                                                                                                                                                                          |
| [FontListComboBox][ fontlistcombobox = [new] [FontListComboBox]();] |
|                                                                                                                                                                                                                                          |
| [fontlistcombobox.Name = [\"FontListComboBox1\"];]                                                                                                           |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 


{border="0"}Note: To display the FontListComboBox using C# code, you must already have a panel in which you are going to add the control. Otherwise, the control cannot be displayed.
