### Background[]{#p64} {#background style="tab-stops: 0pt"}

[] 

You can control the background appearance of the chart area using Background property as follows.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| [\[XAML\]]                                                                                                                                                                                                                                                                                                                                                           |
|                                                                                                                                                                                                                                                                                                                                                                                                          |
| []                                                                                                                                                                                                                                                                                                                                                      |
|                                                                                                                                                                                                                                                                                                                                                                                                          |
| [\<][syncfusion:Chart][\>]                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                          |
| [  \<][syncfusion:ChartArea][ ][Background][=][\"[LightBlue]\"[\>]] |
|                                                                                                                                                                                                                                                                                                                                                                                                          |
| [    \<][syncfusion:ChartSeries][/\>]                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                          |
| [  \</][syncfusion:ChartArea][\>]                                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                          |
| [\</][syncfusion:Chart][\>]                                                                                                                                                                                                                        |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| [\[C#\]]                                                                                                                                                                                                                                                                                                                                                                                            |
