##### Rotator with Button Mode {#rotator-with-button-mode style="tab-stops: 0pt"}

###### 5.6.2.2.6.1 Introduction {#introduction style="tab-stops: 0pt"}

The Rotator control with button mode allows users to browse through a set of items by clicking the buttons. The items can be moved in up or down and left or right directions by clicking the corresponding buttons.[]

###### 5.6.2.2.6.2 Use Case Scenarios {#use-case-scenarios style="tab-stops: 0pt"}

 

[The ]Rotator control with button mode allows users to scroll through the items by clicking buttons.[]

###### 5.6.2.2.6.4 Properties {#properties style="tab-stops: 0pt"}

 

Properties

 

  ------------------ ----------- ------------- -------------------------------------------------------- -----------------------------------------------------
  **     Name**      ** Type**   **Default**   **Description**                                          **Dependency**
  ButtonMode         Boolean     false         Specifies the control to be rendered with button mode.   Set AutoStart property False to enable button mode.
  ButtonBackGround   Color       Black         Specifies the background color of button layer.          NA
