### Adding Codes to the Web.config File {#adding-codes-to-the-web.config-file style="tab-stops: 0pt"}

 

In the Solution Explorer, double-click the **Web.config** file. (There will be two Web.config files. Refer to the one in the root folder.)


[{border="0"}]Note: The Web.config page appears.

{border="0"}Note:



***[·    ]***VS2010 automatically registers all ASP.NET handlers inside the machine.config file. So add the [\<][httpHandlers][\>] and [\<][handlers][\> ]tags under [\<][system.web][\> ]and [\<][system.webServer][\> ]respectively in the web.config file. For more information, refer to [[Clean Web.Config Files (VS 2010 and .NET 4.0 Series)]](http://weblogs.asp.net/scottgu/archive/2009/08/25/clean-web-config-files-vs-2010-and-net-4-0-series.aspx)

***[·    ]***X.X.X.X in the above code corresponds to the correct version number of the Essential Studio version that you are currently using.
