#### AllowSplitterBar and CollapseMode {#allowsplitterbar-and-collapsemode style="LINE-HEIGHT: 12pt; TEXT-INDENT: -43.2pt; MARGIN: 10pt 0pt 0pt 43.2pt; tab-stops: 43.2pt"}

These properties allow you to enable the splitter bar and to set the collapse mode of the splitter bar.

[·      ]**[None]**[: Will not display collapse button and the adjacent panes will not be collapsible]

[·      ]**[Forward:]**[ The splitter bar will display either left-to-right or top-to-bottom collapse button]

[When the user clicks the button, the left (top) adjacent pane will increase its size with the width/height of the right (bottom) adjacent pane.]

[·      ]**[Backward]**[: The splitter bar will display either right-to-left or bottom-to-top collapse button]

[When the user clicks the button, the right (bottom) adjacent pane will increase its size with the width/height of the left (top) adjacent pane.]

[·      ]**[Both]**[: Displays both buttons for forward and backward collapsing.]

 

**Properties**

+------------------+-----------------------------------------------------------------------------------------------------+-------------+---------------------------------------------------------------------------+--------------+
| Name             | Description                                                                                         | Type        | Value Accepted                                                            | Dependencies |
+------------------+-----------------------------------------------------------------------------------------------------+-------------+---------------------------------------------------------------------------+--------------+
| CollapseMode     | [Specifies the type of collapse mode of the splitter bar.] | Enum        | [CollapseType].Both[]     | NA           |
|                  |                                                                                                     |             |                                                                           |              |
|                  |                                                                                                     |             | [CollapseType].Forward[]  |              |
|                  |                                                                                                     |             |                                                                           |              |
|                  |                                                                                                     |             | [CollapseType].Backward[] |              |
|                  |                                                                                                     |             |                                                                           |              |
|                  |                                                                                                     |             | [CollapseType].None                               |              |
+------------------+-----------------------------------------------------------------------------------------------------+-------------+---------------------------------------------------------------------------+--------------+
| AllowSplitterBar | [Enables the splitter bar.]                                | Boolean     | True/False                                                                | NA           |
|                  |                                                                                                     |             |                                                                           |              |
|                  |                                                                                                     |             | Default value is true.                                                    |              |
+==================+=====================================================================================================+=============+===========================================================================+==============+
