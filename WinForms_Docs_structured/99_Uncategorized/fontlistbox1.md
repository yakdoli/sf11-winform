## FontListBox {#fontlistbox style="tab-stops: 0pt"}

A FontListBox is used to create a choice list of system fonts or a customized list of fonts.

 

Features

[] 

[·      ]It has the advanced ability to add font items to the FontListBox without a single piece of code.

[·      ]Easy to select fonts from the list box at run time.

[·      ]Enables to add custom source to the FontListBox collection.

[·      ]Supports adding groups like recently used fonts, all fonts and so on.

[·      ]Displays the font item in its own style.
