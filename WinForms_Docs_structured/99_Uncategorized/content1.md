##### Content {#content style="tab-stops: 0pt"}

[] 

You can align the content in the TableLayout control by using the **ContentAlignment** property. Also you can set the size by making use of the **Height**, **Width**, **MaxHeight**, **MaxWidth**, **MinHeight** and **MinWidth** properties. These are either set in Percentage or Pixel.
