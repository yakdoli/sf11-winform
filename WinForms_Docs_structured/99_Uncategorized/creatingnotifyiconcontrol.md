### Creating NotifyIcon Control {#creating-notifyicon-control style="tab-stops: 0pt"}

[] 

NotifyIcon is created either by using XAML code or with C# code, as follows.

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| [\<][syncfusion:NotifyIcon][ ][Name][=][\"[notifyIcon]\"[ ][BalloonTipText][=]\"[Custom Notify Icon is Available]\"[ ][BalloonTipTitle][=]\"[Default NotifyIcon]\"[ ][ShowBalloonTipTime][=]\"[1000]\"[ ][HideBalloonTipTime][=]\"[1000]\"[/\>]] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+--------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                   |
|                                                                                                                                                  |
| []                                                                                           |
|                                                                                                                                                  |
| [NotifyIcon notifyIcon = [new] NotifyIcon();]                           |
|                                                                                                                                                  |
| [notifyIcon.BalloonTipText = [\"Custom Notify Icon is Available\"];] |
|                                                                                                                                                  |
| [notifyIcon.BalloonTipTitle = [\"Default NotifyIcon\"];]             |
|                                                                                                                                                  |
| [notifyIcon.ShowBalloonTipTime = 1000;]                                                      |
|                                                                                                                                                  |
| [notifyIcon.HideBalloonTipTime = 1000;]                                                      |
+--------------------------------------------------------------------------------------------------------------------------------------------------+
