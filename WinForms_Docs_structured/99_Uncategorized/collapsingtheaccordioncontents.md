#### Collapsing the Accordion Contents {#collapsing-the-accordion-contents style="tab-stops: 0pt"}

Accordion provides support to collapse all the accordion contents at the same time.

 

Properties

+-------------+-----------------------------------------------------------------+----------------------+------------------+-------------+
| Name        | Description                                                     | Type of the property | Value it accepts | Dependency  |
+-------------+-----------------------------------------------------------------+----------------------+------------------+-------------+
| Collapsible | When set, all the accordion contents can be collapsed at a time | bool                 | true/false       | NA          |
|             |                                                                 |                      |                  |             |
|             |                                                                 |                      |                  |             |
+-------------+-----------------------------------------------------------------+----------------------+------------------+-------------+

Using Properties Model

The following steps explain the method to enable collapsing the Accordion contents using Properties model.

1.   In Controller, create an instance of **AccordionModel**, set the Collapsible property and pass the instance through view specific data to the view as given below. **

*[[]]{.underline}* 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[Controller\]]**                                                                                                                    |
|                                                                                                                                                                             |
| [public][ [ActionResult] Index()]                              |
|                                                                                                                                                                             |
| [        {]                                                                                                                             |
|                                                                                                                                                                             |
| [            [//Creating new instance of Accordion Model]]                                                        |
|                                                                                                                                                                             |
| [            [AccordionModel] myModel = [new] [AccordionModel]();] |
|                                                                                                                                                                             |
| [            myModel.TargetControlId = [\"AccordionContents\"];            ]                                    |
|                                                                                                                                                                             |
| [            myModel.Collapsible = [true];]                                                                        |
|                                                                                                                                                                             |
| []                                                                                                                                      |
|                                                                                                                                                                             |
| [            [//Passing the model through View Data]]                                                             |
|                                                                                                                                                                             |
| [            ViewData\[[\"myAccordion\"]\] = myModel;]                                                          |
|                                                                                                                                                                             |
| [            [return] View();]                                                                                     |
|                                                                                                                                                                             |
| [        }]                                                                                                                             |
|                                                                                                                                                                             |
| []                                                                                                                                      |
|                                                                                                                                                                             |
| []                                                                                                                  |
