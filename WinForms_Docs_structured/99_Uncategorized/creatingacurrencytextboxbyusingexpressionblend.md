##### Creating a CurrencyTextBox by using Expression Blend {#creating-a-currencytextbox-by-using-expression-blend style="tab-stops: 0pt"}

 

The steps to create a CurrencyTextBox in the application by using Expression Blend are as follows:

1.   Open Expression Blend.

2.   On the File menu, select **New Project**. This opens the New Project dialog box.

 

{border="0"}

Figure 226: Expression Blend

 

3.   In the Project types panel, select **WPF Application** and then click **OK**.

 

{border="0"}

Figure 227: New Project panel[]

[] 

[] 

4.   Add the following reference with the sample project:

[·      ]Syncfusion.Shared.WPF.dll

5.   On the Window menu, select **Assets**. This opens the Assets Library dialog box.

6.   In the Search box, type **CurrencyTextBox**. This displays the search results.

[] 

{border="0"}

Figure 228: Assets[]

[] 

7.   Drag the **CurrencyTextBox** control to Design View.

[] 

{border="0"}

Figure 229: Expression Blend -- Design View
