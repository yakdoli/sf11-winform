#### Custom Template for Close Button {#custom-template-for-close-button style="tab-stops: 0pt"}

ChromelessWindow enables you to write your own templates for the []{#DDE_LINK21}Close button in the TitleBar. **CloseButtonTemplate** property is used to apply the template for the close button.

 

To set the CloseButtonTemplate property, use the following code.

|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| [\<][shared][:][ChromelessWindow][ x][:][Class][=\"TestChromeless.Window1\"] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| [xmlns][=\"http://schemas.microsoft.com/winfx/2006/xaml/presentation\"]                                                                                                                                                                                                                                                                                                                                                                                                                 |
