#### Navigation and NavigationFilter {#navigation-and-navigationfilter style="tab-stops: 0pt"}

The following steps explain the Navigation of Accordion items.

 

Properties[]

+------------------+-------------------------------------------------------------------------------------------------------------+----------------------------------+----------------------+-------------+
| Name             | Description                                                                                                 | Type of the  Property            | Value it accepts     | Dependency  |
+------------------+-------------------------------------------------------------------------------------------------------------+----------------------------------+----------------------+-------------+
| Navigation       | If set, looks for the anchor that matches location.href and activates it. Great for href-based state-saving | [bool]   | True                 | NA          |
|                  |                                                                                                             |                                  |                      |             |
|                  |                                                                                                             |                                  | False                |             |
+------------------+-------------------------------------------------------------------------------------------------------------+----------------------------------+----------------------+-------------+
| NavigationFilter | Gets or Sets Navigation Filters. Overwrites the default location.href-matching with your own matcher        | [String] | Any Function Handler | Navigation  |
+------------------+-------------------------------------------------------------------------------------------------------------+----------------------------------+----------------------+-------------+
