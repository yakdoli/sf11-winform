### Custom CSS {#custom-css style="tab-stops: 0pt"}

The OlapGrid control provides the option to customize its appearance using user-defined CSS. To enable custom CSS, set the **AutoFormat** as **Custom** and **CssClass** to your CSS class name.

 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                  |
| []                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                  |
| [this.][OlapGrid1.AutoFormat = ][Autoformat][.Custom;] |
|                                                                                                                                                                                                                                                  |
| [this.][OlapGrid1.CssClass = [\"CustomCssName\"];]                                                                                      |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                              |
|                                                                                                                                                                                                                                               |
| []                                                                                                                                                                                           |
|                                                                                                                                                                                                                                               |
| [Me.][OlapGrid1.AutoFormat = ][Autoformat][.Custom] |
|                                                                                                                                                                                                                                               |
| [Me.][OlapGrid1.CssClass = [\"CustomCssName\"]]                                                                                      |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
