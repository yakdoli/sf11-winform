#### Setting the FlowDirection for GroupBar {#setting-the-flowdirection-for-groupbar style="tab-stops: 0pt"}

 

Flow Direction of the GroupBar is set by using the **FlowDirection** property.

 


+-----------------------------------+----------------------------------------------------------------------------------------+
| Property                          | Description                                                                            |
+-----------------------------------+----------------------------------------------------------------------------------------+
| FlowDirection                     | Sets the flow direction for the GroupBar control. The options provided are as follows. |
|                                   |                                                                                        |
|                                   | []   |
|                                   |                                                                                        |
|                                   | [·      ]LeftToRight                                      |
|                                   |                                                                                        |
|                                   | [·      ]RightToLeft                                      |
+-----------------------------------+----------------------------------------------------------------------------------------+
