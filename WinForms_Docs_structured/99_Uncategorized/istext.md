### IsText {#istext style="tab-stops: 0pt"}

The **IsText** function returns a boolean value after determining that the provided value is a string.

 

**Syntax:**

**IsText(text)**

 

**where,**

[·      ]**text** is the value you want to test to check if it is a string or not.
