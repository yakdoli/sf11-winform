## Strongly Typed View {#strongly-typed-view style="tab-stops: 0pt"}

[A strongly typed view is a view that defines its data model as a class instead of a weakly typed dictionary, which could literally hold anything. ]

Advantages

[Strongly typed views offer a number of advantages over standard views:]

[•   ][You don\'t have to go through the laborious process of setting properties in **ViewData**; values can instead be retrieved from **ViewData.Model**.]

[•   ][IntelliSense is supported.]

[•   ][Type safety is supported.]

[•   ][There is no unnecessary casting between types in **ViewData**.]

[•   ][Compile time checks can be implemented.]
