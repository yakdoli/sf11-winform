##### Client-Side Events {#client-side-events style="tab-stops: 0pt"}

[] 

The various client side events of CallbackMultiplexer are given below.

[] 


+---------------------------------------+------------------------------------------------------------------------------------+
|                                       |                                                                                    |
|                                       |                                                                                    |
| Event                                 | Description                                                                        |
+---------------------------------------+------------------------------------------------------------------------------------+
| AfterCallbackResponseProcessedScript  | Specifies the script to execute after the callback result is processed.            |
+---------------------------------------+------------------------------------------------------------------------------------+
| AfterCallbackScript                   | Specifies the script to execute after the callback request is sent to the server.  |
+---------------------------------------+------------------------------------------------------------------------------------+
| BeforeCallbackReponseProcessingScript | Specifies the script to execute before the callback result is processed.           |
+---------------------------------------+------------------------------------------------------------------------------------+
| BeforeCallbackScript                  | Specifies the script to execute before the callback request is sent to the server. |
+---------------------------------------+------------------------------------------------------------------------------------+


[] 

Also you can use **BeforeCallbackResponseProcessingScript** and **AfterCallbackResponseProcessedScript** client side events of each CallbackPanels, that is refreshed on callback.

 

The following example shows how to use CallbackMultiplexer and CallbackPanels client side events.
