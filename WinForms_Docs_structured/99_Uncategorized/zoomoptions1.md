[ **Zoom Operations**]

**[ ]**[Zoom operations can be performed by two methods. They are:]

[·      ][Using the ZoomPan window]

[·      ][Using commands]

**[]** 

**[Using ZoomPan Window]**

[You can perform zooming operation by resizing the ZoomPan Window.]

**[]** 

**[Using]**[ **Commands**]

[You can perform zooming operation using commands.]
