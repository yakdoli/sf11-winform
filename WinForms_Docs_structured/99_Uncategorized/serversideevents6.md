##### Server-Side Events {#server-side-events style="tab-stops: 0pt"}

[] 

The server side events for the Calendar control are listed in the below table.

[] 


  --------------------- ---------------------------------------------------------------------------------------------
  Server-Side Event     Description
  SelectedDateChanged   Occurs when the user had changed the selected date.
  VisibleMonthChanged   Occurs when the user clicks the next/previous month navigator buttons on the title heading.
  RenderDay             Occurs when each day cell in the current calendar month is being rendered.
  --------------------- ---------------------------------------------------------------------------------------------


[] 

To execute the server side events, the **AutoPostBackOnSelectedDateChanged** and the **AutoPostBackOnVisibleMonthChanged** properties must be enabled for the respective events, which triggers a postback and handles the server side event.

[] 


  ----------------------------------- ---------------------------------------------------------------------------------------
  Property                            Description
  AutoPostBackOnSelectedDateChanged   Indicates whether to perform a postback on the page, when a selected date is changed.
  AutoPostBackOnVisibleMonthChanged   Indicates whether to perform a postback on the page, when a visible month is changed.
  ----------------------------------- ---------------------------------------------------------------------------------------


[]
