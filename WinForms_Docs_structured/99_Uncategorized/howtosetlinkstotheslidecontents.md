##### How to set links to the slide contents {#how-to-set-links-to-the-slide-contents style="tab-stops: 0pt"}

[] 

We can give links to any of our contents present in a Rotator control. This tutorial has given a small sample to do this.

[] 

1.   Create an xml file with name products.xml. Add it into your project.  

[] 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                        |

| [  ]                                                                                                                                |

|                                                                                                                                                                                                       |
| [form1.Controls.Add(ticker1);]                                                                                                                    |
|                                                                                                                                                                                                       |
| [ticker1.Text = [\"This is a sample text\"];]                                                                              |
