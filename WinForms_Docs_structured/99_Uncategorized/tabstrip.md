### TabStrip {#tabstrip style="tab-stops: 0pt"}

 

 The TabStrip control enables the creation of rich tabbed user interfaces in your pages.

 

Features

 

[·      ]Custom styles: the look and feel of the control can be customized and enhanced using css styles

[·      ]Server and Client side Events: supports client and server side events

[·      ]Integration with Multipage: ability to integrate TabStrip with Essential Tools MultiPage control to create a fully tabbed environment

[·      ]Orientation: support for tab and text orientation along any edge

[·      ]Hierarchical Tabstrip: Tabstrip allows you to set multiple levels of tab elements

[·      ]Keyboard Shortcut: the tab elements can be easily accessed by setting your own shortcut keys

[·      ]Scrollbar options: scroll buttons can be set for both horizontal and vertical tabstrip that enables you to traverse through the tab elements

[·      ]Browser: TabStrip control can be hosted in Safari browser too
