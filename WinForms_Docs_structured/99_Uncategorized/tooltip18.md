## ToolTip {#tooltip style="tab-stops: 0pt"}

OlapGrid can additionally display the dimension member information within a tooltip when the mouse pointer is moved over the Value Cells of the OlapGrid control.

Use Case Scenario[[]]{.Heading3Char}

ToolTip helps users to view the Measure and Dimension information of cells quickly.
