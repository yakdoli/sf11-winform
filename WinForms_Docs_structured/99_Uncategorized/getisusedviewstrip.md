#### []{#_GetIsUsedViewStrip}GetIsUsedViewStrip

This method is used to check whether the ViewStrip is used in the schedule control or not. It takes no argument and returns a Boolean value.

It returns true, when ViewStrip is used in the schedule else returns false.
