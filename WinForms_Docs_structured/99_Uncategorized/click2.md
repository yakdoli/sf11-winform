#### Click {#click style="tab-stops: 0pt"}

The Click event occurs when the ButtonAdv element is pressed.

The Click event can be implemented as shown in the following codes:

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\][]]**                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                  |
| []                                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                  |
| [\<][sync][:][ButtonAdv][ Click][=\"button_Click\"/\>][] |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]

| **[\[C#\][]]**                                                                                                                  |
|                                                                                                                                                                                             |
