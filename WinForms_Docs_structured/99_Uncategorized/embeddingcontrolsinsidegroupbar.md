##### Embedding Controls inside Groupbar {#embedding-controls-inside-groupbar style="tab-stops: 0pt"}

[] 

Groupbar control supports the use of templates to help embed any custom control as a child of the root groupbar item instance. Template can contain any server controls or html controls.

[] 

{border="0"}

**[]** 

Figure 329: Syncfusion TreeView Embedded inside the GroupBar

[] 

1.   To the application, GroupBar, TreeView and ASP.NET Calendar controls should be added.

12.  Define the treeview and calendar controls inside the GroupBarTemplateControl (set an ID for the control) and **Template** tags.

13.  The html view (sample code snippet) of TreeView and Calendar controls embedded inside GroupBar.
