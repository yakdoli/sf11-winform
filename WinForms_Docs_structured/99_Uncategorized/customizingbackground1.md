##### Customizing Background {#customizing-background style="TEXT-JUSTIFY: inter-ideograph; TEXT-ALIGN: justify; TEXT-INDENT: -36pt; MARGIN: 10pt 0pt 0pt 36pt; tab-stops: 36.0pt"}

To customize the background, use the *PageBackground* of DiagramView. Default value is White.
