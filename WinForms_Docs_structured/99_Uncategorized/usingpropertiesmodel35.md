##### Using Properties Model {#using-properties-model style="tab-stops: 0pt"}

The following steps explain the addition of Accordion to an application using the Properties model:

1.   In the **Controller**, create an instance of the [MobAccordionModel], define the properties and pass the instance through **View Specific Data** to **View** as given below.

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| [\[Controller] [\]]                                      |
|                                                                                                                                                                                |
| [public] [ [ActionResult] Accordion()]                            |
|                                                                                                                                                                                |
| [        {]                                                                                                                                |
|                                                                                                                                                                                |
| [            [MobAccordionModel] model = [new][MobAccordionModel]();] |
|                                                                                                                                                                                |
| [            \-\-\-\-\--]                                                                                                                  |
|                                                                                                                                                                                |
| [            model.FillSpace = [true];]                                                                               |
|                                                                                                                                                                                |
| [            \-\-\-\-\-\--]                                                                                                                |
|                                                                                                                                                                                |
| [            ViewData\[[\"AccordionModel\"]\] = model;]                                                            |
|                                                                                                                                                                                |
| [            [return] View();]                                                                                        |
|                                                                                                                                                                                |
| [        }]                                                                                                                                |
|                                                                                                                                                                                |
| []                                                                                                                                         |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
