#### AllowEdit {#allowedit style="tab-stops: 0pt"}

 

The *AllowEdit* property is used to specify whether the value in the control can be edited or not. The following code illustrates this.

 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| [\<][syncfusion][:][NumericUpDown][ x][:][Name][=\"NumericUpDown1\"][ AllowEdit][=\"true\" /\>] |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+-----------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                  |
|                                                                                                                 |
| []                                                                          |
|                                                                                                                 |
| [NumericUpDown numericUpDown = [new] NumericUpDown();] |
|                                                                                                                 |
| [numericUpDown.AllowEdit = [true];]                    |
+-----------------------------------------------------------------------------------------------------------------+
