#### Handle Buttons Visibility {#handle-buttons-visibility style="tab-stops: 0pt"}

[] 

The **HandleButtonVisibility**[ ]property specifies the visibility of Handle Buttons. Handle Buttons are used for displacement of thumbs to specified intervals. Its default is true. When set to false, the visibilities of Handle Buttons collapse.

[]
