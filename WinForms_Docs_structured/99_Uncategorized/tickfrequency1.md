#### Tick Frequency {#tick-frequency style="tab-stops: 0pt"}

[] 

The **TickFrequency** property specifies the interval at which Ticks and Labels are to be placed. For example, if the range is set from 0-100, where minimum is set to 0 and maximum is set to 100, and the TickFrequency is set to 20, then Ticks will be placed at positions 0, 20,40,..,100.
