##### Animation Speed {#animation-speed style="tab-stops: 0pt"}

The speed of animation that is generated while expanding or collapsing the TreeViewAdv is controlled by using the **AnimationSpeed** property. The default value of this property is set to ***1***. To set this property, use the below code
