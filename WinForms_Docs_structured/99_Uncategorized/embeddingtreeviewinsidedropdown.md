##### Embedding TreeView inside DropDown {#embedding-treeview-inside-dropdown style="tab-stops: 0pt"}

[] 

Any control can be flexibly integrated inside the dropdown container. The following code snippet illustrates how to add a TreeView control inside the DropDown portion of the GenericDropDown control.

[] 

{border="0"}

**[]** 

Figure 100: TreeView embedded inside GenericDropDown

[] 

1.   Open a Web application, and drag the **GenericDropDown** control onto the Web Page.

2.   Drag the **TreeView** control onto the drop-down area of the control.

3.   The html view of the Web application will look as follows.
