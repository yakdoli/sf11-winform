#### Use of MinZoom and MaxZoom {#use-of-minzoom-and-maxzoom style="tab-stops: 0pt"}

MinZoom value is used to set a minimum ZoomFactor value. Below the MinZoom value the Map cannot be zoomed out.

MaxZoom value is used to set a Maximum ZoomFactor value. After the MinZoom value the Map cannot be zoomed in.
