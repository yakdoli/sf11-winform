#### [[Loading by OpenFileDialog]]{.Heading3Char} {#loading-by-openfiledialog style="tab-stops: 0pt"}

 

LoadFromStream method:

The file that is selected by OpenDialog will be converted to FileStream and then the FileStream will be set as a parameter for the method along with the file name. Then, the method will convert the FileStream as Shapes or Polygons.

The following code snippet will describe how to load the shape files:
