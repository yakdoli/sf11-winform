#### DropDownCalendarControl {#dropdowncalendarcontrol style="tab-stops: 0pt"}

 

The DropDownCalendarControl displays a month calendar from which users can select dates.

 

{border="0"}

Figure 51

 

Features

 

[·      ]Supports setting of minimum and maximum values.

[·      ]Supports Data Binding with a datasource.

[·      ]Uses globalization features of .NET platform to provide locale-specific formatting.

[·      ]The control can be hosted in Safari browser too.
