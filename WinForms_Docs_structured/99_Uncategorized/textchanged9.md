#### TextChanged {#textchanged style="tab-stops: 0pt"}

 

TextChanged -- The event occurs when the PercentValue property of the PercentTextBox is changed.

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
