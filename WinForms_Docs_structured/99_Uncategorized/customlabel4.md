##### Custom Label {#custom-label style="tab-stops: 0pt"}

[This feature allows you to add custom text labels using the CustomLabel element of gauge.  ]

[The label value can be set using its  **LabelValue**  property. You can also customize the custom text, using the **Font** properties.]

[The location of the label can be customized using its **Location** property, and its custom text angle can be set using the **TextAngle** property.]

[These properties and others for this feature are given below:]

  ---------------------------------------------------------------------------------------------------------- ------------------------------------------------------------------------------------------------------------- --------------------------------------------------------------------------------------------------------------------- ----------------------------------------------------------------------------------------------------------- -----------------------------------------------------------------------------------------------------------------
  **[Property ]** []   **[Description ]** []   **[Type ]** []                  **[Data Type ]** []   **[Reference links ]** []
  [ LabelValue]                                                   [Sets the label text for the circular gauge]                       [Server-Side] [ /Client-Side]   [String]                                                         [NA]
  [LabelColor]                                                    [Sets the color of the label text]                                 [Server-Side ]                                                             [Color]                                                          [NA]
  [Location]                                                      [Sets the location of the label]                                   [Server-Side/Client-Side]                                                  [Point]                                                          [NA]
  [Opacity]                                                       [Sets the opacity for the label]                                   [Server-Side/Client-Side]                                                  [Double]                                                         [NA]
  [TextAngle]                                                     [Sets the angle of the custom label]                               [Server-Side/Client-Side]                                                  [Double]                                                         [ NA]
