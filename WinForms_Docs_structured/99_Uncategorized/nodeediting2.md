#### Node Editing {#node-editing style="tab-stops: 0pt"}

[] 

You can easily edit the tree node items at runtime, by enabling **IsEditable** property to ***true***. At runtime, you can edit a node, by simply clicking the node text.

Setting Node in EditMode

**[]** 

You can also set a node to be in edit mode when the tree view loads. This is done using the **IsInEditMode** property. When this property is set to ***true***, the particular node will be in edit mode when it loads.

[]
