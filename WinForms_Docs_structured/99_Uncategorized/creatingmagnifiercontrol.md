### Creating Magnifier control {#creating-magnifier-control style="tab-stops: 0pt"}

[] 

Magnifier control is created programmatically using either XAML or C# code.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| []                                                                                                                                                                                                                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [\<][syncfusion][:][Magnifier][ Name][=\"magnifier1\"/\>] |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                       |
|                                                                                                                                                                                                                      |
| []                                                                                                                                                 |
|                                                                                                                                                                                                                      |
| [// grid is the name of grid control]                                                                                                              |
|                                                                                                                                                                                                                      |
| [Magnifier][ magnifier1 = [new] [Magnifier]();] |
|                                                                                                                                                                                                                      |
| [grid.Children.Add(magnifier1);]                                                                                                                                 |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
