##### Frequently Asked Questions {#frequently-asked-questions style="tab-stops: 0pt"}

When the control is set to disabled, we could not make any changes in it. But we can make the text active by setting **DrawActiveWhenDisabled** to **True.**[]

[] 


  -------------------------------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------
  CurrencyTextBox Property[]   Description[]
  DrawActiveWhenDisabled[]     Specifies whether the text should be drawn active even when the control is disabled. **Enabled** property must be set to **False.**[]
  -------------------------------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------
