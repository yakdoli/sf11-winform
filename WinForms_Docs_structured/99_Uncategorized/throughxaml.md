##### Through XAML {#through-xaml style="tab-stops: 0pt"}

To create the CardView control through XAML, add the following namespace to the directives list.

 

+------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                             |
|                                                                                                                                                |
| **[]**                                                                                                     |
|                                                                                                                                                |
| [xmlns:syncfusion=http://schemas.syncfusion.com/wpf][] |
+------------------------------------------------------------------------------------------------------------------------------------------------+

 

After adding the above namespace the CardViewControl can be added to the application as shown below:
