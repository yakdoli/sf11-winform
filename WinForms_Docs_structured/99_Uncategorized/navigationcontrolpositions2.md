### Navigation Control Positions {#navigation-control-positions style="tab-stops: 0pt"}

 

Navigation control can be positioned at the following places on Maps control.

[·      ]Top

[·      ]Right

[·      ]Bottom

[·      ]Left

 

**NavigationControlPosition** is the property, which is used to set the position of Navigation control on Map Control.

The following code snippet will demonstrate how to set position for the Navigation control.
