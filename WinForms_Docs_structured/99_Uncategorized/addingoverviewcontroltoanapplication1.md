### Adding Overview Control to an Application {#adding-overview-control-to-an-application style="tab-stops: 0pt"}

[Follow the steps below to add the Overview control. ]

[1.   Host the content within the*** *OverviewContentHolder** instead of **ScrollViewer** as shown in the following code:]

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| [ ]**[\[XAML\]]**                                                                                                                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                              |
| [\<][ScrollViewer ][Name][=\"SourceAncestor\"\>]                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                              |
| [            ][\<][syncfusion][:][OverviewContentHolder][\>]  |
|                                                                                                                                                                                                                                                                                                                                                                              |
| [               ][\<!---The content should be placed here \--\>]                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                              |
| [            ][\</][syncfusion][:][OverviewContentHolder][\>] |
|                                                                                                                                                                                                                                                                                                                                                                              |
| [        ][\</][ScrollViewer][\>]                                                                                                                                  |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[  ]

[2.   Create an instance of Overview and set the **OverviewSourceAncestor** property to **OverviewContentHolder** or one of its visual parents as shown in the following code:]

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|  [\<][syncfusion][:][Overview][ OverviewSourceAncestor][=\"{][Binding][ElementName][=SourceAncestor}\"/\>] |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
