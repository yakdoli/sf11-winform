### Creating Clock Control {#creating-clock-control style="tab-stops: 0pt"}

You can create a Clock control either by using XAML code or C# code. Use the below code snippet to create a Clock control.

 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                               |
| []                                                                                                                                                                                                                                                                                                                                                           |
|                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [\<][syncfusion][:][Clock][ [ Name][=\"ctlClock\"/\>]] |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

**[]** 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                       |
|                                                                                                                                                                                                      |
| **[]**                                                                                                                             |
|                                                                                                                                                                                                      |
| [Clock][ cl = [new] [Clock]();] |
|                                                                                                                                                                                                      |
| [cl.Name = [\"ctlClock\"];]                                                                                              |
|                                                                                                                                                                                                      |
| [stackPanel.Children.Add(cl);]                                                                                                                   |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 


{border="0"}Note: For creating a Clock control using C# code, you must already have the Panel in which you are going to add the control. Otherwise, the control cannot be displayed.
