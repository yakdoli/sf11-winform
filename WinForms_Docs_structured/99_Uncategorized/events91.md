#### Events {#events style="tab-stops: 0pt"}

The following events are associated with the Dialog control:

 

[·      ]**DialogOpening** -- Triggered when dialog is opening

[·      ]**DialogOpened --** Triggered when dialog is opened

[·      ]**DialogClosing --** Triggered when dialog is closing

[·      ]**DialogClosed --** Triggered when dialog is closed
