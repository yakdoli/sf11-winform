### NormsInv {#normsinv style="tab-stops: 0pt"}

The **NormsInv** function returns the standard normal random variable that has *Mean* 0 and *Standard Deviation* 1

 

**Syntax:**

**NormsDist(value)**

 

**where,**

[·      ]**value** is probability of the standard deviation.
