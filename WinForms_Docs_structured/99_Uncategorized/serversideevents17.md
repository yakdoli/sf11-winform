##### Server-Side Events {#server-side-events style="tab-stops: 0pt"}

The items in the gallery view support the server side click event.

The following code snippet explains this:

4.   Build and run the application that the GalleryView1_Click method will be handling when you click on the items in the Gallery.

In the above sample SelectedItem gives the items value in the Gallery Window; while SelectedExtraItem gives the items value in GalleryExtraItems Window.
