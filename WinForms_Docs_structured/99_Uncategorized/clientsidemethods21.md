#### Client-Side Methods {#client-side-methods style="tab-stops: 0pt"}

The following section details the client-side methods supported by the Ribbon control.

 

**Properties**

 


  **[Method ]**[]   **[Description ]**[]                       **[Parameters ]**[]   **[Return Type ]**[]
  ------------------------------------------------------------- -------------------------------------------------------------------------------------- ----------------------------------------------------------------- ------------------------------------------------------------------
  ShowContextTab(name)                                          [Shows the contextual tab for the selected items in the page.]   [Name of the contextual tab.]               [NA]
  ShowTab(name)                                                 [Shows the ribbon tab.]                                          [Name of the ribbon tab.]                   [NA]
  HideContext(name)                                             [Hides the contextual tab for the selected items in the page.]   [Name of the contextual tab.]               [NA]
  HideTab(name)                                                 [Hides the ribbon tab.]                                          [Name of the ribbon tab.]                   [NA]

The following steps explain how to use the client-side methods.

3.   In the **view**, invoke the **Ribbon** helper with the control ID as the first argument.
