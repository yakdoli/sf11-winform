#### Range Fill {#range-fill style="tab-stops: 0pt"}

The selected range of the slider will be highlighted. You can specify the highlight color using the *RangeFill* property. 

 

The following code illustrates how to set the highlight color as green:

 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                          |
|                                                                                                                                                                                        |
| [  [RangeSlider] slider1 = [new] [RangeSlider]();]               |
|                                                                                                                                                                                        |
| [  slider1.RangeFill = [new] [SolidColorBrush]([Colors].Green);] |
|                                                                                                                                                                                        |
| []                                                                                                                                        |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
