##### FlowDirection {#flowdirection style="tab-stops: 0pt"}

 

The *FlowDirection* property specifies the flow direction for the control. It can be set to one of the following values:

         

[·      ]LeftToRight

[·      ]RightToLeft

 

The following code illustrates this.

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [\<][syncfusion][:][DomainUpDown][ x][:][Name][=\"DomainUpDown1\"][ FlowDirection][=\"LeftToRight\" /\>] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                               |
|                                                                                                                                                                                              |
| []                                                                                                                                                       |
|                                                                                                                                                                                              |
| [DomainUpDown][ domainUpDown = [new] [DomainUpDown]();] |
|                                                                                                                                                                                              |
| [domainUpDown.FlowDirection = EnumFlowDirection.LeftToRight;]                                                                                            |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
