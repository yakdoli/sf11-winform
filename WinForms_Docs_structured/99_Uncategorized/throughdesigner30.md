##### Through Designer {#through-designer style="tab-stops: 0pt"}

[] 

The following steps illustrate how to create the jQueryUITabs control through designer.

[] 

1.   Drag the jQueryUITabs control from the toolbox onto the form and add the following code in the aspx page.

[]

|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [\<][Syncfusion][:][jQueryUITab][ [ID][=\"JQueryUITab1\"] [runat][=\"server\"\>]]                                                                                                                             |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [\<][Syncfusion][:][jQueryUITabItem][ [Text][=\"Header1\"\>]This the content for the Header1.[\</][Syncfusion][:][jQueryUITabItem][\>]] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
