### How do I switch between MVC2 and MVC3 assemblies in  the 9.1version? {#how-do-i-switch-between-mvc2-and-mvc3-assemblies-in-the-9.1version style="tab-stops: 0pt"}

[] 

MVC3 to MVC2:

1.   Run the **SwitchMVC2.bat** file ***(\<Install Location**[\>]\\Syncfusion\\Essential Studio\\9.1.0.20\\Utilities\\MVCVersionSwitcher)***, it will move MVC2 assemblies to the precompiled assemblies folder and configures the sample browser to MVC2.

2.   Run the Assembly Manager from the dashboard manually to place the MVC2 assemblies in GAC.

[] 

MVC2 to MVC3:

1.   Run the **SwitchMVC3.bat** file ***(\<Install Location**[\>]\\Syncfusion\\Essential Studio\\9.1.0.20\\Utilities\\MVCVersionSwitcher)***, it will move MVC3 assemblies to the precompiled assemblies folder and configures the sample browser to MVC3.

2.   Run the Assembly Manager from the dashboard manually to place the MVC3 assemblies in GAC.

[]
