#### Data Source {#data-source style="tab-stops: 0pt"}

 

You can set System or a Custom Folder as the source for the FontListComboBox by using the **FontsSource** property. To set the data source for **FontListComboBox**, use the following code snippet.

 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [\<][syncfusion][:][FontListComboBox][ FontsSource][=\"C:\\\\FontFolderName\"][ x][:][Name][=\"FontListComboBox1\" /\>] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [\<][syncfusion][:][FontListComboBox][ FontsSource][=\"System\"][ x][:][Name][=\"fontlistcombobox1\" /\>]               |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                            |
|                                                                                                                                           |
| []                                                                                                    |
|                                                                                                                                           |
| [//To set the font source to system]                                    |
|                                                                                                                                           |
| [fontlistcombobox1.FontsSource = [\"System\"];]               |
|                                                                                                                                           |
| []                                                                                    |
|                                                                                                                                           |
| [//To set the font source to Custom folder]                             |
|                                                                                                                                           |
| [fontlistcombobox1.FontsSource = [\"C:\\\\FontFolderName\"];] |
+-------------------------------------------------------------------------------------------------------------------------------------------+
