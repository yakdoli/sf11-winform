### Navigate Resource {#navigate-resource style="tab-stops: 0pt"}

**[]** 

It is not possible to view all the appointment data grouped by the resources. The built-in Resource Navigator helps us to navigate the resources. If more then one resource occurs in a single schedule page, the navigator button will be shown automatically. The resource header bar has two buttons. One is to navigate to the \"previous\" resource and the other is to navigate to the \"next\" resource. If no button is displayed, then it represents \"Null\" resources.**[]**
