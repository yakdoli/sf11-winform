##### Binding the Color to an Object {#binding-the-color-to-an-object style="tab-stops: 0pt"}

This is a one way binding. You can bind the selected color to a specific object. When you bind the selected color to an object, the value of the target element will automatically change as you change the source color value.

 

The following code illustrates how to bind the selected color to a rectangle:
