### Applying Themes {#applying-themes style="MARGIN-LEFT: 18pt; tab-stops: 18.0pt"}

**[]** 

The TabControlAdv can be themed by enabling the **ThemesEnabled** property.

[] 


{border="0"} Note:[ ]On setting this property, all the tabpages will be themed. This can be disabled or enabled for individual pages using the TabPageAdv.ThemesEnabled property.


[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                            |
|                                                                                                                                                           |
| **[]**                                                                                                  |
|                                                                                                                                                           |
| [this][.tabControlAdv1.ThemesEnabled = [true];] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
