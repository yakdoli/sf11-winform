##### [Appearance]{#Appearance} {#appearance style="tab-stops: 0pt"}

The appearance of the OlapPager can be customized using the **CssClass** property. The custom CssClass style should have the following CSS styles associated with it:

[·      ]MovePrev---Defines styles for the **Move Previous** button

[·      ]MoveNext---Defines styles for the **Move Next** button

[·      ]MovePrevDisabled---Defines styles for the **Move Previous** button's disabled state

[·      ]MoveNextDisabled---Defines styles for the **Move Next** button's disabled state

[·      ]PagerPanel---Defines styles for the Pager panel

[·      ]PageBox---Defines styles for the **CurrentPage** text box

[·      ]Text---Defines styles for spans used in the pager
