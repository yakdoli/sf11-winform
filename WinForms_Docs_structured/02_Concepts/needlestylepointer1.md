##### Needle Style Pointer {#needle-style-pointer style="tab-stops: 0pt"}

[] 

Pointer Needle can be customized by using the **NeedleStyle** property. The following are the in-built styles available for the NeedleStyle property.

[] 

The styles are listed below.

[] 

[·      ]Arrow

[·      ]Rectangle

[·      ]Trapezoid

[·      ]Triangle

[]
