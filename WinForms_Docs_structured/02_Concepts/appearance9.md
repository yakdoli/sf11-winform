### Appearance {#appearance style="tab-stops: 0pt"}

 

Essential Grid has several built-in skins that make styling extremely easy. It is also possible to easily format the data displayed in the grid.

 

Essential Grid for ASP.NET MVC contains 14 built-in skins to easily customize appearance. Essential Grid\'s **AutoFormat** property allows you to apply predefined skins to the control. Some of the available skins are illustrated in detail in the [[Built-in Skin Styles]]{.underline} section.
