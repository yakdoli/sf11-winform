Using Properties Model

The following steps explain the setting of the Syncfusion theme for Accordion using Properties model.

1.   In the **Controller**, create an instance of **AccordionModel**, define the **AutoFormat** property and pass the instance through view specific data to **View** as given below. **

 

*[[]]{.underline}* 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[Controller\]]**                                                                                                                    |
|                                                                                                                                                                             |
| **[]**                                                                                                                                  |
|                                                                                                                                                                             |
| [public][ [ActionResult] Index()]                              |
|                                                                                                                                                                             |
| [        {]                                                                                                                             |
|                                                                                                                                                                             |
| [            [//Creating new instance of Accordion Model]]                                                        |
|                                                                                                                                                                             |
| [            [AccordionModel] myModel = [new] [AccordionModel]();] |
|                                                                                                                                                                             |
| [            myModel.TargetControlId = [\"AccordionContents\"];]                                                |
|                                                                                                                                                                             |
| [            myModel.AutoFormat = [Skins].VS2010;                       ]                                       |
|                                                                                                                                                                             |
| [            ]                                                                                                                          |
|                                                                                                                                                                             |
| [            [//Passing the model through View Data]]                                                             |
|                                                                                                                                                                             |
| [            ViewData\[[\"myAccordion\"]\] = myModel;]                                                          |
|                                                                                                                                                                             |
| [            [return] View();]                                                                                     |
|                                                                                                                                                                             |
| [        }]                                                                                                                             |
|                                                                                                                                                                             |
| []                                                                                                                  |
