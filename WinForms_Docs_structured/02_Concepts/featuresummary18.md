### Feature Summary {#feature-summary style="tab-stops: 0pt"}

The features of TimeLine Control are:

[·      ]Panning of selected data can be done by using drag and drop in view port

[·      ]View port can also be resized to modify the selected data

[·      ]Double-clicking the view port will display the minimum time line interval

[·      ]When there is an unselected area in TimeLine control, the view port will be automatically dragged to the selected area

[·      ]When mouse over is done on the view port it will display the minimum TimeLine interval
