##### Marker Style {#marker-style style="tab-stops: 0pt"}

[] 

You can customize the Marker by using the **MarkerStyle** property. The following are the built-in styles supported by the MarkerStyle property.

[] 

[·      ]Diamond

[·      ]Ellipse

[·      ]Pentagon

[·      ]Rectangle

[·      ]Trapezoid

[·      ]Triangle

[]
