#### [Appearance]{#Appearance} {#appearance style="tab-stops: 0pt"}

Appearance of OlapPager can be customized using the CssClass property. The custom CssClass style should have the following CSS styles associated with it:

 

[·      ]MovePrev -- Defines styles for Move Previous button

[·      ]MoveNext -- Defines styles for Move Next button

[·      ]MovePrevDisabled - Defines styles for Move Previous button's Disabled State

[·      ]MoveNextDisabled - Defines styles for Move Next button's Disabled State

[·      ]PagerPanel -- Defines styles for Pager panel

[·      ]PageBox -- Defines styles for CurrentPage textbox

[·      ]Text -- Defines styles for spans used in Pager

Adding OlapPager to an Application

 

To enable paging in an application:

[1.   ]Drag and Drop **OlapChart** to the page

[2.   ][Bind the ]OlapDataManager[ to the chart]

[3.   ][Drag and Drop the ]OlapPager[ to the page]

[4.   ][Set the ]OlapControlID[ to Pager.]

[5.   ][Call the ]DataBind()[ of OlapChart method.]
