Using Properties Model

The following steps explain the setting of the jQuery theme for the Accordion through properties model.

1.   In the Controller, create an instance of AccordionModel, define the **jQueryAutoFormat** property and pass the instance through **View Specific Data** to **View** as given below. **

*[[]]{.underline}* 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[Controller\]]**                                                                                                                    |
|                                                                                                                                                                             |
| **[]**                                                                                                                                  |
|                                                                                                                                                                             |
| [public][ [ActionResult] Index()]                              |
|                                                                                                                                                                             |
| [        {]                                                                                                                             |
|                                                                                                                                                                             |
| [            [//Creating new instance of Accordion Model]]                                                        |
|                                                                                                                                                                             |
| [            [AccordionModel] myModel = [new] [AccordionModel]();] |
|                                                                                                                                                                             |
| [            [//Setting the properties]]                                                                          |
|                                                                                                                                                                             |
| [            myModel.TargetControlId = [\"AccordionContents\"];]                                                |
|                                                                                                                                                                             |
| [            myModel.jQueryAutoFormat = [jQuerySkins].Blitzer;                       ]                          |
|                                                                                                                                                                             |
| [            ]                                                                                                                          |
|                                                                                                                                                                             |
| [            [//Passing the model through View Data]]                                                             |
|                                                                                                                                                                             |
| [            ViewData\[[\"myAccordion\"]\] = myModel;]                                                          |
|                                                                                                                                                                             |
| [            [return] View();]                                                                                     |
|                                                                                                                                                                             |
| [        }]                                                                                                                             |
