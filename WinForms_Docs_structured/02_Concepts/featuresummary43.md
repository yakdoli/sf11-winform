## Feature Summary {#feature-summary style="tab-stops: 0pt"}

The important features of Essential Report Designer for WPF are listed below:

 

[·      ]**Data sources**---You can use advanced database servers data sources in Report Designer (SQL Server 2008 and Oracle)

[·      ]**Data sets**---You can add data sets to the data source

[·      ]**Tablix**---Shows summaries and simple tables

[·      ]**Textbox**---Shows textbox data with expression support

[·      ]**Report Parameter**---Views the report based on report parameter value

[·      ]**Basic Expression**---You can use expression to handle reports

[·      ]**Customization**---Customizes the appearance of Report Designer
