## Theme Support {#theme-support style="tab-stops: 0pt"}

OLAP Client control provides the following theme support.

[·      ]Classic

[·      ]Office2010Blue

[·      ]Office2010Black

[·      ]Office2010Silver

[·      ]Custom CSS

 

This can be achieved by setting the "Autoformat" property.

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                  |
|                                                                                                                                                                                                                   |
| [this][.OlapClient1.Autoformat = [Autoformat].Office2010Blue;][] |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                               |
|                                                                                                                                                                                                                |
| [Me][.OlapClient1.Autoformat = [Autoformat].Office2010Blue][] |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
