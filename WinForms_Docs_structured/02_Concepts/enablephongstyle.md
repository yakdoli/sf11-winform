#### EnablePhongStyle {#enablephongstyle style="tab-stops: 0pt"}

[] 

Specifies whether the PhongStyle is enabled.

[] 


+-------------------------------------+-------------------------------------+
|                                                                           |
|                                                                           |
| Details                                                                   |
+-------------------------------------+-------------------------------------+
| Possible Values                     | True or False                       |
+-------------------------------------+-------------------------------------+
| Default Value                       | True                                |
+-------------------------------------+-------------------------------------+
| 2D / 3D Limitations                 | No                                  |
+-------------------------------------+-------------------------------------+
| Applies to Chart Element            | All Series                          |
+-------------------------------------+-------------------------------------+
| Applies to Chart Types              | Bubble Chart                        |
+-------------------------------------+-------------------------------------+


**[]** 

Here is some sample code.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                     |
|                                                                                                                                                                                                    |
| **[]**                                                                                                                                           |
|                                                                                                                                                                                                    |
| [this][.ChartWebControl1.Series\[0\].ConfigItems.BubbleItem.EnablePhongStyle = [false];] |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB.NET\]]**                                                                                                                            |
|                                                                                                                                                                                               |
| **[]**                                                                                                                                      |
|                                                                                                                                                                                               |
| [Me][.ChartWebControl1.Series(0).ConfigItems.BubbleItem.EnablePhongStyle = [False]] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
