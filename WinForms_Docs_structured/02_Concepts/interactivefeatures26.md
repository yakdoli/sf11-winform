### Interactive Features {#interactive-features style="tab-stops: 0pt"}

[] 

The following are the key interactive features of the Range Slider:

[] 

[·      ]**Range**: Specifies the Range of the control, generally indicated by a Start and End value.

[·      ]**HandleButtonsVisibility**: Specifies whether handle buttons are to be expanded or collapsed.

[·      ]**TickFrequency**: Specifies the frequency at which Ticks are to be placed.

[·      ]**TickPlacement**: Specifies the placement of Ticks-Top, Down, Left, Right, all or None.

[·      ]**UniformChange**: Determines the distance thumb needs to cover, when Handle Buttons are clicked.

[·      ]**LargeChange**: Determines the distance a thumb needs to cover, when the Slider bar is pressed.

[·      ]**SetCustomLabel**: Specifies an option to set custom label.

[·      ]**RangeVisibility**: Specifies an option to make Range visible or hidden. When set to false the slider will be set with only one thumb.

[·      ]**Value**: When RangeVisibility is set to false, Value is used to determine the position of thumb.

[·      ]**Minimum**: Specifies the Minimum value of the Range Slider.

[·      ]**Maximum**: Specifies the Maximum value of the Range Slider.

[·      ]**MoveToHandle**: Places the thumb at the position of the mouse pointer.

[]
