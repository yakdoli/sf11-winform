## Feature Summary {#feature-summary style="tab-stops: 0pt"}

The important features of WPF Report Viewer are listed below:

[·      ]**Data sources** - You can use advanced Database server data sources in ReportViewer (SQL Server 2008, Oracle and SQL Azure).

[·      ]**Charts** - Show all basic types of Charts which are available in Microsoft RDL reports.

[·      ]**Tablix** - Shows the summaries and simple tables.

[·      ]**Gauge** - Shows measurement values using expression values.

[·      ]**Textbox** - Shows textbox data with expression support.

[·      ]**Report Parameter** - View the report based on report parameter value.

[·      ]**Expression** - You can use expression to handle reports.

[·      ]**Printing** - Prints the assigned document.

[·      ]**Customization** - You can customize Report Viewer appearance using following properties.
