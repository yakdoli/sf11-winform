#### Feature Summary {#feature-summary style="tab-stops: 0pt"}

Here is a brief overview of various features of the Linear Gauge.

[·      ]**Scales**---allows for complex gauges with one or more scales.

[·      ]**Frame** **types---**allows you to specify the linear built-in frame styles.

[·      ]**Pointers**---complete support for pointers to point the value.

[·      ]**State** **indicator---**complete support for state indicator to indicate the value level.

[·      ]**Range**---full-fledged range support.
