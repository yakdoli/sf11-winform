##### Web Deployment {#web-deployment style="tab-stops: 0pt"}

The following are the steps to organize Web deployment:

1.   Place the **SyncfusionTesseract.dll** and **liblept168.dll** assemblies in the local system and provide an assembly path to the OCR processor.

2.   Refer the following assemblies to your project:
