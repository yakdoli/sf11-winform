## Measure Editor Support {#measure-editor-support style="tab-stops: 0pt"}

OLAP Client allows us to edit the measures that are added in the current report. The Measure Editor will have the support for including/excluding each measure in/from the current report. When you exclude a measure from the current report it will not appear on the result set, but it will be there along with all the other measures of the current report.

Measure Editor allows us to order the measures of the current report and also allows us to remove any measure from the current report. You can perform these operations by using the buttons available in the top right corner to the Measure Editors nodes tab.

Use Case Scenarios

Measure Editor helps users to order the measures of the current report and edit the measures of the current report.
