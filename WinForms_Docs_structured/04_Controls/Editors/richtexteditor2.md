## Rich Text Editor {#rich-text-editor style="tab-stops: 0pt"}

The RichTextEditor control enables users to add formatting to text such as bold, italics, and underline. Font family, font color, and images can also be added in the control.

 

[·      ][Similar to the usage of TextBox control]

[·      ][The RTE contents can be obtained as HTML, XAML, and XML]

[·      ][The markup language contents can be stored and can be loaded later to the RTE which suits Windows Phone usage]

[·      ][Contents can be mailed as HTML (requires external SMTP reference)]

[·      ][Supports Windows Phone font size and font colors]
