## Check/Uncheck a Node in Member Editor {#checkuncheck-a-node-in-member-editor style="tab-stops: 0pt"}

When selecting (checking) the parent node, its child nodes are automatically selected. If a leaf node is selected, it does not affect others as it is the end node of a tree.

When deselecting (unchecking) the parent node, its corresponding child nodes are automatically deselected and when deselecting all the child nodes, their corresponding parent nodes are automatically deselected.
