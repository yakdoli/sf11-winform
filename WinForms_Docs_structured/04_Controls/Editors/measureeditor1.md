### Measure Editor {#measure-editor style="tab-stops: 0pt"}

 

Measure Editor is a dialog window that displays the collection measures in the current report. We can remove a measure element by using Measure Editor.

[] 

{border="0"}

Figure 41: Measure Editor

**[]**  

Removing a measure

In order to remove the measure, right click the measure element and the remove menu will appear. By clicking **Remove,** the selected measure will be removed from the measure collection.
