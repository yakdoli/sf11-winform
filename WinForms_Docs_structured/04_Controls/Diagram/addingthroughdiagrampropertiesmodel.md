#### Adding through DiagramPropertiesModel {#adding-through-diagrampropertiesmodel style="tab-stops: 0pt"}

[\
]The steps to add the node using DiagramPropertiesModel are as follows:

[[1.   ]]{.UGHyperlink}[Create an application]{.UGHyperlink}[[.]]{.UGHyperlink}[ ]{.UGHyperlink}

2.   Add the following code in the **FlatDiagram.aspx file** to create the diagram control in the **View**.

[] 

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[View]**                                                                                                                                                 |
|                                                                                                                                                                                                                 |
| [[]]{.MsoIntenseEmphasis}                                                                                                                                  |
|                                                                                                                                                                                                                 |
| [\<%][{]*[]* |
|                                                                                                                                                                                                                 |
| [  Html.Syncfusion().Diagram([\"FlatDiagram\"])]                                                                                   |
|                                                                                                                                                                                                                 |
| [          .Width([Unit].Pixel(1100))]                                                                                             |
|                                                                                                                                                                                                                 |
| [          .Height([Unit].Pixel(500))]                                                                                             |
|                                                                                                                                                                                                                 |
| [          .Render();]                                                                                                                                     |
|                                                                                                                                                                                                                 |
| [  }]                                                                                                                                                      |
|                                                                                                                                                                                                                 |
| [%\>][]                                                                           |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

3.   In the **controller**, add the **Syncfusion.Mvc.Diagram** and **Syncfusion.Mvc.Shared** namespaces.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[Controller[]{.MsoIntenseEmphasis}]**                                                             |
|                                                                                                                                                          |
| [using][ Syncfusion.Mvc.Diagram;] |
|                                                                                                                                                          |
| [using][ Syncfusion.Mvc.Shared;]  |
|                                                                                                                                                          |
| []                                                                                                  |
+----------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
