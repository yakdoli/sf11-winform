## Hide a Grid {#hide-a-grid style="tab-stops: 0pt"}

 

On setting the display mode option to **ChartOnly**, the grid hides.

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                         |
|                                                                                                                                                                          |
| [this][.OlapClient1.DisplayMode = [DisplayMode].ChartOnly;] |
|                                                                                                                                                                          |
| [this][.OlapClient1.DataBind();]                                                    |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                               |
| [Me][.OlapClient1.DisplayMode = ][DisplayMode][.ChartOnly][] |
|                                                                                                                                                                                                                                                                               |
| [Me][.OlapClient1.DataBind()]**[]**                                                                                                                  |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
