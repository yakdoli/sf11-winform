3.   Create a **GridPropertiesModel** in the **Index** method. Assign grid properties in this model and pass the model from controller to view using the **ViewData** class as shown below:

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| [public][ [ActionResult] Index()]                                                                                                           |

|                                                                                                                                                                                                                                                          |
| [            {]                                                                                                                                                                                                      |
|                                                                                                                                                                                                                                                          |
| [                DataSource = [new] [NorthwindDataContext]().Orders.Take(200),]                                                                                         |
|                                                                                                                                                                                                                                                          |
| [                AllowPaging = [true],]                                                                                                                                                         |
|                                                                                                                                                                                                                                                          |
| [                AllowSorting = [true]]                                                                                                                                                         |
|                                                                                                                                                                                                                                                          |
| [            };]                                                                                                                                                                                                     |
