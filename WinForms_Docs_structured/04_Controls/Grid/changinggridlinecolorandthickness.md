## Changing Gridline Color and Thickness {#changing-gridline-color-and-thickness style="tab-stops: 0pt"}

GridLine color can be changed by using the **GridLineStroke** property of PivotGrid, as seen in the following code.

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]** []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| [\<] [syncfusion] [:] [PivotGridControl ] [x] [:] [Name] [=\"pivotGridControl1\"] [ GridLineStroke] [=\"#2F5BB7\"\>] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| [\</] [syncfusion] [:] [PivotGridControl] [\>]                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]** []                                                                                                                                                        |
|                                                                                                                                                                                                                                                |
| [// Specifying GridLine color. ] []                                                                                                                      |
|                                                                                                                                                                                                                                                |
| [this] [.PivotGridControl1.GridLineStroke = [new][SolidColorBrush]([Colors].Black);] |
|                                                                                                                                                                                                                                                |
| []                                                                                                                                                                                             |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]** []                                                                                                                                                     |
|                                                                                                                                                                                                                                             |
| [\' Specifying GridLine color. ] []                                                                                                                   |
|                                                                                                                                                                                                                                             |
| [Me] [.PivotGridControl1.GridLineStroke = [New][SolidColorBrush]([Colors].Black)] |
|                                                                                                                                                                                                                                             |
| []                                                                                                                                                                                          |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
