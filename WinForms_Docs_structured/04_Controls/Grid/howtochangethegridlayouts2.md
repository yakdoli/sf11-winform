## How to change the Grid layouts? {#how-to-change-the-grid-layouts style="tab-stops: 0pt"}

**Grid** layout can be changed using the **Layout** property of Grid.

+---------------------------------------------------------------------------------------------+
| \[C#\]                                                                                      |
|                                                                                             |
|                                                                                             |
|                                                                                             |
| [///] [ Grid Layout will be Normal]              |
|                                                                                             |
| [this].OlapGrid1.Layout = [GridLayout].Normal; |
|                                                                                             |
|                                                                                             |
+---------------------------------------------------------------------------------------------+

[] 

+------------------------------------------------------------------------------------------+
| \[VB\]                                                                                   |
|                                                                                          |
|                                                                                          |
|                                                                                          |
| [\' Grid Layout will be Normal]                                    |
|                                                                                          |
| [Me].OlapGrid1.Layout = [GridLayout].Normal |
+------------------------------------------------------------------------------------------+
