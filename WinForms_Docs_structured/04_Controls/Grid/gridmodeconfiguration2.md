##### GridMode Configuration {#gridmode-configuration style="tab-stops: 0pt"}

 

[·      ]Essential Grid provides three modes for editing. To change the EditForm mode in editing, use the **EditMode()** method.

 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

|                                                                                                                                                                                                                                                               |
| [                         .Caption([\"Orders\"])                         ]                                                                                                                        |
|                                                                                                                                                                                                                                                               |
| [                        .Editing( edit=\>{]                                                                                                                                                                              |

|                                                                                                                                                                                                                                                               |
| [                        })                      ]                                                                                                                                                                        |
|                                                                                                                                                                                                                                                               |
| [    [%\>]][]                                                                                                                |
