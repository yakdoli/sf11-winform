### Grid Background {#grid-background style="tab-stops: 0pt"}

[]{#p65} 

Essential Chart for Silverlight allows you to change the appearance of the inner grid area using the GridBackground property as follows.

|                                                                                                                                                                                                  |
| [data.Add([new] ChartPoint(2, 8));]                                                                                                     |
|                                                                                                                                                                                                  |
| []                                                                                                                                                           |
|                                                                                                                                                                                                  |

|                                                                                                                                                                                                  |
