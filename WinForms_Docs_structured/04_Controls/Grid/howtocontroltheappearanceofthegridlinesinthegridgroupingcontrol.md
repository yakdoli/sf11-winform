## How to control the appearance of the Grid Lines in the GridGroupingControl {#how-to-control-the-appearance-of-the-grid-lines-in-the-gridgroupingcontrol style="tab-stops: 0pt"}

[] 

The appearance of the grid lines in the Grid can be controlled using the **GridLines** property. The following code example illustrates this.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                           |
|                                                                                                                                                                                                          |
| []                                                                                                                                                      |
|                                                                                                                                                                                                          |
| [this][.GridGroupingControl1.GridLines = System.Web.UI.WebControls.[GridLines].Horizontal;] |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB.NET\]]**                                                                                                                        |
|                                                                                                                                                                             |
| []                                                                                                                                      |
|                                                                                                                                                                             |
| [Me][.GridGroupingControl1.GridLines = System.Web.UI.WebControls.GridLines.Horizontal] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
