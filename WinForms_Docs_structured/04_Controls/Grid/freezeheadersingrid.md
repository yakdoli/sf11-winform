## Freeze Headers in Grid? {#freeze-headers-in-grid style="tab-stops: 0pt"}

 

To freeze Grid headers, refer to the following code.

 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                      |
| [// To Freeze Grid Headers.]                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                      |
| [this][.PivotGridControl1.FreezeHeaders = ][true][;][] |
|                                                                                                                                                                                                                                                                      |
| []                                                                                                                                                                                                                               |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                            |
|                                                                                                                                                                                                                             |
| [\' To Freeze Grid Headers.]                                                                                                                                              |
|                                                                                                                                                                                                                             |
| [Me][.PivotGridControl1.FreezeHeaders = ][True][] |
|                                                                                                                                                                                                                             |
| []                                                                                                                                                                                      |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
