### Chart Style Dialog Box {#chart-style-dialog-box style="tab-stops: 0pt"}

 

The chart style dialog box is basically called using the script in order to avoid postback and the following code snippets provide the solution to invoke the dialog box:

 

 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**[]                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                         |
| [this][.olapChart1.ShowStyleDialog = [true];][]                                                                                           |
|                                                                                                                                                                                                                                                                                         |
| [if][ ([this].olapChart1.ChartStyleDialog != [null])]                                                                                                    |
|                                                                                                                                                                                                                                                                                         |
| [this][.Button1.OnClientClick = [\"ShowWindow(\'\"] + [this].olapChart1.ChartStyleDialog.ClientID + [\"\');return false;\"];] |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**[]                                                                                                                                                                                             |
|                                                                                                                                                                                                                                                                                    |
| [Me][.olapChart1.ShowStyleDialog = [True]][]                                                                                         |
|                                                                                                                                                                                                                                                                                    |
| [If][ [Me].olapChart1.ChartStyleDialog [IsNot] [Nothing] [Then]]                                          |
|                                                                                                                                                                                                                                                                                    |
| [Me][.Button1.OnClientClick = [\"ShowWindow(\'\"] & [Me].olapChart1.ChartStyleDialog.ClientID & [\"\');return false;\"]] |
|                                                                                                                                                                                                                                                                                    |
| [End][ [If]][]                                                                                                         |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+--------------------------------------------------------------------------------------------------------------------+
| **[\[SCRIPT\] ]**[]                        |
|                                                                                                                    |
| [\<script type=\"text/javascript\"\>]                             |
|                                                                                                                    |
| [      function ShowWindow(winowId) {]                            |
|                                                                                                                    |
| [            \$find(winowId).Open();]                             |
|                                                                                                                    |
| [            return false;]                                       |
|                                                                                                                    |
| [      }]                                                         |
|                                                                                                                    |
| [\</script\>][] |
+--------------------------------------------------------------------------------------------------------------------+

[]
