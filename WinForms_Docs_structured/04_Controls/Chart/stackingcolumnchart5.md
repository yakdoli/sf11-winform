### StackingColumn Chart {#stackingcolumn-chart style="tab-stops: 0pt"}

The StackingColumn Chart is a simple form of a Column Chart. Instead of displaying the chart in a group of segments, the segments are stacked vertically.

The following code snippet shows how to select this chart type.

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **[]**                                                                                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                           |
| [\<][sfchart][:][OlapChart][ OlapChartType][=\"StackingColumn\" /\>]**[]** |
|                                                                                                                                                                                                                                                                                                                                                                                                                           |
| []                                                                                                                                                                                                                                                                                                                                                                             |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                        |
|                                                                                                                                                                                                                         |
| []                                                                                                                                                                           |
|                                                                                                                                                                                                                         |
| [this][.olapChart1.OlapChartType = [OlapChartTypes].StackingColumn;][] |
|                                                                                                                                                                                                                         |
| []                                                                                                                                                                           |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

| []                                                                                                                                                                                                                                                                                |
