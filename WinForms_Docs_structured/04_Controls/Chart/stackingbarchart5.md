### StackingBar Chart {#stackingbar-chart style="tab-stops: 0pt"}

StackingBar Chart is similar to StackingColumn Chart but, it is based on Bar Chart type.

The following code snippet shows how to select this chart type.

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **[]**                                                                                                                                                                                                                                                                                                                                                                             |
|                                                                                                                                                                                                                                                                                                                                                                                                                        |
| [\<][sfchart][:][OlapChart][ OlapChartType][=\"StackingBar\" /\>]**[]** |
|                                                                                                                                                                                                                                                                                                                                                                                                                        |
| []                                                                                                                                                                                                                                                                                                                                                                          |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                     |
|                                                                                                                                                                                                                      |
| []                                                                                                                                                                        |
|                                                                                                                                                                                                                      |
| [this][.olapChart1.OlapChartType = [OlapChartTypes].StackingBar;][] |
|                                                                                                                                                                                                                      |
| [                                                                                                           ]                                                             |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                     |
| []                                                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                                                     |
| [Me][.olapChart1.OlapChartType = ][OlapChartTypes][.StackingBar][] |
|                                                                                                                                                                                                                                                                                     |
| []                                                                                                                                                                                                                                       |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
