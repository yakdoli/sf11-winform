#### Range Area Chart {#range-area-chart style="tab-stops: 0pt"}

[]{#p41}[] 

Range Area chart is similar to the Area chart. It has a minimum value and maximum value. The Range Area chart type has the following two attached properties.

**[]** 


  ------------------- ------- -----------------------------------------------------------------------------------------------
  Attached Property   Type    Description
  HighValueInterior   Brush   This color is rendered in the chart when the maximum value is greater than the minimum value.
  LowValueInterior    Brush   This color is rendered in the chart when the minimum value is greater than the maximum value.
  ------------------- ------- -----------------------------------------------------------------------------------------------


**[]**
