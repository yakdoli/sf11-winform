### SplineArea Chart {#splinearea-chart style="tab-stops: 0pt"}

SplineArea is combination of Spline Chart and Area Chart. The following code snippet shows how to select this chart type.

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **[]**                                                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [\<][sfchart][:][OlapChart][ OlapChartType][=\"SplineArea\" /\>]**[]** |
|                                                                                                                                                                                                                                                                                                                                                                                                                       |
| []                                                                                                                                                                                                                                                                                                                                                                         |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                    |
|                                                                                                                                                                                                                     |
| []                                                                                                                                                                       |
|                                                                                                                                                                                                                     |
| [this][.olapChart1.OlapChartType = [OlapChartTypes].SplineArea;][] |
|                                                                                                                                                                                                                     |
| []                                                                                                                                                                       |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                                                                   |
|                                                                                                                                                                                                                                                                                    |
| []                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                    |
| [Me][.olapChart1.OlapChartType = ][OlapChartTypes][.SplineArea][] |
|                                                                                                                                                                                                                                                                                    |
| []                                                                                                                                                                                                                                      |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
