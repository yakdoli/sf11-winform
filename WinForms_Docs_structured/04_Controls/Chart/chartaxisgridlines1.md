### Chart Axis Gridlines {#chart-axis-gridlines style="tab-stops: 0pt"}

[]{#p83} 

The Essential chart for Windows Phone allows you to show / hide the grid lines in the chart area using ShowGridLines property.  If the ShowGridLines property is set to true, then Grid line will be visible in the chart area. Otherwise, the lines are invisible.

 

The following lines of code can be used to hide the grid lines of an axis.

[]
