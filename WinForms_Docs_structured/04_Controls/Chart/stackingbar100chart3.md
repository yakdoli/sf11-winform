### StackingBar100 Chart {#stackingbar100-chart style="tab-stops: 0pt"}

StackingBar100 Chart is a simple chart just like the StackingColumn100 Chart, but it is based on Bar type Chart.

The following code snippet shows how to select this chart type.

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **[]**                                                                                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                           |
| [\<][sfchart][:][OlapChart][ OlapChartType][=\"StackingBar100\" /\>]**[]** |
|                                                                                                                                                                                                                                                                                                                                                                                                                           |
| []                                                                                                                                                                                                                                                                                                                                                                             |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                        |
|                                                                                                                                                                                                                         |
| []                                                                                                                                                                           |
|                                                                                                                                                                                                                         |
| [this][.olapChart1.OlapChartType = [OlapChartTypes].StackingBar100;][] |
|                                                                                                                                                                                                                         |
| []                                                                                                                                                                           |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                        |
| []                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                        |
| [Me][.olapChart1.OlapChartType = ][OlapChartTypes][.StackingBar100][] |
|                                                                                                                                                                                                                                                                                        |
| []                                                                                                                                                                                                                                          |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
