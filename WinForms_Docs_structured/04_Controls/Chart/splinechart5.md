### Spline Chart {#spline-chart style="tab-stops: 0pt"}

Spline charts are very similar to Line charts. Unlike the Line chart, Spline chart connects two points using Spline curves.

The following code snippet shows how to select this chart type.

[] 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **[]**                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                   |
| [\<][sfchart][:][OlapChart][ OlapChartType][=\"Spline\" /\>]**[]** |
|                                                                                                                                                                                                                                                                                                                                                                                                                   |
| []                                                                                                                                                                                                                                                                                                                                                                     |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                |
|                                                                                                                                                                                                                 |
| []                                                                                                                                                                   |
|                                                                                                                                                                                                                 |
| [this][.olapChart1.OlapChartType = [OlapChartTypes].Spline;][] |
|                                                                                                                                                                                                                 |
| []                                                                                                                                                                   |
+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                |
| []                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                |
| [Me][.olapChart1.OlapChartType = ][OlapChartTypes][.Spline][] |
|                                                                                                                                                                                                                                                                                |
| []                                                                                                                                                                                                                                  |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
