### Pie Chart {#pie-chart style="tab-stops: 0pt"}

Pie Chart is a form of a Circular type of Chart. The entire chart is considered as a single **Series.** Each division in a Pie-Chart is known as **Segments.**

The following code snippet shows how to select this chart type.

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                             |
|                                                                                                                                                                                                                                                                                                                                                                                                                |
| **[]**                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                |
| [\<][sfchart][:][OlapChart][ OlapChartType][=\"Pie\" /\>]**[]** |
|                                                                                                                                                                                                                                                                                                                                                                                                                |
| []                                                                                                                                                                                                                                                                                                                                                                  |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                             |
|                                                                                                                                                                                                              |
| []                                                                                                                                                                |
|                                                                                                                                                                                                              |

|                                                                                                                                                                                                              |
| []                                                                                                                                                                |

[]
