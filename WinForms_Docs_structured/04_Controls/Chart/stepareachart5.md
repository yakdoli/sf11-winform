### StepArea Chart {#steparea-chart style="tab-stops: 0pt"}

The StepArea is a combination of StepLine and Area Chart. The following code snippet shows how to select this chart type.

[] 

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **[]**                                                                                                                                                                                                                                                                                                                                                                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [\<][sfchart][:][OlapChart][ OlapChartType][=\"StepArea\" /\>]**[]** |
|                                                                                                                                                                                                                                                                                                                                                                                                                     |
| []                                                                                                                                                                                                                                                                                                                                                                       |
+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                                                                  |
|                                                                                                                                                                                                                   |
| []                                                                                                                                                                     |
|                                                                                                                                                                                                                   |
| [this][.olapChart1.OlapChartType = [OlapChartTypes].StepArea;][] |
|                                                                                                                                                                                                                   |
| []                                                                                                                                                                     |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[VB\]]**                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                        |
| []                                                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                        |
| [Me][.olapChart1.OlapChartType = ][OlapChartTypes][.][StepArea][] |
|                                                                                                                                                                                                                                                                                                                        |
| []                                                                                                                                                                                                                                                                          |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
