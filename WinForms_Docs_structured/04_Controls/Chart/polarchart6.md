### Polar Chart {#polar-chart style="tab-stops: 0pt"}

A Polar Chart is a circular graph on which data is displayed in terms of values and angles. The X values define the angles at which the data points will be plotted. The Y value defines the distance of the data points from the center of the graph, with the center of the graph usually starting at 0. The Polar and Radar axes co-ordinate system can support both clockwise and anti-clockwise chart render.
