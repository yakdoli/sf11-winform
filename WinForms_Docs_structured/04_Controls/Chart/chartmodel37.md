##### ChartModel {#chartmodel style="tab-stops: 0pt"}

[] 

To create PriceDownColor and PriceUpColor in any Financial chart through ChartModel:

1.   In Controller, create an instance of **MVCChartModel**.

2.   Create an instance of **ChartSeries**, and set the SeriesType to **Kagi**.

3.   Set the ChartSeries, ChartArea, and ChartModel properties.

4.   Set PriceDownColor and PriceUpColor in the Financial Config Item.

5.   Return view to the corresponding View page after setting the ChartModel to the ViewData.
