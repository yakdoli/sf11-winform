### RotatedSpline Chart {#rotatedspline-chart style="tab-stops: 0pt"}

RotateSpline is similar to the normal Spline Chart with axes interchanged (their positions).

[]{#OLE_LINK4}[The following code snippet shows how to select this chart type.]{#OLE_LINK3}
