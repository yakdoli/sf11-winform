### Pyramid Chart {#pyramid-chart style="tab-stops: 0pt"}

Pyramid chart is similar to the funnel chart. It's often used for geographical purposes. The Pyramid Chart type displays the data, which when totaled will be 100%. This type of chart is a single series chart representing the data as portions of 100%, and this chart does not use any axes.

The following code snippet shows how to select this chart type.

[]
