#### Digital Gauge Control Template[] {#digital-gauge-control-template style="tab-stops: 0pt"}

The default Digital gauge template can be overwritten to provide custom visual style. For instance, create control template with single border as root element and bind the required properties with the template binding logic to supply values through setter method in style.
