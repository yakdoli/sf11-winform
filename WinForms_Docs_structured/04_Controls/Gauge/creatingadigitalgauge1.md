#### Creating a Digital Gauge {#creating-a-digital-gauge style="tab-stops: 0pt"}

[] 

You have now created a Silverlight application and deployed Essential Gauge. Lets see how to create a Digital Gauge in this application. This is done either by using XAML code or with C# code.

[] 

Here are the step-by-step instructions for creating a Digital gauge in XAML or C# code.

[] 

1.   Add the Digital gauge to the panel using XAML    or C# code as follows.
