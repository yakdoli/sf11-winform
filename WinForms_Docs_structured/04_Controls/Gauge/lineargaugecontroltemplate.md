#### Linear Gauge Control Template {#linear-gauge-control-template style="tab-stops: 0pt"}

The default Linear gauge template can be overwritten to provide custom visual style. For instance, create control template with single border as root element and bind the required properties with the template binding logic to supply values through setter method in style.

{border="0"}Note:Resource bg_Green is a custom Visual Brush which is declared in App.xaml.

{border="0"}Note: While adding custom templates, the \<ControlTemplate\> tag should be followed by the \<AdornerDecorator\> tag, and the \<Border\> tag of name \"PART_ContainerBorder\", for proper rendering of elements.
