#### Creating a Rolling Gauge {#creating-a-rolling-gauge style="tab-stops: 0pt"}

[] 

Let's see how to create a Rolling Gauge in this application. This is done either by using **XAML** code or with **C#** code.

Create a simple rolling gauge, by using the following code.

[] 

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[XAML\]]**                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| []                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [\<][syncfusion][:][RollingGauge][ Name][=\"rollingGauge1\"][ SegmentBackground][=\"Gray\"][ ] |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [SpaceBetWeenSegment][=\"1\"][ [Value][=\"1249\"][ SegmentCount][=\"4\"][ ]]                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [Unit][=\"KM\"][ UnitPosition][=\"End\"][ [IsAutomaticSegmentCountEnabled][=\"False\"\>]]                                                                                                                                                                                   |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [\</][syncfusion][:][RollingGauge][\>][       ]                                                                                                                                                                                        |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[] 

+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **[\[C#\]]**                                                                                                                   |
|                                                                                                                                                                                              |
| []                                                                                                                                       |
|                                                                                                                                                                                              |
| [RollingGauge][ rollingGauge = [new] [RollingGauge]();] |
|                                                                                                                                                                                              |
| [rollingGauge.SpaceBetWeenSegment = [new] [Thickness](1);]                                                  |
|                                                                                                                                                                                              |
| [rollingGauge.Value = [\"1249\"];]                                                                                               |
|                                                                                                                                                                                              |
| [rollingGauge.SegmentCount = 4;]                                                                                                                         |
|                                                                                                                                                                                              |
| [rollingGauge.Unit = [\"KM\"];]                                                                                                  |
|                                                                                                                                                                                              |
| [rollingGauge.UnitPosition = [UnitPosition].End;]                                                                                |
|                                                                                                                                                                                              |
| [this][.Content = rollingGauge;]                                                                        |
|                                                                                                                                                                                              |
| [                            ]                                                                                                      |
+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

[]
