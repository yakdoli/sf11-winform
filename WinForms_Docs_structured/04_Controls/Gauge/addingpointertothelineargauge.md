##### Adding Pointer to the Linear Gauge {#adding-pointer-to-the-linear-gauge style="tab-stops: 0pt"}

[] 

Essential Gauge Silverlight provides pointers to show the value over the scale. You can customize pointers by using the **PointerNeedleType** property. The following are the types of pointers supported by the Linear Gauge.

[] 

[·      ]Marker

[·      ]Bar

[] 


{border="0"}Note: For implementing the pointers, you must already have the Scale in which you are going to add the pointers.


[] 

The following code example illustrates how to add pointers to the Linear Gauge.
