##### Adding a Pointer to the Circular Gauge {#adding-a-pointer-to-the-circular-gauge style="tab-stops: 0pt"}

[] 

Essential Gauge Silverlight provides pointers to show the values over the scale. Pointers can also be customized extensively. Some of the major attributes using which pointers can be customized are

[] 

1.   **PointerNeedleType** - It has three types. They are:

[] 

[·      ]Needle

[·      ]Marker

[·      ]Bar

[] 

The types listed above are considered as the shapes of the Pointers. The default value for pointer needle type is "Needle" style.

[] 

2.   **Pointer placements** - Pointer can be placed in the below three positions as per the requirements.

[] 

[·      ]Inside

[·      ]Cross

[·      ]Outside

[] 


{border="0"}Note: we should have the scales added to the gauge. Only then we can add the pointer and pointer cap to the Circular Gauge.


[]
