### Adding Codes to the Web.config File

1. On the Solution Explorer, double-click the **Web.config** file (There will be two web.config files. Refer the one in the root folder).

2. Add the following assemblies in the Web.config page under the compilation tag:
- Syncfusion.Core
- Syncfusion.Mobile.Shared.Mvc
- Syncfusion.Mobile.Chart.Mvc
